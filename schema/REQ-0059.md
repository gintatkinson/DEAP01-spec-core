## 1. Normative Statement

The semantic lowering engine shall formalize occurrence communications and flow exchanges as `Interaction` classifiers in accordance with KerML. An `Interaction` classifier shall multiply specialize both `Behavior` and `Association`, combining behavioral occurrence execution semantics with relational association semantics across two or more participant occurrences ($`k \ge 2`$).

As an `Association`, an `Interaction` shall declare two or more participant end features ($``P_{1}, \dots, P_{k}``$, $`k \ge 2`$) specifying classifier types and multiplicity bounds; declaring fewer than two participants shall emit diagnostic `E0200`. As a `Behavior`, an `Interaction` shall govern an occurrence lifecycle over constituent `Step` features modeling occurrence performances.

Constituent steps shall include message transfer steps $``s_{\text{transfer}} = \langle e_{\text{send}}, e_{\text{recv}}, \delta_{\text{payload}}, p_{\text{src}}, p_{\text{tgt}}, \tau_{\text{msg}} \rangle``$ transmitting payload $``\delta_{\text{payload}}``$ from send event $``e_{\text{send}}``$ on $``p_{\text{src}}``$ to receive event $``e_{\text{recv}}``$ on $``p_{\text{tgt}}``$. The engine shall enforce a causal precedence poset $``(\mathcal{S}_{I}, \prec)``$ with temporal non-inversion: $``s_{1} \prec s_{2} \implies \tau_{\text{end}}(s_{1}) \le \tau_{\text{start}}(s_{2})``$.

The engine shall validate message transfer constraints and causal acyclicity:
1. Directional Causality: Transmission must precede reception ($``\tau(e_{\text{send}}) \lt \tau(e_{\text{recv}})``$); violations ($``\tau(e_{\text{recv}}) \le \tau(e_{\text{send}})``$) shall emit diagnostic `E0201`.
2. Payload Typing: Payload $``\delta_{\text{payload}}``$ must conform to declared type $``\tau_{\text{msg}}``$ ($``\tau(\delta_{\text{payload}}) \le_{\text{sub}} \tau_{\text{msg}}``$); mismatches shall emit diagnostic `E0202`.
3. Precedence Acyclicity: Precedence graph $``G_{I} = (\mathcal{S}_{I}, \prec_{I})``$ must be a DAG; detected causal cycles ($``s \prec_{I}^{+} s``$) shall emit diagnostic `E0203`.

Upon recording any diagnostic (`E0200`, `E0201`, `E0202`, `E0203`), synchronization token recovery shall sever cycle back-edges in an overlay graph and continue evaluation, halting with `E0199` if diagnostic buffer capacity is reached. Lowered entities shall use contiguous typed storage, 32-bit handles, and deterministic RFC 4122 UUIDv5 anchors. Test fixtures shall use synthetic placeholders (`Package_0`, `Interaction_Alpha`, `Participant_0`, `Participant_1`, `Step_1`, `Step_2`, `Step_Transfer`, `Payload_Type_A`, `param_x : Real`).

## 2. Formal Invariant

Let $``\mathcal{T}_{\text{metamodel}}``$ denote the KerML classifier poset ordered by subtyping $``\le_{\text{sub}}``$.

Dual Specialization and Taxonomy:

```math
\text{Interaction} \le_{\text{sub}} \text{Behavior} \;\wedge\; \text{Interaction} \le_{\text{sub}} \text{Association}
```

```math
\begin{aligned}
\text{Behavior} &\le_{\text{sub}} \text{Class} \le_{\text{sub}} \text{Classifier} \le_{\text{sub}} \text{Type} \\
\text{Association} &\le_{\text{sub}} \text{Relationship} \;\wedge\; \text{Association} \le_{\text{sub}} \text{Classifier}
\end{aligned}
```

Interaction Entity Formalization:

```math
I = \langle \text{id}_{I}, \mathcal{P}_{I}, \mathcal{S}_{I}, \prec_{I}, \Delta_{I} \rangle, \quad |\mathcal{P}_{I}| \ge 2
```

Step Precedence Poset and Temporal Realization:

```math
\forall s_{1}, s_{2} \in \mathcal{S}_{I}, \quad (s_{1} \prec_{I} s_{2} \implies \neg(s_{2} \prec_{I} s_{1})) \;\wedge\; (s_{1} \prec_{I} s_{2} \implies \tau_{\text{end}}(s_{1}) \le \tau_{\text{start}}(s_{2}))
```

Message Transfer Causality and Subtyping:

```math
\forall s_{\text{transfer}} \in \mathcal{S}_{I}, \quad \tau(e_{\text{send}}) \lt \tau(e_{\text{recv}}) \;\wedge\; \tau(\delta_{\text{payload}}) \le_{\text{sub}} \tau_{\text{msg}}
```

Acyclicity and Topological Ranking:

```math
\forall s \in \mathcal{S}_{I}, \quad \neg(s \prec_{I}^{+} s) \iff \exists \sigma : \mathcal{S}_{I} \to \{1, \dots, |\mathcal{S}_{I}|\}, \quad \forall (u, v) \in \prec_{I}, \; \sigma(u) \lt \sigma(v)
```

Diagnostic Code Binding:

```math
\begin{aligned}
|\mathcal{P}_{I}| \lt 2 &\implies \text{Diagnostic}(I, \text{E0200}) \\
\tau(e_{\text{send}}) \ge \tau(e_{\text{recv}}) &\implies \text{Diagnostic}(s_{\text{transfer}}, \text{E0201}) \\
\neg(\tau(\delta_{\text{payload}}) \le_{\text{sub}} \tau_{\text{msg}}) &\implies \text{Diagnostic}(s_{\text{transfer}}, \text{E0202}) \\
\exists s \in \mathcal{S}_{I} : s \prec_{I}^{+} s &\implies \text{Diagnostic}(I, \text{E0203})
\end{aligned}
```


## 3. Computational Complexity & Algorithmic Bounds

Semantic lowering and precedence verification execute strictly within Complexity Class $`\mathbf{P}`$. For interaction $`I`$ with $``V = |\mathcal{S}_{I}|``$ steps, $``E = |\prec_{I}|``$ precedence edges, and $``K = |\mathcal{P}_{I}|``$ participant ends:
1. Participant and Step Validation: Checking cardinality $`K \ge 2`$, step registrations, and message timestamp ordering $``\tau(e_{\text{send}}) \lt \tau(e_{\text{recv}})``$ executes in deterministic $`O(K + V)`$ time.
2. Subtyping Conformance: Validating payload typing $``\tau(\delta_{\text{payload}}) \le_{\text{sub}} \tau_{\text{msg}}``$ against the subtyping poset executes in $`O(1)`$ time per step via precomputed tables, resolving C3 linearization without backtracking in deterministic $`O(V + E)`$ time per NP-3.
3. Precedence Graph Acyclicity: Constructing adjacency structures and executing topological sorting via in-degree reduction or Tarjan strongly connected components processes vertices and edges in $`O(V + E)`$ time, isolating cycles in $`O(V + E)`$ time.
4. Total Asymptotic Bound: Aggregate sequential execution time is strictly linear:

```math
T_{\text{total}}(V, E, K) \in O(K + V + E) \subseteq O(V + E)
```

Auxiliary memory is bounded by $`O(V + E)`$ for adjacency and in-degree structures, with zero unbounded heap allocations, bypassing NP-hard frontiers and guaranteeing deterministic polynomial termination.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Dual Inheritance Metamodel Lowering

- **Given:** A KerML AST declaring interaction classifier `Interaction_Alpha` specializing both `Behavior` and `Association`.
- **When:** The compiler executes the semantic lowering pass.
- **Then:** The lowered AST node exhibits dual generalization edges to `Behavior` and `Association`, inheriting occurrence execution and association endpoint semantics.
- **Diagnostic:** `E0200` emitted on invalid or ambiguous generalization hierarchy.

### AC-02: Participant Cardinality Lower Bound Enforcement

- **Given:** An interaction classifier `Interaction_Alpha` declaring $`k \lt 2`$ participant end features (e.g., 1 participant `Participant_0`).
- **When:** Metamodel validation evaluates structural association endpoints.
- **Then:** The compiler rejects the definition and emits diagnostic error code `E0200`.
- **Diagnostic:** `E0200` emitted when $``|\mathcal{P}_{I}| \lt 2``$.

### AC-03: Message Transfer Directional Causality Verification

- **Given:** A message transfer step $``s_{\text{transfer}}``$ between `Participant_0` and `Participant_1` with transmission event $``e_{\text{send}}``$ and reception event $``e_{\text{recv}}``$.
- **When:** Temporal causality is evaluated where $``\tau(e_{\text{recv}}) \le \tau(e_{\text{send}})``$.
- **Then:** The lowering engine detects the temporal inversion and emits diagnostic error code `E0201`.
- **Diagnostic:** `E0201` emitted when $``\tau(e_{\text{send}}) \ge \tau(e_{\text{recv}})``$.

### AC-04: Message Payload Subtype Conformance

- **Given:** A message transfer step $``s_{\text{transfer}}``$ declared with classifier type `Payload_Type_A` and payload entity $``\delta_{\text{payload}}``$ of type `Payload_Type_B`.
- **When:** Type checking validates payload conformance against the transfer type contract.
- **Then:** If `Payload_Type_B` does not specialize `Payload_Type_A` ($``\tau(\delta_{\text{payload}}) \not\le_{\text{sub}} \tau_{\text{msg}}``$), the engine emits diagnostic error code `E0202`; otherwise, compilation succeeds.
- **Diagnostic:** `E0202` emitted on payload subtyping mismatch.
