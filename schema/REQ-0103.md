## 1. Normative Statement

The metrology engine and type checker of Subsystem 5 SHALL enforce that all arguments to transcendental and trigonometric functions evaluate strictly to the dimensionless null vector $\mathbf{0} \in \mathbb{Q}^7$ over the seven ISQ base dimensions. Evaluated results MUST likewise yield $``\mathbf{d}_{\text{result}} = \mathbf{0} \in \mathbb{Q}^7``$.

The metrology type checker MUST enforce five core invariants:
1. **Function Family**: Governs $``\mathcal{F}_{\text{trans}}``$ (trigonometric, hyperbolic, exponential, logarithmic) and binary forms ($\operatorname{atan2}$, $``\log_B``$).
2. **Dimensionless Argument**: For $f(E)$ with $``f \in \mathcal{F}_{\text{trans}}``$, argument dimension MUST satisfy $\mathbf{d}(E) \equiv \mathbf{0}$; violations emit `E0300`, setting $\mathbf{d}(f(E)) = \mathbf{0}$.
3. **Multi-Argument**: $``\operatorname{atan2}(E_y, E_x)``$ requires $``\mathbf{d}(E_y) \equiv \mathbf{d}(E_x)``$, yielding $\mathbf{d} = \mathbf{0}$; mismatches emit `E0300`. Logarithms $``\log_B(E)``$ and variable powers require $\mathbf{d} \equiv \mathbf{0}$; violations emit `E0300`.
4. **Angular Units**: Angle units (`rad`, `deg`) define dimensionless ratios ($\mathbf{d} = \mathbf{0}$); trigonometric arguments convert to radians, and inverse functions yield $\mathbf{d} = \mathbf{0}$ with unit `rad`.
5. **Taylor Homogeneity**: Per Buckingham $\pi$, analytic $``f(x) = \sum_{k=0}^{\infty} c_k x^k``$ with scalar $``c_0 \ne 0``$ requires $k \cdot \mathbf{d}(x) = \mathbf{0}$, forcing $\mathbf{d}(x) \equiv \mathbf{0}$ for $k \ge 1$.

## 2. Formal Invariant

Transcendental argument dimensionless nullity, multi-argument commensurability, and UUIDv5 invariants:

```math
\begin{aligned}
\mathbf{d} &: \mathcal{E} \to \mathbb{Q}^7 \cup \{ \bot_{\text{dim}} \}, \quad \mathbf{0} = (0, 0, 0, 0, 0, 0, 0) \in \mathbb{Q}^7 \\
\forall f \in \mathcal{F}_{\text{trans}}, \; n = \langle f, E \rangle \in \mathcal{E} &\implies (\mathbf{d}(E) = \mathbf{0} \land \mathbf{d}(n) = \mathbf{0}) \\
n = \langle \text{atan2}, E_y, E_x \rangle \in \mathcal{E} &\implies (\mathbf{d}(E_y) = \mathbf{d}(E_x) \land \mathbf{d}(n) = \mathbf{0}) \\
\forall k \ge 1, \; \mathbf{d}(c_k x^k) = \mathbf{0} &\iff k \cdot \mathbf{d}(x) = \mathbf{0} \iff \mathbf{d}(x) = \mathbf{0} \\
\mathbf{d}(E) \ne \mathbf{0} \lor \mathbf{d}(E_y) \ne \mathbf{d}(E_x) &\implies \text{Diagnostic}(n, \text{E0300}) \in \mathcal{D}_{\text{sink}} \\
\forall n \in \mathcal{V}_{\text{AST}}, \quad \Delta_n &= \text{UUIDv5}(\text{NS}_{\text{DEAP}}, \text{FQN}(n))

Work-stealing across $``N_{\text{max\_workers}}``$ threads scales as $``O(V / N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Dimensionless Transcendental Evaluation
- **Given:** Expressions invoking $\sin, \cos, \exp, \ln$ with dimensionless arguments ($\mathbf{d} = \mathbf{0}$).
- **When:** Metrology type-checking executes.
- **Then:** Invocations pass verification with $\mathbf{d} = \mathbf{0}$ and empty diagnostic sink.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: Commensurable Multi-Argument Resolution
- **Given:** Invocation $``\operatorname{atan2}(E_y, E_x)``$ with length arguments ($``\mathbf{d}(E_y) = \mathbf{d}(E_x) = [L]``$) and $``\sin(\text{param\_theta})``$ with unit `rad`.
- **When:** Commensurability checking and angle conversion execute.
- **Then:** Commensurability holds, angle converts to radians, result yields $\mathbf{d} = \mathbf{0}$, and sink remains empty.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-03: Non-Dimensionless Argument Rejection
- **Given:** Expression `sin(Quantity_Alpha)` where $``\mathbf{d}(\text{Quantity\_Alpha}) = [L]``$.
- **When:** Metrology dimensional type checker evaluates argument dimension.
- **Then:** Compiler detects $\mathbf{d} \ne \mathbf{0}$, halts lowering, binds sentinel $``\bot_{\text{dim}}``$, and emits `E0300`.
- **Diagnostic:** `E0300`.

### AC-04: Incommensurable Operands & Delimiter Recovery
- **Given:** Malformed $``\operatorname{atan2}(E_y, E_x)``$ ($``\mathbf{d}(E_y) = [L], \mathbf{d}(E_x) = [T]``$) preceding valid `param_x : Real = cos(0.0);`.
- **When:** Semantic validation and delimiter recovery execute.
- **Then:** Compiler emits `E0300`, recovers on delimiter (`;`), verifies valid `cos` expression, and emits `E0199` at $``C_{\text{max\_errors}}``$.
- **Diagnostic:** `E0300`, `E0199`.
