## 1. Normative Statement

The CommonMark table parser within the Universal Schema Ingestion Engine shall implement Synchronization Token Error Recovery on table delimiter boundaries per Architectural Directive 4. When encountering unexpected formatting, unescaped pipe characters, malformed scalar literals, or delimiter mismatches within cell $``C_{i, j}``$ of row $``R_i``$, the parser must record a localized diagnostic and resynchronize at the nearest synchronization token boundary without aborting compilation or discarding unaffected cells and rows.

The table synchronization token set comprises column delimiter pipes (`|`, $``\text{SYM}_{\text{PIPE}}``$), record line breaks ($``\text{SYM}_{\text{LF}}``$), and end-of-file ($``t_{\text{EOF}}``$). Upon detecting a cell fault, the parser shall construct a structured diagnostic binding error code `E0102` per REQ-0191 with 1-indexed line and column coordinates, byte span $``[p_{\text{start}}, p_{\text{end}})``$, the offending token slice, and expected grammar production. The parser shall advance the stream pointer monotonically forward to the nearest synchronization token, discard invalid tokens, substitute a typed error sentinel $``\bot_{\text{cell}}``$ into row $``R_i``$, preserve valid preceding cells $``C_{i, 1}, \dots, C_{i, j-1}``$, and resume parsing at cell $``C_{i, j+1}``$ (on pipe) or row $``R_{i+1}``$ (on line break).

The parser shall enforce a total, deterministic, non-panicking execution contract across all inputs. Monotonic forward stream progress ($``\text{ByteOffset}_{t+1} \gt \text{ByteOffset}_t``$) must hold on every recovery transition to eliminate livelocks. The parser shall apply cascading error suppression, suppressing secondary diagnostics detected within proximity window $`\delta \le 3`$ tokens following a synchronization event. Diagnostic accumulation shall enforce a configurable bounded capacity ceiling $``C_{\text{max\_errors}}``$ per compilation unit; upon saturation, the parser shall terminate table ingestion and emit diagnostic code `E0199`.

## 2. Formal Invariant

Let $``B = \langle b_0, b_1, \dots, b_{N-1} \rangle``$ denote input bytes of length $`N = |B|`$, with sentinel $``b_N = t_{\text{EOF}}``$. Tabular schema AST $``T = \langle R_1, \dots, R_M \rangle``$ contains rows $``R_i = \langle C_{i, 1}, \dots, C_{i, K_i} \rangle``$. The synchronization token set is:

```math
\mathcal{T}_{\text{sync}} = \{ \text{SYM}_{\text{PIPE}}, \text{SYM}_{\text{LF}}, t_{\text{EOF}} \}
```

For a syntax fault at byte offset $`p \in \{0, \dots, N-1\}`$ in cell $``C_{i, j}``$, scanning identifies delimiter index $`m`$:

```math
m = \text{ScanUntil}(\mathcal{T}_{\text{sync}}, p) = \min \{ k \in \{p, \dots, N\} \mid b_k \in \mathcal{T}_{\text{sync}} \}
```

Parser resynchronization transition satisfies:

```math
\text{State}_{t+1} = 
\begin{cases}
\text{ParseCell}(R_i, j+1), & \text{if } b_m = \text{SYM}_{\text{PIPE}} \\
\text{ParseRow}(R_{i+1}, 1), & \text{if } b_m = \text{SYM}_{\text{LF}} \\
\text{Halt}, & \text{if } b_m = t_{\text{EOF}}
\end{cases}
```

Monotonic stream progress mandates:

```math
\text{ByteOffset}_{t+1} = 
\begin{cases}
m + 1, & \text{if } b_m \in \{ \text{SYM}_{\text{PIPE}}, \text{SYM}_{\text{LF}} \} \\
N, & \text{if } b_m = t_{\text{EOF}}
\end{cases}
\quad \implies \quad \text{ByteOffset}_{t+1} \gt \text{ByteOffset}_t
```

Strict monotonicity guarantees bounded termination over input stream $`B`$:

```math
\forall \sigma \in \text{ParseExecutions}(B), \quad \text{Steps}(\sigma) \le N + 1
```

Row synthesis with sentinel substitution:

```math
R_i = \langle C_{i, 1}, \dots, C_{i, j-1}, \bot_{\text{cell}}, C_{i, j+1}, \dots, C_{i, K_i} \rangle
```

Row extraction independence:

```math
\forall i, k \in \{1, \dots, M\}, \quad (i \neq k \;\wedge\; \neg \text{Fault}(R_k)) \implies \text{Extracted}(R_k)
```

Cascading error suppression:

```math
\text{EmitDecision}(q, \tau_{\text{last}}) = 
\begin{cases}
\text{Suppress}, & \text{if } q - \tau_{\text{last}} \le \delta \\
\text{Record}, & \text{if } q - \tau_{\text{last}} \gt \delta
\end{cases}
\quad (\delta \le 3)
```

Diagnostic sink bounds:

```math
|\mathcal{D}| \le C_{\text{max\_errors}}, \quad \forall D \in \mathcal{D}, \; \text{Code}(D) \in \{ \text{E0102}, \text{E0199} \}
```

## 3. Computational Complexity & Algorithmic Bounds

The table delimiter recovery engine operates within Complexity Class $`\mathbf{P}`$. Forward scanning is strictly monotonic ($``\text{ByteOffset}_{t+1} \gt \text{ByteOffset}_t``$), inspecting each byte $``b_k \in B``$ at most $`O(1)`$ times without backtracking for deterministic $`O(N)`$ worst-case time across stream length $`N = |B|`$. Row allocations and sentinel substitutions execute in $``O(K_{\text{max}})``$ time per row ($``K_{\text{max}} \le 64``$), bounded overall by $``O(M \cdot K_{\text{max}}) = O(N)``$ for $`M`$ rows. Cascading suppression checks execute in $`O(1)`$ scalar time. Auxiliary heap space is bounded by $``O(K_{\text{max}} + C_{\text{max\_errors}}) = O(1)``$ relative to $`N`$. Delimiter scanning operates strictly in $`\mathbf{P}`$, avoiding all NP frontiers (NP-1--NP-8).

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Multi-Error Resynchronization Across Row Boundaries
- **Given:** 5-row CommonMark table with entities (`Package_0`, `Classifier_Alpha`, `Port_1`, `Flow_A`, `param_x : Real`) and syntax faults in rows 2 and 4.
- **When:** The parser ingests the table in a single compilation pass.
- **Then:** Rows 1, 3, and 5 lower into valid AST nodes, rows 2 and 4 retain valid cells with $``\bot_{\text{cell}}``$ at faulted positions, and exactly 2 diagnostics are emitted.
- **Diagnostic:** Emits localized `E0102` diagnostics with 1-indexed coordinates and byte spans.

### AC-02: Strictly Monotonic Stream Progress & Loop Prevention
- **Given:** Corrupt table input containing consecutive invalid delimiter sequences and unmatched pipes.
- **When:** The parser triggers error recovery upon syntax faults.
- **Then:** Stream position satisfies $``\text{ByteOffset}_{t+1} \gt \text{ByteOffset}_t``$, terminating in at most $`N + 1`$ steps without livelocks.
- **Diagnostic:** `E0102` emitted on recovery transitions; fail-closed termination if the pointer fails to advance.

### AC-03: Cascading Error Suppression Proximity Window
- **Given:** Primary delimiter fault at byte $``\tau_{\text{last}}``$ followed by secondary faults at distance $``q - \tau_{\text{last}} \le \delta``$ ($`\delta = 3`$).
- **When:** The parser evaluates tokens following a synchronization recovery event.
- **Then:** Secondary faults within window $`\delta`$ are suppressed from diagnostic sink $`\mathcal{D}`$.
- **Diagnostic:** Primary fault records `E0102`; secondary faults within $`\delta \le 3`$ emit zero duplicate diagnostics.

### AC-04: Bounded Diagnostic Sink Capacity & Graceful Termination
- **Given:** Degenerate table schema containing $``M \ge C_{\text{max\_errors}}``$ syntax faults.
- **When:** Diagnostic accumulation reaches capacity limit $``C_{\text{max\_errors}}``$.
- **Then:** The parser halts parsing, appends a final sentinel, and concludes ingestion gracefully.
- **Diagnostic:** Diagnostic `E0199` emitted indicating error ceiling reached.

### AC-05: Total Determinism & Panic-Free Non-Zero Exit
- **Given:** Invalid CommonMark tables compiled in Release mode across varying platforms and worker thread allocations.
- **When:** The compiler executes delimiter synchronization recovery.
- **Then:** Execution completes under a total-function contract with zero unhandled panics and bitwise identical diagnostic output.
- **Diagnostic:** `E0102` through `E0199` emitted in structured format with zero panic unwinding.
