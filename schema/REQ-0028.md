## 1. Normative Statement

The compiler ingestion engine shall parse OMG IDL (`.idl`) specifications into intermediate schema representation (IR) without external preprocessors. The engine shall lower IDL `module` namespaces to nested `IngestedPackage` scopes, `struct` definitions to `IngestedClassifierDef` data types with sequential `IngestedAttr` members, discriminated `union` declarations to variant `IngestedClassifierDef` types with explicit discriminant expressions, `enum` declarations to enumerated `IngestedClassifierDef` types, `typedef` declarations to `IngestedTypeDef` aliases, and `interface` declarations to `IngestedPart` definitions annotated with `is_interface: true`.

Every operation parameter must specify an explicit direction (`in`, `out`, or `inout`); omitted or invalid directions shall emit diagnostic `E0102`. The parser shall partition parameters into action inputs (`in`, `inout`) and outputs (`out`, `inout`). Non-void returns shall synthesize output parameter `result`; void returns synthesize no parameter. Bounded sequences `sequence<T, K>`, unbounded sequences `sequence<T>`, and fixed arrays `T[K]` shall lower to multiplicity intervals $`\langle 0, K \rangle`$, $`\langle 0, \infty \rangle`$, and $`\langle K, K \rangle`$ respectively.

## 2. Formal Invariant

Let $``\mathcal{I}_{\text{idl}} = \langle \mathcal{M}_{\text{pkg}}, \mathcal{C}_{\text{type}}, \mathcal{I}_{\text{face}} \rangle``$ denote an IDL compilation unit. The lowering mapping $``\mathcal{T}_{\text{idl}}``$ satisfies:

```math
\begin{aligned}
\text{module } M \{ \mathcal{D}^* \} &\longmapsto \text{IngestedPackage}(M, \text{members}: \mathcal{T}_{\text{idl}}(\mathcal{D}^*)) \\
\text{interface } I \{ \mathcal{F}^* \} &\longmapsto \text{IngestedPart}(I, \text{is\_interface}: \text{true}, \text{members}: \mathcal{T}_{\text{idl}}(\mathcal{F}^*)) \\
\text{struct } S \{ \mathcal{M}^* \} &\longmapsto \text{IngestedClassifierDef}(S, \text{kind}: \text{Struct}, \text{fields}: \mathcal{T}_{\text{idl}}(\mathcal{M}^*)) \\
\text{union } U \text{ switch}(D) \{ \mathcal{B}^* \} &\longmapsto \text{IngestedClassifierDef}(U, \text{kind}: \text{Union}, \text{disc}: D, \text{cases}: \mathcal{T}_{\text{idl}}(\mathcal{B}^*)) \\
\text{enum } E \{ e_0, \dots, e_{k-1} \} &\longmapsto \text{IngestedClassifierDef}(E, \text{kind}: \text{Enum}, \text{variants}: \langle e_0, \dots, e_{k-1} \rangle) \\
\text{typedef } T \; A &\longmapsto \text{IngestedTypeDef}(A, \text{target}: T)
\end{aligned}
```

For an operation $``\text{op} = \langle \text{id}, T_{\text{ret}}, \text{Params}(\text{op}) \rangle``$, lowering satisfies $``\mathcal{T}_{\text{idl}}(\text{op}) = \text{IngestedAction}(\text{id}, \text{in}: \mathcal{P}_{\text{in}}(\text{op}), \text{out}: \mathcal{P}_{\text{out}}(\text{op}))``$ with parameter partitions and direction completeness:

```math
\begin{aligned}
\mathcal{P}_{\text{in}}(\text{op}) &= \{ \langle \text{name}(p), \text{type}(p) \rangle \mid p \in \text{Params}(\text{op}) \wedge \text{dir}(p) \in \{ \text{In}, \text{InOut} \} \} \\
\mathcal{P}_{\text{out}}(\text{op}) &= \{ \langle \text{name}(p), \text{type}(p) \rangle \mid p \in \text{Params}(\text{op}) \wedge \text{dir}(p) \in \{ \text{Out}, \text{InOut} \} \} \cup \text{ReturnParam}(T_{\text{ret}}) \\
\text{ReturnParam}(T_{\text{ret}}) &= \begin{cases} \{ \langle \text{result}, T_{\text{ret}} \rangle \}, & T_{\text{ret}} \ne \text{void} \\ \emptyset, & T_{\text{ret}} = \text{void} \end{cases} \\
\forall p &\in \text{Params}(\text{op}), \quad \text{dir}(p) \in \{ \text{In}, \text{Out}, \text{InOut} \}
\end{aligned}
```

Multiplicity mapping $`\mu(T)`$ and module DAG acyclicity satisfy:

```math
\begin{aligned}
\mu(T) &= \begin{cases} \langle 0, K \rangle, & T = \text{sequence}\langle T', K \rangle \\ \langle 0, \infty \rangle, & T = \text{sequence}\langle T' \rangle \\ \langle K, K \rangle, & T = T'[K] \\ \langle 1, 1 \rangle, & \text{otherwise} \end{cases} \\
\forall M &\in \mathcal{M}_{\text{pkg}}, \quad (M, M) \notin \mathcal{E}_{\text{mod}}^+
\end{aligned}
```

Diagnostic bindings per REQ-0191 satisfy:

```math
\begin{aligned}
\text{dir}(p) \notin \{ \text{In}, \text{Out}, \text{InOut} \} \vee \text{SyntaxFault}(\text{span}) &\implies \text{DiagnosticCode::E0102} \in \mathcal{D} \\
\text{UnsupportedType}(T) \vee \text{DiscriminantMismatch}(U) &\implies \text{DiagnosticCode::E0103} \in \mathcal{D}
\end{aligned}
```

## 3. Computational Complexity & Algorithmic Bounds

The OMG IDL AST ingestion engine executes in Complexity Class $`\mathbf{P}`$. Deterministic recursive descent parsing operates in $`O(N)`$ linear time over $`N`$ input bytes using LL(1) lookahead (bounded LL(2) for scoped symbols `A::B`). String interning runs in $`O(1)`$ amortized time. AST memory node allocation executes in $`O(1)`$ constant time. Parameter partitioning for $`M`$ parameters per operation executes in $`O(M)`$ time, bounding aggregate partitioning across the compilation unit by $`O(N)`$. Module hierarchy validation runs in $`O(D)`$ time with nesting depth $`D \le 64`$, bounding auxiliary stack space by $`O(1)`$. Parallel compilation across $`K`$ schemas on a bounded work-stealing pool ($``N_{\text{max\_workers}}``$) runs in $``O(\lceil K / N_{\text{max\_workers}} \rceil \cdot N_{\text{max}})``$ time. Deterministic linear parsing operates strictly in polynomial time, bypassing combinatorial NP-complete frontiers (NP-1--NP-8).

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Canonical Struct, Union, and Typedef Lowering
- **Given:** Valid IDL declaring `struct Struct_Alpha { long field_1; boolean flag_2; };`, `union Union_Beta switch (short) { case 1: long v1; default: boolean v2; };`, and `typedef double Real_Alias;`.
- **When:** The parser ingests and lowers declarations into intermediate schema IR.
- **Then:** Emits `IngestedClassifierDef` (kind: Struct, Union) with typed members and discriminant cases, emits `IngestedTypeDef`, and allocates nodes in contiguous AST storage with stable offsets.
- **Diagnostic:** `E0102` on syntax fault; `E0103` on discriminant type mismatch.

### AC-02: Interface Operation and Directional Parameter Partitioning
- **Given:** Interface `Interface_Gamma` declaring `long op_step(in Real p_in, out Real p_out, inout Real p_state);`.
- **When:** Lowering the operation declaration into intermediate schema IR.
- **Then:** Emits `IngestedAction` where `p_in` is partitioned into `inputs`, `p_out` into `outputs`, `p_state` into both `inputs` and `outputs`, and non-void return `long` synthesizes output parameter `result : long`.
- **Diagnostic:** `E0102` on parameter signature failure.

### AC-03: Missing or Invalid Parameter Direction Diagnostic Binding
- **Given:** IDL operation omitting an explicit direction token (`void op_bad(Real p_missing);`) or specifying an illegal keyword (`void op_bad2(input Real p_bad);`).
- **When:** Validating parameter direction tokens during parsing.
- **Then:** Emits diagnostic `E0102` with precise byte span, substitutes sentinel $``\bot_{\text{action}}``$, and continues parsing subsequent declarations.
- **Diagnostic:** `E0102` emitted on missing or invalid parameter direction.

### AC-04: Sequence and Fixed Array Multiplicity Lowering
- **Given:** IDL declarations containing bounded sequence `sequence<Real, 16>`, unbounded sequence `sequence<Real>`, and fixed array `Real arr[8]`.
- **When:** Lowering type expressions into schema IR attributes.
- **Then:** Assigns exact multiplicity intervals $`\langle 0, 16 \rangle`$, $`\langle 0, \infty \rangle`$, and $`\langle 8, 8 \rangle`$ respectively.
- **Diagnostic:** `E0103` on malformed sequence bound.
