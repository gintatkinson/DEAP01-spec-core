## 1. Normative Statement

Subsystem 10 SHALL emit freestanding, zero-allocation C++20 header (`.hpp`) and source (`.cpp`) translation units (`TranslationUnit_0`) from classifiers (`Classifier_Alpha`) via `CppEmitter_Alpha`.

---

## 2. Formal Invariant

Let $``\mathcal{T}_{\text{units}}``$ denote emitted units, $``\mathcal{H}_{\text{hosted}}``$ hosted headers, and $``\mathcal{S}_{\text{heap}}, \mathcal{S}_{\text{ex}}, \mathcal{S}_{\text{rtti}}``$ prohibited symbols. Invariants satisfy:

```math
\begin{aligned}
\forall T \in \mathcal{T}_{\text{units}},\quad T&=\langle\text{id}_T,\text{name}_T,\mathbf{D}_T,\mathbf{I}_T,\Delta_T\rangle \\
\mathbf{I}_T \cap \mathcal{H}_{\text{hosted}}=\emptyset,&\quad\text{Symbols}(T)\cap(\mathcal{S}_{\text{heap}}\cup\mathcal{S}_{\text{ex}}\cup\mathcal{S}_{\text{rtti}})=\emptyset \\
\forall f\in\text{Functions}(T),\quad\text{Noexcept}(f)&\equiv\mathbf{true} \\
\forall q\in\text{Features}(T),\ \text{MultiplicityUpper}(q)=N_q\lt\infty&\implies\text{Storage}(q)\in\{\text{array}\langle\tau_q,N_q\rangle,\text{span}\langle\tau_q,N_q\rangle\} \\
\exists s\in\text{Symbols}(T)\cap(\mathcal{S}_{\text{heap}}\cup\mathcal{S}_{\text{ex}}\cup\mathcal{S}_{\text{rtti}})&\implies\text{Diagnostic}(s,\text{E0510})\in\mathcal{D}_{\text{sink}}\land T\gets\bot_{\text{unit}} \\
(\exists i\in\mathbf{I}_T\cap\mathcal{H}_{\text{hosted}}\lor\exists q:\text{MultiplicityUpper}(q)=\infty)&\implies\text{Diagnostic}(\text{E0510})\in\mathcal{D}_{\text{sink}}\land T\gets\bot_{\text{unit}} \\
\neg\text{DimensionallyValid}(T)&\implies\text{Diagnostic}(\text{E0300})\in\mathcal{D}_{\text{sink}} \\
|\mathcal{D}_{\text{sink}}|\ge C_{\text{max\_errors}}&\implies\text{Diagnostic}(\text{E0199})\in\mathcal{D}_{\text{sink}} \\
\Delta_T=\text{UUIDv5}(\text{OID}_{\text{DEAP}},\text{FQN}(T)),&\quad\Delta_d=\text{UUIDv5}(\text{OID}_{\text{DEAP}},\text{FQN}(T)\mathbin{\Vert}\text{"::"}\mathbin{\Vert}\text{name}(d))
\end{aligned}
```

| Symbol / Term | Domain / Formal Definition |
| :--- | :--- |
| $``\mathcal{T}_{\text{units}}, T``$ | Emitted C++20 translation units and unit tuple |
| $``\mathbf{I}_T, \mathcal{H}_{\text{hosted}}``$ | Header inclusion and prohibited hosted sets |
| $``\mathcal{S}_{\text{heap}}, \mathcal{S}_{\text{ex}}, \mathcal{S}_{\text{rtti}}``$ | Prohibited heap, exception, RTTI symbols |
| $\text{Functions}(T), \text{Noexcept}(f)$ | Emitted functions and noexcept predicate |

| $``\Delta_T, \Delta_d, \text{OID}_{\text{DEAP}}``$ | UUIDv5 anchors and namespace OID constant |

## 3. Computational Complexity & Algorithmic Bounds

- **Complexity Class:** Class $\mathbf{P}$.
- **Asymptotic Bound:** Emission runs in $``O(|V_{\text{AST}}|)``$ time for nodes $``V_{\text{AST}}``$. Traversal is $``O(|V_{\text{AST}}| + |E_{\text{AST}}|)``$, formatting is $O(|A|)$, and chunk streaming is $O(1)$. Work-stealing scales as $``O((|V_{\text{AST}}| + |A|) / N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$. Memory is $``O(|V_{\text{AST}}| + |E_{\text{AST}}|)``$.
- **Tractable Subclass and Frontier:** N/A (Deterministic P). Lowers syntax directly, avoiding NP-1 and NP-8.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Freestanding Translation Unit Synthesis
- **Given:** `Classifier_Alpha` declaring `param_x : Real`.
- **When:** Lowering `TranslationUnit_0` via `CppEmitter_Alpha`.
- **Then:** Emits `.hpp` and `.cpp` with freestanding headers, `noexcept`, and UUIDv5 anchors.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: Dynamic Allocation and Exception Rejection
- **Given:** Construct attempting dynamic allocation (`operator new`) or exceptions (`throw`).
- **When:** Validating zero-allocation and freestanding invariants.
- **Then:** Fails closed, binds sentinel $``\bot_{\text{unit}}``$, emitting `E0510`.
- **Diagnostic:** `E0510`.

### AC-03: Fixed Bounds and Dimensional Evaluation
- **Given:** `Classifier_Alpha` with sequence $N = 16$ and mismatched dimensions.
- **When:** Lowering storage and evaluating `constexpr` dimensional expressions.
- **Then:** Detects dimensional violation, binds sentinel $``\bot_{\text{unit}}``$, emitting `E0300`.
- **Diagnostic:** `E0300`.

### AC-04: Delimiter Recovery and Saturation Halting
- **Given:** Syntax error followed by delimiter `;` and `Classifier_Beta`.
- **When:** Detecting fault, recording `E0510` in $``\mathcal{D}_{\text{sink}}``$, recovering across `;`.
- **Then:** Emits `Classifier_Beta`, halting at $``C_{\text{max\_errors}}``$ with `E0199`.
- **Diagnostic:** `E0510`, `E0199`.
