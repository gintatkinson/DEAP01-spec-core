## 1. Normative Statement

The compiler metamodel, node arena storage, and abstract syntax tree (AST) graph engine shall address, reference, and interconnect all AST nodes throughout the compilation pipeline exclusively via deterministic typed integer handles (`NodeHandle<T>`). Raw virtual memory pointers (`*const T`, `*mut T`), dynamic heap references, and unaligned offsets are strictly prohibited across all AST graph edges, symbol tables, and compiler passes.

Every node handle shall be encoded as a compact 64-bit unsigned integer scalar combining three disjoint bitfields:
1. A 32-bit arena slot index ($`\text{Index} \in [0, 2^{32}-1]`$).
2. A 16-bit slot generation counter ($`\text{Generation} \in [0, 2^{16}-1]`$).
3. A 16-bit node type discriminator tag ($`\text{TypeTag} \in [0, 2^{16}-1]`$).

The handle addressing architecture shall enforce the following normative guarantees:
- **Generational Safety**: Every arena slot shall maintain an incarnation generation counter incrementing modulo $`2^{16}`$ upon slot reallocation or mutation. Dereferencing a handle within arena $`\mathcal{A}`$ shall perform constant-time tripartite validation: checking slot index bounds, generation equality, and type tag equality.
- **Dangling Reference Elimination**: Dereferencing a stale handle (generation mismatch), out-of-bounds index, or type-mismatched handle shall evaluate to $`\bot`$ and emit diagnostic error code `E0200` per REQ-0191 without panics or memory faults, upholding Architectural Directive 5 and REQ-0011.
- **Deterministic Serialization & Concurrency**: Handles shall be deterministic functions of topological ingestion order (REQ-0003, REQ-0010) and serialize directly to CBOR/JSON without pointer rebasing (REQ-0044, REQ-0050). Handles have scalar copy semantics, permitting lock-free distribution across the bounded work-stealing thread pool (Directive 2, REQ-0012).
- **Reserved Sentinel**: Handle value `0xFFFF_FFFF_0000_0000` is reserved as the typed null handle (`NodeHandle::NULL`) denoting terminal nodes.
- **Interner Exception**: String literals and identifiers shall be addressed via interned scalar `SymbolId` tokens within the deduplicated symbol interner pool, which constitutes the sole permitted exception to zero-copy memory management (Directive 3, REQ-0036).
- **Abstract MBSE Modeling**: All diagnostics, tests, and models shall strictly use abstract MBSE placeholders (`Package_0`, `Classifier_Alpha`, `Port_1`, `Flow_A`, `param_x : Real`).

## 2. Formal Invariant

Let $``\mathbb{U}_k = \{ x \in \mathbb{N}_0 \mid 0 \le x \lt 2^k \}``$. A typed node handle $``H \in \mathbb{U}_{64}``$ is defined as:

```math
H = \langle \text{Index}, \text{Generation}, \text{TypeTag} \rangle \in \mathbb{U}_{32} \times \mathbb{U}_{16} \times \mathbb{U}_{16}
```

Bit-packing projection $``\pi_{\text{pack}}``$ and decoding projections satisfy:

```math
\begin{aligned}
\pi_{\text{pack}}(\text{Index}, \text{Generation}, \text{TypeTag}) &= (\text{Index} \ll 32) \lor (\text{Generation} \ll 16) \lor \text{TypeTag} \\
\text{Index}(H) &= (H \gg 32) \land (2^{32} - 1) \\
\text{Generation}(H) &= (H \gg 16) \land (2^{16} - 1) \\
\text{TypeTag}(H) &= H \land (2^{16} - 1)
\end{aligned}
```

Handle Compactness: $``\text{sizeof}(H) \le S_{\text{handle}} = 8\text{ bytes}``$.

Let arena $`\mathcal{A}`$ have capacity $``C_{\text{arena}} \in \mathbb{N}``$, with slots $`\mathcal{A}.\text{slots}[i] = \langle \text{node}, \text{gen}, \text{tag}, \text{allocated} \rangle`$. The validity predicate and dereference function evaluate:

```math
\begin{aligned}
\text{Valid}(H, \mathcal{A}) \iff &\; \text{Index}(H) \lt C_{\text{arena}} \wedge \mathcal{A}.\text{slots}[\text{Index}(H)].\text{allocated} \wedge \\
&\; \mathcal{A}.\text{slots}[\text{Index}(H)].\text{gen} = \text{Generation}(H) \wedge \mathcal{A}.\text{slots}[\text{Index}(H)].\text{tag} = \text{TypeTag}(H)
\end{aligned}
```

```math
\text{Deref}(H, \mathcal{A}) = \begin{cases}
\text{ref}(\mathcal{A}.\text{slots}[\text{Index}(H)].\text{node}), & \text{if } \text{Valid}(H, \mathcal{A}) = \text{true} \\
\bot, & \text{otherwise}
\end{cases}
```

Slot Reallocation Invalidation: When slot $`i`$ is reallocated at step $`t+1`$:

```math
\mathcal{A}.\text{slots}[i].\text{gen}_{t+1} = (\mathcal{A}.\text{slots}[i].\text{gen}_t + 1) \pmod{2^{16}} \implies \text{Deref}(H_t, \mathcal{A}_{t+1}) = \bot
```

Zero Dangling Pointers & Null Sentinel:

```math
\text{DanglingPointers}(\text{NodeArena}) = 0 \quad \wedge \quad \text{Deref}(H_{\text{null}}, \mathcal{A}) = \bot
```

## 3. Computational Complexity & Algorithmic Bounds

Node handle operations execute within Complexity Class $`\mathbf{P}`$:
- **Handle Packing & Dereferencing**: Strict $`O(1)`$ worst-case constant time, executing one bounds check, one array indexing, and two scalar equality comparisons ($`\text{gen}`$ and $`\text{tag}`$).
- **Generational Invalidation**: Strict $`O(1)`$ constant time via scalar increment upon slot reclamation.
- **Graph Traversal**: Deterministic $`O(V + E)`$ linear time across $`V = |\text{Nodes}|`$ and $`E = |\text{Edges}|`$, with zero pointer chasing and contiguous memory cache locality.
- **NP-Frontier Avoidance**: Addressing and dereferencing operate without backtracking or combinatorial search, completely avoiding NP-complete complexity frontiers (e.g., NP-3 subtyping lattices or NP-7 register allocation).

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Generational Invalidation on Slot Recycling

- **Given:** Arena $`\mathcal{A}`$ with slot $`k`$ containing `Classifier_Alpha` referenced by handle $``H_1 = \langle k, g, \text{Tag}_{\text{Alpha}} \rangle``$.
- **When:** Slot $`k`$ is recycled to store `Classifier_Beta`, advancing its generation counter to $`(g + 1) \pmod{2^{16}}`$.
- **Then:** Evaluating $``\text{Deref}(H_1, \mathcal{A})``$ deterministically returns $`\bot`$, while newly allocated handle $``H_2 = \langle k, g + 1, \text{Tag}_{\text{Beta}} \rangle``$ dereferences in $`O(1)`$ time.
- **Diagnostic:** `E0200` emitted on attempted access via stale handle $``H_1``$.

### AC-02: Type Tag Discriminator Validation

- **Given:** Arena slot $`k`$ storing `Package_0` with tag $``\text{Tag}_{\text{Package}}``$, and handle $``H_{\text{mismatch}} = \langle k, g, \text{Tag}_{\text{Port}} \rangle``$.
- **When:** The compiler evaluates $``\text{Deref}(H_{\text{mismatch}}, \mathcal{A})``$.
- **Then:** Validation fails, dereferencing evaluates to $`\bot`$, and execution halts without panics.
- **Diagnostic:** `E0200` emitted on type tag mismatch.

### AC-03: Arena Capacity Bounds and Sentinel Safety

- **Given:** Arena $`\mathcal{A}`$ of capacity $``C_{\text{arena}}``$, out-of-bounds handle $``H_{\text{oob}} = \langle C_{\text{arena}} + 10, 0, 0 \rangle``$, and null sentinel $``H_{\text{null}} = \pi_{\text{pack}}(2^{32} - 1, 0, 0)``$.
- **When:** The compiler evaluates $``\text{Deref}(H_{\text{oob}}, \mathcal{A})``$ or $``\text{Deref}(H_{\text{null}}, \mathcal{A})``$.
- **Then:** Both evaluate to $`\bot`$, preserving $`\text{Valid}(H, \mathcal{A}) = \text{false}`$ and zero dangling pointers.
- **Diagnostic:** `E0200` emitted when dereferencing out-of-bounds or null handles.

### AC-04: Cross-Platform Serialization Parity

- **Given:** An AST graph with entities `Package_0`, `Classifier_Alpha`, and `Port_1` interconnected via typed node handles.
- **When:** The graph is serialized to CBOR/JSON (REQ-0044) and deserialized in independent processes.
- **Then:** Deserialized handle integers, slot offsets, and edge topologies exhibit 100% bitwise parity without pointer swizzling.
- **Diagnostic:** `E0200` emitted on deserialization handle corruption.

### AC-05: Panic-Free Release Mode Latency and Memory Bounds

- **Given:** An AST model with $`10^6`$ nodes allocated in contiguous node arena chunks.
- **When:** Dereferencing throughput and arena memory are benchmarked in Release mode (`--release`) under an isolated harness (Directive 5, REQ-0196).
- **Then:** Dereferencing throughput exceeds $`10^8`$ ops/s (latency $`\lt 10\text{ ns}`$) with peak RSS below $`100\text{ MB}`$ and zero panics.
- **Diagnostic:** `E0200` emitted if memory corruption or runtime failure occurs.
