## 2. Formal Invariant

The attribute schema, typing invariants, metric constraints, and diagnostic triggers satisfy:

```math
\begin{aligned}
\forall F\in\mathcal{F}_{\text{proj}},\forall a\in\mathbf{A}_F,&\quad a=\langle\text{name}_a,\tau_a,\mathbf{u}_a,[v_{\min}(a),v_{\max}(a)],v_{\text{default}}(a),\text{access}_a,\Delta_a\rangle \\
\forall a\in\mathbf{A}_F,&\quad\tau_a\in\mathcal{T}_{\text{types}}\setminus\{\bot\}\land\text{access}_a\in\{\text{ReadOnly},\text{Configurable}\}\land\mathbf{u}_a\in\mathbb{Q}^7 \\
&\quad\land v_{\min}(a)\le v_{\text{default}}(a)\le v_{\max}(a)\land v_{\text{default}}(a)\in\text{Domain}(\tau_a)\setminus\{\bot,\text{"TBD"}\} \\
(\tau_a=\bot\lor v_{\min}\gt v_{\max}&\lor v_{\text{default}}\notin[v_{\min},v_{\max}]\lor v_{\text{default}}\notin\text{Domain}(\tau_a))\implies\text{Diagnostic}(a,\text{E0307})\in\mathcal{D}_{\text{sink}}\land a\gets\bot_{\text{attr}} \\
(\mathbf{u}_a\notin\mathbb{Q}^7&\lor\text{DimMismatch}(a))\implies\text{Diagnostic}(a,\text{E0300})\in\mathcal{D}_{\text{sink}}\land\mathbf{u}_a\gets\bot_{\text{dim}} \\
|\mathcal{D}_{\text{sink}}|\ge C_{\text{max\_errors}}&\implies\text{Diagnostic}(\text{E0199})\in\mathcal{D}_{\text{sink}},\quad\Delta_a=\text{UUIDv5}(\text{OID}_{\text{DEAP}},\text{FQN}(a))
\end{aligned}
```

## 3. Computational Complexity & Algorithmic Bounds

- **Complexity Class:** Class $\mathbf{P}$ (Deterministic Polynomial Time).
- **Asymptotic Bound:** $``O(|T_{\text{types}}|)``$ typing projection ($``|T_{\text{types}}| = \sum |\mathbf{A}_F|``$). AST traversal runs in $``O(|T_{\text{types}}|)``$ time. Type, $\mathbb{Q}^7$ unit, and bound checks run in $O(1)$ time. Space: $``O(|T_{\text{types}}|)``$. Pool: $``O(|T_{\text{types}}| / N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$.
- **Tractable Subclass and Frontier:** N/A (Deterministic P). Avoids NP-3 linearization (REQ-0061), NP-6 flow solving (REQ-0105), and NP-8 SMT solving (REQ-0197).

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Canonical Domain State and Structural Typing
- **Given:** `Package_0` with `Property_1 : PrimitiveType_0` ($[0, 100]$, default $25$, unit $\mathbf{0}$, `Configurable`) and `Property_2 : Real` ($[0.0, 50.0]$, default $10.0$, unit $\text{m/s}$, `ReadOnly`).
- **When:** Lowering Feature Layer 1.
- **Then:** Projects attributes into Layer 1 with valid types and envelopes.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: Operational Range Boundary Conformance
- **Given:** Feature `Feature_Alpha` attribute `Property_Alpha` with envelope $[0.0, 100.0]$ and default $``v_{\text{default}} = 100.0``$.
- **When:** Validating range containment.
- **Then:** Confirms $``v_{\min} \le v_{\text{default}} \le v_{\max}``$ holds at boundary.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-03: Range Envelope and Default Value Violation Rejection
- **Given:** Feature `Feature_0` attribute `Property_1` with inverted range $[100, 50]$ or default $150 \notin [0, 100]$.
- **When:** Validating interval containment.
- **Then:** Rejects attribute, binds sentinel $``\bot_{\text{attr}}``$, emitting `E0307`.
- **Diagnostic:** `E0307` (RangeConstraintViolation).

### AC-04: Physical Dimension Mismatch and Delimiter Recovery
- **Given:** Feature declaring `Property_1` with unit vector $\mathbf{u} \notin \mathbb{Q}^7$, delimiter `;`, and valid `Property_2`.
- **When:** Encountering dimensional incompatibility.
- **Then:** Emits `E0300`, binds $``\bot_{\text{dim}}``$, recovers across `;`, parses `Property_2`, halting at $``C_{\text{max\_errors}}``$ with `E0199`.
- **Diagnostic:** `E0300`, `E0199`.
