## 1. Normative Statement

The persistence engine shall perform read-only memory-mapped diffing of candidate artifact byte buffers against on-disk files prior to writing. It shall bypass file emission when generated content matches on-disk bytes identically, preserving modification timestamps (`mtime`), inodes, and metadata attributes.

---

## 2. Formal Invariant

Let $``\mathcal{P}_{\text{out}}``$ denote the universe of output paths, $``P \in \mathcal{P}_{\text{out}}``$ be a target path, and $``B_{\text{new}} \in \Sigma^*``$ be the generated byte buffer of length $``|B_{\text{new}}| \in \mathbb{N}_0``$. Let $``\mathcal{B}_{\text{mmap}}(P)``$ denote the read-only memory-mapped byte slice of file $`P`$ on disk at step $`t`$.

The emission decision function $``\text{ShouldWrite} : \mathcal{P}_{\text{out}} \times \Sigma^* \longrightarrow \{ \text{true}, \text{false} \}``$ evaluates:

```math
\text{ShouldWrite}(P, B_{\text{new}}) = \begin{cases}
\text{true}, & \text{if } \neg \text{FileExists}(P) \\
\text{true}, & \text{if } \text{FileExists}(P) \wedge \text{FileSize}(P) \ne |B_{\text{new}}| \\
\text{false}, & \text{if } \text{FileExists}(P) \wedge \text{FileSize}(P) = |B_{\text{new}}| \wedge \mathcal{B}_{\text{mmap}}(P) = B_{\text{new}} \\
\text{true}, & \text{otherwise}
\end{cases}
```

Timestamp, Inode, and Downstream Zero-Churn Invariant:
When emission is bypassed, filesystem attributes remain invariant and downstream build tasks $``\mathcal{T}_{\text{build}}``$ require zero rebuilding:

```math
\begin{aligned}
\text{ShouldWrite}(P, B_{\text{new}}) = \text{false} \implies &\; \text{mtime}(P, t+1) = \text{mtime}(P, t) \;\wedge \\
&\; \text{inode}(P, t+1) = \text{inode}(P, t) \;\wedge \\
&\; \forall T \in \mathcal{T}_{\text{build}}, \; \text{Rebuild}(T) = \text{false}
\end{aligned}
```

Mapping Bypass & Zero Heap Invariant:
Size divergence bypasses virtual memory mapping, and diffing executes with zero dynamic heap allocations:

```math
\begin{aligned}
\text{FileSize}(P) \ne |B_{\text{new}}| &\implies \text{MmapCreated}(P) = \text{false} \\
\text{HeapAllocations}(\text{DiffEngine}(P, B_{\text{new}})) &= 0
\end{aligned}
```

Diagnostic Code Binding Invariant:
Filesystem permission faults or mapping failures emit diagnostic `E0200`:

```math
\text{Fault}(P) \in \{ \text{PermissionDenied}, \text{MappingFailed}, \text{IOError} \} \implies \text{Diagnostic}(P, \text{E0200}) \in \mathcal{D}
```

## 3. Computational Complexity & Algorithmic Bounds

The memory-mapped diff engine operates within Complexity Class $`\mathbf{P}`$:
- **Metadata Query**: Inspection of file existence and size executes in $`O(1)`$ constant time via filesystem inode caching.
- **Short-Circuit Elimination**: When $``\text{FileSize}(P) \ne |B_{\text{new}}|``$, evaluation terminates in $`O(1)`$ time without memory mapping or disk I/O.
- **Byte Comparison**: For matching sizes $``L = |B_{\text{new}}|``$, vectorized word comparison evaluates $`\lceil L / W \rceil`$ iterations ($`W = 32\text{ bytes}`$ under SIMD), executing in $`O(k^*)`$ time where $`k^* \le L`$ is the first divergent byte (worst-case $`O(L)`$ when identical).
- **Parallel Scaling**: Across $`K`$ artifacts distributed over $``N_{\text{max\_workers}}``$ threads, wall-clock persistence time is bounded by $``O(\lceil K / N_{\text{max\_workers}} \rceil \cdot \bar{L})``$.
- **Space Bounds**: Auxiliary heap memory is strictly $`O(1)`$.
- **NP-Frontier Avoidance**: Diffing evaluates strictly linear byte sequences, bypassing combinatorial NP frontiers (NP-1 through NP-8).

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Timestamp Invariance on Identical Re-Emission

- **Given:** Target output path $`P`$ containing an existing on-disk artifact with modification timestamp $``t_0``$, and freshly generated byte buffer $``B_{\text{new}}``$ with identical content.
- **When:** The persistence engine processes artifact $`P`$ during compilation pass $``t_1 \gt t_0``$.
- **Then:** $``\text{ShouldWrite}(P, B_{\text{new}})``$ evaluates to false, zero write system calls execute, and $``\text{mtime}(P, t_1) = t_0``$.
- **Diagnostic:** `E0200` emitted on unexpected filesystem error.

### AC-02: Size Discrepancy Fast Short-Circuit

- **Given:** Target path $`P`$ where $``\text{FileSize}(P) \ne |B_{\text{new}}|``$.
- **When:** The persistence engine evaluates the emission decision predicate.
- **Then:** $``\text{ShouldWrite}(P, B_{\text{new}})``$ evaluates to true in $`O(1)`$ time, memory mapping is strictly bypassed ($`\text{MmapCreated}(P) = \text{false}`$), and the file is atomically rewritten.
- **Diagnostic:** `E0200` emitted on atomic commit failure.

### AC-03: Single-Byte Divergence Detection and Atomic Commit

- **Given:** On-disk file $`P`$ and candidate buffer $``B_{\text{new}}``$ of identical length $`L`$, differing by 1 byte at index $`k \in \{0, \lfloor L/2 \rfloor, L-1\}`$.
- **When:** Vectorized memory-mapped comparison evaluates $``\mathcal{B}_{\text{mmap}}(P)``$ against $``B_{\text{new}}``$.
- **Then:** Divergence is detected at index $`k`$, $``\text{ShouldWrite}(P, B_{\text{new}})``$ evaluates to true, and $``B_{\text{new}}``$ is persisted atomically via a temporary sibling file.
- **Diagnostic:** `E0200` emitted if atomic rename fails.

### AC-04: Non-Existent Target Atomic Creation

- **Given:** Target path $`P`$ in namespace `Package_0` where $`\text{FileExists}(P) = \text{false}`$.
- **When:** The persistence engine processes output artifact $`P`$.
- **Then:** $``\text{ShouldWrite}(P, B_{\text{new}})``$ evaluates to true without memory mapping, creating the destination artifact atomically.
- **Diagnostic:** `E0200` emitted on directory creation or permission error.
