## 1. Normative Statement

The safety compiler SHALL eliminate extraneous AST nodes and unreachable behaviors lacking reachability to root requirements. The analyzer (`DeadEliminator_1`) MUST evaluate reachability over traceability DAG (`SafetyGraph_Alpha`) from roots $``R_{\text{root}}``$.

---

## 2. Formal Invariant

Traceability reachability, active subgraph induction, and diagnostic mappings satisfy:

```math
\begin{aligned}
G=(V,E),\;R_{\text{root}}\subseteq V,\;I_{\text{safety}}\subseteq V,\;\text{Reachable}(R_{\text{root}},v)\iff\exists r\in R_{\text{root}}:r\rightsquigarrow^* v \\
V_{\text{extraneous}}=\{v\in V\mid\neg\text{Reachable}(R_{\text{root}},v)\},\;V_{\text{active}}=V\setminus V_{\text{extraneous}} \\
E_{\text{active}}=E\cap(V_{\text{active}}\times V_{\text{active}}),\;G_{\text{active}}=(V_{\text{active}},E_{\text{active}}) \\
S_{\text{dead}}=\{s\in S\mid\neg\text{Reachable}(s_0,s)\},\;\delta_{\text{dead}}=\{t\in\delta\mid s_{\text{src}}(t)\in S_{\text{dead}}\lor g_t\equiv\bot\} \\
\forall v\in I_{\text{safety}},\;\neg\text{Reachable}(R_{\text{root}},v)\implies\text{Diagnostic}(v,\text{E0400})\in\mathcal{D}_{\text{sink}} \\
(\sigma_{\text{mode}}=\text{StrictSafety}\land v\in V_{\text{extraneous}})\implies\text{Diagnostic}(v,\text{E0408})\in\mathcal{D}_{\text{sink}} \\
|\mathcal{D}_{\text{sink}}|\ge C_{\text{max\_errors}}\implies\text{Diagnostic}(\bot,\text{E0199})\in\mathcal{D}_{\text{sink}} \\
\Delta_v=\text{UUIDv5}(\text{NS}_{\text{DEAP}},\text{FQN}(v)),\;\Delta_e=\text{UUIDv5}(\text{NS}_{\text{DEAP}},\text{FQN}(u)\mathbin{\Vert}\text{"::"}\mathbin{\Vert}\text{FQN}(v))
\end{aligned}
```

| Symbol / Term | Domain / Formal Definition |
| :--- | :--- |
| $G, V, E$ | Traceability DAG, vertex set, edge set |
| $``R_{\text{root}}, I_{\text{safety}}``$ | Root requirements, safety invariants |
| $``V_{\text{extraneous}}, V_{\text{active}}``$ | Extraneous and active sets |
| $``G_{\text{active}}, E_{\text{active}}``$ | Active subgraph and edge set |

## 3. Computational Complexity & Algorithmic Bounds

- **Complexity Class:** Class $\mathbf{P}$ (Deterministic Polynomial)
- **Asymptotic Bound:** $O(|V| + |E|)$ backward reachability and dead-node filtering. BFS/DFS visits graph elements once in $O(|V| + |E|)$ time and $O(|V|)$ bitset memory; edge filtering takes $O(|E|)$. Work-stealing scales as $``O((|V| + |E|)/N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$.
- **Tractable Subclass & Frontier:** N/A (Deterministic P). Avoids NP-5 (REQ-0124) complexity by traversing DAGs without state unrolling.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Canonical Grounded Model Reachability
- **Given:** `Package_0` declaring `SafetyGraph_Alpha` grounded to `Req_Root_0`.
- **When:** `DeadEliminator_1` executes reachability analysis.
- **Then:** $``V_{\text{extraneous}} = \emptyset``$, $``G_{\text{active}} = G``$; diagnostic sink remains empty.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: Extraneous Node Rejection in Strict Safety Audit Mode
- **Given:** `Package_0` with ungrounded `Node_Orphan` lacking path from $``R_{\text{root}}``$.
- **When:** Compiling under `strict_safety_audit = true`.
- **Then:** Halts lowering, rejects code emission, and emits `E0408`.
- **Diagnostic:** `E0408` (ExtraneousNodeDetected).

### AC-03: Dead Code Elimination & Induced Subgraph Pruning
- **Given:** Model with grounded classifiers and orphan port `Port_Orphan`.
- **When:** Compiling under `dce_pruning = true`.
- **Then:** Prunes `Port_Orphan`, constructs induced $``G_{\text{active}}``$ without dangling edges, and writes `Manifest_Dead_0`.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-04: Ungrounded Safety Invariant & Delimiter Recovery
- **Given:** `Invariant_0` lacking path from $``R_{\text{root}}``$, followed by `;` and valid nodes.
- **When:** Validating invariant grounding and recovery.
- **Then:** Rejects silent pruning, emits `E0400`, recovers on `;`, halting at $``C_{\text{max\_errors}}``$ with `E0199`.
- **Diagnostic:** `E0400`, `E0199`.
