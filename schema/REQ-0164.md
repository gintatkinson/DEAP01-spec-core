## 1. Normative Statement

The projection engine of Subsystem 9 SHALL synthesize Feature specifications from the AST and enforce the 3-Layer Definition of Done (3-Layer DoD) via `DoD_Validator_0`.

---

## 2. Formal Invariant

Let $\mathcal{F}$ denote synthesized feature specifications in `Package_0`. Completeness, purity, and diagnostics satisfy:

```math
\begin{aligned}
F&=\langle\text{Layer}_1(F),\text{Layer}_2(F),\text{Layer}_3(F)\rangle \\
\text{DoD}(F)&\iff\bigwedge_{\ell=1}^3(\neg\text{IsEmpty}(\text{Layer}_\ell(F))\land\neg\text{ContainsPlaceholder}(\text{Layer}_\ell(F))) \\
\exists\ell\in\{1,2,3\}\text{ s.t. }\text{IsEmpty}(\text{Layer}_\ell(F))&\implies\text{Diagnostic}(F,\text{E0300})\in\mathcal{D}_{\text{sink}}\land F\gets\bot_{\text{layer}}\land\text{Reject}(F) \\
\exists\ell\in\{1,2,3\}\text{ s.t. }\text{ContainsPlaceholder}(\text{Layer}_\ell(F))&\implies\text{Diagnostic}(F,\text{E0306})\in\mathcal{D}_{\text{sink}}\land F\gets\bot_{\text{layer}}\land\text{Reject}(F) \\
|\mathcal{D}_{\text{sink}}|\ge C_{\text{max\_errors}}&\implies\text{Diagnostic}(\text{E0199})\in\mathcal{D}_{\text{sink}}\land\text{Halt}() \\
\forall F\in\mathcal{F},&\quad\text{UUID}(F)=\text{UUIDv5}(\text{OID}_{\text{DEAP}},\text{FQN}(F))
\end{aligned}
```

| Symbol / Term | Domain / Formal Definition |
| :--- | :--- |
| $F, \mathcal{F}$ | Feature composite and set of projected features |
| $``\text{Layer}_\ell(F)``$ | Constituent layer descriptors ($\ell \in \{1, 2, 3\}$) |
| $\text{DoD}(F)$ | 3-Layer Definition of Done compliance predicate |
| $\text{IsEmpty}, \text{ContainsPlaceholder}$ | Layer emptiness and banned placeholder predicates |
| $``\bot_{\text{layer}}, \mathcal{D}_{\text{sink}}, C_{\text{max\_errors}}``$ | Recovery sentinel, diagnostic sink, and capacity limit |
| $``\Delta_F, \text{OID}_{\text{DEAP}}, \text{FQN}(F)``$ | UUIDv5 anchor, namespace OID, and topological path |

## 3. Computational Complexity & Algorithmic Bounds

- **Complexity Class:** Class $\mathbf{P}$.
- **Asymptotic Bound:** $O(|F|)$ 3-layer checklist scan where $|F| = |\text{ASTNodes}(F)|$. Layer evaluation runs in $O(|F|)$. Work-stealing scales as $``O(|F| / N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$, with $O(|F|)$ space.
- **Tractable Subclass and Frontier:** N/A (Deterministic P). Structural checklist verification executes deterministically over AST trees without backtracking, bypassing NP-hard frontiers (NP-1 through NP-8).

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Full 3-Layer Feature Conformance
- **Given:** Feature `Feature_Alpha` in `Package_0` declaring valid `Layer_1`, `Layer_2`, and `Layer_3`.
- **When:** Lowering feature through `DoD_Validator_0`.
- **Then:** Confirms $``\text{DoD}(\text{Feature\_Alpha}) \equiv \text{true}``$ and emits artifact.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: Boundary Layer Completeness
- **Given:** Minimal feature `Feature_Beta` with single attribute, transition, and interface binding.
- **When:** Evaluating layer non-emptiness.
- **Then:** Confirms $``\text{IsEmpty}(\text{Layer}_\ell) \equiv \text{false}``$ for $\ell \in \{1, 2, 3\}$ and passes.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-03: Empty Layer Rejection
- **Given:** Feature `Feature_Gamma` lacking `Layer_3`.
- **When:** Evaluating structural completeness.
- **Then:** Fails closed, emits `E0300`, and binds sentinel $``\bot_{\text{layer}}``$.
- **Diagnostic:** `E0300` (Feature Definition of Done violation).

### AC-04: Unbound Placeholder Rejection and Error Recovery
- **Given:** Feature `Feature_Delta` with placeholder `TODO` in `Layer_2`, delimiter `;`, and valid `Feature_Epsilon`.
- **When:** Delimiter recovery processes `Feature_Delta`.
- **Then:** Emits `E0306`, recovers on `;`, validates `Feature_Epsilon`, and halts at $``C_{\text{max\_errors}}``$ with `E0199`.
- **Diagnostic:** `E0306`, `E0199`.
