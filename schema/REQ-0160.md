## 1. Normative Statement

The downstream projection engine of Subsystem 9 SHALL schedule features in strict bottom-up topological order via `Scheduler_1` over dependency DAG `DependencyDAG_0` ($``\mathcal{G}_{\text{dep}} = (\mathcal{F}, \mathcal{E}_{\text{dep}})``$), synthesizing leaf features before dependent composite features to eliminate forward reference gaps.

---

## 2. Formal Invariant

Let $``\mathcal{G}_{\text{dep}} = (\mathcal{F}, \mathcal{E}_{\text{dep}})``$ be the feature dependency DAG. The topological ordering, ready queue selection, and diagnostic bindings satisfy:

```math
\begin{aligned}
\text{deg}^{-}(f)&=|\{f_p\in\mathcal{F}\mid(f_p,f)\in\mathcal{E}_{\text{dep}}\}|,\quad\text{IsLeaf}(f)\iff\text{deg}^{-}(f)=0 \\
\forall(f_a,f_b)\in\mathcal{E}_{\text{dep}},&\quad\text{Order}(f_a)\lt\text{Order}(f_b) \\
Q_t&=\{f\in\mathcal{F}\setminus\mathcal{L}_{t-1}\mid\text{deg}^{-}_t(f)=0\},\quad f_t=\arg\min_{f\in Q_t}(\text{FQN}(f)) \\
\mathcal{L}_t&=\mathcal{L}_{t-1}\mathbin{\Vert}\langle f_t\rangle \\
(\text{HasCycle}(\mathcal{G}_{\text{dep}})\lor(f,f)\in\mathcal{E}_{\text{dep}})&\implies\text{Diagnostic}(f,\text{E0302})\in\mathcal{D}_{\text{sink}}\land\mathcal{G}_{\text{dep}}\gets\bot_{\text{sched}} \\
f_{\text{prereq}}\notin\mathcal{F}&\implies\text{Diagnostic}(f,\text{E0300})\in\mathcal{D}_{\text{sink}} \\
|\mathcal{D}_{\text{sink}}|\ge C_{\text{max\_errors}}&\implies\text{Diagnostic}(\text{E0199})\in\mathcal{D}_{\text{sink}},\quad\Delta_f=\text{UUIDv5}(\text{OID}_{\text{DEAP}},\text{FQN}(f))
\end{aligned}
```

| Symbol / Term | Domain / Formal Definition |
| :--- | :--- |
| $``\mathcal{G}_{\text{dep}}, \mathcal{F}, \mathcal{E}_{\text{dep}}``$ | Feature dependency DAG, feature vertices, and dependency edges |
| $\text{deg}^{-}(f)$ | In-degree count of unresolved prerequisites for feature $f$ |
| $``\text{Order}(f), \mathcal{L}_t``$ | Topological index and linear sequence at step $t$ |
| $``Q_t, f_t``$ | Ready queue and selected feature candidate |
| $``\text{FQN}(f), \text{OID}_{\text{DEAP}}``$ | Interned identifier and compiler namespace OID |
| $``\bot_{\text{sched}}, \mathcal{D}_{\text{sink}}, C_{\text{max\_errors}}``$ | Scheduling sentinel, diagnostic sink, and capacity limit |
| $``\Delta_f``$ | Immutable RFC 4122 UUIDv5 anchor for feature $f$ |

## 3. Computational Complexity & Algorithmic Bounds

- **Complexity Class:** Class $\mathbf{P}$ (Polynomial Time).
- **Asymptotic Bound:** $O(|V| + |E|)$ for $V = |\mathcal{F}|$ and $``E = |\mathcal{E}_{\text{dep}}|``$ via Kahn topological sort; min-heap tie-breaking executes in $O(|V| \log |V| + |E|)$. Parallel scaling: $``O((|V| + |E|)/N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$. Space: $O(|V| + |E|)$.
- **Tractable Subclass and Frontier:** N/A (Deterministic P). Multigraph traversal avoids NP-hard feedback vertex sets, NP-1 interval reasoning (REQ-0117), NP-2 packing (REQ-0147), and NP-8 solving (REQ-0197).

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Canonical Bottom-Up Feature Ordering
- **Given:** DAG with leaves `Feature_Leaf_A`, `Feature_Leaf_B` and composite `Feature_Composite_C`.
- **When:** Scheduling via `Scheduler_1`.
- **Then:** Confirms $``\text{Order}(\text{Feature\_Leaf\_A}) < \text{Order}(\text{Feature\_Composite\_C})``$ and $``\text{Order}(\text{Feature\_Leaf\_B}) < \text{Order}(\text{Feature\_Composite\_C})``$.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: Deterministic Lexicographical Tie-Breaking
- **Given:** Ready queue with leaves `Feature_Beta`, `Feature_Alpha`, `Feature_Gamma` ($\text{deg}^{-} = 0$).
- **When:** Scheduling across repeated runs.
- **Then:** Extracts candidates in ascending lexicographical order (`Feature_Alpha`, `Feature_Beta`, `Feature_Gamma`) with 0-byte diff churn.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-03: Cyclic Dependency Detection and Rejection
- **Given:** Dependency cycle between `Feature_Alpha` and `Feature_Beta`.
- **When:** Evaluating cycle detection.
- **Then:** Rejects cyclic nodes, emits `E0302` with cycle path, and binds sentinel $``\bot_{\text{sched}}``$.
- **Diagnostic:** `E0302` (CyclicFeatureDependency).

### AC-04: Missing Prerequisite and Delimiter Recovery
- **Given:** Reference to missing `Feature_Missing` followed by `;` and `Feature_Alpha`.
- **When:** Delimiter error recovery processes tokens.
- **Then:** Emits `E0300`, recovers on `;`, parses `Feature_Alpha`, halting at $``C_{\text{max\_errors}}``$ with `E0199`.
- **Diagnostic:** `E0300`, `E0199`.
