## 1. Normative Statement

The persistence engine of Subsystem 10 SHALL persist artifacts ($\mathcal{A}$) through manifest `CodegenManifest_Alpha` via fingerprint `ArtifactFingerprint_0` using XXH3 hashing.

---

## 2. Formal Invariant

Let $\mathcal{A}$ denote emitted artifacts with record $``a = \langle p, B, L, h, \Delta_a \rangle``$. Invariants satisfy:

```math
\begin{aligned}
\forall a\in\mathcal{A},\quad\text{Entry}(a)&=\langle p_a,h_a,L_a,\Delta_a\rangle,\quad h_a=\text{XXH3}_{64}(\text{Bytes}(a),0) \\
\text{WriteSkipped}(p,B)&\iff\text{FileExists}(p)\land(\text{FileSize}(p)=|B|)\land(h_{\text{cached}}(p)=h) \\
\text{WriteSkipped}(p,B)&\implies(\text{mtime}(p,t+1)=\text{mtime}(p,t))\land(\text{inode}(p,t+1)=\text{inode}(p,t)) \\
\mathcal{A}^{(t+1)}=\mathcal{A}^{(t)}&\implies\Delta_{\text{writes}}=\sum_{k=1}^K\mathbf{1}_{\{\neg\text{WriteSkipped}(p_k,B_k)\}}=0 \\
\Delta_a&=\text{UUIDv5}(\text{OID}_{\text{DEAP}},\text{FQN}(a)\mathbin{\Vert}\text{"::Artifact::"}\mathbin{\Vert}p_a) \\
\neg\text{IsValidPath}(p)&\implies\text{Diagnostic}(a,\text{E0300})\in\mathcal{D}_{\text{sink}}\land\text{Entry}(a)\gets\bot_{\text{path}} \\
(\text{WriteFailed}(p)\lor h_{\text{disk}}(p)\ne h)&\implies\text{Diagnostic}(a,\text{E0504})\in\mathcal{D}_{\text{sink}}\land\text{Entry}(a)\gets\bot_{\text{write}} \\
|\mathcal{D}_{\text{sink}}| \ge C_{\text{max\_errors}}&\implies\text{Diagnostic}(\text{E0199})\in\mathcal{D}_{\text{sink}}
\end{aligned}
```

| Symbol / Term | Domain / Formal Definition |
| :--- | :--- |
| $\mathcal{A}, a, p, B, L$ | Emitted artifact set, artifact record, relative path, bytes, and length |
| $``h, \mathcal{M}_{\text{cached}}, \mathcal{M}_{\text{new}}``$ | 64-bit XXH3 hash, cached manifest, and active manifest |
| $``\text{WriteSkipped}, \Delta_{\text{writes}}, \Delta_a``$ | Bypass predicate, filesystem write count, and UUIDv5 anchor |
| $``\bot_{\text{path}}, \bot_{\text{write}}, \mathcal{D}_{\text{sink}}, C_{\text{max\_errors}}``$ | Path and write sentinels, diagnostic sink, and error limit |

---

## 3. Computational Complexity & Algorithmic Bounds

- **Complexity Class:** Class $\mathbf{P}$ (Deterministic Polynomial Time).
- **Asymptotic Bound:** $O(|B|)$ hashing ($> 10\text{ GB/s}$) per artifact. Manifest emission for $K = |\mathcal{A}|$ artifacts takes $``O(N_{\text{bytes}} + K \log K)``$. Work-stealing scales as $``O(N_{\text{bytes}} / N_{\text{max\_workers}} + K \log K)``$. Arena space is $O(K)$.
- **Tractable Subclass and Frontier:** N/A (Deterministic P). Avoids NP-1 intervals (REQ-0117), NP-2 packing (REQ-0147), and NP-8 solving (REQ-0197).

---

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Canonical Manifest and Fingerprint Emission
- **Given:** `Package_0` synthesizing `Classifier_Alpha` for `Path_0`.
- **When:** Lowering into `CodegenManifest_Alpha` with bytes $B$.
- **Then:** Computes `ArtifactFingerprint_0` via XXH3 (seed 0), binds UUIDv5 $``\Delta_a``$, and records entry.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: Redundant Write Bypass and Idempotency
- **Given:** File at `Path_0` matching cached `CodegenManifest_Alpha`.
- **When:** Re-compiling with unchanged AST inputs.
- **Then:** Evaluates $``\text{WriteSkipped}(\text{Path\_0}, B) = \text{true}``$, bypasses writes, preserves $mtime$, yielding $``\Delta_{\text{writes}} = 0``$.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-03: Persistence Failure and Hash Mismatch Rejection
- **Given:** Artifact at `Path_0` where write fails or hash diverges.
- **When:** Committing bytes to disk sink `DiskSink_1`.
- **Then:** Fails closed, emits `E0504`, and binds sentinel $``\bot_{\text{write}}``$.
- **Diagnostic:** `E0504` (PersistenceFailure).

### AC-04: Path Traversal Interception and Delimiter Recovery
- **Given:** Artifact with escaping path (`../target`), delimiter `\n`, and `Artifact_Beta`.
- **When:** Validating destination path bounds within the output root.
- **Then:** Emits `E0300`, binds $``\bot_{\text{path}}``$, recovers across `\n`, persists `Artifact_Beta`, halting at $``C_{\text{max\_errors}}``$ with `E0199`.
- **Diagnostic:** `E0300`, `E0199`.
