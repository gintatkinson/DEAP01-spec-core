## 1. Normative Statement

The metamodel lowering engine SHALL formalize SysML v2 `constraint def` (`ConstraintDefinition`) and `constraint` (`ConstraintUsage`) as Boolean predicate functions specializing KerML `Predicate` and `Function`. Every `ConstraintDefinition` SHALL define a pure invariant proposition over formal parameters $``\mathbf{P}_{CD} = (p_1, \dots, p_k)``$` asserting body $``e_{CD}``$` evaluating to `true` across admissible states.

The engine MUST enforce five static invariants during lowering:
1. **Boolean Codomain**: `ConstraintDefinition` specializes `Function` ($`\text{ConstraintDefinition} \le \text{Function} \longrightarrow \mathbb{B}`$`). Body $``e_{CD}``$` MUST unify with `Boolean`; non-Boolean types emit `E0200`.
2. **Parameter Directionality**: Parameters MUST declare or default to `In` ($``\text{dir}(p_i) = \text{In}``$). `Out` or `InOut` parameters emit `E0201`. Body evaluation produces zero state mutation ($`\Delta \text{State} \equiv \emptyset`$); side effects emit `E0200`.
3. **Usage Binding**: `ConstraintUsage` $CU$ MUST bind arguments $``\mathbf{A}_{CU}``$` conforming to $``\mathbf{P}_{CD}``$. Arity mismatch ($m \ne k$) or subtyping failure ($``\tau(a_i) \not\le \tau(p_i)``$) emits `E0200`. Unreadable arguments emit `E0201`.
4. **Call Graph Acyclicity**: Definitions MUST NOT form recursive cycles in call graph $``\mathcal{G}_{\text{c\_dep}}``$; cycles emit `E0203`.
5. **Anonymous Lowering**: Blocks (`constraint { <expr> }`) synthesize an arena `ConstraintDefinition`, project free variables as synthetic `In` parameters, and emit a bound `ConstraintUsage`.

## 2. Formal Invariant

Let $`\mathcal{CD}`$ denote lowered `ConstraintDefinition` nodes and $`\mathcal{CU}`$ denote lowered `ConstraintUsage` nodes:

```math
\begin{aligned}
\text{ConstraintDefinition} &\le \text{Predicate} \le \text{Function} \longrightarrow \mathbb{B} \\
\Phi_{\text{codomain}}(CD) &\iff \tau(e_{CD}) \equiv \text{Boolean} \\
\forall p \in \mathbf{P}_{CD}, &\quad \text{dir}(p) = \text{In} \\
\Phi_{\text{binding}}(CU, CD) &\iff (|\mathbf{A}_{CU}| = |\mathbf{P}_{CD}|) \;\wedge\; \bigwedge_{i=1}^k (\tau(a_i) \le \tau(p_i)) \\
\forall \sigma \in \Sigma_{\text{valid}}, &\quad ⟦ CU ⟧(\sigma) \equiv ⟦ e_{\tau(CU)} ⟧\left( [p_i \mapsto \sigma(a_i)]_{i=1}^k \right) \equiv \text{true} \\
\forall CD \in \mathcal{CD}, &\quad (CD, CD) \notin \mathcal{R}_{\text{c\_dep}}^+ \\
\forall n \in \mathcal{CD} \cup \mathcal{CU}, &\quad \Delta_n = \text{UUIDv5}(\text{NS}_{\text{DEAP}}, \text{FQN}(n))
\end{aligned}
```

## 3. Computational Complexity & Algorithmic Bounds

Constraint lowering and verification execute strictly within Complexity Class $\mathbf{P}$.

For $N = |\mathcal{CD}|$ definitions, $M = |\mathcal{CU}|$ usages, and $``E_{\text{nodes}}``$ expression nodes:
- **Predicate Typing**: $``O(|e_{CD}|)``$ per definition ($``O(E_{\text{nodes}})``$ total).
- **Parameter Binding**: $O(1)$ amortized per usage ($k \le 16$).
- **Call Graph Acyclicity**: $``O(|\mathcal{CD}| + |\mathcal{R}_{\text{c\_dep}}|)``$ via Tarjan's SCC.
- **Grounded Evaluation**: $O(1)$ stack ops per expression node.
- **Tractable Frontier**: Deterministic polynomial fragment of NP-1 (Horn) and NP-3 (subtyping).

Total sequential complexity is $``O(N + M + E_{\text{nodes}} + |\mathcal{R}_{\text{c\_dep}}|)``$; parallel scales as $``O((N + M + E_{\text{nodes}} + |\mathcal{R}_{\text{c\_dep}}|) / N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Canonical Lowering and Binding
- **Given:** `ConstraintDef_Alpha` (`in param_x : Real; in param_y : Real; param_x <= param_y`) and usage `ConstraintUsage_1` in `Classifier_Alpha`.
- **When:** Lowering constraint definition, binding arguments, and verifying Boolean codomain.
- **Then:** Nodes lower into arena storage with bound arguments and empty diagnostic sink.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: Non-Boolean Predicate Rejection
- **Given:** Definition `ConstraintDef_Alpha` with non-Boolean body `param_x + param_y : Real`.
- **When:** Validating Boolean codomain invariant $``\Phi_{\text{codomain}}``$.
- **Then:** Lowering rejects definition, assigns sentinel $``\bot_{\text{type}}``$, and emits diagnostic `E0200`.
- **Diagnostic:** `E0200` on non-Boolean body.

### AC-03: Parameter Directionality and Arity Rejection
- **Given:** Definition declaring `out param_z : Real`, or usage with arity mismatch ($m \ne k$).
- **When:** Validating parameter directionality and signature arity conformance.
- **Then:** Directionality violation emits `E0201`; arity mismatch emits `E0200`.
- **Diagnostic:** `E0201` on invalid parameter direction; `E0200` on arity mismatch.

### AC-04: Circular Dependency Detection and Recovery
- **Given:** Mutually recursive definitions `ConstraintDef_Alpha` and `ConstraintDef_Beta` in call graph $``\mathcal{G}_{\text{c\_dep}}``$.
- **When:** Dependency cycle analysis and sync-token error recovery execute.
- **Then:** Cycle detection emits `E0203`; compiler emits terminal `E0199` at limit $``C_{\text{max\_errors}}``$.
- **Diagnostic:** `E0203` on cyclic dependency; `E0199` on diagnostic saturation.
