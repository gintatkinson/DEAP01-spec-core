## 1. Normative Statement

The compiler architecture shall resolve multi-file compilation units and enforce hierarchical package scoping across modular schema libraries without cross-module symbol collision or namespace pollution. Each compilation unit ingested from the workspace shall bind to a hierarchical package namespace matching its declared package path. The compiler must construct a global package forest where each package possesses a unique fully qualified name (FQN) joined by `::`.

Symbol visibility and lexical scoping rules shall govern identifier resolution:
1. **Local Precedence**: Local declarations in a package scope shadow imported symbols and outer ancestor declarations.
2. **Ancestor Traversal**: Unqualified symbols not declared locally resolve along ascending parent lexical scopes up to the package root.
3. **Explicit Imports**: External symbols require explicit qualified paths (e.g., `Package_0::Package_1::Classifier_Alpha`) or unambiguous import bindings.
4. **Disjoint Namespaces**: Distinct packages maintain disjoint qualified namespaces; identical local identifiers in distinct packages remain isolated without collision.
5. **Ambiguity Rejection**: Unqualified references matching multiple imported candidates must be rejected as ambiguous.
6. **Nesting Depth Bound**: Package hierarchy nesting depth is strictly bounded by $``D_{\max} = 16``$.

Failure modes--conflicting declarations within a scope, unresolvable package paths, cyclic imports, depth violations ($`D \gt 16`$), and ambiguous references--shall halt compilation and emit diagnostic error code `E0100` with unit coordinates and source byte spans.

## 2. Formal Invariant

Let $`\mathcal{U}`$ denote the set of input compilation units. Let $`\mathcal{P}`$ denote the hierarchical package forest. For each package $`P \in \mathcal{P}`$, let $``\text{FQN}(P) = \langle p_1, p_2, \dots, p_k \rangle``$ be its canonical path with depth $``\text{Depth}(P) = k \le D_{\max} = 16``$. Let $`\text{Declared}(P)`$ be locally declared symbols in $`P`$, and $`\text{Exported}(P) \subseteq \text{Declared}(P)`$ be publicly visible symbols.

The qualified symbol namespace of package $`P`$ satisfies:

```math
\text{QualifiedNamespace}(P) = \{ \text{FQN}(P) \mathbin{::} \sigma \mid \sigma \in \text{Exported}(P) \}
```

Disjoint Qualified Namespace Invariant for distinct packages $``P_i \neq P_j``$:

```math
\text{FQN}(P_i) \neq \text{FQN}(P_j) \implies \text{QualifiedNamespace}(P_i) \cap \text{QualifiedNamespace}(P_j) = \emptyset
```

Unambiguous Import Invariant: for referencing package $``P_{\text{src}} \in \mathcal{P}``$ and unqualified symbol $`\sigma`$, let $``\text{ImportTargets}(P_{\text{src}}, \sigma) = \{ P_{\text{tgt}} \in \mathcal{P} \mid \text{Import}(P_{\text{src}}, P_{\text{tgt}}) \wedge \sigma \in \text{Exported}(P_{\text{tgt}}) \}``$. Every referenced unqualified symbol satisfies:

```math
|\text{ImportTargets}(P_{\text{src}}, \sigma)| \le 1
```

Symbol Resolution Mapping: the resolution function $``\text{Resolve}(\sigma, P_{\text{src}})``$ evaluates deterministically:

```math
\text{Resolve}(\sigma, P_{\text{src}}) = \begin{cases}
\text{FQN}(P_{\text{src}}) \mathbin{::} \sigma, & \text{if } \sigma \in \text{Declared}(P_{\text{src}}) \\
\text{FQN}(P_{\text{tgt}}) \mathbin{::} \sigma, & \text{if } \sigma \notin \text{Declared}(P_{\text{src}}) \wedge \exists! P_{\text{tgt}} \in \text{ImportTargets}(P_{\text{src}}, \sigma) \\
\text{Resolve}(\sigma, \text{Parent}(P_{\text{src}})), & \text{if } \sigma \notin \text{Declared}(P_{\text{src}}) \wedge \text{ImportTargets}(P_{\text{src}}, \sigma) = \emptyset \wedge P_{\text{src}} \neq \text{Root} \\
\bot, & \text{otherwise}
\end{cases}
```

Deterministic UUIDv5 Anchor Invariant: for each package $`P \in \mathcal{P}`$, its synthetic anchor $``\Delta_P \in \{0, 1\}^{128}``$ is derived from compiler namespace constant $``\text{NS}_{\text{DEAP}}``$:

```math
\Delta_P = \text{UUIDv5}(\text{NS}_{\text{DEAP}}, \text{FQN}(P))
```

Ambiguity and Resolution Diagnostic Gate:

```math
\forall \sigma \in \text{References}(P_{\text{src}}), \quad (|\text{ImportTargets}(P_{\text{src}}, \sigma)| \gt 1 \lor \text{Resolve}(\sigma, P_{\text{src}}) = \bot) \implies \text{Diagnostic}(\sigma, P_{\text{src}}) = \text{E0100}
```

## 3. Computational Complexity & Algorithmic Bounds

Multi-file compilation unit resolution and hierarchical package scoping execute strictly within Complexity Class $`\mathbf{P}`$. Constructing the package forest over $`|\mathcal{U}|`$ compilation units executes in deterministic $`O(|V| + |E|)`$ time for package vertices $`V = |\mathcal{P}|`$ and containment or import edges $`E`$. Symbol table population scales linearly as $`O(N)`$ for $``N = \sum_{P \in \mathcal{P}} |\text{Declared}(P)|``$, with $`O(1)`$ amortized interned lookups. Lexical ancestor scope resolution executes in $`O(D)`$ time with depth $``D \le D_{\max} = 16``$, bounded by $`O(1)`$ constant-time lookups per frame. Import ambiguity checking evaluates in $`O(K)`$ time for $``K = |\text{Imports}(P_{\text{src}})| \le |V|``$.

NP Frontier Context: Although general subtyping lattice satisfiability and multiple-inheritance feature redefinition across general posets is NP-complete (Algorithmic Bound NP-3), lexical package scoping and symbol lookup form a strict hierarchical forest without backtracking, guaranteeing deterministic polynomial-time evaluation in $`O(M \cdot D) = O(M)`$ time for $`M`$ symbol reference sites. Auxiliary memory overhead is bounded by $`O(N)`$ for interned symbol identifiers, package symbol tables, and scope frame references.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Multi-File Hierarchical Package Assembly
- **Given:** Multi-file compilation units declaring nested packages `Package_0::Package_1` across workspace files.
- **When:** The compiler executes the package forest construction pass.
- **Then:** A unified package tree is constructed with canonical `::` FQNs, deterministic RFC 4122 UUIDv5 anchors, and nesting depth $`D \le 16`$.
- **Diagnostic:** `E0100` on nesting depth $`D \gt 16`$ or malformed path structure.

### AC-02: Local Declaration Precedence & Namespace Isolation
- **Given:** Distinct packages `Package_0` and `Package_1` declaring identical local symbol `Classifier_Alpha`.
- **When:** Unqualified lookup for `Classifier_Alpha` is evaluated within `Package_0`.
- **Then:** Binds strictly to `Package_0::Classifier_Alpha`, satisfying $``\text{QualifiedNamespace}(\text{Package\_0}) \cap \text{QualifiedNamespace}(\text{Package\_1}) = \emptyset``$.
- **Diagnostic:** `E0100` on cross-module collision or scope corruption.

### AC-03: Qualified Path & Unambiguous Import Resolution
- **Given:** Package `Package_src` importing `Package_tgt` which exports `Classifier_Beta`.
- **When:** Resolving unqualified `Classifier_Beta` in `Package_src` or explicit path `Package_tgt::Classifier_Beta`.
- **Then:** Evaluates unambiguously to `Package_tgt::Classifier_Beta`, verifying $``|\text{ImportTargets}(P_{\text{src}}, \text{Classifier\_Beta})| = 1``$.
- **Diagnostic:** `E0100` if target symbol cannot be resolved or is private.

### AC-04: Conflicting Import Ambiguity Detection
- **Given:** Package `Package_src` importing `Package_1` and `Package_2`, both exporting `Classifier_Gamma`.
- **When:** Resolving unqualified `Classifier_Gamma` in `Package_src`.
- **Then:** Rejects binding due to multiple targets ($``|\text{ImportTargets}(P_{\text{src}}, \text{Classifier\_Gamma})| = 2 \gt 1``$), recording diagnostic into error sink.
- **Diagnostic:** `E0100` citing ambiguous symbol and conflicting source packages.
