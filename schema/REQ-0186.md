## 1. Normative Statement

Subsystem 10 SHALL synthesize freestanding, zero-allocation C99 and C++20 MMIO register headers (`.h`, `.hpp`) from peripheral blocks (`RegBlock_0`) via `RegisterHeaderGen_Alpha`.

---

## 2. Formal Invariant

Let $\mathcal{B}$ denote peripheral blocks, $\mathcal{R}(B)$ registers, and $\mathcal{F}(R)$ bitfields. Emission satisfies:

```math
\begin{aligned}
\forall B\in\mathcal{B},\ \forall R\in\mathcal{R}(B),\quad\text{RegAddress}(R)&=\text{BaseOffset}(B)+\Delta_{\text{register}}(R) \\
\text{sizeof}(R)\in\{1,2,4,8\}&\land\text{RegAddress}(R)\equiv 0\pmod{\text{sizeof}(R)} \\
\forall R_i,R_j\in\mathcal{R}(B),\ i\ne j\implies&[\Delta_{\text{register}}(R_i),\Delta_{\text{register}}(R_i)+\text{sizeof}(R_i)-1] \\
&\cap[\Delta_{\text{register}}(R_j),\Delta_{\text{register}}(R_j)+\text{sizeof}(R_j)-1]=\emptyset \\
\forall f\in\mathcal{F}(R),\quad\text{Width}(f)\ge 1&\land\text{Shift}(f)+\text{Width}(f)\le 8\times\text{sizeof}(R) \\
\text{Mask}(f)&=((1\ll\text{Width}(f))-1)\ll\text{Shift}(f) \\
\forall f_i,f_j\in\mathcal{F}(R),\ i\ne j\implies&\text{Mask}(f_i)\mathbin{\mathrm{AND}}\text{Mask}(f_j)=0 \\
\neg\text{ValidIdentifier}(R)&\implies\text{Diagnostic}(R,\text{E0300})\in\mathcal{D}_{\text{sink}}\land R\gets\bot_{\text{reg}} \\
(\text{Misaligned}(R)\lor\text{Overlap}(R)\lor\text{OutOfBounds}(f))&\implies\text{Diagnostic}(R,\text{E0512})\in\mathcal{D}_{\text{sink}}\land R\gets\bot_{\text{reg}} \\
|\mathcal{D}_{\text{sink}}|\ge C_{\text{max\_errors}}&\implies\text{Diagnostic}(\text{E0199})\in\mathcal{D}_{\text{sink}} \\
\Delta_R=\text{UUIDv5}(\text{OID}_{\text{DEAP}},\text{FQN}(B)&\mathbin{\Vert}\text{"::Reg::"}\mathbin{\Vert}\text{name}(R))
\end{aligned}
```

| Symbol / Term | Domain / Formal Definition |
| :--- | :--- |
| $\mathcal{B}, \mathcal{R}(B), \mathcal{F}(R)$ | Peripheral blocks, registers, and bitfields |
| $``\text{BaseOffset}(B), \Delta_{\text{register}}(R)``$ | Base address and register offset |
| $\text{RegAddress}(R), \text{sizeof}(R)$ | MMIO address and width ($1, 2, 4, 8$ bytes) |
| $\text{Mask}(f), \text{Shift}(f), \text{Width}(f)$ | Mask, shift, and bit width |
| $``\bot_{\text{reg}}, \mathcal{D}_{\text{sink}}, C_{\text{max\_errors}}``$ | Sentinel, diagnostic sink, and error limit |
| $``\Delta_R, \text{OID}_{\text{DEAP}}, \text{FQN}``$ | UUIDv5 anchor, namespace OID, and FQN |

## 3. Computational Complexity & Algorithmic Bounds

- **Complexity Class:** Class $\mathbf{P}$ (Deterministic Polynomial Time).
- **Asymptotic Bound:** $``O(|R_{\text{registers}}|)``$ register header emission. Lowering takes $O(1)$ per register ($``O(|R_{\text{registers}}|)``$ total). Offset checks take $``O(|R_{\text{registers}}|)``$. Work-stealing scales as $``O(|R_{\text{registers}}| / N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$. Arena space is $``O(|R_{\text{registers}}|)``$.
- **Tractable Subclass and Frontier:** N/A (Deterministic P). Avoids NP-1 intervals (REQ-0117), NP-2 packing (REQ-0147), NP-7 registers (REQ-0180), and NP-8 solving (REQ-0197).

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: MMIO Header Synthesis
- **Given:** `RegBlock_0` with 32-bit register `Register_0`.
- **When:** Lowering `RegisterHeaderGen_Alpha` to C99 and C++20 headers.
- **Then:** Emits include guards, `extern "C"` blocks, `volatile` accessors, and atomic helpers.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: Alignment and Typing
- **Given:** `RegBlock_0` with registers of widths 1, 2, 4, 8 bytes at aligned offsets.
- **When:** Validating alignment and typing.
- **Then:** Confirms $``\text{RegAddress}(R) \equiv 0 \pmod{\text{sizeof}(R)}``$ and emits `<stdint.h>` types.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-03: Misalignment Rejection
- **Given:** `RegBlock_0` with misaligned offset `0x03` or overflowing `BitField_1`.
- **When:** Validating geometry.
- **Then:** Fails closed, emits `E0512`, and binds sentinel $``\bot_{\text{reg}}``$.
- **Diagnostic:** `E0512`.

### AC-04: Syntax Delimiter Recovery
- **Given:** Malformed token `1_Bad_Reg`, delimiter `;`, and `Register_1`.
- **When:** Recovering across delimiters.
- **Then:** Emits `E0300`, binds sentinel $``\bot_{\text{reg}}``$, recovers across `;`, parses `Register_1`, halting at $``C_{\text{max\_errors}}``$ with `E0199`.
- **Diagnostic:** `E0300`, `E0199`.
