## 1. Normative Statement

The compiler SHALL verify topological consistency across the $N^2$ System Interface Matrix $\mathbf{M}$ (`InterfaceMatrix_Alpha`), ensuring bidirectional channels exhibit symmetry and directed flows exhibit antisymmetry.

---

## 2. Formal Invariant

Let $``\mathcal{V}_{\text{AST}}``$ denote AST entities. Interface matrix verification satisfies:

```math
\begin{aligned}
\mathbf{M}=[M_{ij}]_{i,j=1}^N,\;\mathcal{I}=\mathcal{C}\cup\mathcal{F},\;\mathcal{C}\cap\mathcal{F}=\emptyset,\;\forall i,M_{ii}\cap(\mathcal{C}\cup\mathcal{F})=\emptyset \\
\forall i\ne j,\;\forall c\in\mathcal{C},\;c\in M_{ij}\iff c\in M_{ji} \\
\forall i\ne j,\;\forall f\in\mathcal{F},\;f\in M_{ij}\implies f\notin M_{ji} \\
\forall i\ne j,\;\forall f\in M_{ij}\cap\mathcal{F},\;(\exists f'\in M_{ji}\cap\mathcal{F})\implies\text{IsConjugateFlow}(f,f') \\
\forall x\in M_{ij},\;\text{endpoints}(x)\subseteq\text{Ports}(S_i)\cup\text{Ports}(S_j) \\
\text{Violation}_{\text{sym}}(x)\lor\text{Violation}_{\text{diag}}(x)\lor\text{Violation}_{\text{end}}(x)\implies\text{Diagnostic}(x,\text{E0200})\in\mathcal{D}_{\text{sink}} \\
\text{Violation}_{\text{antisym}}(f)\lor\text{Violation}_{\text{conj}}(f)\implies\text{Diagnostic}(f,\text{E0202})\in\mathcal{D}_{\text{sink}} \\
\forall e,\Delta_e=\text{UUIDv5}(\text{OID}_{\text{DEAP}},\text{FQN}(e)),\;|\mathcal{D}_{\text{sink}}|\ge C_{\text{max\_errors}}\implies\text{Diagnostic}_{\text{term}}(\text{E0199})\in\mathcal{D}_{\text{sink}}
\end{aligned}
```

| Symbol / Term | Domain / Formal Definition |
| :--- | :--- |
| $``\mathbf{M}, M_{ij}``$ | $N^2$ System Interface Matrix cells |
| $``\mathcal{S}, S_i``$ | Universe of $N$ subsystems |
| $\mathcal{C}, \mathcal{F}$ | Bidirectional channels and directed flows |
| $\text{IsConjugateFlow}(f,f')$ | Symmetric conjugate flow predicate |
| $\text{endpoints}(x)$ | Boundary port endpoints of contract $x$ |
| $``\mathcal{D}_{\text{sink}}, C_{\text{max\_errors}}``$ | Diagnostic sink and capacity threshold |
| $``\Delta_e, \text{OID}_{\text{DEAP}}``$ | UUIDv5 anchor and root namespace |

## 3. Computational Complexity & Algorithmic Bounds

- **Complexity Class:** Class $\mathbf{P}$ (Deterministic Polynomial Time).
- **Asymptotic Bound:** $O(N^2 \cdot |\text{Interconnects}|)$ topological validation for $N = |\mathcal{S}|$ and $|\text{Interconnects}| = |\mathcal{C}| + |\mathcal{F}|$. Checks run in $O(N^2 + |\mathcal{C}| + |\mathcal{F}|)$. Work-stealing scales as $``O((N^2 \cdot |\text{Interconnects}|)/N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$. Space is $O(N^2 + |\mathcal{C}| + |\mathcal{F}|)$.
- **Tractable Subclass & Frontier:** N/A (Deterministic P). Evaluates static incidence, bypassing NP-1 through NP-8.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Canonical Matrix Symmetry & Antisymmetry
- **Given:** Model `Package_0` with `Interconnect_1` in $``M_{\alpha\beta}, M_{\beta\alpha}``$ and flow `Flow_0` in $``M_{\alpha\beta}``$.
- **When:** Matrix symmetry validation executes.
- **Then:** Symmetry and antisymmetry invariants hold.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: Interconnect Symmetry Rejection
- **Given:** Model `Package_0` with `Interconnect_1` in $``M_{\alpha\beta}``$ omitted from $``M_{\beta\alpha}``$.
- **When:** Transpose symmetry validation executes.
- **Then:** Rejects lowering and emits `E0200`.
- **Diagnostic:** `E0200` on symmetry mismatch.

### AC-03: Flow Antisymmetry Rejection
- **Given:** Model `Package_0` with duplicate `Flow_0` in $``M_{\alpha\beta}, M_{\beta\alpha}``$.
- **When:** Flow antisymmetry validation executes.
- **Then:** Rejects lowering and emits `E0202`.
- **Diagnostic:** `E0202` on antisymmetry breach.

### AC-04: Diagonal Exclusion & Delimiter Recovery
- **Given:** Model `Package_0` with `Interconnect_1` in diagonal cell $``M_{ii}``$ before `;`.
- **When:** Compiler encounters breach and resynchronizes.
- **Then:** Recovers on `;`, halting at $``C_{\text{max\_errors}}``$ with `E0199`.
- **Diagnostic:** `E0200`, `E0199`.
