## 1. Normative Statement

The core metamodel, node arena, and AST graph engine shall provide a deterministic, depth-bounded semantic AST slicing facility (`query_slice`) to extract self-contained subgraphs surrounding a target element for focused reasoning, code generation, and micro-verification within context-isolated subagent environments.

---

## 2. Formal Invariant

Let AST multigraph $`G = (V, E)`$ have node handles $``V \subset \mathbb{U}_{32}``$. The symmetric projection $``G_{\text{sym}} = (V, E_{\text{sym}})``$ is defined as:

```math
E_{\text{sym}} = \{ \{u, v\} \mid \exists \kappa : (u, v, \kappa) \in E \;\lor\; (v, u, \kappa) \in E \}
```

The metric neighborhood $``\mathcal{B}_k(n_{\text{target}})``$ and transitive dependency set $`\text{Ref}(v)`$ evaluate:

```math
\begin{aligned}
\mathcal{B}_k(n_{\text{target}}) &= \{ v \in V \mid \text{dist}_{G}(n_{\text{target}}, v) \le k \} \\
\text{Ref}(v) &= \{ w \in V \mid \exists (v, w, \kappa) \in E : \kappa \in \{ \text{Typing}, \text{Subtyping}, \text{Constraint} \} \}
\end{aligned}
```

The sliced subgraph $``G_{\text{slice}} = (V_{\text{slice}}, E_{\text{slice}})``$ is the least fixed point:

```math
\begin{aligned}
V_{\text{slice}} &= \mathcal{B}_k(n_{\text{target}}) \cup \bigcup_{v \in V_{\text{slice}}} \text{Ref}(v) \\
E_{\text{slice}} &= \{ (u, v, \kappa) \in E \mid u \in V_{\text{slice}} \;\wedge\; v \in V_{\text{slice}} \}
\end{aligned}
```

Semantic Closure, Boundary Stub Port, and Token Invariants:

```math
\begin{aligned}
\forall v \in V_{\text{slice}}, \; \text{Ref}(v) \subseteq V_{\text{slice}} &\implies \text{UnresolvedSymbols}(G_{\text{slice}}) = \emptyset \\
(u \in V_{\text{slice}} \;\wedge\; v \notin V_{\text{slice}} \;\wedge\; (u, v, \text{Conn}) \in E) &\implies \exists v_{\text{stub}} \in V_{\text{slice}} : \tau_V(v_{\text{stub}}) = \tau_V(v) \\
|\text{Tokens}(\text{Slice}(n_{\text{target}}, k))| &\le 0.15 \cdot |\text{Tokens}(\mathcal{A})| \quad (k \le 3)
\end{aligned}
```

Deterministic Identity and Diagnostic Invariants:

```math
\begin{aligned}
\forall v \in V_{\text{slice}}, \quad \text{UUID}(v) &= \text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(v)) \\
(\neg\text{ValidHandle}(n_{\text{target}}) \;\lor\; k \le 0 \;\lor\; k \gt k_{\text{max}}) &\implies \text{Diagnostic}(n_{\text{target}}, \text{E0200}) \in \mathcal{D}_{\text{sink}} \\
|\mathcal{D}_{\text{sink}}| \ge C_{\text{max\_errors}} &\implies \exists D \in \mathcal{D}_{\text{sink}} : \text{Code}(D) = \text{E0199}
\end{aligned}
```

## 3. Computational Complexity & Algorithmic Bounds

Context-bounded AST slice extraction executes strictly within Complexity Class $`\mathbf{P}`$:
- **Target Handle Dereferencing**: Generational validation executes in strict $`O(1)`$ constant time with zero heap allocations.
- **Bounded Breadth-First Search**: For ball vertex count $``V_k = |\mathcal{B}_k(n_{\text{target}})|``$ and incident edges $``E_k``$, traversal executes in $``O(V_k + E_k)``$ time.
- **Transitive Semantic Closure**: Closure evaluates in $``O(|V_{\text{slice}}|)``$ time via $`O(1)`$ arena lookups per referenced handle.
- **Total Slice Extraction**: Total execution time satisfies $``O(|V_{\text{slice}}| + |E_{\text{slice}}|)``$ with auxiliary space bounded by $``O(|V_{\text{slice}}|)``$ queue and bitset storage.
- **Bounded Work-Stealing Concurrency**: Parallel dispatch across $``N_{\text{max\_workers}}``$ threads scales as $``O((|V_{\text{slice}}| + |E_{\text{slice}}|) / N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$.
- **NP-Frontier Avoidance**: Bounded slicing operates strictly in polynomial time without combinatorial search, avoiding NP-complete subtyping (NP-3) and state reachability (NP-5).

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Depth-Bounded Metric Neighborhood Extraction

- **Given:** A 6-level containment hierarchy (`Package_0` down to `Part_5`) and depth bound $`k = 2`$.
- **When:** `query_slice` targets mid-level entity `Part_2`.
- **Then:** Subgraph contains strictly nodes at distance $``\text{dist}_{G}(n_{\text{target}}, v) \le 2``$; nodes at distance $`d \gt 2`$ without dependencies are excluded.
- **Diagnostic:** `E0200` emitted on traversal violation.

### AC-02: Transitive Semantic Closure and Independent Compilability

- **Given:** `Classifier_Alpha` referencing type `DataType_Sigma` and constraint `Constraint_Alpha` outside metric ball ($`d \gt k`$).
- **When:** `query_slice` is executed on `Classifier_Alpha` and slice is compiled in an isolated subagent context.
- **Then:** `DataType_Sigma` and `Constraint_Alpha` are included in $``V_{\text{slice}}``$, satisfying $``\text{UnresolvedSymbols}(G_{\text{slice}}) = \emptyset``$.
- **Diagnostic:** `E0200` emitted on unresolvable symbol.

### AC-03: Boundary Port Reification and Stub Synthesis

- **Given:** `Port_1` on `Part_0` connected across slice boundary to external `Port_2`.
- **When:** `query_slice` extracts `Part_0` while excluding `Port_2`'s parent classifier.
- **Then:** Boundary stub `Port_Stub` is synthesized preserving direction (`in`, `out`, `inout`) and payload type without including external hierarchies.
- **Diagnostic:** `E0201` emitted on interface signature mismatch.

### AC-04: Token Volume Reduction and Context Isolation

- **Given:** Model $`\mathcal{A}`$ with $`10^4`$ nodes and target `Classifier_Alpha` with depth $`k \le 3`$.
- **When:** Slice $``G_{\text{slice}}``$ is serialized to canonical representation.
- **Then:** Serialized token volume satisfies $``|\text{Tokens}(G_{\text{slice}})| \le 0.15 \cdot |\text{Tokens}(\mathcal{A})|``$.
- **Diagnostic:** `E0200` emitted on token volume violation.
