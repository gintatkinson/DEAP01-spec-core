## 1. Normative Statement

The compiler core metamodel, lexical analyzer, and abstract syntax tree (AST) graph engine shall intern all identifier strings, type names, docstrings, and qualified paths across compilation units into a thread-safe concurrent string interner pool, mapping each distinct string to a 32-bit scalar symbol handle ($`\sigma \in \text{SymbolId}`$, $`\text{sizeof}(\sigma) \le 4\text{ bytes}`$) supporting $`O(1)`$ constant-time scalar equality comparisons.

Slicing and copying string bytes from read-only memory-mapped source file buffers into the deduplicated global symbol interner pool during the initial lexical pass represents the sole permitted architectural exception to the zero-copy memory management invariant, in accordance with Architectural Directive 3 and REQ-0009. All downstream AST nodes, intermediate representations, symbol tables, lexical scope environments, and graph structures shall exclusively store, reference, and pass 32-bit scalar `SymbolId` handles rather than heap-allocated string objects or cloned buffers.

The interner shall provide bijective bidirectional mapping: forward interning ($`\text{intern}(s) \to \sigma`$) mapping UTF-8 slices to unique scalar handles, and reverse resolution ($`\text{resolve}(\sigma) \to \text{str}`$) returning borrowed immutable `&str` slices from contiguous backing storage without heap allocation. Multi-threaded access shall be scheduled on a bounded work-stealing pool with worker ceiling $``N_{\text{max\_workers}}``$ (Architectural Directive 2, REQ-0012) ensuring data-race freedom. The interner shall enforce string length limit $``L_{\text{max\_str}} = 65536\text{ bytes}``$ and capacity bound $``S_{\text{max\_count}} = 2^{32} - 2``$. In accordance with Architectural Directive 5, the interface is a total function: invalid UTF-8 sequences, strings exceeding $``L_{\text{max\_str}}``$, or pool exhaustion shall emit diagnostic `E0200` per REQ-0191 and yield typed sentinel $``\bot_{\text{sym}} = 2^{32} - 1``$ without unhandled panics. All illustrative examples shall strictly use synthetic abstract MBSE placeholders (e.g., `Package_0`, `Classifier_Alpha`, `Port_1`, `Flow_A`, `param_x : Real`).

## 2. Formal Invariant

Let $`\mathcal{S} \subset \Sigma^*`$ represent the set of valid UTF-8 strings bounded by maximum length $``L_{\text{max\_str}}``$, and let $``\text{SymbolId} = \{ \sigma \in \mathbb{N}_0 \mid 0 \le \sigma \lt 2^{32} - 1 \}``$ denote compact scalar handles with reserved sentinel $``\bot_{\text{sym}} = 2^{32} - 1``$. Handle footprint satisfies:

```math
\forall \sigma \in \text{SymbolId} \cup \{ \bot_{\text{sym}} \}, \quad \text{sizeof}(\sigma) \le S_{\max} = 4\text{ bytes}
```

The interner pool $``\mathcal{I} = (\mathcal{M}_{\text{fwd}}, \mathcal{M}_{\text{rev}}, \mathcal{B}_{\text{pool}})``$ defines forward map $``\mathcal{M}_{\text{fwd}} : \mathcal{S} \to \text{SymbolId}``$, reverse map $``\mathcal{M}_{\text{rev}} : \text{SymbolId} \to \mathcal{S}``$, and contiguous backing buffer $``\mathcal{B}_{\text{pool}}``$. Forward interning satisfies:

```math
\text{intern}(\mathcal{I}, s) = \begin{cases} \mathcal{M}_{\text{fwd}}(s), & \text{if } s \in \text{dom}(\mathcal{M}_{\text{fwd}}) \\ \sigma_{\text{new}}, & \text{if } s \in \mathcal{S} \setminus \text{dom}(\mathcal{M}_{\text{fwd}}) \;\wedge\; |\text{dom}(\mathcal{M}_{\text{fwd}})| \lt S_{\text{max\_count}} \\ \bot_{\text{sym}}, & \text{otherwise} \end{cases}
```

Bijective Round-Trip and Scalar Equality Invariants:

```math
\begin{aligned}
\forall s \in \text{dom}(\mathcal{M}_{\text{fwd}}), \quad &\text{resolve}(\mathcal{I}, \text{intern}(\mathcal{I}, s)) = s \\
\forall s_1, s_2 \in \text{dom}(\mathcal{M}_{\text{fwd}}), \quad &s_1 = s_2 \iff \text{intern}(\mathcal{I}, s_1) = \text{intern}(\mathcal{I}, s_2)
\end{aligned}
```

Buffer Allocation Boundary Exception Invariant (Directive 3):

```math
\text{HeapAllocs}(\text{ParsePass}(\mathcal{B}_{\text{file}})) \subseteq \text{Storage}(\text{StringInternerPool})
```

Concurrent Determinism Invariant under Bounded Work-Stealing ($``N_{\text{max\_workers}}``$):

```math
\forall t_a, t_b \in \mathcal{T}_{\text{workers}}, \quad \text{intern}_{t_a}(\mathcal{I}, s) = \text{intern}_{t_b}(\mathcal{I}, s)
```

Diagnostic Code Binding Invariant:

```math
(\neg\text{ValidUTF8}(s) \;\vee\; |s| \gt L_{\text{max\_str}} \;\vee\; |\text{dom}(\mathcal{M}_{\text{fwd}})| \ge S_{\text{max\_count}}) \implies \text{intern}(\mathcal{I}, s) = \bot_{\text{sym}} \;\wedge\; \text{Diagnostic}(s, \text{DiagnosticCode::E0200}) \in \mathcal{D}
```

## 3. Computational Complexity & Algorithmic Bounds

String interning operates in Complexity Class $`\mathbf{P}`$. Initial interning of string $`s`$ takes deterministic $`O(|s|)`$ time to hash and copy bytes into contiguous buffer $``\mathcal{B}_{\text{pool}}``$. Subsequent lookups require $`O(|s|)`$ time for hash computation and expected $`O(1)`$ amortized table probe. Reverse symbol resolution ($`\text{resolve}(\sigma)`$) executes in strict $`O(1)`$ worst-case constant time via array indexing into $``\mathcal{M}_{\text{rev}}``$ with zero heap allocations. Scalar equality comparison ($``\sigma_1 == \sigma_2``$) executes in strict $`O(1)`$ constant time via a single 32-bit register comparison. Total front-end interning across $`N`$ tokens of aggregate byte size $``M = \sum |s_i|``$ is $`O(M)`$. Memory is bounded by $``O(U + N_{\text{tokens}} \cdot S_{\max})``$ where $`U`$ is unique interned byte volume, reducing AST node memory footprint by greater than 60%. String interning requires no combinatorial search, operating outside NP-complete frontiers (NP-1 through NP-8) and ensuring deterministic polynomial execution.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Deduplicated Scalar Handle Assignment & O(1) Equality
- **Given:** Abstract MBSE tokens with repeated identifier strings (`Package_0`, `Classifier_Alpha`, `Port_1`, `Flow_A`, `param_x : Real`).
- **When:** The compiler lexical scanner interns each token into the global symbol interner pool.
- **Then:** Identical strings map to identical 32-bit scalar handles ($``\sigma_a = \sigma_b \iff s_a = s_b``$), handle memory footprint satisfies $`\text{sizeof}(\sigma) \le 4\text{ bytes}`$, and identifier comparisons during type checking execute in $`O(1)`$ constant time via scalar integer equality with zero character iteration.
- **Diagnostic:** `E0200` emitted if duplicate string values receive distinct handles or scalar equality evaluation fails.

### AC-02: Zero-Copy Allocation Boundary Exception
- **Given:** A memory-mapped source file buffer $``\mathcal{B}_{\text{file}}``$ ingested during `ParsePass`.
- **When:** The compiler profiles dynamic heap allocations during lexical analysis and AST construction.
- **Then:** Dynamic heap allocations during parsing are strictly confined to the symbol interner pool ($``\text{HeapAllocs}(\text{ParsePass}(\mathcal{B}_{\text{file}})) \subseteq \text{Storage}(\text{StringInternerPool})``$), while all AST nodes reside in bump arenas or borrow slices from $``\mathcal{B}_{\text{file}}``$.
- **Diagnostic:** `E0200` emitted if unauthorized heap string allocations occur outside the interner pool during parsing.

### AC-03: Bijective Inversion & Thread-Safe Bounded Concurrency
- **Given:** Worker threads ($``T \le N_{\text{max\_workers}}``$) scheduled on the bounded work-stealing pool processing disjoint AST units with overlapping synthetic identifiers.
- **When:** Threads concurrently intern strings and perform bidirectional resolution.
- **Then:** For all interned strings, $`\text{resolve}(\text{intern}(s)) = s`$ and $`\text{intern}(\text{resolve}(\sigma)) = \sigma`$ without data races, deadlocks, or handle divergence across threads ($``\text{intern}_{t_a}(s) = \text{intern}_{t_b}(s)``$).
- **Diagnostic:** `E0200` emitted if round-trip resolution diverges or concurrent race conditions produce inconsistent handles.

### AC-04: Total Function Sentinel Diagnostics & Release Performance
- **Given:** Pathological inputs (invalid UTF-8 bytes, strings exceeding $``L_{\text{max\_str}} = 65536\text{ bytes}``$, or pool capacity exhaustion), and Release mode (`--release`) benchmark harnesses.
- **When:** The compiler interns malformed inputs or executes $`10^6`$ token benchmarks.
- **Then:** Pathological inputs yield sentinel $``\bot_{\text{sym}} = 2^{32} - 1``$ and emit diagnostic `E0200` without panicking; release benchmarking achieves throughput exceeding $`5 \times 10^6\text{ tokens/s}`$, reverse resolution latency under $`20\text{ ns}`$, execution latency under 25 ms, and greater than 60% AST memory reduction.
- **Diagnostic:** `E0200` emitted on invalid encoding, length overflow, pool exhaustion, or benchmark gate violation.
