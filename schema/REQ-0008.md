## 1. Normative Statement

The compiler platform shall establish and maintain the unified, multi-file SysML v2 / KerML Abstract Syntax Tree (AST) synthesized from modular schemas in the `schema/` directory as the sovereign Single Source of Truth (SSOT) for all architectural structures, interfaces, and constraints across the compilation lifecycle. Downstream representations--including Epics, Features, Interface Control Documents (ICDs), simulation models, and target source code--shall function strictly as deterministic, pure mathematical projections of this authoritative AST. Downstream artifacts are prohibited from acting as independent sources of truth or introducing unauthorized architectural mutations.

Every entity within the central AST model shall be deterministically anchored by an RFC 4122 UUIDv5 identifier computed from fixed compiler namespace OID $``\text{NS}_{\text{DEAP}}``$ and the entity's fully qualified topological path. When downstream artifacts are parsed or evaluated during compilation or synchronization passes, automated bidirectional reconciliation gates shall compare on-disk artifacts against authoritative AST projections. If structural discrepancy or uncoordinated modification is detected, the central AST model unconditionally governs. If irreconcilable structural divergence or downstream entity invention occurs without corresponding upstream schema modification, the compiler shall halt execution and emit diagnostic error code `E0100` detailing the offending artifact path, diverging node identifier, expected AST projection digest, and observed downstream content.

## 2. Formal Invariant

Let $``\mathcal{S} = \{ s_1, \dots, s_M \}``$ denote the set of modular schema input units in `schema/`. Let $``\mathcal{A}_{\text{SSOT}} = (V, E, \mu)``$ denote the resolved sovereign root AST multigraph synthesized from $`\mathcal{S}`$, where $`V`$ represents metamodel AST node handles, $`E`$ directed relationship edges, and $`\mu : V \to \mathcal{T}`$ node metamodel definitions.

For each node $`v \in V`$, let $``\text{path}(v) = \langle p_1, \dots, p_d \rangle``$ denote its fully qualified topological path, and let $``\text{NS}_{\text{DEAP}} \in \{0, 1\}^{128}``$ denote the fixed RFC 4122 namespace UUID. Each node possesses an immutable topological anchor:

```math
\text{Anchor}(v) = \text{UUIDv5}(\text{NS}_{\text{DEAP}}, \text{path}(v))
```

where RFC 4122 version and variant bits satisfy $``(u_6 \land 0\text{xF0}) = 0\text{x50}``$ and $``(u_8 \land 0\text{xC0}) = 0\text{x80}``$.

Let $``\mathcal{D}_{\text{downstream}} = \{ D_1, \dots, D_K \}``$ denote downstream specification artifacts, documentation projections, and generated target code representations. For each artifact category $`k \in \{1, \dots, K\}`$, a deterministic projection mapping $``\psi_k``$ emits byte stream $`\mathcal{B}^* = \{0, 1\}^*`$:

```math
D_k = \psi_k(\mathcal{A}_{\text{SSOT}})
```

Let $``D_k^{\text{disk}} \in \mathcal{B}^*``$ denote observed on-disk artifact content. The compiler enforces the Anti-Drift Invariant:

```math
\text{Drift}(D_k) \iff D_k^{\text{disk}} \neq \psi_k(\mathcal{A}_{\text{SSOT}})
```

Authoritative Reconciliation Gate:

```math
\forall D_k \in \mathcal{D}_{\text{downstream}}, \quad \text{Reconcile}(D_k^{\text{disk}}, \mathcal{A}_{\text{SSOT}}) = \begin{cases} \text{Valid}, & \text{if } D_k^{\text{disk}} = \psi_k(\mathcal{A}_{\text{SSOT}}) \\ \text{Conflict}, & \text{if } D_k^{\text{disk}} \neq \psi_k(\mathcal{A}_{\text{SSOT}}) \end{cases}
```

Let $``\mathcal{F}_{\text{arch}} : \mathcal{B}^* \to \mathcal{P}(V)``$ be the semantic extraction operator recovering MBSE structural entities from an artifact byte stream. The Downstream Non-Invention Invariant mandates:

```math
\begin{aligned}
\forall D_k^{\text{disk}}, \quad \mathcal{F}_{\text{arch}}(D_k^{\text{disk}}) &\subseteq V(\mathcal{A}_{\text{SSOT}}) \\
\mathcal{F}_{\text{arch}}(D_k^{\text{disk}}) \setminus V(\mathcal{A}_{\text{SSOT}}) &= \emptyset
\end{aligned}
```

Merkle Root Cryptographic Determinism: for SHA-256 digest function $`\mathcal{H}`$, the sovereign AST Merkle root $``\mathcal{M}(\mathcal{A}_{\text{SSOT}})``$ deterministically governs all projected artifact digests:

```math
\mathcal{M}(\mathcal{A}_{\text{SSOT}}^{(1)}) = \mathcal{M}(\mathcal{A}_{\text{SSOT}}^{(2)}) \implies \forall k, \quad \mathcal{H}(\psi_k(\mathcal{A}_{\text{SSOT}}^{(1)})) = \mathcal{H}(\psi_k(\mathcal{A}_{\text{SSOT}}^{(2)}))
```

## 3. Computational Complexity & Algorithmic Bounds

The SSOT multi-file AST resolution and projection pipeline operates strictly within Complexity Class $`\mathbf{P}`$. Unified AST synthesis $``\mathcal{A}_{\text{SSOT}}``$ across $`M`$ schema files with $`N`$ total tokens executes in deterministic linear time $`O(N)`$ with multigraph linking bounded by $`O(|V| + |E|)`$. Each downstream projection $``\psi_k``$ traverses relevant subgraphs in $``O(|V_k| + |E_k|)``$ time, bounded across all $`K`$ targets by $`O(K \cdot (|V| + |E|))`$. On-disk drift verification across total byte size $``B = \sum_{k=1}^K |D_k^{\text{disk}}|``$ executes in linear time $`O(B)`$ via streaming SHA-256 hashing. Auxiliary memory consumption is strictly bounded by $`O(N + |V| + |E|)`$ for contiguous AST storage, symbol interner pools, and projection buffers.

NP Frontier Context: While invariant contract satisfiability over general logical theories is NP-complete or undecidable (Algorithmic Bound NP-8), downstream SSOT projection and anti-drift evaluation execute as deterministic acyclic multigraph traversals without backtracking or combinatorial search, guaranteeing polynomial-time execution.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Sovereign Multi-File AST Synthesis and Unification
- **Given:** Modular schema input files $`\mathcal{S}`$ in `schema/` declaring interdependent packages (`Package_0`, `Package_1`) and classifiers (`Classifier_Alpha`, `Classifier_Beta`).
- **When:** The compiler front-end executes schema ingestion and multi-file AST unification.
- **Then:** Synthesizes sovereign root AST $``\mathcal{A}_{\text{SSOT}} = (V, E, \mu)``$ with all node handles deterministically anchored via RFC 4122 UUIDv5 hashing from $``\text{NS}_{\text{DEAP}}``$ and topological paths.
- **Diagnostic:** `E0100` emitted on schema parse failure, duplicate anchor generation, or ungrounded node handles.

### AC-02: Deterministic Downstream Projection Parity
- **Given:** Resolved sovereign AST $``\mathcal{A}_{\text{SSOT}}``$ and projection mapping $``\psi_k``$ for downstream artifact $``D_k``$ (e.g., ICD tables or target code).
- **When:** Projection generator $``\psi_k(\mathcal{A}_{\text{SSOT}})``$ executes across repeated invocations or varied host environments.
- **Then:** Emitted byte streams satisfy $``D_k = \psi_k(\mathcal{A}_{\text{SSOT}})``$ with 0-byte diff churn and identical SHA-256 digests.
- **Diagnostic:** `E0100` emitted if output streams diverge across repeated compilations of an identical AST.

### AC-03: Bidirectional Reconciliation and Anti-Drift Primacy
- **Given:** Downstream artifact $``D_k^{\text{disk}}``$ containing uncoordinated modifications (e.g., manual alteration of `Port_1` or unmapped attribute `param_x : Real`).
- **When:** The compiler reconciliation gate evaluates $``\text{Reconcile}(D_k^{\text{disk}}, \mathcal{A}_{\text{SSOT}})``$.
- **Then:** Detects drift ($``D_k^{\text{disk}} \neq \psi_k(\mathcal{A}_{\text{SSOT}})``$), enforces AST primacy, halts compilation, and rejects downstream mutation.
- **Diagnostic:** `E0100` emitted citing artifact path, byte offsets, divergent symbol, and expected AST digest.

### AC-04: Downstream Non-Invention Enforcement
- **Given:** Downstream artifact $``D_k^{\text{disk}}``$ evaluated during reverse-synchronization or ingestion passes.
- **When:** Extraction operator $``\mathcal{F}_{\text{arch}}(D_k^{\text{disk}})``$ parses structural elements.
- **Then:** Confirms $``\mathcal{F}_{\text{arch}}(D_k^{\text{disk}}) \subseteq V(\mathcal{A}_{\text{SSOT}})``$ and $``\mathcal{F}_{\text{arch}}(D_k^{\text{disk}}) \setminus V(\mathcal{A}_{\text{SSOT}}) = \emptyset``$, rejecting invented classifiers or ports.
- **Diagnostic:** `E0100` emitted if downstream content introduces structural elements absent from $``\mathcal{A}_{\text{SSOT}}``$.
