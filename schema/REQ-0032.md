## 1. Normative Statement

The textual emission and model serialization engine shall sort all model declarations--packages, classifiers, ports, attributes, connections, constraints, and behaviors--strictly by canonical fully qualified name prior to canonical model emission (`schema/model.sysml`, REQ-0031) and serialized artifact generation (REQ-0044, REQ-0145, REQ-0178).

The canonical fully qualified name $`\text{QName}(d)`$ shall concatenate ancestor namespace identifiers separated by `::`, rooted at the top-level compilation unit (e.g., `Package_0::Classifier_Alpha::Port_1`), using sanitized ASCII identifiers (REQ-0019). Sibling declarations in each scope shall be sorted by lexicographical ASCII byte ordering ($``\prec_{\text{lex}}``$). If declarations share an identical qualified name but distinct metaclasses, sorting shall order them deterministically by metaclass ordinal $`\text{KindOrdinal}(\tau(d))`$.

Duplicate declarations possessing identical qualified names and metaclasses within the same scope shall trigger diagnostic `E0102`. Under Synchronization Token Error Recovery, the engine shall log `E0102`, substitute sentinel $``\bot_{\text{sym}}``$, and resume sorting remaining symbols. If accumulated diagnostics reach capacity $``C_{\text{max\_errors}}``$, the engine shall emit `E0199` and terminate.

## 2. Formal Invariant

Let $`\mathcal{D}`$ denote the set of AST declarations. Each declaration $`d \in \mathcal{D}`$ is formalized as:

```math
d = \langle \text{id}, \text{parent}, \tau \rangle \in \mathcal{S}_{\text{sym}} \times (\mathcal{D} \cup \{ \bot \}) \times \mathcal{T}_{\text{kind}}
```

The canonical fully qualified name function $`\text{QName} : \mathcal{D} \to \Sigma^*`$ is defined recursively:

```math
\text{QName}(d) = \begin{cases} \text{id}(d), & \text{if } \text{parent}(d) = \bot \\ \text{QName}(\text{parent}(d)) \mathbin{\Vert} \text{"::"} \mathbin{\Vert} \text{id}(d), & \text{otherwise} \end{cases}
```

Let $``s_1, s_2 \in \Sigma^*``$ be ASCII byte sequences. Lexicographical byte precedence $``\prec_{\text{lex}}``$ satisfies:

```math
s_1 \prec_{\text{lex}} s_2 \iff \exists i \ge 0 : (i \le \min(|s_1|, |s_2|)) \wedge (\forall j \lt i, s_1[j] = s_2[j]) \wedge \big((i \lt \min(|s_1|, |s_2|) \implies s_1[i] \lt s_2[i]) \vee (i = |s_1| \lt |s_2|)\big)
```

The canonical declaration ordering relation $``\prec_{\text{sym}}``$ over $`\mathcal{D} \times \mathcal{D}`$ is:

```math
d_1 \prec_{\text{sym}} d_2 \iff (\text{QName}(d_1) \prec_{\text{lex}} \text{QName}(d_2)) \vee \big(\text{QName}(d_1) = \text{QName}(d_2) \wedge \text{KindOrdinal}(\tau(d_1)) \lt \text{KindOrdinal}(\tau(d_2))\big)
```

Strict Total Ordering Invariant over collision-free declarations:

```math
\forall d_1 \ne d_2 \in \mathcal{D}_{\text{valid}}, \quad (d_1 \prec_{\text{sym}} d_2) \oplus (d_2 \prec_{\text{sym}} d_1)
```

Zero Diff Churn & Determinism across permutations $`\Pi(\mathcal{A})`$ and schedules $``\sigma_1, \sigma_2``$ on $``N_{\text{max\_workers}}``$ threads:

```math
\forall \mathcal{A}_1, \mathcal{A}_2 \in \Pi(\mathcal{A}), \forall \sigma_1, \sigma_2: \quad \mathcal{E}(\mathcal{A}_1; \sigma_1) = \mathcal{E}(\mathcal{A}_2; \sigma_2) \wedge \text{SHA256}(\mathcal{E}(\mathcal{A}_1; \sigma_1)) = \text{SHA256}(\mathcal{E}(\mathcal{A}_2; \sigma_2))
```

Diagnostic Code Binding Invariants:

```math
\begin{aligned}
(\exists d_1 \ne d_2 : \text{QName}(d_1) = \text{QName}(d_2) \wedge \tau(d_1) = \tau(d_2)) &\implies \text{Diagnostic}(d_2, \text{DiagnosticCode::E0102}) \in \mathcal{D}_{\text{diag}} \\
\text{SHA256}(\mathcal{E}(\mathcal{A}_1)) \ne \text{SHA256}(\mathcal{E}(\mathcal{A}_2)) &\implies \text{Diagnostic}(\text{span}_{\text{root}}, \text{DiagnosticCode::E0100}) \in \mathcal{D}_{\text{diag}} \\
|\mathcal{D}_{\text{diag}}| \ge C_{\text{max\_errors}} &\implies \exists D_{\text{term}} \in \mathcal{D}_{\text{diag}} : \text{code}(D_{\text{term}}) = \text{DiagnosticCode::E0199}
\end{aligned}
```

## 3. Computational Complexity & Algorithmic Bounds

The deterministic qualified-name symbol sorting and emission engine operates in Complexity Class $`\mathbf{P}`$.

Let $`M = |\mathcal{D}|`$ denote total declarations across $`K`$ parent scopes, with scope $`j`$ containing $``m_j``$ declarations ($``\sum_{j=1}^K m_j = M``$). Let $`L`$ denote maximum qualified name length ($`L \le 1024`$ bytes). Comparing two qualified name strings requires $`O(L)`$ byte operations. Sorting declarations within scope $`j`$ via comparison sort requires $``O(L \cdot m_j \log m_j)``$ operations. Summed across all scopes:

```math
\sum_{j=1}^{K} O(L \cdot m_j \log m_j) \le O(L \cdot M \log M)
```

Because $`L`$ is bounded by a fixed constant, sequential sorting runtime is strictly $`O(M \log M)`$., parallel sorting across independent package subtrees executes in $``O((M \log M) / N_{\text{max\_workers}} + M_{\text{root}} \log M_{\text{root}})``$ wall-clock time. Space complexity is $`O(M)`$ for declaration handle vectors in model memory with zero redundant string cloning.

NP frontier reference: As a deterministic sorting transformation, the algorithm operates strictly in polynomial time $`\mathbf{P}`$, bypassing combinatorial NP-hard scheduling frontiers (NP-7, REQ-0180).

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Permutation Invariance and Zero Diff Churn
- **Given:** AST with 500 declarations across packages, classifiers, ports, and attributes in arbitrary order.
- **When:** Sorting symbols by qualified name and emitting canonical SysML v2 text across 20 randomized orderings.
- **Then:** All 20 emitted output byte streams produce identical SHA-256 digests, confirming zero diff churn ($`\text{Diff} = \emptyset`$).
- **Diagnostic:** `E0100` on bitwise determinism mismatch.

### AC-02: Hierarchical Scope Qualified Name Ordering
- **Given:** Nested AST elements (`Package_B::Classifier_1`, `Package_A::Subsystem_1::Classifier_Alpha`, `Package_A::Classifier_Beta`).
- **When:** Sorting declarations prior to canonical emission.
- **Then:** Emits top-level packages alphabetically (`Package_A` before `Package_B`), and inside `Package_A`, orders members alphabetically (`Package_A::Classifier_Beta` before `Package_A::Subsystem_1`).
- **Diagnostic:** `E0100` on scope ordering inversion.

### AC-03: Lexicographical ASCII Byte Order and Case Precedence
- **Given:** Sibling declarations named `Classifier_1`, `Classifier_10`, `Classifier_2`, `Classifier_Alpha`, `Classifier_alpha`.
- **When:** Applying qualified-name symbol sorting.
- **Then:** Sorts strictly by ASCII byte value (`Classifier_1` $``\prec_{\text{lex}}``$ `Classifier_10` $``\prec_{\text{lex}}``$ `Classifier_2` $``\prec_{\text{lex}}``$ `Classifier_Alpha` $``\prec_{\text{lex}}``$ `Classifier_alpha`).
- **Diagnostic:** `E0100` on collation order mismatch.

### AC-04: Duplicate Qualified Name Collision Recovery
- **Given:** AST containing two distinct classifier declarations with identical qualified name `Package_0::Classifier_Alpha` and identical metaclass in the same scope.
- **When:** Executing symbol sorting and verification.
- **Then:** Detects symbol collision, records diagnostic `E0102`, substitutes sentinel $``\bot_{\text{sym}}``$, and resumes sorting remaining declarations.
- **Diagnostic:** `E0102` on duplicate symbol declaration collision.
