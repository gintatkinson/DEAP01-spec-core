## 1. Normative Statement

The Core Metamodel, Node Arena & AST Graph Engine shall provide deterministic, bidirectional, lossless serialization and deserialization of compiled Abstract Syntax Trees (AST) to and from minified JSON (RFC 8259) and binary CBOR (RFC 8949). Codecs must preserve all AST structural entities: packages, part definitions, port definitions, item definitions, connection definitions, action definitions, constraint definitions, attributes, expressions, multiplicity intervals, relational edges, port directions (`in`, `out`, `inout`), conjugation flags, and exact source spans $``\langle \text{file\_id}, p_{\text{start}}, p_{\text{end}}, \text{line}, \text{col} \rangle``$ per REQ-0002.

Per Directive 1 and REQ-0010, every serialized AST node must store a deterministic RFC 4122 UUIDv5 identifier derived from compiler namespace constant $``\text{NS}_{\text{DEAP}}``$ and canonical topological path; time-based UUIDs are prohibited. AST nodes shall be reconstructed directly into contiguous bump arena storage per REQ-0009 and REQ-0034 using typed generational node handles per REQ-0035 without pointer swizzling. Centralized string deduplication must be enforced; copying string bytes into the global symbol interner pool during deserialization is the sole permitted exception to zero-copy memory management per Directive 3 and REQ-0036.

Serialized binary CBOR payload size must satisfy $`|\text{CBOR}(\mathcal{A})| \le 0.40 \cdot |\text{JSON}(\mathcal{A})|`$ for models where $`|\text{Nodes}(\mathcal{A})| \ge 100`$. Round trips must preserve structural isomorphism ($`\mathcal{D}(\mathcal{S}(\mathcal{A})) \cong \mathcal{A}`$) and bitwise idempotency ($`\mathcal{S}(\mathcal{D}(\mathcal{S}(\mathcal{A}))) = \mathcal{S}(\mathcal{A})`$), enforcing zero diff churn per REQ-0003.

Per Directive 4, REQ-0013, and REQ-0016, deserialization shall implement synchronization token recovery on record boundaries: malformed payload bytes or truncated streams record diagnostic error code `E0200` per REQ-0191 and continue parsing, emitting `E0199` if accumulated diagnostics reach $``C_{\text{max\_errors}}``$. Per Directive 5, REQ-0011, and REQ-0196, the engine enforces a non-panicking execution contract; in compiled Release mode (`--release`), CBOR deserialization of a 100,000-node model must complete in under 15 ms with total latency under 25 ms and peak RSS memory under 100 MB. All fixtures, diagnostics, and models shall exclusively use synthetic abstract placeholders (`Package_0`, `Classifier_Alpha`, `Port_1`, `Flow_A`, `param_x : Real`).

## 2. Formal Invariant

Let $``\mathcal{A} = (\mathcal{V}, \mathcal{E}, \mathcal{T}_{\text{sym}})``$ denote a compiled AST model with arena nodes $`\mathcal{V}`$, relational edges $`\mathcal{E}`$, and string symbol table $``\mathcal{T}_{\text{sym}}``$. Let $``\mathcal{S}_{\mathcal{F}}``$ and $``\mathcal{D}_{\mathcal{F}}``$ denote serialization and deserialization operators for $`\mathcal{F} \in \{ \text{JSON}, \text{CBOR} \}`$.

Round-Trip Structural Isomorphism:

```math
\forall \mathcal{F} \in \{ \text{JSON}, \text{CBOR} \}, \quad \mathcal{D}_{\mathcal{F}}(\mathcal{S}_{\mathcal{F}}(\mathcal{A})) \cong \mathcal{A}
```

Element-Wise Preservation Invariant:

```math
\forall n \in \mathcal{V}, \quad \text{Deref}(\mathcal{D}_{\mathcal{F}}(\mathcal{S}_{\mathcal{F}}(n))) \equiv n
```

where node properties satisfy:

```math
\begin{aligned}
\text{UUID}(n) &= \text{UUIDv5}(\text{NS}_{\text{DEAP}}, \text{FQN}(n)) \\
\text{Span}(n) &= \langle \text{file\_id}, p_{\text{start}}, p_{\text{end}}, \text{line}, \text{col} \rangle
\end{aligned}
```

Bitwise Serialization Idempotency:

```math
\forall \mathcal{F} \in \{ \text{JSON}, \text{CBOR} \}, \quad \mathcal{S}_{\mathcal{F}}(\mathcal{D}_{\mathcal{F}}(\mathcal{S}_{\mathcal{F}}(\mathcal{A}))) = \mathcal{S}_{\mathcal{F}}(\mathcal{A})
```

CBOR Binary Compaction Bound:

```math
|\mathcal{V}| \ge 100 \implies |\mathcal{S}_{\text{CBOR}}(\mathcal{A})| \le 0.40 \cdot |\mathcal{S}_{\text{JSON}}(\mathcal{A})|
```

Diagnostic Code Binding Invariant:

```math
\begin{aligned}
\text{MalformedPayload}(\mathcal{B}) &\implies \text{Diagnostic}(p_{\text{byte}}, \text{E0200}) \in \mathcal{D}_{\text{sink}} \\
\neg(\mathcal{D}_{\mathcal{F}}(\mathcal{S}_{\mathcal{F}}(\mathcal{A})) \cong \mathcal{A}) &\implies \text{Diagnostic}(p_{\text{byte}}, \text{E0200}) \in \mathcal{D}_{\text{sink}} \\
|\mathcal{D}_{\text{sink}}| \ge C_{\text{max\_errors}} &\implies \text{Diagnostic}(p_{\text{byte}}, \text{E0199}) \in \mathcal{D}_{\text{sink}}
\end{aligned}
```

## 3. Computational Complexity & Algorithmic Bounds

The serialization and deserialization engine operates within Complexity Class $`\mathbf{P}`$. Traversing $`N = |\mathcal{V}|`$ nodes, $`E = |\mathcal{E}|`$ edges, and $``M = |\mathcal{T}_{\text{sym}}|``$ interned symbols executes in deterministic linear time $`O(N + E + M) = O(N)`$. Reconstructing node slots into contiguous bump arena storage takes $`O(1)`$ amortized time per node, and symbol interning requires $`O(1)`$ amortized time per string, yielding total deserialization complexity $`O(|\mathcal{B}|) = O(N)`$ for input byte stream $`\mathcal{B}`$. In compiled Release mode, CBOR deserialization of a 100,000-node model completes in under 15 ms. The operations operate outside NP-hard frontiers (e.g., NP-1 through NP-8) without combinatorial search or backtracking. Auxiliary space is bounded by $`O(N)`$ for serialization byte buffers and $`O(1)`$ stack space.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Bidirectional Structural Round-Trip Isomorphism & Dereference Equality
- **Given:** A compiled model AST $`\mathcal{A}`$ containing abstract MBSE entities (`Package_0`, `Classifier_Alpha`, `Port_1`, `Flow_A`, `param_x : Real`).
- **When:** The compiler serializes $`\mathcal{A}`$ to minified JSON or binary CBOR and deserializes back into AST $``\mathcal{A}' = \mathcal{D}_{\mathcal{F}}(\mathcal{S}_{\mathcal{F}}(\mathcal{A}))``$.
- **Then:** Reconstructed AST satisfies $`\mathcal{A}' \cong \mathcal{A}`$ and $``\forall n \in \mathcal{V}, \text{Deref}(\mathcal{D}_{\mathcal{F}}(\mathcal{S}_{\mathcal{F}}(n))) \equiv n``$, preserving node count, hierarchy, edge targets, span coordinates, node flags, and RFC 4122 UUIDv5 hashes.
- **Diagnostic:** `E0200` emitted on structural discrepancy, attribute divergence, or span mismatch between $`\mathcal{A}`$ and $`\mathcal{A}'`$.

### AC-02: CBOR Binary Compaction Bound
- **Given:** A compiled AST model $`\mathcal{A}`$ comprising $`|\mathcal{V}| \ge 100`$ nodes.
- **When:** The AST is serialized to canonical minified JSON and canonical binary CBOR.
- **Then:** Serialized byte sizes satisfy $``|\mathcal{S}_{\text{CBOR}}(\mathcal{A})| \le 0.40 \cdot |\mathcal{S}_{\text{JSON}}(\mathcal{A})|``$, achieving at least a 60% compaction gain.
- **Diagnostic:** `E0200` emitted if the emitted CBOR artifact exceeds 40% of the minified JSON byte size.

### AC-03: String Interner Symbol Deduplication & Idempotency
- **Given:** An AST containing $`K`$ node instances referencing $`M`$ unique identifier strings ($`M \ll K`$).
- **When:** The model undergoes successive serialize-deserialize-serialize cycles.
- **Then:** Serialized payloads store a centralized table of exactly $`M`$ deduplicated strings, deserialization interns symbols without duplication per Directive 3, and successive serialization streams $``\mathcal{B}_1 = \mathcal{B}_2``$ exhibit zero diff churn per REQ-0003.
- **Diagnostic:** `E0200` emitted on symbol duplication or bitwise divergence across serialize-deserialize cycles.

### AC-04: Error Recovery, Diagnostic Binding & Performance Gates
- **Given:** Serialized payload inputs containing malformed byte tokens at offset $``p_{\text{byte}}``$, or a 100,000-node AST evaluated in compiled Release mode (`--release`).
- **When:** Deserialization evaluates malformed streams or executes performance benchmark harnesses.
- **Then:** Per Directive 4, the deserializer resynchronizes on record boundaries, emitting structured diagnostic `E0200` (or `E0199` on sink exhaustion); per Directive 5 and REQ-0196, 100,000-node CBOR deserialization latency is $`\le 15`$ ms, serialization is $`\le 25`$ ms, and RSS memory is $`\le 100`$ MB with zero panics.
- **Diagnostic:** `E0200` emitted for malformed stream tokens, panics, or benchmark latency and memory limit violations.
