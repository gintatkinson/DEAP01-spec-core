## 2. Formal Invariant

File persistence operations and inode preservation satisfy:

```math
\begin{aligned}
\forall p\in\mathcal{P},\quad\Phi_{\text{persist}}(p,B)&=\begin{cases}
\text{OpenFile}(p,\text{O\_WRONLY}\mid\text{O\_TRUNC}).\text{write}(B),&\text{if }\text{FileExists}(p) \\
\text{OpenFile}(p,\text{O\_WRONLY}\mid\text{O\_CREAT}\mid\text{O\_EXCL}).\text{write}(B),&\text{if }\neg\text{FileExists}(p)
\end{cases} \\
\text{FileExists}(p)&\implies\text{inode}(p,t+1)=\text{inode}(p,t)\land\text{inode}(\text{dir}(p),t+1)=\text{inode}(\text{dir}(p),t) \\
\text{LockMode}(\text{dir}(p),\text{InPlace})&=\text{SharedRead},\quad\text{DirectoryLockContention}(\text{InPlaceWrite})\equiv 0 \\
\forall j\ne k,\quad\mathcal{P}_j\cap\mathcal{P}_k&=\emptyset\implies\text{WriteLockSet}(W_j)\cap\text{WriteLockSet}(W_k)=\emptyset \\
\text{PostWriteValid}(p,B)&\iff(\text{size}(\text{inode}(p))=|B|)\land(\text{XXH3}_{64}(\text{Disk}(p))=\text{XXH3}_{64}(B)) \\
\neg\text{IsConfinablePath}(p)&\implies\text{Diagnostic}(p,\text{E0300})\in\mathcal{D}_{\text{sink}}\land p\gets\bot_{\text{io}} \\
(\neg\text{PostWriteValid}(p,B)\lor\text{IOError}(p))&\implies\text{Diagnostic}(p,\text{E0515})\in\mathcal{D}_{\text{sink}}\land p\gets\bot_{\text{io}} \\
|\mathcal{D}_{\text{sink}}| \ge C_{\text{max\_errors}}&\implies\text{Diagnostic}(\text{E0199})\in\mathcal{D}_{\text{sink}} \\
\Delta_{\text{persist}}(p)&=\text{UUIDv5}(\text{OID}_{\text{DEAP}},\text{FQN}(A)\mathbin{\Vert}\text{"::FilePersistence::"}\mathbin{\Vert} p)
\end{aligned}
```

| Symbol / Term | Domain / Formal Definition |
| :--- | :--- |
| $``\Phi_{\text{persist}}(p, B), \text{dir}(p)``$ | Persistence operator, parent directory |
| $``\text{inode}(p, t), \text{WriteLockSet}(W_j)``$ | Inode number, exclusive lock set |
| $``\mathcal{P}_j, W_j``$ | Disjoint paths, worker thread $j$ |
| $\text{PostWriteValid}(p, B)$ | Size equality, XXH3 predicate |
| $``\bot_{\text{io}}, \mathcal{D}_{\text{sink}}, C_{\text{max\_errors}}``$ | Fault sentinel, sink, error limit |
| $``\Delta_{\text{persist}}(p), \text{OID}_{\text{DEAP}}``$ | UUIDv5 anchor, namespace OID |

## 3. Computational Complexity & Algorithmic Bounds

- **Complexity Class:** Class $\mathbf{P}$ (Deterministic Polynomial Time).
- **Asymptotic Bound:** $O(|B|)$ streaming write time per artifact ($``O(N_{\text{bytes}})``$ across $K$ artifacts with $``N_{\text{bytes}} = \sum_{k=1}^K |B_k|``$). Validation takes $O(|p|)$. Work-stealing scales as $``O(N_{\text{bytes}} / N_{\text{max\_workers}} + K)``$. Memory is $``B_{\text{max\_chunk}} = 64\text{ KB} \in O(1)``$.
- **Tractable Subclass and Frontier:** N/A (Deterministic P). Bypasses NP-1 intervals (REQ-0117), NP-2 packing (REQ-0147), and NP-8 solving (REQ-0197).

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: In-Place Overwrite and Inode Preservation
- **Given:** File `Artifact_0` at `Path_0` with inode `Inode_0` and buffer $B$.
- **When:** `FilePersistence_Alpha` persists updated artifact.
- **Then:** Writes in place via truncation flags, preserving inode ($``\text{inode}_{t+1} == \text{inode}_t``$) and directory metadata.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: Direct Atomic File Creation Boundary
- **Given:** Artifact `Artifact_1` at non-existent `Path_1`.
- **When:** `FilePersistence_Alpha` evaluates file existence.
- **Then:** Directly creates file with flags `O_WRONLY | O_CREAT | O_EXCL`.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-03: Path Traversal Security Rejection
- **Given:** Path `Path_Escaping = "../Package_0/Out.out"`.
- **When:** `FilePersistence_Alpha` validates root confinement.
- **Then:** Fails closed, binds $``\bot_{\text{io}}``$, emitting `E0300`.
- **Diagnostic:** `E0300`.

### AC-04: Write Fault and Delimiter Error Recovery
- **Given:** Failing `Path_0` with delimiter `;` and valid `Path_1`.
- **When:** `FilePersistence_Alpha` encounters write failure.
- **Then:** Emits `E0515`, binds $``\bot_{\text{io}}``$, recovers across `;`, persists `Path_1`, halting at $``C_{\text{max\_errors}}``$ with `E0199`.
- **Diagnostic:** `E0515`, `E0199`.
