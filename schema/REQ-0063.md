## 1. Normative Statement

The semantic lowering engine and AST graph engine shall formalize the KerML conjugation relationship (`~`) and port inversion transformation across all port definitions, interface definitions, and port usages. The engine shall evaluate conjugation as an algebraic involution over the directional algebra $`\mathcal{D} = \{ \text{In}, \text{Out}, \text{InOut}, \text{None} \}`$, mapping $`\text{In} \mapsto \text{Out}`$, $`\text{Out} \mapsto \text{In}`$, while keeping $`\text{InOut}`$ and $`\text{None}`$ invariant.

For any port or interface definition $`P`$, lowering conjugated classifier $`\widetilde{P} = {\sim}P`$ shall preserve structural feature names, payload types ($`\tau`$), multiplicity intervals ($`\mu`$), and behavioral invariant contracts ($`\Psi`$) without alteration, inverting exclusively the flow and parameter directions of contained features: $`\text{dir}(f') = {\sim}\text{dir}(f)`$. Nested port and interface usages within $`P`$ shall conjugate recursively. Consecutive conjugation operators shall simplify algebraically: $`{\sim}^{2k} P \equiv P`$ and $`{\sim}^{2k+1} P \equiv {\sim}P`$ for $``k \in \mathbb{N}_{0}``$.

Conjugation applies strictly to classifiers with interaction or port semantics (`PortDefinition`, `InterfaceDefinition`, `PortUsage`). Applying `~` to non-conjugable types (scalars `Integer`, `Real`, `Boolean`, `String`, enumerations, or records lacking ports) shall be rejected, emitting diagnostic `E0200`.

Per Algorithmic Bound NP-3, multiple inheritance hierarchies with conjugated parent types (e.g., `Classifier_Alpha :> ~Classifier_Beta, Classifier_Gamma`) shall form a monotonic meet-semilattice and be linearized via the C3 algorithm without backtracking. Conflicting orderings or cycles shall emit diagnostic `E0203`.

Connecting two port instances requires conjugate complementarity: an output flow must bind to an input flow of conforming payload type. Direct connections between identical unidirectional flows shall emit diagnostic `E0201`.

## 2. Formal Invariant

Let $`\mathcal{D} = \{ \text{In}, \text{Out}, \text{InOut}, \text{None} \}`$ denote the closed directional algebra. The conjugation operator $`{\sim} : \mathcal{D} \to \mathcal{D}`$ is an algebraic involution:

```math
\begin{aligned}
{\sim}(\text{In}) &= \text{Out}, \quad {\sim}(\text{Out}) = \text{In} \\
{\sim}(\text{InOut}) &= \text{InOut}, \quad {\sim}(\text{None}) = \text{None}
\end{aligned}
```

Involution identity:

```math
\forall d \in \mathcal{D}, \quad {\sim}({\sim}d) \equiv d \implies {\sim}({\sim}P) \equiv P
```

For port classifier $``P = \langle \text{id}_P, \text{name}_P, \text{features}(P), \Psi(P), \mu(P) \rangle``$, its conjugated counterpart $`\widetilde{P} = {\sim}P`$ satisfies:

```math
\begin{aligned}
\text{features}(\widetilde{P}) &= \{ f' \mid \exists f \in \text{features}(P), \, \text{name}(f') = \text{name}(f) \wedge \tau(f') = \tau(f) \\
&\quad \wedge \mu(f') = \mu(f) \wedge \text{dir}(f') = {\sim}\text{dir}(f) \}
\end{aligned}
```

Consecutive conjugation simplification:

```math
{\sim}^k P = \begin{cases}
P, & k \equiv 0 \pmod 2 \\
{\sim}P, & k \equiv 1 \pmod 2
\end{cases}
```

Lattice order-preserving automorphism:

```math
P_1 \le P_2 \iff {\sim}P_1 \le {\sim}P_2, \quad {\sim}(P_1 \wedge P_2) \equiv {\sim}P_1 \wedge {\sim}P_2
```

Diagnostic mapping rules:

```math
\begin{aligned}
\text{IsConjugated}(C) \wedge \text{Kind}(C) \notin \{ \text{PortDef}, \text{InterfaceDef}, \text{PortUsage} \} &\implies \text{Diagnostic}(C, \text{E0200}) \\
\text{Connected}(p_1, p_2) \wedge \text{dir}(p_1) = \text{dir}(p_2) \wedge \text{dir}(p_1) \ne \text{InOut} &\implies \text{Diagnostic}(\langle p_1, p_2 \rangle, \text{E0201}) \\
\text{HasCycle}(\text{C3Linearize}(P)) &\implies \text{Diagnostic}(P, \text{E0203})
\end{aligned}
```

## 3. Computational Complexity & Algorithmic Bounds

Port and interface conjugation executes strictly within Complexity Class $`\mathbf{P}`$. For classifier $`P`$ declaring $`K = |\text{features}(P)|`$ features, inverted feature synthesis executes in deterministic linear time $`O(K) = O(|\text{features}(P)|)`$ with zero memory reallocation beyond contiguous AST storage. Operator normalization $`{\sim}^k`$ executes in $`O(1)`$ scalar parity arithmetic.

Multiple-inheritance subtyping posets under conjugation are restricted to a monotonic meet-semilattice and linearized via C3 in deterministic $`O(V + E)`$ polynomial time, eliminating exponential search and backtracking (Algorithmic Bound NP-3). Auxiliary memory is bounded by $`O(1)`$ stack space.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Algebraic Direction Involution & Port Inversion

- **Given:** `PortDef_Alpha` declaring features `Flow_In` (`In`), `Flow_Out` (`Out`), and `Flow_Bi` (`InOut`).
- **When:** Lowering processes conjugated classifier `~PortDef_Alpha`.
- **Then:** Containment features invert orientations: `Flow_In` becomes `Out`, `Flow_Out` becomes `In`, and `Flow_Bi` remains `InOut`.
- **Diagnostic:** `E0201` emitted on directional inversion failure.

### AC-02: Structural Payload & Invariant Contract Preservation

- **Given:** `PortDef_Alpha` declaring feature `Flow_A` with payload type `param_x : Real`, multiplicity `[1..2]`, and invariant constraints.
- **When:** Lowering lowers `~PortDef_Alpha` into the AST.
- **Then:** The conjugated feature preserves payload type `param_x : Real`, multiplicity `[1..2]`, and constraints identically.
- **Diagnostic:** `E0200` emitted on payload schema or multiplicity mutation during conjugation.

### AC-03: Involutive Simplification & Normalization Gate

- **Given:** AST declarations containing nested operators `~~PortDef_Alpha` and `~~~PortDef_Alpha`.
- **When:** Lowering evaluates operator parity normalization.
- **Then:** `~~PortDef_Alpha` simplifies to `PortDef_Alpha` and `~~~PortDef_Alpha` simplifies to canonical `~PortDef_Alpha`.
- **Diagnostic:** `E0200` emitted if normalization fails to resolve canonical parity forms.

### AC-04: Non-Conjugable Target Classifier Rejection

- **Given:** An AST model applying `~` to non-conjugable classifier `~Classifier_Alpha` (`Real`, `Integer`, or a class without ports).
- **When:** Lowering validates conjugation target applicability.
- **Then:** The compiler rejects the expression, assigns sentinel node $``\bot_{\text{type}}``$, and emits diagnostic `E0200`.
- **Diagnostic:** `E0200` emitted when `~` is applied to non-conjugable classifiers.
