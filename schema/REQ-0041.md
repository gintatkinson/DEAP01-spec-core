## 1. Normative Statement

The Core Metamodel, Node Arena & AST Graph Engine shall implement hierarchical lexical scope lookup and path evaluation using double-colon scoping (`::`) to resolve identifier references across nested lexical scopes, package boundaries, and imported namespaces.

The resolver shall evaluate references via two deterministic mechanisms:
1. **Unqualified Lexical Lookup:** Given unqualified identifier $`\sigma`$ in active scope $``S_{\text{active}}``$, the resolver searches outward along the parent chain $`\text{parent}(S)`$ to root namespace $``S_{\text{root}}``$. The first matching visible declaration binds to the reference, establishing lexical shadowing where inner definitions shadow enclosing ones.
2. **Qualified Path Resolution:** Given path $``p_1 \mathbin{::} \dots \mathbin{::} p_k``$, a leading `::` indicates an absolute path evaluated from $``S_{\text{root}}``$. Otherwise, $``p_1``$ resolves via unqualified lookup in $``S_{\text{active}}``$. Subsequent segments $``p_j``$ ($`2 \le j \le k`$) resolve as direct members of predecessor $``p_{j-1}``$.
3. **Visibility & Ambiguity:** `Public` symbols are accessible universally. `Private` symbols are accessible strictly within their declaring package. `Protected` symbols are accessible within declaring and conforming classifiers. Inaccessible accesses or conflicting wildcard imports emit diagnostic `E0200` per REQ-0191.

## 2. Formal Invariant

Let $`\mathcal{S}`$ be the set of lexical scopes in tree $``\mathcal{T}_{\text{scope}} = (\mathcal{S}, \prec, S_{\text{root}})``$. Each scope $`S \in \mathcal{S}`$ owns local symbols $``\mathcal{M}_S``$, imported symbols $``\mathcal{I}_S``$, and parent pointer $`\text{parent}(S) \in \mathcal{S} \cup \{ \bot \}`$. Symbol entry $``e = \langle \sigma_e, h_e, \text{vis}_e \rangle``$ has visibility $``\text{vis}_e \in \{ \text{Public}, \text{Private}, \text{Protected} \}``$.

Visibility predicate:

```math
\text{IsVisible}(e, S) \iff (e.\text{vis}_e = \text{Public}) \vee (e.\text{vis}_e = \text{Private} \wedge \text{Pkg}(e) = \text{Pkg}(S)) \vee (e.\text{vis}_e = \text{Protected} \wedge S \le \text{Scope}(e))
```

Unqualified lookup:

```math
\text{Find}(\sigma, S, S_{\text{caller}}) = \begin{cases}
e.h_e, & \text{if } \exists e \in \mathcal{M}_S : e.\sigma_e = \sigma \wedge \text{IsVisible}(e, S_{\text{caller}}) \\
\text{Find}(\sigma, S.\text{parent}, S_{\text{caller}}), & \text{if } (\forall e \in \mathcal{M}_S, e.\sigma_e \ne \sigma) \wedge S.\text{parent} \ne \bot \\
\bot_{\text{node}}, & \text{otherwise}
\end{cases}
```

Qualified path resolution for $``\pi = p_1 \mathbin{::} \dots \mathbin{::} p_k``$ with $`\alpha \in \{ \text{Absolute}, \text{Relative} \}`$:

```math
\text{FindQualified}(\pi, \alpha, S) = \text{Traverse}(\text{BaseScope}(p_1, \alpha, S), 2, k, \pi, S)
```

where:

```math
\begin{aligned}
\text{BaseScope}(p_1, \alpha, S) &= \begin{cases} \text{Member}(S_{\text{root}}, p_1), & \text{if } \alpha = \text{Absolute} \\ \text{ScopeOf}(\text{Find}(p_1, S, S)), & \text{if } \alpha = \text{Relative} \end{cases} \\
\text{Traverse}(S, j, k, \pi, S_{\text{caller}}) &= \begin{cases} S, & \text{if } j \gt k \wedge S \ne \bot_{\text{node}} \\ \bot_{\text{node}}, & \text{if } S = \bot_{\text{node}} \\ \text{Traverse}(\text{Member}(S, p_j), j + 1, k, \pi, S_{\text{caller}}), & \text{otherwise} \end{cases}
\end{aligned}
```

Shadowing, bounds, and diagnostic invariants:

```math
\begin{aligned}
(e_1 \in \mathcal{M}_{S_{\text{inner}}} \wedge e_2 \in \mathcal{M}_{S_{\text{outer}}} \wedge S_{\text{inner}} \prec^+ S_{\text{outer}} \wedge e_1.\sigma_e = e_2.\sigma_e) &\implies \text{Find}(e_1.\sigma_e, S_{\text{inner}}, S_{\text{inner}}) = e_1.h_e \\
\forall S \in \mathcal{S}, \quad \text{Depth}(S) \le D_{\max} = 16, &\quad \Delta_S = \text{UUIDv5}(\text{NS}_{\text{DEAP}}, \text{FQN}(S)) \\
\text{Find}(\sigma, S, S) = \bot_{\text{node}} \vee \text{FindQualified}(\pi, \alpha, S) = \bot_{\text{node}} &\implies \text{Diagnostic}(\text{E0200}) \in \mathcal{D}_{\text{sink}} \\
|\mathcal{D}_{\text{sink}}| \ge C_{\text{max\_errors}} &\implies \text{Diagnostic}(\text{E0199}) \in \mathcal{D}_{\text{sink}}
\end{aligned}
```

## 3. Computational Complexity & Algorithmic Bounds

The scope resolution engine operates strictly within Complexity Class $`\mathbf{P}`$.

1. **Unqualified Lookup Complexity:** Traversal along parent pointers is bounded by lexical depth $``D_{\max} \le 16 = O(1)``$. Hash queries on interned `SymbolId` tokens require amortized $`O(1)`$ time, yielding $``T_{\text{unqual}}(\sigma) \le D_{\max} \cdot O(1) = O(1)``$.
2. **Qualified Path Resolution Complexity:** For path length $`k \le 16`$, evaluating base scope and successive member lookups requires $`O(k) = O(1)`$ time.
3. **Aggregate Bounds:** For an AST with $`N`$ references, total sequential resolution time is $``T(N) = \sum_{i=1}^N O(1) \in O(N)``$. Parallel execution across units on $``N_{\text{max\_workers}}``$ threads scales as $``O(N / N_{\text{max\_workers}} + |\mathcal{S}| \log N_{\text{max\_workers}})``$. Space complexity is $`O(N)`$ arena storage with $`O(1)`$ auxiliary stack frames.

Bounded scope depth and direct hash lookups bypass backtracking, avoiding NP-hard subtyping and scheduling frontiers (NP-1 through NP-8) with guaranteed polynomial termination.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Lexical Scope Shadowing

- **Given:** AST hierarchy `Package_Root::Package_0::Classifier_Alpha` with `param_x : Real` in `Package_0` and local `param_x : Real` in `Classifier_Alpha`.
- **When:** Resolving unqualified `param_x` within `Classifier_Alpha` and qualified `::Package_Root::Package_0::param_x`.
- **Then:** Unqualified `param_x` resolves to `Classifier_Alpha` local handle; qualified path resolves to `Package_0` handle with zero diagnostics.
- **Diagnostic:** `E0200` on shadow resolution failure or qualified path fault.

### AC-02: Absolute vs Relative Qualified Path Resolution

- **Given:** Sibling scopes `Package_Root::Package_0::Classifier_Alpha` and `Package_Root::Package_1::Classifier_Beta`.
- **When:** `Classifier_Beta` resolves absolute path `::Package_Root::Package_0::Classifier_Alpha` and `Package_Root` resolves relative path `Package_0::Classifier_Alpha`.
- **Then:** Both paths resolve to `Classifier_Alpha` 32-bit arena handle with 0-byte diff churn.
- **Diagnostic:** `E0200` on qualified path traversal fault.

### AC-03: Package Visibility Boundary Enforcement

- **Given:** Package `Package_0` declaring private member `Feature_A` and public member `Feature_B`.
- **When:** Scope `Package_1` resolves `Package_0::Feature_A` and `Package_0::Feature_B`.
- **Then:** Resolution of `Feature_B` succeeds; resolution of `Feature_A` is rejected with diagnostic `E0200` with source spans.
- **Diagnostic:** `E0200` on inaccessible private member access across packages.

### AC-04: Ambiguous Import Conflict Detection

- **Given:** A scope importing `Package_0` and `Package_1`, both exporting identifier `Port_1` without local shadowing.
- **When:** An unqualified reference to `Port_1` is evaluated.
- **Then:** The resolver rejects the reference as ambiguous, emits diagnostic `E0200` citing candidate locations, and binds sentinel $``\bot_{\text{node}}``$.
- **Diagnostic:** `E0200` on colliding imported identifiers.
