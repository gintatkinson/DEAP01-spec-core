## 1. Normative Statement

The engine SHALL compute and validate 7D dimension vectors and scale factors for rational power expressions ($A^k$, $\operatorname{pow}(A, k)$, $\operatorname{sqrt}(A)$, $\operatorname{cbrt}(A)$, $\operatorname{root}(A, n)$) with base dimension $``\mathbf{d}_A \in \mathbb{Q}^7``$ and rational exponent $k = p/q \in \mathbb{Q}$ ($p \in \mathbb{Z}, q \in \mathbb{Z}^+, \gcd(|p|, q) = 1$), evaluating $``\mathbf{d}_{A^k} = k \cdot \mathbf{d}_A \in \mathbb{Q}^7``$.

---

## 2. Formal Invariant

Rational power evaluation, radical lowering, and diagnostic rules:

```math
\begin{aligned}
\mathbf{d} &\in \mathbb{Q}^7,\; \mathbf{0} = (0,\dots,0),\; n = \langle \text{Pow}, A, p/q \rangle \implies \mathbf{d}(n) = (p/q) \cdot \mathbf{d}(A) \\
\mathbf{d}(\operatorname{sqrt}(A)) &= \frac{1}{2}\mathbf{d}(A),\; \mathbf{d}(\operatorname{cbrt}(A)) = \frac{1}{3}\mathbf{d}(A),\; \mathbf{d}(\operatorname{root}(A, m)) = \frac{1}{m}\mathbf{d}(A) \\
\mathbf{d}(A^0) &= \mathbf{0},\; \mathbf{d}((A^k)^m) = (km)\mathbf{d}(A),\; c(A^k) = c_A^k \; (k \in \mathbb{Z}) \\
(o(A) \ne 0 \wedge k \ne 1) &\vee (q = 0) \vee (\mathbf{d}_A \ne \mathbf{0} \wedge E_{\text{exp}} \notin \mathbb{Q}) \implies \text{Diagnostic}(n, \text{E0300}) \wedge \mathbf{d}(n) = \bot_{\text{dim}} \\
\Delta_n &= \text{UUIDv5}(\text{NS}_{\text{DEAP}}, \text{FQN}(n))
\end{aligned}
```

## 3. Computational Complexity & Algorithmic Bounds

- **Complexity Class:** $\mathbf{P}$ (Deterministic Polynomial)
- **Asymptotic Bound:** $O(1)$ per power node; aggregate lowering is $O(V)$ over AST node set $``V = |\mathcal{V}_{\text{AST}}|``$.
- **Tractable Subclass & Frontier:** Coordinate multiplication across 7 ISQ dimensions executes in $O(1)$ Euclidean $\gcd$ steps ($\le 30$ divisions), within the polynomial fragment of NP-3. Work-stealing scales as $``O(V / N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Rational Exponent Multiplication & Radical Lowering
- **Given:** Base `Base_Alpha` ($(0, 2, 0, 0, 0, 0, 0)$) and scale $c = 4$.
- **When:** Lowering `Base_Alpha ^ (3/2)` and `sqrt(Base_Alpha)`.
- **Then:** Dimensions evaluate to $(0, 3, 0, 0, 0, 0, 0)$ with scale $8$ and $(0, 1, 0, 0, 0, 0, 0)$ with scale $2$.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: Zero Exponent Identity & Dimensionless Invariance
- **Given:** Quantity `Quantity_Alpha` ($(1, 1, -2, 0, 0, 0, 0)$) and parameter `param_x : Real` ($\mathbf{0}$).
- **When:** Lowering `Quantity_Alpha ^ 0` and `param_x ^ (5/3)`.
- **Then:** Both evaluate to null vector $\mathbf{0} \in \mathbb{Q}^7$ with scale $1$.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-03: Affine Unit & Non-Rational Exponent Rejection
- **Given:** Expression `Base_Alpha ^ 2` with affine unit ($o = 273.15$) and `Quantity_Alpha ^ param_y`.
- **When:** Metrology type checking executes.
- **Then:** Rejection emits `E0300` and assigns sentinel $``\bot_{\text{dim}}``$.
- **Diagnostic:** `E0300`.

### AC-04: Domain Singularity & Delimiter Recovery
- **Given:** Expression `Base_Alpha ^ (1 / 0)` before valid `Quantity_Beta = Base_Alpha ^ 2;`.
- **When:** Validation and delimiter recovery execute.
- **Then:** Rejection emits `E0300`, assigns sentinel $``\bot_{\text{dim}}``$, recovers on `;`, and halts at $``C_{\text{max\_errors}}``$ with `E0199`.
- **Diagnostic:** `E0300`, `E0199`.
