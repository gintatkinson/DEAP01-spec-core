## 1. Normative Statement

The ingestion engine shall parse CommonMark Markdown tables containing component declarations, interfaces, attributes, and constraints using an explicit deterministic pushdown automaton (DPDA) that emits an event stream of structural tokens. Lexing and tokenization must strictly prohibit regular expressions and catastrophic backtracking.

Front-end table ingestion passes shall operate directly on contiguous UTF-8 byte streams, executing scalar byte-matching transitions to classify cell boundaries, row terminators, header delimiters, and escaped literal sequences. Token emissions must occur on-the-fly via a streaming event sink interface, delivering structured token events without materializing intermediate syntax trees or buffering unneeded file contents in memory. Every emitted token event shall capture exact source provenance, including 0-indexed byte offset intervals and 1-indexed line and column coordinates.

The lexer shall enforce an explicit bounded frame stack with maximum nesting depth $`D \le 4`$, rejecting deeper nesting or unclosed frames deterministically with diagnostic code `E0100` or `E0102`. Lexer execution shall follow a total, non-panicking execution contract with deterministic error emission upon encountering invalid byte encodings or structural anomalies. In accordance with synchronization token error recovery on table delimiter boundaries, when encountering unexpected tokens or malformed cells, the lexer shall emit diagnostic `E0102`, resynchronize to the next column delimiter pipe or newline boundary, and continue processing subsequent cells and rows without crashing or abandoning the compilation unit.

## 2. Formal Invariant

The CommonMark table lexer is formalized as a 7-tuple deterministic pushdown automaton:

```math
M_{\text{table}} = (Q, \Sigma, \Gamma, \delta, q_0, Z_0, F)
```

where:

```math
\begin{aligned}
Q &= \{ q_{\text{scan}}, q_{\text{header}}, q_{\text{delimiter}}, q_{\text{row}}, q_{\text{cell}}, q_{\text{escape}}, q_{\text{halt}} \} \\
\Sigma &= \{ b \in \mathbb{N} \mid 0 \le b \le 255 \} \\
\Gamma &= \{ Z_0, \text{TableFrame}, \text{HeaderFrame}, \text{RowFrame}, \text{CellFrame} \} \\
q_0 &= q_{\text{scan}}, \quad Z_0 \in \Gamma, \quad F = \{ q_{\text{halt}} \}
\end{aligned}
```

The deterministic transition function satisfies:

```math
\delta : Q \times (\Sigma \cup \{ \epsilon \}) \times \Gamma \longrightarrow Q \times \Gamma^*
```

Determinism and transition cardinality:

```math
\forall q \in Q, \; \forall \gamma \in \Gamma, \; (\delta(q, \epsilon, \gamma) \neq \emptyset \implies \forall a \in \Sigma, \; \delta(q, a, \gamma) = \emptyset) \quad \wedge \quad |\delta(q, a, \gamma)| \le 1
```

The token stream $``\mathcal{S}_{\text{events}} = \langle e_1, \dots, e_m \rangle``$ emits tuples $``e_i = \langle \text{tag}, \text{span} \rangle``$:

```math
\text{tag} \in \{ \text{StartTable}, \text{StartHeader}, \text{EndHeader}, \text{StartRow}, \text{EndRow}, \text{StartCell}, \text{CellText}, \text{EndCell}, \text{EndTable} \}
```

Zero Backtracking and Zero Regex Invariant:

```math
\text{BacktrackCount}(M_{\text{table}}) = 0, \quad \text{RegexEvaluations}(M_{\text{table}}) = 0
```

Monotonic Forward Progress and Bounded Stack Invariant:

```math
\forall t \in \mathbb{N}, \quad \text{pos}_{t+1} \ge \text{pos}_t \quad \wedge \quad |\text{stack}_t| \le D \le 4
```

Token Stream Structural Balance Invariant:

```math
\begin{aligned}
\text{count}(\text{StartTable}, \mathcal{S}_{\text{events}}) &= \text{count}(\text{EndTable}, \mathcal{S}_{\text{events}}) \\
\text{count}(\text{StartHeader}, \mathcal{S}_{\text{events}}) &= \text{count}(\text{EndHeader}, \mathcal{S}_{\text{events}}) \\
\text{count}(\text{StartRow}, \mathcal{S}_{\text{events}}) &= \text{count}(\text{EndRow}, \mathcal{S}_{\text{events}}) \\
\text{count}(\text{StartCell}, \mathcal{S}_{\text{events}}) &= \text{count}(\text{EndCell}, \mathcal{S}_{\text{events}})
\end{aligned}
```

Diagnostic Code Containment Invariant:

```math
\forall D_k \in \mathcal{D}_{\text{lexer}}, \quad \text{code}(D_k) \in \{ \text{E0100}, \text{E0102} \}
```

## 3. Computational Complexity & Algorithmic Bounds

The table lexer executes within Complexity Class $`\mathbf{P}`$. Because transitions evaluate scalar byte matches without backtracking ($`\text{BacktrackCount} = 0`$) and regular expressions are strictly prohibited ($`\text{RegexEvaluations} = 0`$), each input byte is processed in $`O(1)`$ operations, guaranteeing strictly linear time complexity $`O(N)`$ where $`N`$ is input byte length. Stack operations execute in $`O(1)`$ time, and the pushdown stack depth is bounded by constant $`D \le 4`$, establishing an auxiliary memory bound of $`O(D) = O(1)`$. The streaming sink architecture writes directly to output buffers with $`O(1)`$ active memory overhead independent of file length $`N`$. The automaton requires zero backtracking search, strictly bypassing combinatorial NP-hard problem frontiers (e.g., NP-1 through NP-8) and guaranteeing total-function polynomial termination.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Deterministic Event-Driven Streaming Tokenization

- **Given:** A valid CommonMark table declaring MBSE structural entities (`Package_0`, `Classifier_Alpha`, `Port_1`, `Flow_A`, `param_x : Real`) encoded as a contiguous UTF-8 byte stream.
- **When:** The table lexer $``M_{\text{table}}``$ executes the lexical analysis pass.
- **Then:** The lexer emits a balanced stream of structural tokens $``\mathcal{S}_{\text{events}}``$ on-the-fly via the streaming sink, satisfying $``\text{count}(\text{StartCell}, \mathcal{S}_{\text{events}}) = \text{count}(\text{EndCell}, \mathcal{S}_{\text{events}})``$ and $``\text{count}(\text{StartRow}, \mathcal{S}_{\text{events}}) = \text{count}(\text{EndRow}, \mathcal{S}_{\text{events}})``$ without intermediate full-tree buffering.
- **Diagnostic:** `E0100` emitted on token stream generation failure or unbalanced structural tags.

### AC-02: Zero Backtracking and Zero Regular Expression Execution

- **Given:** An input schema file containing CommonMark Markdown tables.
- **When:** Lexical analysis and token classification are executed across the byte stream.
- **Then:** Byte scanning advances monotonically ($``\text{pos}_{t+1} \ge \text{pos}_t``$) with zero backtracking ($`\text{BacktrackCount} = 0`$) and zero regular expression evaluations ($`\text{RegexEvaluations} = 0`$), executing purely via scalar byte-matching transitions.
- **Diagnostic:** `E0100` emitted on non-monotonic stream cursor rollback or regular expression library invocation.

### AC-03: Bounded Pushdown Stack Depth Invariant

- **Given:** A deeply nested or complex tabular markdown sequence.
- **When:** The pushdown automaton stack transitions are evaluated during table parsing.
- **Then:** The pushdown stack depth remains strictly bounded by $``|\text{stack}_t| \le D \le 4``$ across all evaluation steps $`t`$, rejecting unclosed frames or exceeding depths deterministically.
- **Diagnostic:** `E0102` emitted if table nesting depth exceeds 4 or stack underflow occurs.

### AC-04: Total Function Non-Panicking Contract and Delimiter Synchronization

- **Given:** A malformed table input containing unclosed cells, illegal byte sequences, or truncated row delimiter lines.
- **When:** The lexer encounters a lexical anomaly or delimiter mismatch.
- **Then:** The engine terminates without panicking, emits a structured diagnostic with exact byte span and line/column coordinates, and resynchronizes to the next delimiter boundary.
- **Diagnostic:** `E0102` emitted for table delimiter or cell framing anomalies.
