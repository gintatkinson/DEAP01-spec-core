## 1. Normative Statement

`TaxonomyEngine_Alpha` SHALL partition diagnostics into five disjoint taxonomy ranges: Ingestion/Lexer (`E0100`--`E0199`), Metamodel/Typing (`E0200`--`E0299`), Metrology/Conservation (`E0300`--`E0399`), Spatio-Temporal/Safety (`E0400`--`E0499`), and Backend/Emission (`E0500`--`E0599`). Unclassified codes MUST NOT be emitted.

---

## 2. Formal Invariant

Diagnostic taxonomy partitioning and coordinates satisfy:

```math
\begin{aligned}
\mathcal{E}&=\bigcup_{i=0}^4\mathcal{E}_i,\quad\forall j\ne k,\;\mathcal{E}_j\cap\mathcal{E}_k=\emptyset \\
\forall i\in\{0,\dots,4\},\quad\mathcal{E}_i&=\{e\in\mathcal{E}\mid(100\cdot(i+1))\le\text{code}(e)\le(100\cdot(i+1)+99)\} \\
D&=\langle\text{id}_D,c,s,p,[b_{\text{start}},b_{\text{end}}),\lambda,\mu,\Delta_D\rangle,\quad 0\le b_{\text{start}}\le b_{\text{end}}\le|B_{\text{source}}| \\
\lambda&=\langle\ell(b_{\text{start}}),\text{col}(b_{\text{start}}),\ell(b_{\text{end}}),\text{col}(b_{\text{end}})\rangle,\quad\ell(b)=\max\{k\le M\mid\mathcal{L}_{\text{offsets}}[k]\le b\} \\
\text{col}(b)&=(b-\mathcal{L}_{\text{offsets}}[\ell(b)])+1,\quad\mu(D)=\langle[b_s,b_e),B_{\text{patch}},\kappa_{\text{conf}}\rangle \\
\Delta_D&=\text{UUIDv5}(\text{OID}_{\text{DEAP}},p\mathbin{\Vert}\text{"::Diagnostic::"}\mathbin{\Vert}\text{str}(c)\mathbin{\Vert}\text{str}(b_{\text{start}})\mathbin{\Vert}\text{str}(b_{\text{end}})) \\
\mathcal{D}_{k+1}&=\begin{cases}
\mathcal{D}_k\cup\{D_{k+1}\},&\text{if }|\mathcal{D}_k|<C_{\text{max\_errors}} \\
\mathcal{D}_k\cup\{D_{\text{term}}\},&\text{if }|\mathcal{D}_k|=C_{\text{max\_errors}}\land\text{code}(D_{\text{term}})=199 \\
\mathcal{D}_k,&\text{if }|\mathcal{D}_k|>C_{\text{max\_errors}}
\end{cases} \\
\text{ExitCode}(\mathcal{D}_{\text{sink}})&=\begin{cases}
1,&\text{if }\exists D\in\mathcal{D}_{\text{sink}}:s(D)\in\{\text{Fatal},\text{Error}\}\lor(s(D)=\text{Warning}\land\text{Flag}_{\text{Werror}}) \\
0,&\text{otherwise}
\end{cases}
\end{aligned}
```

| Symbol / Term | Domain / Formal Definition |
| :--- | :--- |
| $``\mathcal{E}, \mathcal{E}_i, c``$ | Catalog, partition $i$, code $c$ |
| $``D, \text{id}_D, s``$ | Record, arena handle, severity |
| $``p, [b_s, b_e), \lambda``$ | Path, byte span, coordinates |
| $``\mathcal{L}_{\text{offsets}}, M``$ | Offset array, line count |
| $``\mu(D), \kappa_{\text{conf}}``$ | Remediation patch, confidence |
| $``\Delta_D, \mathcal{D}_{\text{sink}}``$ | UUIDv5 anchor, error sink |
| $``C_{\text{max\_errors}}, \text{ExitCode}``$ | Saturation limit ($``C_{\text{max\_errors}} \ge 100``$), exit code |

## 3. Computational Complexity & Algorithmic Bounds

- **Complexity Class:** Class $\mathbf{P}$ (Deterministic Polynomial Time).
- **Asymptotic Bound:** $O(1)$ taxonomy range classification. Offset indexing requires $``O(|B_{\text{source}}|)``$; coordinate binary search requires $O(\log M)$. Deduplication sort in $``\mathcal{D}_{\text{sink}}``$ is $``O(C_{\text{max\_errors}} \log C_{\text{max\_errors}}) = O(1)``$. Work-stealing scales as $``O(|B_{\text{source}}| / N_{\text{max\_workers}} + 1)``$. Space is $``O(|B_{\text{source}}| + C_{\text{max\_errors}})``$ in arena storage.
- **Tractable Subclass and Frontier:** N/A (Deterministic P). Bypasses NP-1 intervals (REQ-0117) and NP-2 packing (REQ-0147).

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Ingestion Delimiter Recovery and Sink Saturation
- **Given:** Malformed input in `Package_0` exceeding $``C_{\text{max\_errors}} = 100``$.
- **When:** `TaxonomyEngine_Alpha` executes delimiter synchronization.
- **Then:** Recovers across delimiters, accumulating 100 diagnostics before emitting sentinel `E0199`.
- **Diagnostic:** `E0199`.

### AC-02: Metamodel and Typing Taxonomy Partitioning
- **Given:** Circular inheritance between `Classifier_Alpha` and `Classifier_Beta`.
- **When:** `TaxonomyEngine_Alpha` evaluates metamodel typing.
- **Then:** Classifies error into `Partition_1` (`E0200`--`E0299`), emitting `E0200` with patch guidance.
- **Diagnostic:** `E0200`.

### AC-03: Metrology and Conservation Taxonomy Partitioning
- **Given:** Incompatible physical quantity addition on `Port_1`.
- **When:** `TaxonomyEngine_Alpha` executes dimensional homogeneity validation.
- **Then:** Classifies fault into `Partition_2` (`E0300`--`E0399`), emitting `E0300` with highlight spans.
- **Diagnostic:** `E0300`.

### AC-04: Spatio-Temporal and Safety Taxonomy Partitioning
- **Given:** Conflicting temporal relations in `State_0`.
- **When:** `TaxonomyEngine_Alpha` verifies interval constraints.
- **Then:** Classifies conflict into `Partition_3` (`E0400`--`E0499`), emitting `E0400` without panicking.
- **Diagnostic:** `E0400`.
