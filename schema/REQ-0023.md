## 1. Normative Statement

The Universal Schema Ingestion Engine shall parse CommonMark tabular schemas specifying classifier attributes, scalar types, default values, engineering units, and numerical bounds into `IngestedAttr` AST entities. The parser shall map columns via an order-independent binding vector into canonical properties: identifier (`id`), owner classifier reference (`owner`), scalar data type ($`\tau`$), default value ($``v_{\text{default}}``$), envelope interval ($``\mathcal{I} = \langle L, U, o_L, o_U \rangle``$), and unit exponent vector ($`\mathbf{u} \in \mathbb{Q}^7`$).

Scalar types shall be restricted to `Real`, `Integer`, `Boolean`, `String`, or `ClassifierRef`. The parser shall extract numerical envelopes as closed, open, half-open, or unbounded intervals over real or integer values, enforcing $`L \le U`$. Degenerate intervals ($`L = U`$) are valid iff boundaries are closed ($``\neg o_L \wedge \neg o_U``$). Any specified default value must satisfy $``v_{\text{default}} \in \mathcal{I}``$ and type rules. Non-numeric types (`Boolean`, `String`) shall not declare restrictive envelopes or non-zero unit vectors. Engineering units shall map to rational exponent vectors $`\mathbf{u} \in \mathbb{Q}^7`$ or dimensionless vector $``\mathbf{0}_{\mathbb{Q}^7}``$. Copying string bytes into the symbol interner pool during this pass is the sole permitted exception to zero-copy memory management.

## 2. Formal Invariant

Let $`\mathcal{A}`$ denote ingested attribute entities. Each entity $`A \in \mathcal{A}`$ is formalized as:

```math
A = \langle \text{id}, \text{owner}, \tau, v_{\text{default}}, \mathcal{I}, \mathbf{u}, \text{span} \rangle
```

where constituent domains and bounds satisfy:

```math
\begin{aligned}
\tau &\in \mathcal{T}_{\text{type}} = \{ \text{Real}, \text{Integer}, \text{Boolean}, \text{String}, \text{ClassifierRef} \} \\
v_{\text{default}} &\in \text{Domain}(\tau) \cup \{ \bot \}, \quad \mathbf{u} \in \mathbb{Q}^7 \\
\mathcal{I} &= \langle L, U, o_L, o_U \rangle \in (\mathbb{R} \cup \{ -\infty \}) \times (\mathbb{R} \cup \{ +\infty \}) \times \mathbb{B}^2 \\
\text{span} &= \langle \text{file\_id}, p_{\text{start}}, p_{\text{end}}, \text{line}, \text{col} \rangle
\end{aligned}
```

Well-formedness, containment, and compatibility predicates:

```math
\begin{aligned}
\text{ValidInterval}(\mathcal{I}) &\iff (L \le U) \wedge (L = U \implies (\neg o_L \wedge \neg o_U \wedge L \in \mathbb{R})) \\
v \in \mathcal{I} &\iff (o_L \mathrel{?} L \lt v \mathrel{:} L \le v) \wedge (o_U \mathrel{?} v \lt U \mathrel{:} v \le U) \\
v_{\text{default}} \ne \bot &\implies (v_{\text{default}} \in \text{Domain}(\tau) \wedge (\tau \in \{ \text{Real}, \text{Integer} \} \implies v_{\text{default}} \in \mathcal{I})) \\
\tau \in \{ \text{Boolean}, \text{String} \} &\implies (\mathcal{I} = \langle -\infty, +\infty, \text{true}, \text{true} \rangle \wedge \mathbf{u} = \mathbf{0}_{\mathbb{Q}^7})
\end{aligned}
```

Diagnostic trigger invariants:

```math
\begin{aligned}
(\neg \text{ValidInterval}(\mathcal{I}) \vee (v_{\text{default}} \ne \bot \wedge v_{\text{default}} \notin \mathcal{I}) \vee \mu(\text{unit\_str}) = \bot) &\implies \text{Diagnostic}(A, \text{E0103}) \in \mathcal{D} \\
|\mathcal{D}| \ge C_{\text{max\_errors}} &\implies \exists D_{\text{term}} \in \mathcal{D} : \text{code}(D_{\text{term}}) = \text{E0199}
\end{aligned}
```

## 3. Computational Complexity & Algorithmic Bounds

Tabular attribute schema ingestion executes within Complexity Class $`\mathbf{P}`$. For $`R`$ rows and $`C \le 32`$ columns, each row requires $`O(1)`$ operations: column binding $`O(C) = O(1)`$, symbol interning $`O(1)`$, scalar type lookup $`O(1)`$, numeric boundary parsing $`O(1)`$, interval check ($`L \le U`$) $`O(1)`$, default containment check $`O(1)`$, and unit mapping into $`\mathbb{Q}^7`$ $`O(1)`$. Total sequential ingestion time is strictly linear:

```math
T(R) = O(R)
```

Parallel execution across $`M`$ files using a bounded work-stealing pool with $``N_{\text{max\_workers}}``$ threads scales as $``O(R / N_{\text{max\_workers}})``$. Auxiliary memory is $`O(1)`$ heap overhead per row via arena allocation, with preallocated diagnostic sink bounded by $``O(C_{\text{max\_errors}}) = O(1)``$. Operates strictly in $`\mathbf{P}`$, orthogonal to NP frontiers (NP-1--NP-8).

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Valid Attribute & Numerical Envelope Extraction
- **Given:** A tabular schema with attributes across `Real`, `Integer`, `Boolean`, and `String`, valid intervals (`[0.0, 100.0]`, `(0, 50]`, `[-10, 10]`, `[0.0, +inf)`), defaults, and SI units (`"m/s"`, `"kg"`).
- **When:** The parser processes table rows.
- **Then:** Each row synthesizes an `IngestedAttr` AST node with exact SI exponent vector $`\mathbf{u} \in \mathbb{Q}^7`$, exact boundary limits, and zero diagnostics.
- **Diagnostic:** None emitted.

### AC-02: Degenerate Singleton Interval Validation
- **Given:** Table rows with singleton intervals ($`L = U = 10.0`$) and default $``v_{\text{default}} = 10.0``$.
- **When:** Parser evaluates closed `[10.0, 10.0]` versus open `(10.0, 10.0)`.
- **Then:** Closed `[10.0, 10.0]` succeeds; open `(10.0, 10.0)` is rejected as empty, substituting sentinel $``\bot_{\text{attr}}``$.
- **Diagnostic:** `E0103` on open singleton interval.

### AC-03: Inverted Interval Bounds & Default Boundary Violation
- **Given:** Table rows with inverted bounds ($`L \gt U`$, e.g. `[100.0, 50.0]`) or defaults violating bounds ($``v_{\text{default}} = 150.0``$ for `[0.0, 100.0]`).
- **When:** Interval validity and default containment predicates are evaluated.
- **Then:** Validation fails closed, substituting sentinel $``\bot_{\text{attr}}``$ into the AST with exact source span mapping.
- **Diagnostic:** `E0103`.

### AC-04: Non-Numeric Type Envelope Incompatibility
- **Given:** A row with non-numeric attribute type (`Boolean`, `String`) declaring a restrictive numerical envelope or non-zero unit vector (`param_flag : Boolean` with `[0, 1]`).
- **When:** Type-envelope compatibility rules are verified.
- **Then:** Incompatible envelopes are rejected and sentinel $``\bot_{\text{attr}}``$ is substituted.
- **Diagnostic:** `E0103`.
