## 1. Normative Statement

## 2. Formal Invariant

Diagnostic records and filtering satisfy:

```math
\begin{aligned}
D&=\langle c,s,p,[b_{\text{start}},b_{\text{end}}),\lambda,\mu,\sigma,\Delta_{\text{diag}}\rangle \\
\lambda&=\langle\ell(b_{\text{start}}),c(b_{\text{start}}),\ell(b_{\text{end}}),c(b_{\text{end}})\rangle \\
\ell(b)&=\max\{i\in\{1,\dots,M\}\mid l_i\le b\},\quad c(b)=(b-l_{\ell(b)})+1 \\
\mathcal{D}_{k+1}&=\begin{cases}
\mathcal{D}_k\cup\{D_{k+1}\},&\text{if }|\mathcal{D}_k|<K_{\text{max\_errors}} \\
\mathcal{D}_k,&\text{otherwise}
\end{cases} \\
\text{Emit}(j,\tau_{\text{last}})&=\begin{cases}
\text{Suppress},&\text{if }j-\tau_{\text{last}}\le\delta \\
\text{Record},&\text{if }j-\tau_{\text{last}}>\delta
\end{cases} \\
(b_{\text{start}}>b_{\text{end}}\lor b_{\text{end}}>|S|)&\implies\text{Diagnostic}(\text{E0190})\in\mathcal{D}_{\text{sink}}\land D\gets\bot_{\text{diag}} \\
\text{ParseError}(\text{Token}_1)&\implies\text{Diagnostic}(\text{Token}_1,\text{E0100})\in\mathcal{D}_{\text{sink}} \\
|\mathcal{D}_{\text{sink}}|\ge K_{\text{max\_errors}}&\implies\text{Diagnostic}(\text{E0199})\in\mathcal{D}_{\text{sink}} \\
\Delta_{\text{diag}}&=\text{UUIDv5}(\text{OID}_{\text{DEAP}},p\mathbin{\Vert}\text{"::"}\mathbin{\Vert}\text{str}(c)\mathbin{\Vert}\text{"::"}\mathbin{\Vert}\text{str}(b_{\text{start}})\mathbin{\Vert}\text{"::"}\mathbin{\Vert}\text{str}(b_{\text{end}}))
\end{aligned}
```

| Symbol / Term | Domain / Formal Definition |
| :--- | :--- |
| $``D, [b_{\text{start}}, b_{\text{end}}), \lambda``$ | Diagnostic tuple, byte span, coordinates |
| $c, s, p, \mu, \sigma$ | Code, severity, path, remediation, token |
| $``\ell(b), c(b), L_{\text{starts}}``$ | Coordinate mappings, line-start table |
| $``\mathcal{D}_k, \mathcal{D}_{\text{sink}}, K_{\text{max\_errors}}``$ | Accumulation state, sink, limit |
| $``\tau_{\text{last}}, \delta, \bot_{\text{diag}}``$ | Recovery position, window, fault sentinel |
| $``\Delta_{\text{diag}}, \text{OID}_{\text{DEAP}}``$ | UUIDv5 anchor, namespace OID |

## 3. Computational Complexity & Algorithmic Bounds

- **Complexity Class:** Class $\mathbf{P}$ (Deterministic Polynomial Time).
- **Asymptotic Bound:** Indexing takes $O(|S|)$. Coordinate lookup takes $O(\log M)$. Accumulation takes $O(1)$ amortized time, bounding collection to $O(|\mathcal{D}|)$ ($``|\mathcal{D}| \le K_{\text{max\_errors}}``$). Sorting takes $O(|\mathcal{D}| \log |\mathcal{D}|)$. Work-stealing across $``N_{\text{max\_workers}}``$ threads scales as $``O(|S| / N_{\text{max\_workers}} + |\mathcal{D}| \log |\mathcal{D}|)``$. Memory is $``O(M + K_{\text{max\_errors}})``$.
- **Tractable Subclass and Frontier:** N/A (Deterministic P). Avoids NP-1 (REQ-0117), NP-2 (REQ-0147), NP-8 (REQ-0197).

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Diagnostic Construction and Coordinate Resolution
- **Given:** Buffer `SourceFile_0` with $``L_{\text{starts}}``$ and span `ByteSpan_0` = $``[b_{\text{start}}, b_{\text{end}})``$.
- **When:** Constructing diagnostic `ErrorRecord_0`.
- **Then:** Resolves coordinates, rendering margin bars (`|`), carets (`^`), squiggles (`~~~`).
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: Boundary Byte Span and Single-Token Mapping
- **Given:** Buffer `SourceFile_0` with point fault ($``b_{\text{start}} = b_{\text{end}} - 1``$) at $|S| - 1$.
- **When:** Formatting ASCII snippet.
- **Then:** Resolves column without overread, emitting caret (`^`).
- **Diagnostic:** Diagnostic sink remains empty.

### AC-03: Malformed Byte Span Rejection
- **Given:** Inverted span ($``b_{\text{start}} > b_{\text{end}}``$) or offset ($``b_{\text{end}} > |S|``$).
- **When:** Validating span invariants.
- **Then:** Rejects coordinates, binds $``\bot_{\text{diag}}``$, emitting `E0190`.
- **Diagnostic:** `E0190`.

### AC-04: Delimiter Recovery and Error Saturation
- **Given:** Malformed `Token_1` separated by `;`, and sink limit $``K_{\text{max\_errors}} = 100``$.
- **When:** Parser encounters syntax errors across statements.
- **Then:** Emits `E0100`, recovers across `;`, and halts at limit with `E0199`.
- **Diagnostic:** `E0100`, `E0199`.
