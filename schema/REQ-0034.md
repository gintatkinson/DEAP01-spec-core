## 1. Normative Statement

The compiler core metamodel lowering engine shall lower all ingested schema abstract syntax tree (AST) entities (packages, part definitions, port definitions, action definitions, constraint definitions) into contiguous virtual memory allocations within a typed node arena. AST entities must be allocated in uniform-sized contiguous slots of size $``S_{\text{slot}} = \text{sizeof}(\text{NodeSlot})``$ with 64-bit alignment ($``A_{\text{align}} = 8\text{ bytes}``$), eliminating per-node heap allocator headers, pointer chasing, and heap fragmentation.

All inter-node edges and hierarchies within the lowered AST shall reference target entities exclusively via typed scalar integer handles (`NodeIndex`), guaranteeing a pointer indirection depth of zero ($``\text{PointerIndirectionDepth}(\mathcal{A}_{\text{node}}) = 0``$). Insertion into pre-allocated arena chunks shall execute in amortized $`O(1)`$ time, and complete lowering of an AST with $`N`$ entities shall execute in deterministic linear time $`O(N)`$ with $`O(1)`$ base-plus-offset random slot access.

## 2. Formal Invariant

Let $``\mathcal{A}_{\text{node}}``$ denote a contiguous typed arena buffer with base address $``\text{Base}(\mathcal{A}_{\text{node}})``$, uniform slot size $``S_{\text{slot}} = \text{sizeof}(\text{NodeSlot})``$, and 64-bit alignment $``A_{\text{align}} = 8\text{ bytes}``$.

Contiguous Address Arithmetic and Alignment Invariant:

```math
\begin{aligned}
\forall i \in \{0, \dots, N-1\}, \quad \text{Address}(\text{Node}_i) &= \text{Base}(\mathcal{A}_{\text{node}}) + i \cdot S_{\text{slot}} \\
\forall i \in \{0, \dots, N-2\}, \quad \text{Address}(\text{Node}_{i+1}) - \text{Address}(\text{Node}_i) &= S_{\text{slot}} \\
\forall i \in \{0, \dots, N-1\}, \quad \text{Address}(\text{Node}_i) &\equiv 0 \pmod{A_{\text{align}}}
\end{aligned}
```

Zero Pointer Indirection Depth Invariant:

```math
\begin{aligned}
\text{PointerIndirectionDepth}(\mathcal{A}_{\text{node}}) &= 0 \\
\forall (u, v) \in \mathcal{E}_{\text{AST}}, \quad \text{TargetHandle}(u, v) &\in \mathbb{N}_0
\end{aligned}
```

Asymptotic Lowering and Constant-Time Access Invariants:

```math
\begin{aligned}
T_{\text{lower}}(N) &\le c_1 \cdot N + c_0, \quad \forall N \ge 1 \\
T_{\text{access}}(i) &\le c_2 \cdot 1, \quad \forall i \in \{0, \dots, N-1\}
\end{aligned}
```

Spatial Cache Line Locality Bound: For cache line size $``L_{\text{cache}} \in \{64, 128\}\text{ bytes}``$, sequential traversal over $`k`$ consecutive slots incurs cache transfers bounded by:

```math
\mathcal{M}_{\text{cache}}(k) \le \left\lceil \frac{k \cdot S_{\text{slot}}}{L_{\text{cache}}} \right\rceil + 1
```

Capacity and Diagnostic Invariant: For arena slot capacity $``C_{\text{slots}} \in \mathbb{N}``$:

```math
i \ge C_{\text{slots}} \implies \text{Diagnostic}(\text{span}(\text{Node}_i), \text{E0200})
```

## 3. Computational Complexity & Algorithmic Bounds

The contiguous memory lowering engine executes within Complexity Class $`\mathbf{P}`$. Slot allocation executes in amortized $`O(1)`$ time via pointer bump and capacity check. Complete lowering of an AST with $``N = |\mathcal{V}_{\text{AST}}|``$ nodes executes in deterministic linear time $`O(N)`$ in a single traversal pass. Random slot access executes in worst-case $`O(1)`$ constant time via base-plus-offset address arithmetic $``\text{Base} + i \cdot S_{\text{slot}}``$. Sequential traversal executes in $`O(N)`$ time with hardware cache prefetching. Total memory footprint is strictly bounded by $`O(N)`$ linear space proportional to $``N \cdot S_{\text{slot}}``$ with zero per-node heap allocator overhead. Parallel lowering across $`K`$ units on bounded work-stealing threads ($``N_{\text{max\_workers}}``$) achieves $``O(\lceil K / N_{\text{max\_workers}} \rceil \cdot N_{\text{max\_unit}})``$ wall-clock scaling. Metamodel arena lowering operates entirely in polynomial time $`\mathbf{P}`$, serving as the zero-indirection substrate for downstream tractable graph passes (e.g., NP-3 type linearization in $`O(V+E)`$).

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Contiguous Virtual Memory Layout & Alignment

- **Given:** AST entities (`Package_0`, `PartDef_Alpha`) lowered into arena $``\mathcal{A}_{\text{node}}``$ with $`N = 10^4`$ nodes.
- **When:** Lowering commits entities into sequential arena slots.
- **Then:** For all consecutive pairs $`(i, i+1)`$, $``\text{Address}(\text{Node}_{i+1}) - \text{Address}(\text{Node}_i) = S_{\text{slot}}``$ and $``\text{Address}(\text{Node}_i) \equiv 0 \pmod 8``$.
- **Diagnostic:** `E0200` emitted on non-contiguous layout or alignment violation.

### AC-02: Constant-Time Random Access & Zero Pointer Indirection

- **Given:** Node arena with $`N = 10^5`$ AST nodes addressed via handles (`NodeIndex`).
- **When:** Executing $`10^6`$ randomized index lookups across the arena buffer.
- **Then:** Every slot dereference computes in $`O(1)`$ constant time via base-plus-offset arithmetic with $``\text{PointerIndirectionDepth}(\mathcal{A}_{\text{node}}) = 0``$.
- **Diagnostic:** `E0200` emitted on invalid handle dereference or non-zero pointer indirection.

### AC-03: Linear Lowering Throughput Scaling

- **Given:** Synthetic AST models scaling from $`N = 10^3`$ to $`N = 10^6`$ entities.
- **When:** Lowering transforms the model into the contiguous arena in a single pass.
- **Then:** Lowering latency satisfies $``T_{\text{lower}}(N) \le c_1 \cdot N``$ with regression fit $`R^2 \ge 0.99`$.
- **Diagnostic:** `E0200` emitted if lowering throughput exceeds linear algorithmic bounds.

### AC-04: Arena Boundary Enforcement & Non-Panicking Diagnostic Recovery

- **Given:** Arena buffer with fixed capacity $``C_{\text{slots}}``$ and invalid index request ($``i \ge C_{\text{slots}}``$).
- **When:** An operation attempts slot allocation or lookup exceeding capacity limits.
- **Then:** Execution halts gracefully without panicking, recording structured diagnostic `E0200`.
- **Diagnostic:** `E0200` recorded upon arena capacity exhaustion or out-of-bounds slot access.
