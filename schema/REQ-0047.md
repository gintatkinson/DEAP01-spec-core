## 1. Normative Statement

The compiler core shall construct, maintain, and query an in-memory bidirectional directed property multigraph $`G = (V, E)`$ over abstract syntax tree (AST) nodes stored in the AST. The multigraph implementation must remain strictly technology-neutral, clean-room engineered, and decoupled from external graph libraries, operating directly on arena index slabs, scalar node handles (`NodeHandle`), and deterministic adjacency lists.

The multigraph architecture shall enforce the following normative guarantees:

1. Representation & Parallelism: Vertices $`v \in V`$ correspond to typed node handles per REQ-0034 and REQ-0035; raw pointers are prohibited. Edges $`e \in E`$ possess unique 32-bit identifiers (`EdgeId`), endpoints $`(\text{src}(e), \text{dst}(e))`$, kind tag $``k \in \mathcal{K}_{\text{edge}}``$, and property payload. Parallel directed edges between identical node pairs $`(u, v)`$ are permitted for distinct relationships (e.g., parallel port connections or flow channels).
2. Canonical Kinds & Bidirectionality: Edges belong to closed set $``\mathcal{K}_{\text{edge}} = \{ \text{Contains}, \text{Specializes}, \text{Types}, \text{ConnectsTo}, \text{FlowsTo}, \text{AllocatesTo}, \text{Constrains}, \text{DependsOn} \}``$. For every edge $`e \in E`$, the engine registers $`e`$ simultaneously in outgoing list $`\text{OutEdges}(\text{src}(e))`$ and incoming list $`\text{InEdges}(\text{dst}(e))`$. Forward and reverse traversals exhibit symmetric algorithmic efficiency.
3. Deterministic Canonical Ordering: Incident edge lists maintain a total order keyed by: (1) category tag, (2) neighbor index, and (3) declaration sequence, ensuring bitwise reproducible compilation (REQ-0003) and invariant RFC 4122 UUIDv5 hashing (REQ-0010).
4. Error Recovery & Diagnostics: Operations enforce a deterministic, non-panicking contract (REQ-0011). Inserting an edge with an invalid or stale handle emits diagnostic `E0200`. Introducing a cycle into containment forest $``G_{\text{cont}} = (V, E_{\text{Contains}})``$ emits diagnostic `E0203`. Diagnostics strictly use synthetic abstract MBSE placeholders (`Package_0`, `Classifier_Alpha`, `Port_1`, `Flow_A`, `param_x : Real`).

## 2. Formal Invariant

Let $`\mathcal{A}`$ denote the contiguous node arena. The AST model multigraph is formally defined as a 6-tuple:

```math
G = \langle V, E, \text{src}, \text{dst}, \text{kind}, \text{prop} \rangle
```

where:

```math
\begin{aligned}
V &= \text{Nodes}(\mathcal{A}) \subset \mathbb{U}_{32}, \quad E \subset \mathbb{U}_{32} \\
\text{src}, \text{dst} &: E \longrightarrow V, \quad \text{kind} : E \longrightarrow \mathcal{K}_{\text{edge}}, \quad \text{prop} : E \longrightarrow \mathcal{P}
\end{aligned}
```

Canonical edge kinds and multigraph parallel edge admissibility:

```math
\begin{aligned}
\mathcal{K}_{\text{edge}} &= \{ \text{Contains}, \text{Specializes}, \text{Types}, \text{ConnectsTo}, \text{FlowsTo}, \text{AllocatesTo}, \text{Constrains}, \text{DependsOn} \} \\
\exists e_1, e_2 \in E &: (e_1 \ne e_2 \;\wedge\; \text{src}(e_1) = \text{src}(e_2) \;\wedge\; \text{dst}(e_1) = \text{dst}(e_2))
\end{aligned}
```

Bidirectional Adjacency and Degree Conservation:

```math
\begin{aligned}
\text{OutEdges}(u) = \{ e \in E \mid \text{src}(e) = u \}, &\quad \text{InEdges}(v) = \{ e \in E \mid \text{dst}(e) = v \} \\
\forall e \in E, \quad e \in \text{OutEdges}(\text{src}(e)) &\;\wedge\; e \in \text{InEdges}(\text{dst}(e)) \\
\sum_{v \in V} |\text{OutEdges}(v)| &= |E| = \sum_{v \in V} |\text{InEdges}(v)|
\end{aligned}
```

Deterministic Canonical Edge Ordering:

```math
\begin{aligned}
e_1 \prec_E e_2 \iff & (\text{kind}(e_1) \lt \text{kind}(e_2)) \lor (\text{kind}(e_1) = \text{kind}(e_2) \wedge \text{dst}(e_1) \lt \text{dst}(e_2)) \\
& \lor (\text{kind}(e_1) = \text{kind}(e_2) \wedge \text{dst}(e_1) = \text{dst}(e_2) \wedge e_1 \lt e_2)
\end{aligned}
```

Output-Sensitive Query Bound, Containment Acyclicity, and Diagnostics:

```math
\begin{aligned}
T_{\text{neighbors}}(v) &\le C_{\text{adj}} \cdot (|\text{OutEdges}(v)| + |\text{InEdges}(v)| + 1) \\
G_{\text{cont}} = (V, E_{\text{Contains}}), &\quad \text{Cycles}(G_{\text{cont}}) = \emptyset \\
\exists e \in E : (\text{src}(e) \notin V \lor \text{dst}(e) \notin V) &\implies \text{Diagnostic}(e, \text{E0200}) \in \mathcal{D} \\
\text{Cycles}(G_{\text{cont}}) \ne \emptyset &\implies \text{Diagnostic}(e, \text{E0203}) \in \mathcal{D}
\end{aligned}
```

## 3. Computational Complexity & Algorithmic Bounds

The AST multigraph operates strictly within Complexity Class $`\mathbf{P}`$.

- Node Access: Vertex lookup executes in worst-case $`O(1)`$ time via arena indexing.
- Edge Insertion: Inserting directed edge $`e = (u, v, k, \mathbf{p})`$ executes in amortized $`O(1)`$ time, yielding $`O(|V| + |E|)`$ total construction time for $`|V|`$ vertices and $`|E|`$ edges.
- Neighbor Retrieval: Forward queries $`\text{OutEdges}(v)`$ and reverse queries $`\text{InEdges}(v)`$ execute in output-sensitive $`O(\text{deg}(v))`$ time proportional to local degree $`\text{deg}(v) = |\text{OutEdges}(v)| + |\text{InEdges}(v)|`$. Kind filtering evaluates within $`O(\text{deg}(v))`$ time.
- Space Complexity: Memory scales linearly in $`O(|V| + |E|)`$ space using compact 32-bit index slabs without pointer indirection.

Deterministic adjacency indexing eliminates combinatorial backtracking, bypassing NP-hard register allocation (NP-7) and state reachability (NP-5) frontiers with guaranteed polynomial termination.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Bidirectional Adjacency Registration & Degree Conservation

- **Given:** AST nodes `Package_0`, `Classifier_Alpha`, `Classifier_Beta`, and `Port_1`.
- **When:** The multigraph builder inserts directed edges across kinds `Contains`, `Specializes`, and `ConnectsTo`.
- **Then:** Every edge $`e`$ is queryable in both $`\text{OutEdges}(\text{src}(e))`$ and $`\text{InEdges}(\text{dst}(e))`$, satisfying $``\sum_{v \in V} |\text{OutEdges}(v)| = |E| = \sum_{v \in V} |\text{InEdges}(v)|``$.
- **Diagnostic:** `E0200` emitted on adjacency registration discrepancy.

### AC-02: Parallel Multigraph Edge Admissibility

- **Given:** AST nodes `Port_1` and `Port_2`.
- **When:** The compiler records connection edge $``e_1``$ (`ConnectsTo`) and two flow edges $``e_2, e_3``$ (`FlowsTo` for `Flow_A` and `Flow_B`) between $``(\text{Port\_1}, \text{Port\_2})``$.
- **Then:** All three edges are assigned distinct 32-bit `EdgeId` keys without collision or property loss.
- **Diagnostic:** `E0200` emitted if parallel edge insertion collapses distinct edge identities.

### AC-03: Structural Containment Forest Acyclicity

- **Given:** Containment path where `Package_0` contains `Classifier_Alpha`, which contains `Port_1`.
- **When:** A compilation pass attempts to insert an inverted containment edge (`Contains`) from child `Port_1` to ancestor `Package_0`.
- **Then:** The engine rejects the cycle, preserves valid forest structure, and emits diagnostic `E0203` without panicking.
- **Diagnostic:** `E0203` emitted on detected cycle in containment hierarchy.

### AC-04: Invalid and Stale Node Handle Rejection

- **Given:** An edge insertion request referencing an unallocated 32-bit arena index or an expired node handle.
- **When:** Endpoint handles are validated during edge insertion.
- **Then:** Insertion is rejected under a total-function contract, graph state remains unchanged, and diagnostic `E0200` is recorded.
- **Diagnostic:** `E0200` emitted on invalid or out-of-bounds node handle.
