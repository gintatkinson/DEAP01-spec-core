## 1. Normative Statement

The compiler SHALL lower SysML v2 verification case definitions (`verification def`, `VerificationCaseDefinition`) as behavioral procedures specializing KerML `Behavior` and SysML v2 `CaseDefinition`, and verification usages (`verification`, `VerificationCaseUsage`) as discrete occurrences specializing KerML `Step` and `OccurrenceUsage`.

The lowering engine MUST enforce five core invariants:
1. **Specialization**: Definitions specialize KerML `Behavior` and `CalculationDefinition` (via `CaseDefinition`); usages specialize KerML `Step` and `OccurrenceUsage`.
2. **Subject Parameter**: Definitions MUST declare subject parameter $``s \in \mathbf{P}_{\text{subj}}``$ with direction `In` or `InOut` ($``\text{dir}(s) \in \{ \text{In}, \text{InOut} \}``$); `Out` direction emits `E0201`. Usages MUST bind conforming arguments ($``\tau(a_s) \le \tau(s)``$); mismatches emit `E0202`, omissions emit `E0200`.
3. **Verdict Codomain**: Definitions MUST declare result parameter of type `VerdictKind` with codomain $``\mathcal{V} = \{ \text{Pass}, \text{Fail}, \text{Inconclusive} \}``$; invalid return types emit `E0200`.
4. **Verification Binding**: The compiler SHALL formalize `verify` relationships ($V \xrightarrow{\text{verifies}} R$), certifying requirement $R$ verified iff evaluation yields `Pass`; `Fail` refutes, `Inconclusive` halts certification. Dangling references emit `E0200`.
5. **Acyclicity**: Invocation multigraph $``\mathcal{G}_{\text{v\_dep}}``$ MUST be a DAG; cycles emit `E0203`.

Metamodel specialization, subject typing, verdict codomain, and invocation acyclicity invariants:

\forall s\in\mathbf{P}_{\text{subj}}(VD),\quad\text{dir}(s)&\in\{\text{In},\text{InOut}\}\;\wedge\;\mathbf{P}_{\text{subj}}(VD)\ne\emptyset \\
\tau(p_{\text{verdict}})\equiv\text{VerdictKind}&\;\wedge\;\text{dir}(p_{\text{verdict}})\equiv\text{Out} \\

## 3. Computational Complexity & Algorithmic Bounds

Verification lowering and validation execute within Complexity Class $\mathbf{P}$.

For $N = |\mathcal{VD}|$ definitions, $M = |\mathcal{VU}|$ usages, and call edges $``|\mathcal{E}_{\text{v\_dep}}|``$:
- **Signature & Directionality**: Checking parameters and verdict types executes in $O(1)$ time per definition ($O(N)$ total).
- **Subtyping Conformance**: Subject argument conformance evaluates in $O(1)$ amortized time via cached bitsets (NP-3 fragment).
- **Traceability Binding**: Resolving each $(VU, R)$ verify edge executes in $O(1)$ symbol lookup time.
- **DAG Acyclicity**: Cycle detection over $``\mathcal{G}_{\text{v\_dep}}``$ executes in deterministic $``O(N + |\mathcal{E}_{\text{v\_dep}}|)``$ time.
- **Dispatch**: Verification dispatch and verdict recording execute in $O(1)$ state machine updates.

Total sequential complexity is $``O(N + M + |\mathcal{E}_{\text{v\_dep}}|)``$. Parallel work-stealing lowering scales as $``O((N + M + |\mathcal{E}_{\text{v\_dep}}|) / N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Canonical Verification Case Lowering & Verdict Resolution
- **Given:** `VerificationDef_Alpha` in `Package_0` with subject `Subject_A : Classifier_Alpha` and output `verdict : VerdictKind`, instantiated as `VerificationUsage_1` binding `Subject_A = Classifier_Alpha`.
- **When:** Lowering and type checking execute.
- **Then:** Nodes lower into arena storage with valid subject binding, specializing KerML `Behavior`, with empty diagnostic sink.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: Subject Parameter Directionality Violation Rejection
- **Given:** `VerificationDef_Alpha` declaring formal subject parameter with `out` directionality (`out Subject_A : Classifier_Alpha`).
- **When:** Parameter directionality analysis executes.
- **Then:** Lowering rejects non-`In`/`InOut` directionality with sentinel $``\bot_{\text{verif}}``$ and emits diagnostic `E0201`.
- **Diagnostic:** `E0201` (Invalid subject parameter direction).

### AC-03: Subject Argument Subtyping Mismatch & Missing Binding
- **Given:** Usage `VerificationUsage_1 : VerificationDef_Alpha` omitting subject argument or binding argument of type `Classifier_Beta` ($``\text{Classifier\_Beta} \not\le \text{Classifier\_Alpha}``$).
- **When:** Subject parameter conformance checking executes.
- **Then:** Lowering rejects invalid bindings with sentinel $``\bot_{\text{verif}}``$, emitting `E0202` on type mismatch or `E0200` on omission.
- **Diagnostic:** `E0202` on subtyping mismatch, `E0200` on missing subject argument.

### AC-04: Mandatory Tri-State Verdict Codomain Violation
- **Given:** `VerificationDef_Alpha` omitting verdict return parameter or specifying invalid return type `Real`.
- **When:** Signature verification and verdict type unification execute.
- **Then:** Lowering rejects malformed signature with sentinel $``\bot_{\text{verif}}``$ and emits diagnostic `E0200`.
- **Diagnostic:** `E0200` (Malformed verification signature).
