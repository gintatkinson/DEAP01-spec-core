## 1. Normative Statement

The compiler SHALL lower SysML v2 `transition` usages (`TransitionUsage`) as directed behavioral edges between state configurations, specializing KerML `ActionUsage` and `Step`.

The lowering engine MUST enforce five core invariants:
1. **Endpoint Resolution & Orthogonality**: Transitions SHALL connect valid source $``S_{\text{src}}``$ and target $``S_{\text{tgt}}``$ states; unresolved vertices emit `E0200`. Forks ($``|S_{\text{tgt}}| \ge 2``$) and joins ($``|S_{\text{src}}| \ge 2``$) MUST partition across distinct orthogonal regions of a common parallel parent; violations emit `E0200`.
2. **Trigger & Guard Typing**: Triggers $``e_{\text{trigger}}``$ MUST specialize KerML `EventOccurrence` (omitted triggers denote completion events $\epsilon$); invalid trigger types emit `E0201`. Guards $``g_{\text{guard}}``$ MUST evaluate to `Boolean` ($``\tau(g_{\text{guard}}) \equiv \text{Boolean}``$); non-boolean guards emit `E0202`. Sibling transitions with identical source and trigger MUST have disjoint guards; overlapping guards emit `E0200`.
3. **Inner-First Conflict Precedence**: When enabled transitions conflict on exit states, priority SHALL be decided by source tree depth. Deeper source states take precedence ($``\text{Depth}(t_1.s_{\text{src}}) > \text{Depth}(t_2.s_{\text{src}})``$).
4. **Triggerless Cycle Elimination**: Closed cycles of triggerless, guardless transitions emit `E0203`.
5. **Three-Phase Step Ordering**: Firing transition $t$ with $``s_{\text{LCA}} = \text{LCA}(S_{\text{src}}, S_{\text{tgt}})``$ SHALL: (1) exit states from $``S_{\text{src}}``$ to $``s_{\text{LCA}}``$ innermost-first, (2) execute effect $``a_{\text{effect}}``$ atomically, and (3) enter states to $``S_{\text{tgt}}``$ outermost-first.

## 2. Formal Invariant

Metamodel specialization, enabledness, conflict precedence, and cycle invariants:

```math
\begin{aligned}
\text{TransitionUsage} \le \text{ActionUsage} &\le \text{Step} \le \text{OccurrenceUsage} \\
\text{Enabled}(t, C, e, \sigma) &\iff (S_{\text{src}}(t) \subseteq C) \wedge (e_{\text{trigger}}(t) \approx e) \wedge (g_{\text{guard}}(t)(\sigma) = \text{true}) \\
\text{Conflicting}(t_1, t_2) &\iff \text{ExitSet}(t_1) \cap \text{ExitSet}(t_2) \ne \emptyset \\
\text{Conflicting}(t_1, t_2) \wedge \text{Enabled}(t_1) \wedge \text{Enabled}(t_2) &\implies (\text{Priority}(t_1) > \text{Priority}(t_2) \iff \text{Depth}(t_1.s_{\text{src}}) > \text{Depth}(t_2.s_{\text{src}})) \\
\forall s \in \mathcal{S}_{\text{states}}, \quad &(s, s) \notin \mathcal{T}_{\epsilon}^+, \quad \forall t \in \mathcal{T}_{\text{transitions}}, \quad \Delta_t = \text{UUIDv5}(\text{NS}_{\text{DEAP}}, \text{FQN}(t))
\end{aligned}
```

| Symbol / Term | Domain / Formal Definition |
| :--- | :--- |
| $``\mathcal{S}_{\text{states}}, \mathcal{T}_{\text{transitions}}``$ | State vertices and transition edges |
| $\text{Depth}(s)$ | Tree depth of state $s$ relative to root |
| $``\text{LCA}(S_{\text{src}}, S_{\text{tgt}})``$ | Least common ancestor state bounding exit/entry ladders |
| $\text{ExitSet}(t), \text{EnterSet}(t)$ | States exited and entered during firing |
| $``\mathcal{T}_{\epsilon}``$ | Set of instantaneous triggerless, guardless transitions |
| $``\Delta_t``$ | UUIDv5 identifier from $``\text{NS}_{\text{DEAP}}``$ and FQN |

## 3. Computational Complexity & Algorithmic Bounds

- **Complexity Class:** $\mathbf{P}$ (Deterministic Polynomial Time)
- **Asymptotic Bound:** $O(h)$ for LCA traversal ($h \le 32$); $O(1)$ for precedence checks; $O(V + E)$ for cycle detection.
- **Tractable Subclass & Frontier:** Grounds the tractable polynomial fragment of NP-5 (REQ-0124). Local precedence resolution and LCA synthesis execute in deterministic $O(h) \subseteq O(1)$ time without product state exploration. Parallel lowering scales as $``O((V + E) / N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Canonical Lowering & 3-Phase Execution
- **Given:** `StateDef_Alpha` declaring `State_A`, `State_B`, and `transition Transition_1 first State_A accept Event_0 if Guard_0 do Action_Effect then State_B`.
- **When:** Transition lowering executes.
- **Then:** `Transition_1` lowers into arena storage with an ordered 3-phase ladder (exit `State_A`, run `Action_Effect`, enter `State_B`).
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: Inner-First Conflict Resolution Precedence
- **Given:** Composite `State_Composite` with substate `State_Sub_1`, parent transition $``t_{\text{parent}}``$ to `State_B` on `Event_0`, and child transition $``t_{\text{child}}``$ from `State_Sub_1` to `State_A` on `Event_0`.
- **When:** `Event_0` is dispatched in active configuration $``\{ \text{State\_Composite}, \text{State\_Sub\_1} \}``$.
- **Then:** Engine selects $``t_{\text{child}}``$ over $``t_{\text{parent}}``$ because $``\text{Depth}(\text{State\_Sub\_1}) > \text{Depth}(\text{State\_Composite})``$.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-03: Orthogonal Fork-Join & Sibling Guard Rejection
- **Given:** Transitions with non-orthogonal endpoints, or sibling transitions sharing `Event_0` with overlapping guards.
- **When:** Orthogonality and guard disjointness validations execute.
- **Then:** Compiler rejects malformed definitions with sentinel $``\bot_{\text{transition}}``$ and emits `E0200`.
- **Diagnostic:** `E0200` on non-orthogonal endpoints or overlapping sibling guards.

### AC-04: Trigger Typing, Guard Typing & Instant Cycle Rejection
- **Given:** Transitions with non-event trigger `accept Classifier_Alpha`, non-boolean guard `if param_x + 1.0`, or instant cycle `State_1 -> State_2 -> State_1`.
- **When:** Semantic type checking and cycle detection execute.
- **Then:** Compiler emits `E0201` for trigger mismatch, `E0202` for non-boolean guard, and `E0203` for instant cycle.
- **Diagnostic:** `E0201`, `E0202`, or `E0203` on corresponding violation.
