## 1. Normative Statement

The KerML lowering engine SHALL formalize spatio-temporal entities as `OccurrenceDefinition` (specializing `Class`) and `OccurrenceUsage` (specializing `Feature` and `Occurrence`). Every `OccurrenceUsage` MUST be typed by one or more `OccurrenceDefinition` classifiers via `FeatureTyping`; typing with non-occurrence classifiers (e.g., `DataType`) SHALL be rejected with diagnostic `E0200`.

Each occurrence individual $`o`$ maps to a four-dimensional world-line manifold $`\mathcal{W}(o) \subseteq \mathbb{R}^3 \times \mathbb{R}`$ whose temporal projection yields bounded interval $``\text{temporal\_extent}(o) = [t_{\text{start}}(o), t_{\text{end}}(o)] \subset \mathbb{R}``$ with monotonic ordering $``t_{\text{start}}(o) \le t_{\text{end}}(o)``$. Inverted intervals ($``t_{\text{start}} \gt t_{\text{end}}``$) SHALL emit diagnostic `E0200`. Degenerate intervals ($``t_{\text{start}} = t_{\text{end}}``$) are valid instantaneous snapshot events. Multiplicity intervals $``\mu = [m_{\min}, m_{\max}]``$ MUST satisfy $``0 \le m_{\min} \le m_{\max}``$, or emit diagnostic `E0200`.

For composite occurrences ($``o_{\text{sub}} \subseteq_{\text{occ}} o_{\text{super}}``$), the compiler SHALL enforce manifold containment $``\mathcal{W}(o_{\text{sub}}) \subseteq \mathcal{W}(o_{\text{super}})``$, requiring temporal containment $``[t_{\text{start}}(o_{\text{sub}}), t_{\text{end}}(o_{\text{sub}})] \subseteq [t_{\text{start}}(o_{\text{super}}), t_{\text{end}}(o_{\text{super}})]``$. Parent extent violations SHALL emit diagnostic `E0200`. Containment graphs MUST be acyclic; cyclic chains SHALL emit diagnostic `E0203`.

## 2. Formal Invariant

Let $``\mathcal{O}_{\text{all}} = \mathcal{O}_{\text{def}} \cup \mathcal{O}_{\text{use}}``$ with $``\mathcal{O}_{\text{def}} \cap \mathcal{O}_{\text{use}} = \emptyset``$. Elements are formalized as tuples:

```math
\begin{aligned}
D &= \langle \text{id}_D, \text{name}_D, \mathcal{S}_D, \mathcal{F}_D, \mathcal{T}_D, \Delta_D \rangle \in \mathcal{O}_{\text{def}} \\
U &= \langle \text{id}_U, \text{name}_U, \text{owner}_U, \tau(U), \mu(U), \mathcal{T}_U, \Delta_U \rangle \in \mathcal{O}_{\text{use}}
\end{aligned}
```

where $``\text{id} \in \mathbb{N}_{32}``$, $``\text{name} \in \mathcal{S}_{\text{intern}}``$, $``\tau(U) \subseteq \mathcal{O}_{\text{def}} \setminus \{ \emptyset \}``$, $``\mu(U) = [m_{\min}(U), m_{\max}(U)]``$, and $`\Delta \in \{0, 1\}^{128}`$.

Each occurrence individual $`o \in ⟦ \mathcal{O} ⟧`$ maps to a 4D manifold $`\mathcal{W}(o) \subseteq \mathbb{R}^3 \times \mathbb{R}`$ with temporal projection $``\pi_{\text{time}}``$:

```math
\pi_{\text{time}}(\mathcal{W}(o)) = [t_{\text{start}}(o), t_{\text{end}}(o)] \subset \mathbb{R}, \quad t_{\text{start}}(o) \le t_{\text{end}}(o)
```

Sub-Occurrence Manifold and Temporal Interval Containment Invariant:

```math
\forall (o_1, o_2) \in \mathcal{R}_{\text{sub\_occ}}, \quad \mathcal{W}(o_1) \subseteq \mathcal{W}(o_2) \implies [t_{\text{start}}(o_1), t_{\text{end}}(o_1)] \subseteq [t_{\text{start}}(o_2), t_{\text{end}}(o_2)]
```

which decomposes to:

```math
\forall (o_1, o_2) \in \mathcal{R}_{\text{sub\_occ}}, \quad t_{\text{start}}(o_2) \le t_{\text{start}}(o_1) \le t_{\text{end}}(o_1) \le t_{\text{end}}(o_2)
```

Acyclicity, Multiplicity, and RFC 4122 UUIDv5 Invariants:

```math
\begin{aligned}
\forall o \in \mathcal{O}_{\text{all}}, \quad &(o, o) \notin \mathcal{R}_{\text{sub\_occ}}^+ \\
\forall U \in \mathcal{O}_{\text{use}}, \quad &\tau(U) \subseteq \mathcal{O}_{\text{def}} \quad \wedge \quad 0 \le m_{\min}(U) \le m_{\max}(U) \\
\forall n \in \mathcal{O}_{\text{all}}, \quad &\Delta_n = \text{UUIDv5}(\text{NS}_{\text{DEAP}}, \text{FQN}(n))
\end{aligned}
```

| Symbol / Term | Domain / Formal Definition |
| :--- | :--- |
| $``\mathcal{O}_{\text{def}}``$ | Set of lowered `OccurrenceDefinition` classifier arena records |
| $``\mathcal{O}_{\text{use}}``$ | Set of lowered `OccurrenceUsage` feature arena records |
| $\mathcal{W}(o)$ | Four-dimensional world-line manifold in $\mathbb{R}^3 \times \mathbb{R}$ |
| $``\pi_{\text{time}}``$ | Temporal interval projection mapping manifold to $``[t_{\text{start}}, t_{\text{end}}]``$ |
| $``\mathcal{R}_{\text{sub\_occ}}``$ | Directed sub-occurrence containment relation graph |
| $\tau(U)$ | Set of typing classifiers associated with usage $U$ via `FeatureTyping` |
| $\mu(U)$ | Multiplicity cardinality interval $``[m_{\min}, m_{\max}]``$ |
| $``\Delta_n``$ | Deterministic RFC 4122 UUIDv5 hash derived from namespace $``\text{NS}_{\text{DEAP}}``$ and topological FQN |

## 3. Computational Complexity & Algorithmic Bounds

The occurrence lowering, typing, and temporal containment validation passes execute strictly within Complexity Class $\mathbf{P}$.

For an input model with $``V = |\mathcal{O}_{\text{all}}|``$ occurrence nodes and $``E = |\mathcal{R}_{\text{sub\_occ}}|``$ containment edges:
1. Node allocation, interning, and type tag checking execute in amortized $O(1)$ time per node, totaling $O(V)$ time.
2. Temporal bounds validation $``t_{\text{start}} \le t_{\text{end}}``$ and multiplicity checking $``m_{\min} \le m_{\max}``$ execute in $O(1)$ scalar comparisons per node, totaling $O(V)$ time.
3. Sub-occurrence temporal containment checking requires $O(1)$ scalar comparisons per edge, totaling $O(E)$ time.
4. Sub-occurrence acyclicity checking executes in $O(V + E)$ time and $O(V)$ space via Tarjan's strongly connected components algorithm.

Total sequential verification complexity is $O(V + E)$. While unconstrained temporal constraint satisfiability is NP-complete (NP-1, REQ-0117), static occurrence temporal checking in REQ-0067 evaluates fixed scalar bounds over hierarchical containment DAGs without backtracking. Parallel package execution scales as $``O((V + E) / N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Canonical Occurrence Lowering and Temporal Extent Binding
- **Given:** A model declaring `OccurrenceDef_Alpha` with extent `[0.0, 100.0]` and nested `OccurrenceUsage_1 : OccurrenceDef_Alpha [1..1]` with extent `[10.0, 50.0]`.
- **When:** The compiler executes occurrence lowering and type validation.
- **Then:** Both elements are lowered into contiguous arena storage with valid 32-bit node handles, correct feature typing, and zero diagnostic emissions.
- **Diagnostic:** `E0200` emitted if type resolution or temporal extent binding fails.

### AC-02: Non-Occurrence Classifier Type Rejection
- **Given:** A structural primitive or identity-free data type `DataType_Beta`.
- **When:** An occurrence usage is declared typing a non-occurrence classifier (`OccurrenceUsage_Err : DataType_Beta`).
- **Then:** The compiler rejects the declaration at compile time, assigns an error sentinel, and records diagnostic error code `E0200`.
- **Diagnostic:** `E0200` emitted for invalid occurrence classifier typing.

### AC-03: Temporal Interval Bounds and Containment Violations
- **Given:** An occurrence with inverted bounds `[50.0, 10.0]` ($``t_{\text{start}} \gt t_{\text{end}}``$), or a sub-occurrence `OccurrenceUsage_Child` with extent `[10.0, 60.0]` exceeding parent `OccurrenceDef_Alpha` extent `[0.0, 50.0]`.
- **When:** The static semantic validation pass evaluates temporal well-formedness and containment.
- **Then:** The compiler rejects the invalid interval or containment violation with exact source byte spans and diagnostic error code `E0200`.
- **Diagnostic:** `E0200` emitted for temporal interval boundary or containment violations.

### AC-04: Sub-Occurrence Containment Acyclicity Verification
- **Given:** A synthetic cyclic sub-occurrence containment chain (`OccurrenceUsage_1` containing `OccurrenceUsage_2` containing `OccurrenceUsage_1`).
- **When:** The topological cycle detection pass traverses the containment relation graph.
- **Then:** The compiler detects the circular dependency, halts containment processing for the cycle, and emits diagnostic error code `E0203` detailing participating nodes.
- **Diagnostic:** `E0203` emitted for circular occurrence containment dependency.
