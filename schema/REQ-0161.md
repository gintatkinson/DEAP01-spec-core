## 1. Normative Statement

The projection engine of Subsystem 9 SHALL synthesize Epic specifications by projecting capability allocations across architectural subsystems under an M:N allocation model pursuant to OMG SysML v2 and INCOSE SE Handbook v5.0.

---

## 2. Formal Invariant

Let $``\mathcal{S} = \{S_1, \dots, S_m\}``$ and $``\mathcal{M}_{\text{capabilities}} = \{c_1, \dots, c_n\}``$. Capability allocation relation $``\mathcal{A} \subseteq \mathcal{M}_{\text{capabilities}} \times \mathcal{S}``$ and synthesis invariants satisfy:

```math
\begin{aligned}
\text{AllocatedSubsystems}(c)&=\{S\in\mathcal{S}\mid(c,S)\in\mathcal{A}\} \\
\text{SubsystemCapabilities}(S_k)&=\{c\in\mathcal{M}_{\text{capabilities}}\mid(c,S_k)\in\mathcal{A}\} \\
\text{Epic}(c)&=\langle\text{name}(c),\text{FQN}(c),\text{AllocatedSubsystems}(c)\rangle,\quad\forall c\in\mathcal{M}_{\text{capabilities}} \\
\forall c\in\mathcal{M}_{\text{capabilities}},&\quad|\text{AllocatedSubsystems}(c)|\ge 1 \\
(\text{AllocatedSubsystems}(c)=\emptyset&\lor\exists S\in\text{AllocatedSubsystems}(c):S\notin\mathcal{S})\implies\text{Diagnostic}(c,\text{E0303})\in\mathcal{D}_{\text{sink}}\land c\gets\bot_{\text{epic}} \\
(\text{HasCycle}(\text{Hierarchy}(S_k))&\lor\text{depth}(S_k)\gt D)\implies\text{Diagnostic}(S_k,\text{E0300})\in\mathcal{D}_{\text{sink}}\land S_k\gets\bot_{\text{epic}} \\
|\mathcal{D}_{\text{sink}}|\ge C_{\text{max\_errors}}&\implies\text{Diagnostic}(\text{E0199})\in\mathcal{D}_{\text{sink}},\quad\Delta_x=\text{UUIDv5}(\text{OID}_{\text{DEAP}},\text{FQN}(x))
\end{aligned}
```

| Symbol / Term | Domain / Formal Definition |
| :--- | :--- |
| $``\mathcal{S}, S_k``$ | Architectural subsystems and subsystem node $k$ |
| $``\mathcal{M}_{\text{capabilities}}, c``$ | SysML v2 capability universe and capability element |
| $``\mathcal{A}``$ | M:N capability allocation relation ($\mathcal{A} \subseteq \mathcal{M}_{\text{capabilities}} \times \mathcal{S}$) |
| $``\text{AllocatedSubsystems}(c)``$ | Subsystems allocated to capability $c$ |
| $``\text{SubsystemCapabilities}(S_k)``$ | Capabilities realized across subsystem $S_k$ |
| $``\text{Hierarchy}(S_k), D``$ | Structural decomposition tree and depth limit $D$ |
| $``\bot_{\text{epic}}, \mathcal{D}_{\text{sink}}, C_{\text{max\_errors}}``$ | Sentinel, diagnostic sink, and error limit |
| $``\Delta_x, \text{OID}_{\text{DEAP}}``$ | UUIDv5 anchor and canonical namespace OID |

## 3. Computational Complexity & Algorithmic Bounds

- **Complexity Class:** Class $\mathbf{P}$ (Deterministic Polynomial Time).
- **Asymptotic Bound:** $O(|S| \cdot D)$ tree decomposition traversal and $O(|C| + |S|)$ capability synthesis ($|S| = |\mathcal{S}|$, depth $D$, $``|C| = |\mathcal{M}_{\text{capabilities}}|``$). Work-stealing pool scales as $``O((|S| \cdot D + |C|)/N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$. Space: $O(|S| \cdot D + |C|)$; buffer: $O(1)$.
- **Tractable Subclass and Frontier:** N/A (Deterministic P). Tree traversal avoids NP-2 packing (REQ-0147) and NP-8 solving (REQ-0197).

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Structural Decomposition and Capability Projection
- **Given:** Subsystem `Subsystem_0` with `Part_0`, `Port_0` ($D = 3$), and `Capability_0`.
- **When:** Lowering Epic `Epic_Alpha`.
- **Then:** Emits `Epic_Alpha` with structural tree, capability table, and UUIDv5 anchors.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: Multi-Subsystem Capability Allocation
- **Given:** Capabilities mapped across one or more subsystems under an M:N allocation model.
- **When:** Projecting capability allocations across subsystems into Epics.
- **Then:** Confirms capabilities allocate across multiple subsystems ($|\text{AllocatedSubsystems}(c)| \ge 1$) without disjoint partition rejection, synthesizing valid cross-cutting Epics.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-03: Dangling Capability Allocation Rejection
- **Given:** Capability `Capability_Alpha` unallocated ($|\text{AllocatedSubsystems}(c)| = 0$) or allocated to non-existent subsystem $S \notin \mathcal{S}$.
- **When:** Validating capability allocation integrity.
- **Then:** Rejects model, emits `E0303`, and binds sentinel $``\bot_{\text{epic}}``$.
- **Diagnostic:** `E0303` (CapabilityAllocationViolation).

### AC-04: Decomposition Cycle and Delimiter Recovery
- **Given:** Subsystem `Subsystem_0` with cyclic nesting ($> D$) and undeclared targets, separated by `;`.
- **When:** Delimiter recovery processes faults.
- **Then:** Emits `E0300` and `E0303`, recovers on `;`, and halts at $``C_{\text{max\_errors}}``$ with `E0199`.
- **Diagnostic:** `E0300`, `E0303`, `E0199`.
