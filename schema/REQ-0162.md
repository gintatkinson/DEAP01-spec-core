## 1. Normative Statement

The downstream engine of Subsystem 9 SHALL synthesize UML class and component architecture diagrams within Epic specifications using synthesizer `Diagram_Alpha`, streaming artifacts directly through `ArtifactSink_0`.

---

## 2. Formal Invariant

Let $``\mathcal{V}_{\text{AST}}``$ denote arena AST nodes and $``\mathcal{S}_{\text{intern}}``$ denote interned symbols. Diagram topology, streaming bounds, and diagnostics satisfy:

```math
\begin{aligned}
\forall (u,v)\in E_{\text{diag}},&\quad\exists c\in\text{Connections}(\text{AST})\cup\text{Containments}(\text{AST})\land\text{endpoints}(c)=\{u,v\} \\
\forall u\in V_{\text{diag}},&\quad\exists n\in\mathcal{V}_{\text{AST}}\cap\text{Scope}(\text{Epic})\land\text{handle}(u)=n \\
M_{\text{sink}}\le&\;B_{\text{max\_chunk\_size}}\in O(1),\quad\lim_{|A|\to\infty}\frac{M_{\text{sink}}(|A|)}{|A|}=0 \\
u_i\prec_{\text{canon}} u_j&\iff\text{FQN}(u_i)\prec_{\text{lex}}\text{FQN}(u_j) \\
\neg\exists c:\text{endpoints}(c)=\{u,v\}&\implies\text{Diagnostic}(e,\text{E0300})\in\mathcal{D}_{\text{sink}}\land e\gets\bot_{\text{diag}} \\
\text{WriteFailure}(\text{ArtifactSink\_0})&\implies\text{Diagnostic}(\Sigma_{\text{sink}},\text{E0304})\in\mathcal{D}_{\text{sink}}\land\Sigma_{\text{sink}}\gets\bot_{\text{sink}} \\
|\mathcal{D}_{\text{sink}}|\ge C_{\text{max\_errors}}&\implies\text{Diagnostic}(\text{E0199})\in\mathcal{D}_{\text{sink}},\quad\Delta_x=\text{UUIDv5}(\text{OID}_{\text{DEAP}},\text{FQN}(x))
\end{aligned}
```

| Symbol / Term | Domain / Formal Definition |
| :--- | :--- |
| $``V_{\text{diag}}, E_{\text{diag}}``$ | Vertices and relation edges of projected diagram |
| $\text{Connections}, \text{Containments}$ | AST interconnect bindings and containment pairs |
| $``M_{\text{sink}}, B_{\text{max\_chunk\_size}}``$ | Active sink memory and chunk bound ($64\text{ KB}$) |
| $``|A|, \prec_{\text{canon}}``$ | Total artifact byte size and canonical ordering |
| $``\bot_{\text{diag}}, \bot_{\text{sink}}``$ | Sentinels for diagram faults and sink failures |
| $``\mathcal{D}_{\text{sink}}, C_{\text{max\_errors}}, \Delta_x``$ | Diagnostic sink, error capacity, and UUIDv5 anchor |

## 3. Computational Complexity & Algorithmic Bounds

- **Complexity Class:** Class $\mathbf{P}$ (Deterministic Polynomial Time).
- **Asymptotic Bound:** $O(|V| + |E|)$ graph traversal; streaming runs in $O(|A|)$ time with $O(1)$ buffer memory ($``M_{\text{sink}} \le B_{\text{max\_chunk\_size}}``$). Parallel pool scales as $``O((|V| + |E| + |A|)/N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$. Space: $O(|V| + |E|)$.
- **Tractable Subclass and Frontier:** N/A (Deterministic P). Streaming projection avoids NP-2 packing (REQ-0147) and NP-8 solving (REQ-0197).

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Canonical Architecture Diagram Synthesis
- **Given:** Model `Package_0` declaring subsystem `Classifier_Alpha` with parts `Node_0` and `Node_1`.
- **When:** Synthesizing architecture diagrams via `Diagram_Alpha`.
- **Then:** Emits valid UML class and component Mermaid diagrams.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: Streaming Artifact Sink Memory Invariant
- **Given:** Epic specification with artifact size $|A| \ge 10\text{ MB}$.
- **When:** Streaming chunks through `ArtifactSink_0` with threshold $``B_{\text{max\_chunk\_size}} = 64\text{ KB}``$.
- **Then:** Confirms resident memory satisfies $``M_{\text{sink}} \le 64\text{ KB} \in O(1)``$.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-03: Phantom Diagram Edge and Dangling Endpoint Rejection
- **Given:** Diagram referencing an edge to dangling endpoint `Node_1` lacking AST backing.
- **When:** Enforcing diagram soundness.
- **Then:** Fails closed, emits `E0300`, and binds sentinel $``\bot_{\text{diag}}``$.
- **Diagnostic:** `E0300` (PhantomDiagramEdgeViolation).

### AC-04: Streaming Sink Write Failure and Error Recovery
- **Given:** Write fault on `ArtifactSink_0` and syntax faults separated by `;`.
- **When:** Delimiter error recovery processes faults.
- **Then:** Emits `E0304`, binds $``\bot_{\text{sink}}``$, halts at $``C_{\text{max\_errors}}``$ with `E0199`.
- **Diagnostic:** `E0304`, `E0199`.
