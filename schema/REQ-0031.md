## 1. Normative Statement

The compiler ingestion engine shall provide a canonical SysML v2 textual concrete syntax emitter ($``\mathcal{E}_{\text{sysml}}``$) that serializes parsed intermediate schema IR entities into standard-compliant OMG SysML v2 textual notation, writing the unified model atomically to `schema/model.sysml`.

The emitter shall lower intermediate schema IR entities to normative SysML v2 syntax: packages to `package <name> {... }`, part definitions to `part def <name> {... }`, usages to `part <name> : <Type>;`, ports to directional declarations (`in port`, `out port`, `inout port`, `port`), attributes to `attribute <name> : <Type>;` with optional multiplicity intervals (`[l..u]`) and default values, connections to `connect <src> to <tgt>;`, constraints to `assert constraint <name> { <expr> };`, actions to `action def <name> {... }`, and item flows to `flow of <Type> from <src> to <tgt>;`.

Formatting shall enforce 4 ASCII spaces per indentation level (tabs prohibited) and single line feed terminations ($``\text{SYM}_{\text{LF}}``$, `0x0A`; carriage returns prohibited). Reserved keywords and non-standard identifiers shall be escaped in single backticks. Emitted files shall commence with a fixed timestamp-free header comment ensuring bitwise determinism (REQ-0003). Scoped child entities shall be sequenced in ascending lexicographical order by fully qualified name (REQ-0032).

## 2. Formal Invariant

Let $``\mathcal{A}_{\text{IR}} = \langle \mathcal{V}_{\text{IR}}, \mathcal{E}_{\text{IR}}, \rho \rangle``$ denote intermediate schema IR, with entity set $``\mathcal{V}_{\text{IR}}``$ and root package $`\rho`$. Canonical emission $``\mathcal{E}_{\text{sysml}} : \mathcal{V}_{\text{IR}} \to \Sigma^*``$ maps entities to SysML v2 textual syntax:

```math
\begin{aligned}
\mathcal{E}_{\text{sysml}}(P) &\longmapsto \text{"package "} \mathbin{\Vert} \text{Sanitize}(P) \mathbin{\Vert} \text{" \{ ... \}"} \\
\mathcal{E}_{\text{sysml}}(C) &\longmapsto \text{"part def "} \mathbin{\Vert} \text{Sanitize}(C) \mathbin{\Vert} \text{" \{ ... \}"} \\
\mathcal{E}_{\text{sysml}}(p) &\longmapsto \text{DirPrefix}(p) \mathbin{\Vert} \text{"port "} \mathbin{\Vert} \text{Sanitize}(p) \mathbin{\Vert} \text{" : "} \mathbin{\Vert} \text{type}(p) \mathbin{\Vert} \text{";"} \\
\mathcal{E}_{\text{sysml}}(a) &\longmapsto \text{"attribute "} \mathbin{\Vert} \text{Sanitize}(a) \mathbin{\Vert} \text{" : "} \mathbin{\Vert} \text{type}(a) \mathbin{\Vert} \text{MultSuffix}(a) \mathbin{\Vert} \text{";"} \\
\mathcal{E}_{\text{sysml}}(k) &\longmapsto \text{"connect "} \mathbin{\Vert} \text{path}(k_{\text{src}}) \mathbin{\Vert} \text{" to "} \mathbin{\Vert} \text{path}(k_{\text{tgt}}) \mathbin{\Vert} \text{";"} \\
\mathcal{E}_{\text{sysml}}(c) &\longmapsto \text{"assert constraint "} \mathbin{\Vert} \text{Sanitize}(c) \mathbin{\Vert} \text{" \{ "} \mathbin{\Vert} \text{expr}(c) \mathbin{\Vert} \text{" \};"} \\
\mathcal{E}_{\text{sysml}}(\alpha) &\longmapsto \text{"action def "} \mathbin{\Vert} \text{Sanitize}(\alpha) \mathbin{\Vert} \text{" \{ ... \}"}
\end{aligned}
```

Directional port prefixes and identifier sanitization satisfy:

```math
\text{DirPrefix}(p) = \begin{cases}
\text{"in "}, & \text{dir}(p) = \text{In} \\
\text{"out "}, & \text{dir}(p) = \text{Out} \\
\text{"inout "}, & \text{dir}(p) = \text{InOut} \\
\varepsilon, & \text{dir}(p) = \bot
\end{cases}
\qquad
\text{Sanitize}(s) = \begin{cases}
\text{"\`"} \mathbin{\Vert} s \mathbin{\Vert} \text{"\`"}, & s \in \mathcal{K}_{\text{sysml}} \lor \neg\text{IsIdent}(s) \\
s, & \text{otherwise}
\end{cases}
```

Deterministic qualified-name ordering, syntax grammar membership, atomic persistence, and diagnostic bindings satisfy:

```math
\begin{aligned}
\forall u \in \mathcal{V}_{\text{IR}}, \; \forall c_i, c_j \in \text{Children}(u): &\quad i \lt j \implies \text{FQN}(c_i) \prec_{\text{sym}} \text{FQN}(c_j) \\
\mathcal{S}_{\text{model}} = \mathcal{E}_{\text{sysml}}(\rho) &\implies \mathcal{S}_{\text{model}} \in \mathcal{L}(\mathcal{G}_{\text{sysml}}) \;\wedge\; \text{Diagnostics}(\text{Parse}_{\text{sysml}}(\mathcal{S}_{\text{model}})) = \emptyset \\
\text{WriteModel}(\mathcal{S}_{\text{model}}) &\iff \text{AtomicRename}(\text{TempFile}, \text{"schema/model.sysml"}) \\
\text{IOError}(\text{TempFile}) \lor \text{IOError}(\text{AtomicRename}) &\implies \text{DiagnosticCode::E0199} \in \mathcal{D} \\
\text{SyntaxFault}(u) &\implies \text{DiagnosticCode::E0102} \in \mathcal{D} \\
\text{UnresolvedType}(T) &\implies \text{DiagnosticCode::E0103} \in \mathcal{D}
\end{aligned}
```

## 3. Computational Complexity & Algorithmic Bounds

The canonical SysML v2 textual emitter executes within Complexity Class $`\mathbf{P}`$. Depth-first AST traversal visits each node $``u \in \mathcal{V}_{\text{IR}}``$ once in deterministic $``O(|\mathcal{V}_{\text{IR}}|)``$ time. Sorting child entities by fully qualified name within scopes of size $``k_u``$ requires $``O(\sum k_u \log k_u) \le O(|\mathcal{V}_{\text{IR}}| \log k_{\text{max}})``$, reducing to $``O(|\mathcal{V}_{\text{IR}}|)``$ with pre-sorted scope tables (REQ-0032, REQ-0040). Token formatting and contiguous buffer appends scale linearly as $``O(L_{\text{bytes}}) = O(|\mathcal{V}_{\text{IR}}|)``$. Atomic persistence requires $``O(L_{\text{bytes}})``$ sequential stream writes and an $`O(1)`$ rename syscall. Total runtime is strictly linear in model size: $``T(|\mathcal{V}_{\text{IR}}|, L_{\text{bytes}}) \in O(|\mathcal{V}_{\text{IR}}| + L_{\text{bytes}}) = O(N)``$. Auxiliary space is $``O(L_{\text{bytes}}) = O(N)``$ for pre-allocated buffers and $``O(D_{\text{max}}) = O(1)``$ stack frames for nesting depth $``D_{\text{max}} \le 64``$. Parallel emission across $`K`$ units on a bounded work-stealing pool ($``N_{\text{max\_workers}}``$) runs in $``O(\lceil K / N_{\text{max\_workers}} \rceil \cdot N_{\text{max}})``$ time. Deterministic linear emission executes strictly in polynomial time $`\mathbf{P}`$, bypassing NP-complete frontiers (NP-1--NP-8).

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Canonical SysML v2 Syntax Emission
- **Given:** Schema IR with `Package_0`, `Classifier_Alpha`, ports `Port_1`, `Port_2`, attributes, connections, constraints, and actions.
- **When:** Synthesizing the canonical SysML v2 model via $``\mathcal{E}_{\text{sysml}}``$.
- **Then:** Emits valid concrete syntax to `schema/model.sysml` parsing cleanly with zero diagnostics.
- **Diagnostic:** `E0102` on syntax mapping failure.

### AC-02: Deterministic Qualified-Name Symbol Ordering
- **Given:** Schema IR declaring child entities in reverse order within `Package_0`.
- **When:** Lowering child entities to text.
- **Then:** Emits child elements in ascending order $``\prec_{\text{sym}}``$ by fully qualified name per REQ-0032.
- **Diagnostic:** `E0102` on ordering violation.

### AC-03: Identifier Sanitization and Keyword Escaping
- **Given:** Schema IR entities with identifiers colliding with reserved keywords (`package`, `part`, `def`, `attribute`, `connect`, `flow`, `action`).
- **When:** Serializing identifier tokens.
- **Then:** Encloses colliding identifiers in single backticks (e.g., `` `package` ``) while emitting valid identifiers unescaped.
- **Diagnostic:** `E0102` on escaping failure.

### AC-04: Atomic File Persistence and Integrity
- **Given:** Schema IR targeting `schema/model.sysml` with simulated failure prior to `AtomicRename`.
- **When:** Executing file persistence to disk.
- **Then:** Destination `schema/model.sysml` retains its prior valid state or transitions completely, leaving zero corrupted files.
- **Diagnostic:** `E0199` on I/O write or rename failure.
