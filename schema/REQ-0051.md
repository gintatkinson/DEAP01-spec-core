## 1. Normative Statement

The compiler core metamodel and AST graph engine shall implement a deterministic incremental compilation caching subsystem structured upon an explicit module dependency directed acyclic graph (DAG) $`G = (V, E)`$. For each module $`M \in V`$, the compiler shall compute a 64-bit cryptographic content hash $``H_{\text{source}}(M)``$ upon source ingestion, capturing normalized source tokens and syntax tree nodes. Each directed edge $`(U, V) \in E`$ denotes that downstream module $`V`$ depends on upstream module $`U`$.

For each module $`M \in V`$, the incremental engine shall compute composite state hash $``H_{\text{state}}(M)``$ by combining $``H_{\text{source}}(M)``$ with upstream dependency state hashes $`\text{Deps}(M)`$ via bitwise XOR reduction. State hash propagation shall proceed in topological sort order over $`G`$. The compiler shall compare $``H_{\text{state}}(M)``$ against cached state hash $``H_{\text{cached}}(M)``$ from the cache manifest.

If $``H_{\text{state}}(M) = H_{\text{cached}}(M)``$, the compiler shall bypass re-analysis and re-emission for module $`M`$, reusing cached AST subgraphs, typed symbol tables, and artifacts directly ($``T_{\text{recompile}}(M) = 0``$). If $``H_{\text{source}}(M) \neq H_{\text{cached\_source}}(M)``$ or any upstream state hash changes, the compiler shall invalidate module $`M`$ and its transitive downstream dependent set $`\text{TransitiveDependents}(M)`$, scheduling strictly these affected modules for recomputation. Modules outside this invalidation closure shall be preserved and reused from cache.

All recomputed state hashes, source hashes, and artifact descriptors must be committed atomically to the persistent cache manifest upon pass completion. If a dependency cycle is detected during DAG construction or topological sorting, the compiler shall reject the invalid graph, emit diagnostic error code `E0203` detailing the cyclic path, and terminate gracefully. If the cache manifest is missing or corrupted, the compiler shall emit diagnostic error code `E0200`, discard the cache partition, and execute a full clean build from scratch.

## 2. Formal Invariant

Let $`G = (V, E)`$ be the module dependency DAG where $`V`$ represents compilation modules and directed edge $`(U, V) \in E`$ denotes that module $`V`$ depends on upstream module $`U`$. Let $`\text{Deps}(M) = \{ U \in V \mid (U, M) \in E \}`$ denote the direct upstream dependencies of $`M \in V`$.

The transitive downstream dependent set $`\text{TransitiveDependents}(M)`$ is defined by forward path reachability:

```math
\text{TransitiveDependents}(M) = \{ D \in V \mid M \to^+ D \}
```

The composite state hash $``H_{\text{state}}(M)``$ satisfies:

```math
H_{\text{state}}(M) = \text{Hash64}\left( H_{\text{source}}(M) \mathbin{\Vert} \bigoplus_{D \in \text{Deps}(M)} H_{\text{state}}(D) \right)
```

where $`\mathbin{\Vert}`$ denotes byte concatenation and $``\bigoplus_{D \in \emptyset} H_{\text{state}}(D) = 0^{64}``$.

Topological Order and Cache Bypass Invariants:

```math
\begin{aligned}
\forall (U, V) \in E &\implies \pi(U) \lt \pi(V) \\
H_{\text{state}}(M) = H_{\text{cached}}(M) &\implies \text{ReuseCachedArtifacts}(M) \quad \land \quad T_{\text{recompile}}(M) = 0
\end{aligned}
```

Downstream Transitive Invalidation Invariant:

```math
H_{\text{source}}(M) \neq H_{\text{cached\_source}}(M) \implies \forall D \in \text{TransitiveDependents}(M), \quad \text{InvalidateCache}(D)
```

Recomputation Set Equivalence: for mutated source set $``\mathcal{M}_{\text{mut}} = \{ M \in V \mid H_{\text{source}}(M) \neq H_{\text{cached\_source}}(M) \}``$:

```math
\mathcal{R} = \bigcup_{M \in \mathcal{M}_{\text{mut}}} \left( \{ M \} \cup \text{TransitiveDependents}(M) \right) = \{ M \in V \mid H_{\text{state}}(M) \neq H_{\text{cached}}(M) \}
```

Deterministic Merkle Parity and Atomic Commit Invariants:

```math
\begin{aligned}
\mathcal{A}_{\text{inc}} \equiv \mathcal{A}_{\text{clean}} &\quad \land \quad \text{MerkleRoot}(\mathcal{A}_{\text{inc}}) = \text{MerkleRoot}(\mathcal{A}_{\text{clean}}) \\
\forall v \in V, \quad \neg (v &\to^+ v) \\
\text{Commit}(\mathcal{M}_{\text{staged}}) &\implies (\mathcal{M}_{\text{manifest}} \leftarrow \mathcal{M}_{\text{staged}})
\end{aligned}
```

## 3. Computational Complexity & Algorithmic Bounds

The module dependency tracking and incremental cache invalidation engine operates strictly within Complexity Class $`\mathbf{P}`$. DAG construction, cycle detection, and topological sorting execute in deterministic linear time $`O(|V| + |E|)`$ and auxiliary memory $`O(|V| + |E|)`$ via Tarjan's SCC or Kahn's algorithm. State hash propagation in topological order requires $`O(|V| + |E|)`$ aggregate time. Transitive invalidation closure $`\mathcal{R}`$ computation executes in $``O(|\mathcal{R}| + |E_{\mathcal{R}}|) \subseteq O(|V| + |E|)``$ via forward breadth-first search. Cache lookup for unimpacted modules $`V \setminus \mathcal{R}`$ requires $`O(1)`$ amortized time per unit. Incremental invalidation operates strictly in polynomial time $`\mathbf{P}`$, requiring no combinatorial search and bypassing downstream NP-hard frontiers such as NP-2 (REQ-0147) and NP-7 (REQ-0180).

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Leaf Module Mutation and Isolated Recompilation
- **Given:** A dependency DAG in `Package_0` structured as `Module_Alpha -> Module_Beta -> Module_Gamma`, with state hashes matching cached records.
- **When:** Leaf module `Module_Gamma` source is mutated ($``H_{\text{source}}(\text{Module\_Gamma}) \neq H_{\text{cached\_source}}(\text{Module\_Gamma})``$) and incremental compilation executes.
- **Then:** Strictly `Module_Gamma` is marked for recomputation ($``\mathcal{R} = \{ \text{Module\_Gamma} \}``$); upstream `Module_Alpha` and `Module_Beta` are reused directly from cache ($``T_{\text{recompile}} = 0``$).
- **Diagnostic:** `E0200` emitted on redundant re-analysis of unaffected modules.

### AC-02: Root Module Mutation and Transitive Downstream Invalidation
- **Given:** A dependency chain `Module_Alpha -> Module_Beta -> Module_Gamma` and disjoint `Module_Delta` in `Package_0`.
- **When:** Root module `Module_Alpha` source is mutated.
- **Then:** The compiler identifies $``\text{TransitiveDependents}(\text{Module\_Alpha}) = \{ \text{Module\_Beta}, \text{Module\_Gamma} \}``$, recomputes $``\mathcal{R} = \{ \text{Module\_Alpha}, \text{Module\_Beta}, \text{Module\_Gamma} \}``$, and reuses `Module_Delta` from cache.
- **Diagnostic:** `E0200` emitted if any transitive dependent is omitted from invalidation or if `Module_Delta` is re-analyzed.

### AC-03: Clean No-Op Incremental Cache Hit Bypass
- **Given:** An unmodified workspace where all module source hashes match cached records ($``H_{\text{source}}(M) = H_{\text{cached\_source}}(M)``$ for all $`M \in V`$).
- **When:** Incremental compilation executes.
- **Then:** All module state hashes match cached state hashes ($``H_{\text{state}}(M) = H_{\text{cached}}(M)``$), all AST subgraphs are reused from cache ($``T_{\text{recompile}}(M) = 0``$), and Merkle root parity is preserved.
- **Diagnostic:** `E0200` emitted if any module undergoes re-parsing during an unmodified build.

### AC-04: Circular Module Dependency Rejection
- **Given:** An incremental module import introducing a cyclic dependency (`Module_Alpha -> Module_Beta -> Module_Alpha`).
- **When:** The compiler executes DAG construction and cycle detection.
- **Then:** The compiler detects non-acyclicity, halts lowering, rejects the invalid graph, and emits diagnostic error code `E0203` detailing cycle path coordinates without panicking.
- **Diagnostic:** `E0203` (Circular module dependency detected in module DAG).
