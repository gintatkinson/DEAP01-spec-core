## 1. Normative Statement

The solver SHALL analyze state machine reachability, diagnosing dead states, unreachable transitions, and trap states.

Lowering MUST enforce:
1. **Initial Singularity**: Scopes require initial state $``s_0 \in \mathcal{S}``$ ($``|\{s \mid \text{is\_initial}(s)\}| = 1``$); faults emit `E0400`. State $``s_0``$ is reachable ($``s_0 \in \mathcal{R}``$).
2. **Fixed-Point Reachability**: Reachable set $\mathcal{R} \subseteq \mathcal{S}$ is least fixed point $``\mathcal{R} = \mu X. (\{s_0\} \cup \text{Post}(X))``$ via BFS/DFS over a visited bitset. $\text{Post}(X)$ evaluates transitions $\tau \in \mathcal{T}$ with satisfiable guards ($``\text{Sat}(g_\tau) \ne \text{false}``$).
3. **Dead States**: States lacking paths from $``s_0``$ ($``s \in \mathcal{D}_{\text{dead}} = \mathcal{S} \setminus \mathcal{R}``$) emit `E0400`, detecting isolated vertices and cyclic islands.
4. **Dead Transitions & Trap Sinks**: Transitions from dead states ($``s_{\text{src}} \in \mathcal{D}_{\text{dead}}``$) or with unsatisfiable guards emit `E0403`. Reachable non-final states lacking outgoing transitions are trap states ($``s \in \mathcal{D}_{\text{trap}}``$), emitting `E0403`.
5. **Hierarchy Propagation**: Unreachable composite state $``S_{\text{comp}} \in \mathcal{D}_{\text{dead}}``$ transitively invalidates nested states. Reachable composite states propagate reachability to internal initial states.

## 2. Formal Invariant

State machine reachability closure, dead state partitions, and diagnostic triggers:

```math
\begin{aligned}
\mathcal{G}_{\text{sm}}=\langle\mathcal{S},\mathcal{T},s_0,\mathcal{S}_{\text{final}}\rangle,\; s_0\in\mathcal{S},\;\mathcal{S}_{\text{final}}\subseteq\mathcal{S}\\
|\{s\in\mathcal{S}\mid\text{is\_initial}(s)=\text{true}\}|=1\\
\text{Post}(X)=\{s'\in\mathcal{S}\mid\exists s\in X,\;\exists\tau=(s,s',g_\tau)\in\mathcal{T}:\text{Sat}(g_\tau)\}\\
\mathcal{R}=\mu X.(\{s_0\}\cup\text{Post}(X))=\bigcup_{k=0}^{|\mathcal{S}|-1}R_k,\; R_0=\{s_0\},\; R_{k+1}=R_k\cup\text{Post}(R_k)\\
\mathcal{D}_{\text{dead}}=\mathcal{S}\setminus\mathcal{R},\;\mathcal{T}_{\text{dead}}=\{(s,s',g_\tau)\in\mathcal{T}\mid s\in\mathcal{D}_{\text{dead}}\lor\neg\text{Sat}(g_\tau)\}\\
\mathcal{D}_{\text{trap}}=\{s\in\mathcal{R}\setminus\mathcal{S}_{\text{final}}\mid\forall(s,s',g_\tau)\in\mathcal{T},\;\neg\text{Sat}(g_\tau)\}\\
(|\{s\in\mathcal{S}\mid\text{is\_initial}(s)\}|\ne 1\lor s\in\mathcal{D}_{\text{dead}})\implies\text{Diagnostic}(s,\text{E0400})\land s\gets\bot_{\text{state}}\\
(\tau\in\mathcal{T}_{\text{dead}}\lor s\in\mathcal{D}_{\text{trap}})\implies\text{Diagnostic}(\tau\lor s,\text{E0403})\land\tau\gets\bot_{\text{trans}}\\
\forall n\in\mathcal{S}\cup\mathcal{T},\;\Delta_n=\text{UUIDv5}(\text{NS}_{\text{DEAP}},\text{FQN}(n))
\end{aligned}
```

| Symbol / Term | Domain / Formal Definition |
| :--- | :--- |
| $``\mathcal{G}_{\text{sm}}, \mathcal{S}, \mathcal{T}``$ | State machine graph, state set, transitions |
| $``s_0, \mathcal{S}_{\text{final}}``$ | Initial state and terminal state set |
| $\text{Post}(X), \mathcal{R}$ | Forward post-image and reachable state set |
| $``\mathcal{D}_{\text{dead}}, \mathcal{T}_{\text{dead}}``$ | Dead states and unreachable transitions |
| $``\mathcal{D}_{\text{trap}}``$ | Non-final states lacking outgoing transitions |
| $``\bot_{\text{state}}, \bot_{\text{trans}}, \Delta_n``$ | Error sentinels and UUIDv5 identifier |

## 3. Computational Complexity & Algorithmic Bounds

- **Complexity Class:** $\mathbf{P}$
- **Asymptotic Bound:** $O(|\mathcal{S}| + |\mathcal{T}|)$ BFS/DFS traversal; $O(|\mathcal{S}|)$ dead state sweep; $O(|\mathcal{S}| \log |\mathcal{S}|)$ diagnostic sorting.
- **Tractable Subclass & Frontier:** Avoids state explosion of concurrent regions (NP-5). Work-stealing scales as $``O((|\mathcal{S}| + |\mathcal{T}|) / N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Canonical Reachability & Convergence
- **Given:** `StateMachine_Alpha` with initial `State_0` reaching `State_1`, `State_2` cyclically.
- **When:** Reachability executes fixed-point BFS traversal.
- **Then:** Computes $``\mathcal{R} = \{\text{State\_0}, \text{State\_1}, \text{State\_2}\}``$, with $``\mathcal{D}_{\text{dead}} = \emptyset``$.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: Bitset Marking & Hierarchical Propagation
- **Given:** `State_Composite_1` with initial `State_Sub_0` chained through 1,024 states.
- **When:** Reachability marks the bitset and traverses composite containment.
- **Then:** All 1,024 states are marked reachable; zero dead states reported.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-03: Dead State & Island Rejection
- **Given:** `StateMachine_Alpha` with reachable `State_0`, isolated `State_Dead_1`, and island `State_Dead_2` $\to$ `State_Dead_3`.
- **When:** Reachability evaluates $``\mathcal{D}_{\text{dead}} = \mathcal{S} \setminus \mathcal{R}``$.
- **Then:** Rejects compilation, diagnosing `State_Dead_1`, `State_Dead_2`, `State_Dead_3` as dead.
- **Diagnostic:** `E0400` (DeadStateDetected).

### AC-04: Dead Transition, Trap & Delimiter Recovery
- **Given:** `StateMachine_Alpha` with false guard ($``g_\tau \equiv \text{false}``$) and trap `State_Trap_1` before `;`, followed by `StateMachine_Beta`.
- **When:** Reachability and delimiter recovery execute.
- **Then:** Emits `E0403`, binds $``\bot_{\text{trans}}``$, recovers on `;`, validating `StateMachine_Beta`, halting at $``C_{\text{max\_errors}}``$ with `E0199`.
- **Diagnostic:** `E0403`, `E0199`.
