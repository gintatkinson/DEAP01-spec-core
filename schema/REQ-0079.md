## 1. Normative Statement

The statechart lowering engine SHALL formalize SysML v2 state machine definitions (`state def`, `StateDefinition`) and state usages (`state`, `StateUsage`) as behavioral classifiers specializing KerML `ActionDefinition` and `ActionUsage`.

The lowering engine MUST enforce hierarchical containment and concurrency invariants:
1. **Hierarchical State Tree**: States form a rooted tree $(S, \sqsubseteq)$ where $``s_1 \sqsubset s_2``$ denotes ownership of sub-state $``s_1``$ by composite state $``s_2``$. Containment MUST be acyclic; cyclic chains ($``s_1 \sqsubset^+ s_1``$) emit diagnostic `E0203`. In non-parallel composite states, at most one sub-state is active simultaneously ($|\text{active}(s)| \le 1$). Sibling state names within identical scope MUST be unique; duplicates emit `E0200`.
2. **Orthogonal Parallel Concurrency**: Parallel composite states SHALL contain $k \ge 2$ orthogonal regions $``R_1, \dots, R_k``$. Degenerate states ($k \lt 2$) emit `E0200`.
3. **Cartesian State Configuration**: Active state configurations SHALL satisfy Cartesian product vector $``\mathbf{s} \in \prod_{i=1}^k \text{States}(R_i)``$, enforcing $``|\text{active}(R_i)| = 1``$ for each region.
4. **Transition Synchronization**: Direct transitions between distinct orthogonal regions ($``s_a \in R_i \to s_b \in R_j, i \ne j``$) without fork/join mediation emit `E0200`. Non-state typing emits `E0200`.

## 2. Formal Invariant

Metamodel specialization hierarchy, containment acyclicity, and concurrency invariants:

```math
\begin{aligned}
\text{StateDef} \le \text{ActionDefinition} &\le \text{Behavior}, \quad \text{StateUsage} \le \text{ActionUsage} \le \text{Feature} \\
s_1 \sqsubset^+ s_2 &\implies s_2 \not\sqsubset^+ s_1 \\
\text{is\_parallel}(s) = \text{false} &\implies |\text{active}(\mathcal{C}_s)| \le 1 \\
\text{is\_parallel}(s) = \text{true} &\implies |\mathcal{R}_s| = k \ge 2 \;\wedge\; \mathbf{s} \in \prod_{i=1}^k \text{States}(R_i) \\
(s_{\text{src}} \in R_i \wedge s_{\text{tgt}} \in R_j \wedge i \ne j) &\implies \text{false} \\
\forall n \in \mathcal{S}_{\text{all}}, \quad \Delta_n &= \text{UUIDv5}(\text{NS}_{\text{DEAP}}, \text{FQN}(n))
\end{aligned}
```

## 3. Computational Complexity & Algorithmic Bounds

State lowering, hierarchy construction, and structural validation execute in Complexity Class $\mathbf{P}$.

For an input model with $V$ state nodes ($``V = |\mathcal{S}_{\text{all}}|``$) and $E$ transition edges:
1. Arena allocation, symbol interning, and ancestor/LCA lookups evaluate in $O(1)$ amortized time ($h \le 32$).
2. Containment tree acyclicity and region partitioning validate in $O(V)$ time via Tarjan SCC algorithm.
3. Cross-region transition legality checks verify region membership in $O(1)$ time per transition, totaling $O(E)$ time.

Total sequential verification complexity is $O(V + E)$, grounding the tractable polynomial fragment of NP-5. Parallel package lowering scales as $``O((V + E) / N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Canonical Hierarchical State Lowering
- **Given:** Valid `state def StateDef_Alpha` declaring composite `State_A` with sub-states `State_1` and `State_2`.
- **When:** State machine lowering and hierarchy construction execute.
- **Then:** States lower into arena storage with active exclusivity ($``|\text{active}(\text{State\_A})| \le 1``$) and zero diagnostics.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: Orthogonal Parallel State and Cartesian Space Conformance
- **Given:** Parallel composite `ParallelState_Omega` declaring $k = 2$ orthogonal regions `Region_1` and `Region_2`.
- **When:** Region partitioning is evaluated.
- **Then:** Cartesian space $``\text{States}(R_1) \times \text{States}(R_2)``$ is established with $``|\text{active}(R_i)| = 1``$.
- **Diagnostic:** `E0200` on region partitioning failure.

### AC-03: Degenerate Parallel State and Cross-Region Transition Rejection
- **Given:** A parallel state with $k \lt 2$ regions, or direct transition crossing orthogonal regions without fork/join.
- **When:** Semantic validation checks region cardinality and transition boundaries.
- **Then:** The compiler rejects the model and emits diagnostic `E0200`.
- **Diagnostic:** `E0200` on degenerate parallel regions or unsynchronized transitions.

### AC-04: Circular State Containment Cycle Detection
- **Given:** Cyclic containment chain `State_1 \sqsubset State_2 \sqsubset State_3 \sqsubset State_1`.
- **When:** Topological acyclicity analysis traverses the containment graph.
- **Then:** The compiler isolates the cycle, halts containment lowering, and emits diagnostic `E0203`.
- **Diagnostic:** `E0203` on circular state containment cycle.
