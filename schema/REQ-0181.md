## 1. Normative Statement

## 2. Formal Invariant

Continuous and discrete dynamics, RK4 updates, and stability bounds satisfy:

```math
\begin{aligned}
\dot{\mathbf{x}}(t)=\mathbf{A}\mathbf{x}(t)+\mathbf{B}\mathbf{u}(t),&\quad\mathbf{y}(t)=\mathbf{C}\mathbf{x}(t)+\mathbf{D}\mathbf{u}(t) \\
\mathbf{x}_{k+1}=\mathbf{A}_d\mathbf{x}_k+\mathbf{B}_d\mathbf{u}_k,&\quad\mathbf{A}_d=e^{\mathbf{A}h},\quad\mathbf{B}_d=\int_0^h e^{\mathbf{A}\tau}d\tau\cdot\mathbf{B} \\
\mathbf{k}_1=f(t_n,\mathbf{x}_n),&\quad\mathbf{k}_2=f(t_n+\tfrac{h}{2},\mathbf{x}_n+\tfrac{h}{2}\mathbf{k}_1) \\
\mathbf{k}_3=f(t_n+\tfrac{h}{2},\mathbf{x}_n+\tfrac{h}{2}\mathbf{k}_2),&\quad\mathbf{k}_4=f(t_n+h,\mathbf{x}_n+h\mathbf{k}_3) \\
\mathbf{x}_{n+1}=\mathbf{x}_n+\tfrac{h}{6}(\mathbf{k}_1+2\mathbf{k}_2+2\mathbf{k}_3+\mathbf{k}_4),&\quad R(z)=1+z+\tfrac{z^2}{2}+\tfrac{z^3}{6}+\tfrac{z^4}{24} \\
\forall\lambda\in\text{eig}(\mathbf{A}),\ |R(\lambda h)|\le 1,&\quad(\text{rows}(\mathbf{A})\ne\text{cols}(\mathbf{A}))\implies\text{Diagnostic}(v,\text{E0300})\in\mathcal{D}_{\text{sink}} \\
(h\le 0\lor |R(\lambda h)|>1\lor\text{IsNaN}(\mathbf{x}))&\implies\text{Diagnostic}(v,\text{E0507})\in\mathcal{D}_{\text{sink}}\land v\gets\bot_{\text{ss}} \\
|\mathcal{D}_{\text{sink}}|\ge C_{\text{max\_errors}}&\implies\text{Diagnostic}(\text{E0199})\in\mathcal{D}_{\text{sink}},\quad\Delta_v=\text{UUIDv5}(\text{OID}_{\text{DEAP}},\text{FQN}(v))
\end{aligned}
```

| Symbol / Term | Domain / Formal Definition |
| :--- | :--- |
| $``\mathbf{A},\mathbf{B},\mathbf{C},\mathbf{D},\mathbf{A}_d,\mathbf{B}_d``$ | Continuous and discrete state-space matrices |
| $``\mathbf{x},\mathbf{u},\mathbf{y},\mathbf{k}_1..\mathbf{k}_4``$ | State, input, output vectors, RK4 stages |
| $R(z),\text{eig}(\mathbf{A})$ | Stability polynomial, eigenvalue spectrum |
| $``\bot_{\text{ss}},\mathcal{D}_{\text{sink}},C_{\text{max\_errors}}``$ | Fault sentinel, diagnostic sink, error limit |
| $``\Delta_v,\text{OID}_{\text{DEAP}},\text{FQN}(v)``$ | UUIDv5 anchor, namespace OID, topological path |

## 3. Computational Complexity & Algorithmic Bounds

- **Complexity Class:** Class $\mathbf{P}$.
- **Asymptotic Bound:** State evaluation runs in $O(n^2)$ time per step; RK4 update takes $O(n)$ time. Offline ZOH discretization requires $O(n^3)$ operations. Work-stealing scales as $``O(S \cdot n^2 / N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$. Memory is $O(n^2)$.
- **Tractable Subclass and Frontier:** N/A (Deterministic P). Stepping is deterministic without branching, avoiding NP-1 and NP-8.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: State-Space Evaluation and RK4 Convergence
- **Given:** Model `StateSpaceEngine_Alpha` with `Matrix_A0` ($n = 2$), `Matrix_B0`, and `Vector_X1`.
- **When:** `RK4Solver_0` integrates across steps $``h_1 = 0.1``$ and $``h_2 = 0.05``$.
- **Then:** Trajectory converges with local error $O(h^5)$ and global error $O(h^4)$ within 2% tolerance.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: Matrix Dimension Boundary Verification
- **Given:** Model with `Matrix_A0` dimensions $2 \times 3$ for $n = 2$.
- **When:** `StateSpaceEngine_Alpha` verifies matrix dimensions.
- **Then:** Halts lowering, binds sentinel $``\bot_{\text{ss}}``$, emitting `E0300`.
- **Diagnostic:** `E0300`.

### AC-03: Numerical Instability and Non-Finite Interception
- **Given:** Model with $|R(\lambda h)| > 1$ or $\text{NaN}$ in derivative $``\mathbf{k}_1``$.
- **When:** `RK4Solver_0` evaluates stability and numeric validity.
- **Then:** Halts simulation, binds sentinel $``\bot_{\text{ss}}``$, emitting `E0507`.
- **Diagnostic:** `E0507`.

### AC-04: Delimiter Recovery and Error Containment
- **Given:** Malformed matrix syntax followed by delimiter `;` and `Classifier_Alpha`.
- **When:** Parser detects fault, records `E0300` in $``\mathcal{D}_{\text{sink}}``$, recovering across `;`.
- **Then:** Parses `Classifier_Alpha`, halting at $``C_{\text{max\_errors}}``$ with `E0199`.
- **Diagnostic:** `E0300`, `E0199`.
