## 1. Normative Statement

The safety compiler SHALL synthesize FMECA records across four universal failure dimensions (Interface, State, Action, Resource) for every architectural component in the system AST.

The synthesis engine MUST enforce:
1. **Component Decomposition**: Partitions $``C \in \mathcal{C}_{\text{arch}}``$ (`Component_Alpha`) elements into disjoint sets $``\text{Elements}_d(C)``$ (Interface `Port_1`, State `State_0`, Action `Action_0`, Resource `Resource_0`). Empty elements emit `E0400`.
2. **Failure Kinds Alphabets**: Binds 21 canonical failure kinds across Interface (6), State (5), Action (5), and Resource (5); malformed kinds emit `E0400`.
3. **Cartesian Synthesis**: Generates $``\mathcal{F}(C) = \bigcup_{d} \{ (c, d, m) \mid c \in \text{Elements}_d(C), m \in \text{FailureKinds}(d) \}``$ (`FailureMode_0`) with $|\mathcal{F}(C)| \le 21 \cdot |\text{Elements}(C)|$.
4. **Record Formulation**: Allocates arena records (`FMECA_Table_1`) binding effects ($``\mathcal{E}_{\text{local}}, \mathcal{E}_{\text{next}}, \mathcal{E}_{\text{end}}``$ to `Hazard_0`), $``\mathcal{D}_{\text{mech}}``$, $``\mathcal{M}_{\text{prov}}``$, and $``\Delta_R``$. Unmapped propagation or unmitigated critical failures emit `E0400`.
5. **Deterministic Reduction**: Evaluates and sorts records via $``\prec_{\text{fmeca}}``$ across work-stealing threads; guarantees bitwise parity.

## 2. Formal Invariant

Failure mode synthesis, record formulation, sorting, and diagnostic triggers satisfy:

```math
\begin{aligned}
\mathcal{D}_{\text{univ}}=\{\text{Interface},\text{State},\text{Action},\text{Resource}\},\quad |\mathcal{D}_{\text{univ}}|=4,\quad K_{\text{kinds}}=\sum_{d\in\mathcal{D}_{\text{univ}}}|\text{FailureKinds}(d)|=21 \\
\text{Elements}(C)=\biguplus_{d\in\mathcal{D}_{\text{univ}}}\text{Elements}_d(C),\quad \mathcal{F}(C)=\bigcup_{d\in\mathcal{D}_{\text{univ}}}\{(c,d,m)\mid c\in\text{Elements}_d(C),m\in\text{FailureKinds}(d)\} \\
|\mathcal{F}(C)|\le 21\cdot|\text{Elements}(C)|,\quad \mathcal{F}_{\text{sys}}=\biguplus_{C\in\mathcal{C}_{\text{arch}}}\mathcal{F}(C),\quad |P_{\text{workers}}|\le N_{\text{max\_workers}} \\
R=\langle\text{id}_R,C,c,d,m,\mathcal{E}_{\text{local}},\mathcal{E}_{\text{next}},\mathcal{E}_{\text{end}},\mathcal{D}_{\text{mech}},\mathcal{M}_{\text{prov}},\Delta_R\rangle \\
\Delta_R=\text{UUIDv5}(\text{OID}_{\text{DEAP}},\text{FQN}(C)\mathbin{\Vert}\text{"::"}\mathbin{\Vert}\text{FQN}(c)\mathbin{\Vert}\text{"::"}\mathbin{\Vert} d\mathbin{\Vert}\text{"::"}\mathbin{\Vert} m) \\
R_1\prec_{\text{fmeca}} R_2\iff\langle\text{FQN}(C_1),\text{FQN}(c_1),\text{idx}(d_1),\text{idx}(m_1)\rangle\lt_{\text{lex}}\langle\text{FQN}(C_2),\text{FQN}(c_2),\text{idx}(d_2),\text{idx}(m_2)\rangle \\
(|\text{Elements}(C)|=0\lor\exists m^*\notin\text{FailureKinds}(d))\implies\text{Diagnostic}(C,\text{E0400})\land R\gets\bot_{\text{fmeca}} \\
(\text{IsCritical}(R)\land\mathcal{D}_{\text{mech}}=\bot\land\mathcal{M}_{\text{prov}}=\bot)\lor(\text{IsConnected}(c)\land\mathcal{E}_{\text{next}}=\bot)\implies\text{Diagnostic}(R,\text{E0400}) \\
|\mathcal{D}_{\text{sink}}|\ge C_{\text{max\_errors}}\implies\text{Diagnostic}(\text{E0199})
\end{aligned}
```

## 3. Computational Complexity & Algorithmic Bounds

- **Complexity Class:** Class $\mathbf{P}$ (Deterministic Polynomial Time).
- **Asymptotic Bound:** Cartesian generation: $O(|C| \cdot |\text{Elements}| \cdot 4 \cdot |\text{Kinds}|)$ for $``|C| = |\mathcal{C}_{\text{arch}}|``$ ($``K_{\text{kinds}} = 21``$). Work-stealing: $``O((N \log N + E_{\text{conn}}) / N_{\text{max\_workers}} + \log N)``$. Sorting: $O(N \log N)$. Space: $O(N)$.
- **Tractable Subclass & Frontier:** Strictly deterministic polynomial; establishes baseline safety synthesis without NP-4 (REQ-0135) combinatorial explosion.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Canonical 4-Dimension FMECA Synthesis
- **Given:** `Package_0` with component `Component_Alpha` having partitioned elements.
- **When:** Lowering FMECA failure mode synthesis.
- **Then:** Allocates Cartesian records in arena storage (`FMECA_Table_1`).
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: Universal Failure Kinds Completeness
- **Given:** `Component_Alpha` with 2 elements per dimension (8 total).
- **When:** Lowering Cartesian expansion.
- **Then:** Synthesizes 42 records (`FailureMode_0`) across 21 kinds.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-03: Empty Element & Invalid Failure Kind Rejection
- **Given:** Component with $|\text{Elements}(C)| = 0$ or invalid kind `FailureKind_Custom`.
- **When:** Validating elements and failure kinds.
- **Then:** Halts lowering, emits diagnostic `E0400`, and binds sentinel $``\bot_{\text{fmeca}}``$.
- **Diagnostic:** `E0400` (EmptyComponentElements or InvalidFailureKind).

### AC-04: Delimiter Recovery & Error Accumulation
- **Given:** Unmitigated critical failure before `;`, followed by valid `Component_Beta`.
- **When:** Performing propagation and delimiter synchronization.
- **Then:** Emits `E0400`, recovers on `;`, halting at $``C_{\text{max\_errors}}``$ with `E0199`.
- **Diagnostic:** `E0400`, `E0199`.
