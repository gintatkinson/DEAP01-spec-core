## 1. Normative Statement

The compiler ingestion engine shall classify input schema files into target schema formats using file extensions and deterministic content prefix signatures across 5 supported formats: CommonMark Markdown tables (`.md`, `.markdown`), Protocol Buffers (`.proto`), OMG IDL (`.idl`), OpenAPI schemas (`.json`, `.yaml`, `.yml`), and XML Schema Definitions (`.xml`, `.xsd`). Detection shall evaluate canonical lowercase file extensions followed by an initial bounded prefix window $`\text{head}(F, K)`$ of at most $`K = 512`$ bytes using deterministic scalar byte matching. Classification must execute strictly without regular expressions ($`\text{RegexEvaluations} = 0`$) or exploratory backtracking ($`\text{BacktrackCount} = 0`$).

If a file cannot be classified or exhibits an unrecognized, corrupt, or contradictory signature, the engine shall classify it as `Unknown` and emit structured diagnostic `E0100`., the engine shall implement synchronization recovery, recording the diagnostic and proceeding to subsequent compilation units to accumulate all diagnostics without aborting prematurely.

## 2. Formal Invariant

Let $`\mathcal{F}`$ denote input schema files. For file $`F \in \mathcal{F}`$, let $``|F| \in \mathbb{N}_{0}``$ denote byte length, $`\text{ext}(F) \in \Sigma^*`$ canonical lowercase extension, $``B(F) = \langle b_{0}, \dots, b_{|F|-1} \rangle``$ raw bytes ($``b_{i} \in \{0, \dots, 255\}``$), and $`K = 512`$ the prefix inspection window bound. Bounded prefix sequence:

```math
\text{head}(F, K) = \langle b_{0}, \dots, b_{m-1} \rangle, \quad m = \min(|F|, K)
```

The target format domain $`\mathcal{M}`$ is defined as:

```math
\mathcal{M} = \{ \text{MarkdownTable}, \text{Protobuf}, \text{OmgIdl}, \text{OpenApi}, \text{XmlSchema}, \text{Unknown} \}
```

The deterministic format classifier function $`\Delta : \mathcal{F} \longrightarrow \mathcal{M}`$ is defined as:

```math
\Delta(F) = \begin{cases}
\text{MarkdownTable}, & \text{if } \text{ext}(F) \in \{\text{".md"}, \text{".markdown"}\} \wedge \text{HasMarkdownTable}(\text{head}(F, K)) \\
\text{Protobuf}, & \text{if } \text{ext}(F) = \text{".proto"} \vee \text{HasPrefix}(\text{head}(F, K), \text{"syntax = proto"}) \\
\text{OmgIdl}, & \text{if } \text{ext}(F) = \text{".idl"} \vee \text{HasKeyword}(\text{head}(F, K), \text{"module"}) \\
\text{OpenApi}, & \text{if } \text{ext}(F) \in \{\text{".json"}, \text{".yaml"}, \text{".yml"}\} \wedge \text{HasKeys}(\text{head}(F, K), \{\text{"openapi"}, \text{"swagger"}\}) \\
\text{XmlSchema}, & \text{if } \text{ext}(F) \in \{\text{".xml"}, \text{".xsd"}\} \wedge \text{HasXmlRoot}(\text{head}(F, K)) \\
\text{Unknown}, & \text{otherwise}
\end{cases}
```

Bounded inspection, zero regex, and zero backtracking:

```math
\forall F \in \mathcal{F}, \quad \text{BytesInspected}(F) = \min(|F|, K) \le K = 512
```

```math
\text{RegexEvaluations}(\Delta) = 0 \quad \wedge \quad \text{BacktrackCount}(\Delta) = 0
```

Total function determinism and diagnostic emission:

```math
\forall F \in \mathcal{F}, \quad \text{Panic}(\Delta(F)) \equiv \text{false} \quad \wedge \quad \Delta(F) \in \mathcal{M}
```

```math
\Delta(F) = \text{Unknown} \implies \mathcal{D}_{\text{emit}}(F) = \langle \text{E0100}, \text{path}(F), \text{span}(0, \min(|F|, K)) \rangle
```

```math
\forall D \in \mathcal{D}_{\text{format}}, \quad \text{code}(D) \in \mathcal{E}_{\text{ingest}} = \{ e \in \mathbb{N} \mid 100 \le e \le 199 \}
```

## 3. Computational Complexity & Algorithmic Bounds

The format detection engine operates within Complexity Class $`\mathbf{P}`$. Classification of an individual file executes in strict $`O(K) = O(1)`$ constant time relative to total file size $`|F|`$, inspecting at most $`K = 512`$ bytes without heap allocation. File extension matching operates in $``O(L_{\text{ext}}) = O(1)``$ time for $``L_{\text{ext}} \le 16``$. Content prefix scanning executes via single-pass exact byte comparison over $`[0, \min(|F|, K)]`$, guaranteeing each byte is inspected at most $`O(1)`$ times with zero backtracking. For $`M`$ schema files, sequential detection time is $`O(M \cdot K) = O(M)`$ linear time;, parallel wall-clock time scales as $``O(\lceil M / N_{\text{max\_workers}} \rceil \cdot K) = O(M / N_{\text{max\_workers}})``$. Auxiliary memory is bounded by $`O(K) = O(1)`$ space per worker thread. Purely linear deterministic prefix scanning operates strictly in $`\mathbf{P}`$, bypassing all NP frontiers (NP-1--NP-8).

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Multi-Format Classification Precision
- **Given:** Canonical schema files covering all 5 supported formats containing synthetic MBSE declarations (`Package_0`, `Classifier_Alpha`, `Port_1`, `Flow_A`, `param_x : Real`).
- **When:** The ingestion engine executes format classification $`\Delta(F)`$.
- **Then:** Each file is classified into its matching format (`MarkdownTable`, `Protobuf`, `OmgIdl`, `OpenApi`, `XmlSchema`) with 100% precision and zero false positives.
- **Diagnostic:** None emitted on valid format classification.

### AC-02: Bounded Window Inspection & Regex Prohibition
- **Given:** Schema input file $`F`$ of size $`|F| \ge 10\,\text{MB}`$.
- **When:** The format detection engine inspects file $`F`$.
- **Then:** Exactly $`\min(|F|, K) \le 512`$ bytes are read from disk or buffer, static assertions confirm $`\text{RegexEvaluations}(\Delta) = 0`$ and $`\text{BacktrackCount}(\Delta) = 0`$, and execution terminates in $`O(1)`$ time.
- **Diagnostic:** `E0100` emitted if reading fails or content is unclassifiable.

### AC-03: Unknown & Corrupted Payload Diagnostic Binding
- **Given:** Input files with unrecognized extensions, empty files ($`|F| = 0`$), truncated fragments ($`|F| \lt K`$), arbitrary binary blobs, or contradictory signatures.
- **When:** The classifier evaluates input file $`F`$.
- **Then:** $`\Delta(F)`$ evaluates to `Unknown`, constructing diagnostic `E0100` with byte span $`[0, \min(|F|, K)]`$, and recovers to process subsequent compilation units without aborting.
- **Diagnostic:** `E0100` emitted into diagnostic sink $`\mathcal{D}`$.
