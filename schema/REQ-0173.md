## 1. Normative Statement

The projection engine of Subsystem 9 SHALL reconcile divergence between upstream AST models and downstream projections via `ConflictResolver_Alpha`.

Reconciliations MUST resolve base $B$, upstream $U$, and downstream $D$:
1. **Three-Way Extraction**: For $``e \in C_{\text{diff}}``$ in `Package_0`, computes $``\Delta_U(e) = (U(e) \ne B(e))``$ and $``\Delta_D(e) = (D(e) \ne B(e))``$. Malformed schema records emit `E0300`.
2. **Automated Policies**: Disjoint mutations ($``\Delta_U \land \neg \Delta_D``$ or $``\neg \Delta_U \land \Delta_D``$) accept edits under `Policy_1`. Convergent edits ($``\Delta_U \land \Delta_D \land U = D``$) merge into $``M_{\text{resolved}}``$ without conflict.
3. **Contradictory Divergence**: Incompatible concurrent edits ($``\Delta_U \land \Delta_D \land U \ne D``$) under `Policy_Alpha` MUST fail closed, emitting `E0315` (`DivergenceConflictViolation`) and binding sentinel $``\bot_{\text{resolve}}``$.
4. **Sentinels and Recovery**: Faults record in $``\mathcal{D}_{\text{sink}}``$, bind $``\bot_{\text{resolve}}``$, and recover on delimiters (`;`, `###`, `---`), halting at $``C_{\text{max\_errors}}``$ with `E0199`.
5. **Directives**: UUIDv5 anchors (Directive 1); work-stealing pool $``N_{\text{max\_workers}}``$ (Directive 2); symbol interning in $``\mathcal{S}_{\text{intern}}``$ (Directive 3); delimiter recovery halts at $``C_{\text{max\_errors}}``$ with `E0199` (Directive 4); release performance isolation (Directive 5). Placeholders (`Package_0`, `ConflictResolver_Alpha`, `Divergence_0`, `Policy_1`, `param_x : Real`) used.

## 2. Formal Invariant

Candidate diff set $``C_{\text{diff}}``$, resolved model $``M_{\text{resolved}}``$, and diagnostic triggers satisfy:

```math
\begin{aligned}
C_{\text{diff}}&=\{e\in\text{Dom}(B)\cup\text{Dom}(U)\cup\text{Dom}(D)\mid U(e)\ne B(e)\lor D(e)\ne B(e)\} \\
\forall e\in C_{\text{diff}},&\quad\Delta_U(e)=(U(e)\ne B(e)),\quad\Delta_D(e)=(D(e)\ne B(e)) \\
M_{\text{resolved}}(e)&=\begin{cases}
U(e) & \text{if }\Delta_U(e)\land\neg\Delta_D(e) \\
D(e) & \text{if }\neg\Delta_U(e)\land\Delta_D(e) \\
U(e) & \text{if }\Delta_U(e)\land\Delta_D(e)\land U(e)=D(e) \\
\bot_{\text{resolve}} & \text{if }\Delta_U(e)\land\Delta_D(e)\land U(e)\ne D(e)
\end{cases} \\
(\Delta_U(e)\land\Delta_D(e)\land U(e)\ne D(e))&\implies\text{Diagnostic}(e,\text{E0315})\in\mathcal{D}_{\text{sink}}\land M_{\text{resolved}}(e)\gets\bot_{\text{resolve}} \\
\text{IsMalformed}(e)&\implies\text{Diagnostic}(e,\text{E0300})\in\mathcal{D}_{\text{sink}}\land M_{\text{resolved}}(e)\gets\bot_{\text{resolve}} \\
|\mathcal{D}_{\text{sink}}|\ge C_{\text{max\_errors}}&\implies\text{Diagnostic}(\text{E0199})\in\mathcal{D}_{\text{sink}},\quad\Delta_e=\text{UUIDv5}(\text{OID}_{\text{DEAP}},\text{FQN}(e))
\end{aligned}
```

| Symbol / Term | Domain / Formal Definition |
| :--- | :--- |
| $B, U, D$ | Base specification, upstream AST, downstream projection |
| $``C_{\text{diff}}``$ | Candidate divergent elements |
| $``\Delta_U(e), \Delta_D(e)``$ | Boolean mutation predicates |
| $``M_{\text{resolved}}(e), \bot_{\text{resolve}}``$ | Resolved element and error sentinel |
| $``\mathcal{D}_{\text{sink}}, C_{\text{max\_errors}}``$ | Diagnostic sink and capacity limit |
| $``\text{OID}_{\text{DEAP}}, \text{FQN}(e)``$ | Namespace UUID and topological path |

## 3. Computational Complexity & Algorithmic Bounds

- **Complexity Class:** Class $\mathbf{P}$ (Deterministic Polynomial Time).
- **Asymptotic Bound:** $``O(|C_{\text{diff}}|)``$ 3-way conflict resolution ($``|C_{\text{diff}}| = |\text{Dom}(B) \cup \text{Dom}(U) \cup \text{Dom}(D)|``$). Diff evaluation and dispatch run in $O(1)$ time per element. Work-stealing pool scales as $``O(|C_{\text{diff}}| / N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$. Arena memory: $``O(|C_{\text{diff}}|)``$.
- **Tractable Subclass and Frontier:** N/A (Deterministic P). Local 3-way reconciliation avoids NP-complete graph coloring (REQ-0180) and SMT solving (REQ-0197).

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Disjoint Non-Conflicting 3-Way Divergence Resolution
- **Given:** Base $B$ in `Package_0`, edit $U$ on `Element_0`, and edit $D$ on disjoint `Element_1` under `Policy_1`.
- **When:** Lowering through `ConflictResolver_Alpha`.
- **Then:** Reconciles mutations into $``M_{\text{resolved}}``$, preserving both edits.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: Convergent Concurrent Mutation Boundary
- **Given:** Base $B$ attribute `param_x : Real` on `Element_0`, with identical edits in $U$ and $D$.
- **When:** Evaluating convergent divergence under `Policy_1`.
- **Then:** Confirms $U(e) = D(e)$ and merges mutation into $``M_{\text{resolved}}``$.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-03: Contradictory Divergence Rejection and Sentinel Binding
- **Given:** Conflicting edits to `param_x` on `Element_0` across $U$ and $D$ under `Policy_Alpha`.
- **When:** Resolving conflicting divergence.
- **Then:** Fails closed, emits diagnostic `E0315`, and binds sentinel $``\bot_{\text{resolve}}``$.
- **Diagnostic:** `E0315` (DivergenceConflictViolation).

### AC-04: Malformed Schema Record and Delimiter Recovery
- **Given:** Record `Divergence_0` violating typing, delimiter `;`, and valid `Divergence_1`.
- **When:** Executing delimiter recovery across `;`.
- **Then:** Emits `E0300`, binds $``\bot_{\text{resolve}}``$, resynchronizes across `;`, parses `Divergence_1`, halting at $``C_{\text{max\_errors}}``$ with `E0199`.
- **Diagnostic:** `E0300`, `E0199`.

### AC-05: Deterministic UUIDv5 Anchors and Release Performance Bounds
- **Given:** Model with $``|C_{\text{diff}}| = 10^4``$ diff elements evaluated across $``N_{\text{max\_workers}}``$ threads.
- **When:** Benchmarking in Release mode (`--release`).
- **Then:** Emits identical UUIDv5 anchors; latency $< 25\text{ ms}$, peak RSS $< 100\text{ MB}$.
- **Diagnostic:** Diagnostic sink remains empty.
