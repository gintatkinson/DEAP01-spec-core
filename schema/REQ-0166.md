## 1. Normative Statement

Subsystem 9 SHALL project Feature Layer 2 specifications for every classifier `Feature_0`.

Lowering MUST enforce:
1. **Dynamic Operations**: Operations `Operation_Alpha` lowered from actions, calcs, or functions SHALL define signatures $``op = \langle \text{Name}, \mathbf{P}_{op}, \tau_{\text{return}} \rangle``$. Parameters $``\mathbf{P}_{op} = \langle (p_i, \text{dir}_i, \tau_i) \rangle``$ MUST declare directions $``\text{dir}_i \in \{\text{In}, \text{Out}, \text{InOut}\}``$ and types $``\tau_i \in \mathcal{V}_{\text{AST}}``$. Missing directions or duplicate names emit `E0300`; untyped parameters or return mismatches emit `E0308`.
2. **State Machines**: Machine `StateMachine_0` SHALL formalize states $s \in \mathcal{S}(F)$ and transitions $``t = \langle s_{\text{source}}, e_{\text{trigger}}, g_{\text{guard}}, s_{\text{target}} \rangle \in \mathcal{T}(F)``$. Initial pseudostates MUST have one outgoing transition with trigger $\epsilon$. Unresolved states (`State_Missing`) emit `E0300`.
3. **Guards and Actions**: Guards $``g_{\text{guard}}``$ MUST evaluate side-effect free to `Boolean` (violations emit `E0308`). Overlapping guards on identical triggers emit `E0300`. Action hooks `Action_1` MUST bind operations in $\mathcal{O}(F)$.
4. **Sentinels**: Violations record diagnostics in sink $``\mathcal{D}_{\text{sink}}``$, bind sentinels $``\bot_{\text{op}}``$ or $``\bot_{\text{trans}}``$, and continue lowering.
5. **Directives**: UUIDv5 anchors (Directive 1); work-stealing ceiling $``N_{\text{max\_workers}}``$ (Directive 2); symbol interning (Directive 3); recovery on `;`, `|`, `}` halting at $``C_{\text{max\_errors}}``$ with `E0199` (Directive 4); Release budget ($< 25\text{ ms}$ for $10^4$ nodes, $< 100\text{ MB}$) (Directive 5). Placeholders (`Package_0`, `Feature_0`, `StateMachine_0`, `Operation_Alpha`, `Action_1`, `State_0`, `State_Missing`, `param_x : Real`) used.

## 2. Formal Invariant

Feature Layer 2 projections satisfy:

```math
\begin{aligned}
\forall op\in\mathcal{O}(F),&\quad\mathbf{P}_{op}=\langle(p_i,\text{dir}_i,\tau_i)\rangle_{i=1}^k\land\forall i,(\text{dir}_i\in\{\text{In},\text{Out},\text{InOut}\}\land\tau_i\in\mathcal{V}_{\text{AST}}) \\
\forall t\in\mathcal{T}(F),&\quad t=\langle s_{\text{src}}(t),e_{\text{trig}}(t),g_{\text{guard}}(t),s_{\text{tgt}}(t)\rangle\land s_{\text{src}}(t),s_{\text{tgt}}(t)\in\mathcal{S}(F) \\
\forall t\in\mathcal{T}(F),&\quad\text{Type}(g_{\text{guard}}(t))=\tau_{\text{bool}}\land\text{IsSideEffectFree}(g_{\text{guard}}(t))\equiv\text{true} \\
(s_{\text{src}}(t_a)=s_{\text{src}}(t_b)\land e_{\text{trig}}(t_a)=e_{\text{trig}}(t_b))&\implies(g_{\text{guard}}(t_a)\land g_{\text{guard}}(t_b)\equiv\text{false}) \\
(\tau_i=\bot\lor\text{Type}(g_{\text{guard}})\ne\tau_{\text{bool}})&\implies\text{Diagnostic}(\text{E0308})\in\mathcal{D}_{\text{sink}}\land op\gets\bot_{\text{op}} \\
(s_{\text{src}}\notin\mathcal{S}(F)\lor s_{\text{tgt}}\notin\mathcal{S}(F)\lor p_i=p_j)&\implies\text{Diagnostic}(\text{E0300})\in\mathcal{D}_{\text{sink}}\land t\gets\bot_{\text{trans}} \\
|\mathcal{D}_{\text{sink}}|\ge C_{\text{max\_errors}}&\implies\text{Diagnostic}(\text{E0199})\in\mathcal{D}_{\text{sink}},\quad\Delta_x=\text{UUIDv5}(\text{OID}_{\text{DEAP}},\text{FQN}(x))
\end{aligned}
```

## 3. Computational Complexity & Algorithmic Bounds

- **Complexity Class:** Class $\mathbf{P}$ (Deterministic Polynomial Time).
- **Asymptotic Bound:** $O(|S| + |T|)$ logic and state machine lowering ($|S| = |\mathcal{O}| + |\mathcal{S}|$, $|T| = |\mathbf{P}| + |\mathcal{T}|$). Work-stealing scales as $``O((|S| + |T|)/N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$. Arena: $O(|S| + |T|)$.
- **Tractable Subclass and Frontier:** N/A (Deterministic P). Linear lowering bypasses NP-5 reachability (REQ-0124) and NP-8 (REQ-0197).

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Operation Signature and Statechart Lowering
- **Given:** Feature `Feature_0` with operation `Operation_Alpha` and machine `StateMachine_0`.
- **When:** Lowering Feature Layer 2 specifications.
- **Then:** Formalizes signature $op$ and transition $t$.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: Pseudostate and Spontaneous Transition Boundary
- **Given:** Machine `StateMachine_0` with initial state `State_Init` and transition $``t_{\text{init}}``$ ($\epsilon$).
- **When:** Validating initial state topology.
- **Then:** Confirms single outgoing transition from `State_Init` and lowers $``t_{\text{init}}``$.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-03: Type Mismatch and Non-Boolean Guard Rejection
- **Given:** Transition $``t_1``$ with guard typing to `Real`, or parameter type error.
- **When:** Type checking transition guards and signatures.
- **Then:** Fails closed, emits `E0308`, and binds sentinel $``\bot_{\text{trans}}``$ or $``\bot_{\text{op}}``$.
- **Diagnostic:** `E0308` (TypeMismatchViolation).

### AC-04: Unmapped State and Delimiter Recovery
- **Given:** Transition $``t_2``$ referencing `State_Missing`, then `;` and `Operation_Alpha`.
- **When:** Delimiter recovery resynchronizes across statement tokens.
- **Then:** Emits `E0300`, binds $``\bot_{\text{trans}}``$, lowers `Operation_Alpha`, and halts at $``C_{\text{max\_errors}}``$ with `E0199`.
- **Diagnostic:** `E0300`, `E0199`.

### AC-05: UUIDv5 Determinism and Release Performance Bounds
- **Given:** $10^4$ elements across $``N_{\text{max\_workers}}``$ threads.
- **When:** Lowering Layer 2 projections in Release mode (`--release`).
- **Then:** Generates identical UUIDv5 anchors; latency $< 25\text{ ms}$, RSS $< 100\text{ MB}$.
- **Diagnostic:** Diagnostic sink remains empty.
