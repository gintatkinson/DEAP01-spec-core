## 1. Normative Statement

The Universal Schema Ingestion Engine shall parse CommonMark tabular schemas defining formal constraints, safety conditions, and operational envelopes into strongly typed `IngestedConstraint` AST entities. For each row, the parser shall extract the constraint identifier (`id`), owning classifier (`owner`), verbatim raw constraint expression (`expr`), formal invariant kind (`kind` $`\in \{ \text{Assert}, \text{Assume} \}`$, default `Assert`), severity tier (`severity` $`\in \{ \text{Critical}, \text{Degraded}, \text{Advisory} \}`$, default `Critical`), and optional operational envelope interval ($``\mathcal{I} = \langle L, U, o_L, o_U \rangle``$).

Ingestion operates directly on tokenized table rows resolved via dynamic column binding vectors ($`\vec{\beta}`$). Per the Verbatim Expression Preservation Invariant, raw constraint expressions shall be captured without character mutation, re-encoding, or evaluation, preserving bitwise-identical lexical byte sequences for downstream Boolean AST parsing (REQ-0138) and SMT encoding (REQ-0188).

Constraint identifiers shall be unique within the owning classifier scope. When present, operational envelopes must satisfy $`L \le U`$, with degenerate intervals ($`L = U`$) requiring closed bounds. Inverted bounds ($`L \gt U`$) or malformed numerical syntax shall emit diagnostic `E0103`. Missing mandatory columns (`id`, `owner`, `expr`), unrecognized kind or severity tokens, or duplicate scoped identifiers shall emit diagnostic `E0102`.

## 2. Formal Invariant

Let $``\mathcal{T}_{\text{constraint}} = (\mathbf{H}, \mathbf{R})``$ denote a constraint table schema with column headers $`\mathbf{H}`$ and row sequence $``\mathbf{R} = \langle R_1, \dots, R_M \rangle``$. Let $`\vec{\beta}`$ map column indices to canonical attributes.

Each synthesized entity $``C_i \in \mathcal{C}``$ is formalized as a 7-tuple:

```math
C_i = \langle \text{id}_i, \text{owner}_i, \text{expr}_i, \text{kind}_i, \text{severity}_i, \mathcal{I}_i, \text{span}_i \rangle
```

with constituent domains:

```math
\begin{aligned}
\text{id}_i, \text{owner}_i &\in \mathcal{S}_{\text{sym}}, \quad \text{expr}_i \in \Sigma^* \\
\text{kind}_i &\in \{ \text{Assert}, \text{Assume} \}, \quad \text{severity}_i \in \{ \text{Critical}, \text{Degraded}, \text{Advisory} \} \\
\mathcal{I}_i &\in (\mathbb{R} \cup \{ -\infty \}) \times (\mathbb{R} \cup \{ +\infty \}) \times \mathbb{B}^2 \cup \{ \bot_{\text{env}} \} \\
\text{span}_i &= \langle \text{file\_id}, p_{\text{start}}, p_{\text{end}}, \text{line}, \text{col} \rangle
\end{aligned}
```

Verbatim Expression Preservation Invariant:

```math
\text{RawBytes}(\text{expr}_i) \equiv \text{SourceCellSlice}(R_i, \beta^{-1}(\text{expr}))
```

Classification defaulting, envelope consistency, and scoped uniqueness satisfy:

```math
\begin{aligned}
\text{ParseKind}(s) &= \begin{cases} \text{Assert}, & \text{if } s \in \{ \bot, \text{""}, \text{"assert"}, \text{"invariant"}, \text{"guarantee"} \} \\ \text{Assume}, & \text{if } s \in \{ \text{"assume"}, \text{"precondition"}, \text{"require"} \} \\ \bot_{\text{kind}}, & \text{otherwise} \end{cases} \\
\text{ParseSeverity}(s) &= \begin{cases} \text{Critical}, & \text{if } s \in \{ \bot, \text{""}, \text{"critical"}, \text{"fatal"}, \text{"high"} \} \\ \text{Degraded}, & \text{if } s \in \{ \text{"degraded"}, \text{"warning"}, \text{"medium"} \} \\ \text{Advisory}, & \text{if } s \in \{ \text{"advisory"}, \text{"info"}, \text{"low"} \} \\ \bot_{\text{sev}}, & \text{otherwise} \end{cases} \\
\text{ValidEnvelope}(\langle L, U, o_L, o_U \rangle) &\iff (L \le U) \wedge (L = U \implies \neg o_L \wedge \neg o_U \wedge L \in \mathbb{R}) \\
\forall C_a, C_b \in \mathcal{C}, \quad (C_a.\text{owner} = C_b.\text{owner} &\wedge C_a.\text{id} = C_b.\text{id}) \implies C_a = C_b
\end{aligned}
```

Diagnostic Code Binding Invariant:

```math
\begin{aligned}
(\text{MissingCol}(R_i) \vee \text{ParseKind} = \bot_{\text{kind}} \vee \text{ParseSeverity} = \bot_{\text{sev}} \vee \text{DuplicateId}) &\implies \text{DiagnosticCode::E0102} \\
(\mathcal{I}_i \ne \bot_{\text{env}} \wedge \neg \text{ValidEnvelope}(\mathcal{I}_i)) &\implies \text{DiagnosticCode::E0103} \\
|\mathcal{D}| \ge C_{\text{max\_errors}} &\implies \text{DiagnosticCode::E0199}
\end{aligned}
```

## 3. Computational Complexity & Algorithmic Bounds

Tabular schema ingestion for formal constraints executes within Complexity Class $`\mathbf{P}`$. For $`N`$ input bytes, $`R`$ rows, and $`C`$ columns ($``C \le C_{\text{max\_cols}} = 32``$), ingestion runs in deterministic linear time $`O(R) = O(N)`$. Per-row tasks--column lookup, symbol interning ($`O(1)`$ amortized), zero-copy slice extraction ($`O(1)`$), enum matching ($`O(1)`$), and envelope validation ($`O(1)`$)--require $`O(1)`$ auxiliary stack space. Downstream proof obligations under NP-8 (REQ-0197) and temporal networks under NP-1 (REQ-0117) are decoupled from ingestion, requiring zero backtracking. Dispatching $`K`$ tables across $``N_{\text{max\_workers}}``$ threads scales as $``O(\lceil K / N_{\text{max\_workers}} \rceil \cdot R_{\text{max}})``$.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Verbatim Constraint Expression Ingestion
- **Given:** Tabular rows containing constraint expressions (`param_x >= 0.0 && param_x <= 100.0`, `param_a + param_b == param_c`, `!(flag_1 && flag_2) || state == State_A`).
- **When:** Ingestion pass executes.
- **Then:** 100% of raw expression strings in synthesized `IngestedConstraint` AST entities match source cell byte slices with 0-byte divergence.
- **Diagnostic:** `E0102` on cell extraction failure or byte mutation.

### AC-02: Constraint Kind and Severity Defaulting
- **Given:** Tabular rows omitting `kind` and `severity`.
- **When:** Parser synthesizes `IngestedConstraint` entities.
- **Then:** Omitted `kind` fields evaluate to `Assert` and omitted `severity` fields evaluate to `Critical`.
- **Diagnostic:** `E0102` on failure to apply normative defaults.

### AC-03: Scoped Constraint Identifier Uniqueness
- **Given:** Schema declaring two constraints with duplicate identifier `Constraint_1` under owner `Classifier_Alpha`.
- **When:** Parser validates scoped uniqueness.
- **Then:** Detects identifier collision, emits `E0102`, substitutes sentinel $``\bot_{\text{constraint}}``$, and continues row processing.
- **Diagnostic:** `E0102` with duplicate identifier byte span.

### AC-04: Operational Envelope Interval Consistency
- **Given:** Rows specifying valid envelopes (`[0.0, 100.0]`) alongside an invalid row with inverted bounds (`[100.0, 10.0]`).
- **When:** Parser evaluates interval consistency.
- **Then:** Valid intervals yield $``\mathcal{I}_i \in \mathbb{E}``$; inverted row emits `E0103` and substitutes sentinel $``\bot_{\text{constraint}}``$.
- **Diagnostic:** `E0103` on inverted or degenerate open bounds.
