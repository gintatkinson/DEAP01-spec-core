## 1. Normative Statement

The ICD engine of Subsystem 8 SHALL extract the canonical Master Signal Flow Dictionary `FlowDictionary_0` from AST item flows without ungrounded tokens or fallbacks.

Every record in `FlowDictionary_0` MUST be an authoritative 10-tuple $``\sigma = \langle \text{ID}, S_{\text{src}}, P_{\text{src}}, S_{\text{tgt}}, P_{\text{tgt}}, \tau_{\text{payload}}, u_{\text{unit}}, f_{\text{rate}}, v_{\text{failsafe}}, \pi_{\text{protocol}} \rangle``$: interned `ID` (`Signal_Alpha`), subsystems $``S_{\text{src}}, S_{\text{tgt}}``$, ports $``P_{\text{src}}, P_{\text{tgt}}``$, payload $``\tau_{\text{payload}}``$, SI dimension $``u_{\text{unit}} \in \mathbb{Q}^7``$, rate $``f_{\text{rate}} \gt 0``$, failsafe $``v_{\text{failsafe}}``$, and protocol $``\pi_{\text{protocol}}``$. Records with $|\sigma| \ne 10$ or null tokens ($\bot$) SHALL emit `E0200`.

Interface contracts MUST be valid: $``P_{\text{src}}``$ owned by $``S_{\text{src}}``$ emitting ($``\text{dir}(P_{\text{src}}) \in \{ \text{Out}, \text{InOut} \}``$); $``P_{\text{tgt}}``$ owned by $``S_{\text{tgt}}``$ ingesting ($``\text{dir}(P_{\text{tgt}}) \in \{ \text{In}, \text{InOut} \}``$); payload matching $``\tau_{\text{payload}}``$; and $``v_{\text{failsafe}} \in \text{Domain}(\tau_{\text{payload}})``$. Contract violations or $``f_{\text{rate}} \le 0``$ SHALL emit `E0204`.

## 2. Formal Invariant

Let $\mathcal{F}$ denote routed item flows and $``\mathbf{R}_{\text{dict}}``$ denote canonical 10-column signal records:

```math
\begin{aligned}
\mathbf{D}_{\text{signal}} &= \langle\mathcal{S},\mathcal{P},\mathcal{F},\mathbf{R}_{\text{dict}},\mathbf{K}_{10},\Delta_{\mathbf{D}}\rangle \\
\forall\sigma\in\mathbf{R}_{\text{dict}}, \quad \sigma &= \langle\text{ID},S_{\text{src}},P_{\text{src}},S_{\text{tgt}},P_{\text{tgt}},\tau_{\text{payload}},u_{\text{unit}},f_{\text{rate}},v_{\text{failsafe}},\pi_{\text{protocol}}\rangle \\
\Phi_{\text{complete}}(\sigma) &\iff |\sigma|=10 \land \forall k\in\{1,\dots,10\}, \sigma[k]\ne\bot \\
\Phi_{\text{unique}}(\mathbf{R}_{\text{dict}}) &\iff \forall\sigma_a\ne\sigma_b \implies \text{ID}(\sigma_a)\ne\text{ID}(\sigma_b) \\
\Phi_{\text{contract}}(\sigma) &\iff \text{Owner}(P_{\text{src}})=S_{\text{src}} \land \text{Owner}(P_{\text{tgt}})=S_{\text{tgt}} \land \text{dir}(P_{\text{src}})\in\{\text{Out},\text{InOut}\} \\
&\quad \land \text{dir}(P_{\text{tgt}})\in\{\text{In},\text{InOut}\} \land \tau(P_{\text{src}})\equiv\tau_{\text{payload}}\equiv\tau(P_{\text{tgt}}) \\
&\quad \land \text{Dim}(\tau_{\text{payload}})=u_{\text{unit}}\in\mathbb{Q}^7 \land f_{\text{rate}}\gt 0 \land v_{\text{failsafe}}\in\text{Domain}(\tau_{\text{payload}}) \\
\forall n\in\mathbf{D}_{\text{signal}}\cup\mathbf{R}_{\text{dict}}, \quad \Delta_n &= \text{UUIDv5}(\text{NS}_{\text{DEAP}},\text{FQN}(n))
\end{aligned}
```

| Symbol / Term | Domain / Formal Definition |
| :--- | :--- |
| $``\mathbf{D}_{\text{signal}}, \mathbf{R}_{\text{dict}}``$ | Dictionary aggregate record and 10-column record set |
| $``\sigma, \mathbf{K}_{10}``$ | Authoritative 10-tuple and ordered schema definition |
| $``S_{\text{src}}, S_{\text{tgt}}``$ | Source and target subsystem classifiers in $\mathcal{S}$ |
| $``P_{\text{src}}, P_{\text{tgt}}``$ | Boundary interface ports in $\mathcal{P}$ |
| $``\tau_{\text{payload}}, u_{\text{unit}}``$ | Payload classifier and rational SI dimension in $\mathbb{Q}^7$ |
| $``f_{\text{rate}}, v_{\text{failsafe}}``$ | Positive frequency (Hz) and failsafe default value |
| $``\pi_{\text{protocol}}, \Delta_n``$ | Transport protocol and RFC 4122 UUIDv5 identifier |

## 3. Computational Complexity & Algorithmic Bounds

- **Complexity Class:** Class $\mathbf{P}$ (Deterministic Polynomial Time)
- **Asymptotic Bound:** $O(|F|)$ dictionary extraction; sorting runs in $O(|F| \log |F|)$ time. Work-stealing ($``N_{\text{max\_workers}}``$) scales as $``O((|F| \log |F|) / N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$.
- **Tractable Subclass & Frontier:** N/A (Deterministic P). Single-pass traversal over the flow graph feeds NP-2 channel allocation.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: 10-Column Record Synthesis
- **Given:** Model `Package_0` with flow `Signal_Alpha` connecting `Port_1` to `Port_2`.
- **When:** Lowering constructs `FlowDictionary_0`.
- **Then:** Record $\sigma$ is allocated with ten non-null columns.
- **Diagnostic:** Diagnostic sink empty.

### AC-02: Incomplete Field Rejection
- **Given:** Flow declaration with fewer than 10 columns or null sentinels ($\bot$).
- **When:** Completeness validation checks $``\mathbf{K}_{10}``$.
- **Then:** Compiler rejects the record and emits `E0200`.
- **Diagnostic:** `E0200`.

### AC-03: Contract and Typing Validation
- **Given:** Flow `Signal_Beta` with reversed port directions, type mismatch, or $``f_{\text{rate}} \le 0``$.
- **When:** Interface verification validates endpoints.
- **Then:** Compiler rejects the declaration and emits `E0204`.
- **Diagnostic:** `E0204`.

### AC-04: Resynchronization & Saturation Recovery
- **Given:** Malformed flow followed by `;` and valid `Signal_Gamma`.
- **When:** Parser encounters the syntax fault.
- **Then:** Compiler emits `E0200`, resynchronizes at `;`, parses `Signal_Gamma`, and halts at $``C_{\text{max\_errors}}``$ with `E0199`.
- **Diagnostic:** `E0200`, `E0199`.
