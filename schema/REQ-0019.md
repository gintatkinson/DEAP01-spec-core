## 1. Normative Statement

The CommonMark table parser within the Universal Schema Ingestion Engine shall map each valid table row to a corresponding intermediate representation (IR) entity in contiguous memory storage while sanitizing raw entity names into valid OMG SysML v2 and KerML basic identifiers using deterministic replacement, contiguous delimiter collapse, prefixing, and scope collision avoidance.

For each table row $``\mathbf{r}_i = \langle c_{i, 0}, \dots, c_{i, C-1} \rangle``$, the engine shall extract cell values positionally via column-to-attribute binding vector $`\vec{\beta}`$ and instantiate an IR entity. The raw name string $``S_{\text{raw}}``$ is extracted from the cell bound to $``k_{\text{name}}``$. If a row omits the name cell or contains only whitespace under mandatory naming, the engine shall record diagnostic error code `E0102` with 1-indexed coordinates and synthesize deterministic fallback identifier $``\text{"id\_anonymous\_"} \mathbin{\Vert} \text{Str}(i)``$.

The engine shall transform $``S_{\text{raw}}``$ into a valid basic identifier satisfying grammar $``[a\text{-}zA\text{-}Z\_][a\text{-}zA\text{-}Z0\text{-}9\_]^*``$ via a four-stage pipeline:
1. Strip leading and trailing ASCII whitespace.
2. Map non-alphanumeric bytes outside ASCII alphanumerics and underscore to an underscore (`_`).
3. Collapse contiguous runs of underscores into a single underscore (`_`).
4. Prepend prefix `id_` if the initial character is an ASCII digit or matches a reserved keyword.

The engine shall track active namespace scope. If a sanitized identifier collides with an existing sibling, the engine shall append an underscore and the monotonic occurrence count $`k \ge 2`$ (`_2`, `_3`) until unique. Per REQ-0002, synthesized entities must retain both the sanitized identifier and original $``S_{\text{raw}}``$ with source byte span coordinates. The pipeline shall enforce a total, non-panicking contract bounding raw identifiers to $``L_{\text{max}} = 256``$ bytes; exceeding $``L_{\text{max}}``$ triggers diagnostic `E0102`.

## 2. Formal Invariant

Let $``\Sigma_{\text{ident}} = \Sigma_{\text{alpha}} \cup \Sigma_{\text{digit}} \cup \{ 0\text{x}5\text{F} \}``$, where $`0\text{x}5\text{F}`$ is ASCII `_`. Let $``\mathcal{K}_{\text{reserved}}``$ denote reserved keywords. The set of valid basic identifiers $`\text{BasicIdentifier} \subset \Sigma^*`$ satisfies:

```math
\text{BasicIdentifier} = \{ s \in \Sigma^+ \mid s[0] \in (\Sigma_{\text{alpha}} \cup \{ 0\text{x}5\text{F} \}) \;\wedge\; (\forall j \in \{1, \dots, |s|-1\}, \, s[j] \in \Sigma_{\text{ident}}) \;\wedge\; s \notin \mathcal{K}_{\text{reserved}} \}
```

The sanitization function $``\sigma_{\text{id}} : \Sigma^* \to \text{BasicIdentifier}``$ satisfies:

```math
\sigma_{\text{id}}(S_{\text{raw}}) = \begin{cases}
S_{\text{raw}}, & \text{if } S_{\text{raw}} \in \text{BasicIdentifier} \\
\pi_{\text{id}}(\text{Collapse}(\rho^*(\text{Trim}(S_{\text{raw}})))), & \text{otherwise}
\end{cases}
```

where $`\rho(b) = b`$ for $``b \in \Sigma_{\text{ident}}``$ and $`0\text{x}5\text{F}`$ otherwise, $``\text{Collapse}(u \mathbin{\Vert} \text{"\_\_"} \mathbin{\Vert} v) = \text{Collapse}(u \mathbin{\Vert} \text{"\_"} \mathbin{\Vert} v)``$, and:

```math
\pi_{\text{id}}(s) = \begin{cases}
\text{"id\_"} \mathbin{\Vert} s, & \text{if } s = \varepsilon \;\lor\; s[0] \in \Sigma_{\text{digit}} \;\lor\; s \in \mathcal{K}_{\text{reserved}} \\
s, & \text{otherwise}
\end{cases}
```

Canonical Example Sanitization Invariant:

```math
\sigma_{\text{id}}(\text{"123-Alpha (Beta)"}) = \text{"id\_123\_Alpha\_Beta\_"}
```

Let $`\text{Scope} \subset \text{BasicIdentifier}`$ denote registered sibling identifiers. Collision resolution satisfies:

```math
\begin{aligned}
\text{Count}(\sigma, \text{Scope}) &= |\{ s \in \text{Scope} \mid s = \sigma \;\lor\; \exists k \in \mathbb{N}_{\ge 2} : s = \sigma \mathbin{\Vert} \text{"\_"} \mathbin{\Vert} \text{Str}(k) \}| \\
\text{Disambiguate}(\sigma, \text{Scope}) &= \begin{cases}
\sigma, & \text{if } \sigma \notin \text{Scope} \\
\sigma \mathbin{\Vert} \text{"\_"} \mathbin{\Vert} \text{Str}(\text{Count}(\sigma, \text{Scope}) + 1), & \text{if } \sigma \in \text{Scope}
\end{cases}
\end{aligned}
```

Row Identifier Resolution and Scope Evolution:

```math
\begin{aligned}
\text{ResolveIdent}(\mathbf{r}_i, \text{Scope}_{i-1}) &= \begin{cases}
\text{Disambiguate}(\sigma_{\text{id}}(c_{i, j_{\text{name}}}), \text{Scope}_{i-1}), & \text{if } j_{\text{name}} \ne \bot \;\wedge\; \text{Trim}(c_{i, j_{\text{name}}}) \ne \varepsilon \\
\text{Disambiguate}(\text{"id\_anonymous\_"} \mathbin{\Vert} \text{Str}(i), \text{Scope}_{i-1}), & \text{otherwise}
\end{cases} \\
\text{Scope}_i &= \text{Scope}_{i-1} \cup \{ \text{ResolveIdent}(\mathbf{r}_i, \text{Scope}_{i-1}) \}
\end{aligned}
```

Diagnostic Error Code Binding Invariants:

```math
\begin{aligned}
(j_{\text{name}} = \bot \;\lor\; \text{Trim}(c_{i, j_{\text{name}}}) = \varepsilon) \;\wedge\; \text{Strict}(\mathcal{T}) &\implies \text{Diagnostic}(i, j_{\text{name}}, \text{E0102}, \text{MissingIdentifier}) \in \mathcal{D} \\
|c_{i, j_{\text{name}}}| \gt L_{\text{max}} &\implies \text{Diagnostic}(i, j_{\text{name}}, \text{E0102}, \text{IdentifierTooLong}) \in \mathcal{D}
\end{aligned}
```

## 3. Computational Complexity & Algorithmic Bounds

Identifier sanitization and row-to-entity mapping operate within Complexity Class $`\mathbf{P}`$. For any raw identifier $``S_{\text{raw}}``$ with $``|S_{\text{raw}}| \le L_{\text{max}} = 256``$, whitespace trimming, character mapping $`\rho^*`$, underscore collapsing, and prefixing $``\pi_{\text{id}}``$ execute in a single forward pass in $``O(|S_{\text{raw}}|) = O(1)``$ time. Keyword lookup against $``\mathcal{K}_{\text{reserved}}``$ operates in $`O(1)`$ time via a static hash table. Sibling collision resolution executes in $`O(1)`$ amortized time via hash table lookups. For a table of $`M`$ rows and $`C \le 32`$ columns with total size $``N = \sum_{i=1}^M |\mathbf{r}_i|``$ bytes, row-to-entity synthesis executes in deterministic linear time $`O(N)`$ with $`O(M)`$ auxiliary arena storage. The transformation is strictly polynomial, bypassing NP-hard combinatorial search spaces (NP-1--NP-8).

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Valid Basic Identifier Passthrough
- **Given:** A table row declaring an entity with raw name cell $``S_{\text{raw}} = \text{"Classifier\_Alpha"}``$ conforming to $`\text{BasicIdentifier}`$.
- **When:** The ingestion engine executes identifier sanitization $``\sigma_{\text{id}}(S_{\text{raw}})``$.
- **Then:** The identifier passes through unaltered with $``\sigma_{\text{id}}(S_{\text{raw}}) = \text{"Classifier\_Alpha"}``$.
- **Diagnostic:** Diagnostic `E0102` emitted if a valid basic identifier is mutated or rejected.

### AC-02: Non-Alphanumeric Character Sanitization & Leading Digit Prefixing
- **Given:** A table row with raw name cell $``S_{\text{raw}} = \text{"123-Alpha (Beta)"}``$.
- **When:** The ingestion engine executes the sanitization transformation pipeline.
- **Then:** The sanitized identifier equals $``\text{"id\_123\_Alpha\_Beta\_"}``$, confirming underscore mapping, delimiter collapse, `id_` prefixing, and trailing underscore retention.
- **Diagnostic:** Diagnostic `E0102` emitted if non-alphanumeric characters or leading digits fail canonical sanitization.

### AC-03: Scope Sibling Collision Disambiguation
- **Given:** An input table containing three distinct rows declaring entities with identical raw name $``S_{\text{raw}} = \text{"Port\_1"}``$ in parent scope `Package_0`.
- **When:** The engine processes rows sequentially and executes collision resolution $`\text{Disambiguate}`$.
- **Then:** The engine assigns distinct identifiers $``\text{"Port\_1"}``$, $``\text{"Port\_1\_2"}``$, and $``\text{"Port\_1\_3"}``$, ensuring scope injectivity.
- **Diagnostic:** Diagnostic `E0102` emitted on unhandled identifier collision or non-deterministic disambiguation index assignment.

### AC-04: Reserved Keyword Disambiguation
- **Given:** A table row declaring an entity whose raw name matches reserved keyword $``S_{\text{raw}} = \text{"part"}``$.
- **When:** The ingestion engine evaluates $``S_{\text{raw}}``$ against $``\mathcal{K}_{\text{reserved}}``$ and executes sanitization.
- **Then:** The engine prepends `id_`, producing sanitized identifier $``\text{"id\_part"}``$.
- **Diagnostic:** Diagnostic `E0102` emitted if a reserved keyword is lowered without `id_` prefix disambiguation.
