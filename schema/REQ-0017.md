## 1. Normative Statement

The CommonMark tabular schema parser within the Universal Schema Ingestion Engine shall implement dynamic semantic header key normalization and order-independent column binding for all tabular model specifications. The parser shall accept column headers in arbitrary horizontal order and normalize each raw header string $`H`$ into a canonical attribute key $``k \in \mathcal{K}_{\text{canonical}}``$ via a deterministic four-stage pipeline: (1) ASCII whitespace trimming, (2) ASCII case folding, (3) punctuation stripping and whitespace collapse, and (4) alias lookup against immutable catalog $``\mathcal{K}_{\text{canonical}}``$.

The engine shall construct binding vector $``\vec{\beta} \in (\mathcal{K}_{\text{canonical}} \cup \{ \bot \})^C``$ for column count $``C \le C_{\text{max\_cols}} = 32``$. Data rows shall be projected positionally through $`\vec{\beta}`$, ensuring any column permutation $``\pi \in \mathfrak{S}_C``$ synthesizes an AST entity identical to the unpermuted schema.

Execution shall be deterministic and non-panicking. Header resolution must enforce injective column assignment: duplicate collisions or ambiguous bindings shall emit diagnostic `E0102` and engage synchronization token recovery per REQ-0016. If mandatory attribute set $``\mathcal{M} \subseteq \mathcal{K}_{\text{canonical}}``$ is not fully covered by $`\vec{\beta}`$, or if strict validation encounters an unrecognized header ($`\beta(H) = \bot`$), the parser shall emit diagnostic `E0102`. Tables exceeding column ceiling $``C \gt C_{\text{max\_cols}} = 32``$ shall be rejected with diagnostic `E0102`.

## 2. Formal Invariant

Let $`\Sigma`$ denote the byte alphabet. Let raw header string $`H \in \Sigma^*`$ have byte length $`|H|`$. Trimming operator $`\text{Trim} : \Sigma^* \to \Sigma^*`$ strips leading and trailing bytes in $``\{ \text{SYM}_{\text{SPACE}}, \text{SYM}_{\text{TAB}}, \text{SYM}_{\text{LF}}, \text{SYM}_{\text{CR}} \}``$.

ASCII case folding $`\text{CaseFold} : \Sigma^* \to \Sigma^*`$ maps uppercase ASCII bytes $`[0\text{x}41, 0\text{x}5\text{A}]`$ to lowercase $`[0\text{x}61, 0\text{x}7\text{A}]`$:

```math
\text{CaseFold}(b) = 
\begin{cases}
b + 0\text{x}20, & \text{if } 0\text{x}41 \le b \le 0\text{x}5\text{A} \\
b, & \text{otherwise}
\end{cases}
```

The punctuation stripping operator $`\text{StripPunct} : \Sigma^* \to \Sigma^*`$ strips non-alphanumeric punctuation and collapses contiguous whitespace runs. The composite normalization operator $`\eta : \Sigma^* \to \Sigma^*`$ is:

```math
\eta(H) = \text{CaseFold}(\text{StripPunct}(\text{Trim}(H)))
```

For canonical keys $``\mathcal{K}_{\text{canonical}}``$ with pairwise disjoint aliases:

```math
\forall k_a \ne k_b \in \mathcal{K}_{\text{canonical}}, \quad \text{Aliases}(k_a) \cap \text{Aliases}(k_b) = \emptyset
```

Binding function $``\beta : \Sigma^* \to \mathcal{K}_{\text{canonical}} \cup \{ \bot \}``$ maps normalized headers:

```math
\beta(H) = 
\begin{cases}
k, & \text{if } \exists ! \, k \in \mathcal{K}_{\text{canonical}} \text{ s.t. } \eta(H) \in \text{Aliases}(k) \\
\bot, & \text{otherwise}
\end{cases}
```

Deterministic Resolution, Injective Assignment, and Mandatory Coverage:

```math
\begin{aligned}
\forall H \in \mathbf{H}, \quad \beta(H) \ne \bot &\implies |\{ k \in \mathcal{K}_{\text{canonical}} \mid \eta(H) \in \text{Aliases}(k) \}| = 1 \\
\forall i \ne j \in \{0, \dots, C-1\}, \quad (\beta(H_i) \ne \bot \;\wedge\; \beta(H_j) \ne \bot) &\implies \beta(H_i) \ne \beta(H_j) \\
\mathcal{M}(T_{\text{entity}}) &\subseteq \{ \beta(H_j) \mid 0 \le j \lt C \}
\end{aligned}
```

For data row $``\mathbf{r} = \langle c_0, \dots, c_{C-1} \rangle``$, synthesized attributes and permutation invariance satisfy:

```math
\mathcal{E}(\mathbf{H}, \mathbf{r}) = \{ (\beta(H_j), c_j) \mid 0 \le j \lt C \;\wedge\; \beta(H_j) \ne \bot \}
```

```math
\forall \pi \in \mathfrak{S}_C, \quad \mathcal{E}(\pi(\mathbf{H}), \pi(\mathbf{r})) \equiv \mathcal{E}(\mathbf{H}, \mathbf{r}) \implies \text{SynthesizeAST}(\pi(\mathcal{T})) \equiv \text{SynthesizeAST}(\mathcal{T})
```

Diagnostic Error Code Binding Invariant:

```math
\begin{aligned}
(\exists i \ne j \text{ s.t. } \beta(H_i) = \beta(H_j) \ne \bot) &\implies \text{Diagnostic}(R_0, C_j, \text{E0102}) \in \mathcal{D} \\
(\mathcal{M}(T_{\text{entity}}) \setminus \{ \beta(H_j) \}_{j=0}^{C-1} \ne \emptyset) &\implies \text{Diagnostic}(R_0, 0, \text{E0102}) \in \mathcal{D} \\
(\exists j \text{ s.t. } \beta(H_j) = \bot \;\wedge\; \text{Strict}(\mathcal{S})) &\implies \text{Diagnostic}(R_0, C_j, \text{E0102}) \in \mathcal{D} \\
(C \gt C_{\text{max\_cols}}) &\implies \text{Diagnostic}(R_0, C, \text{E0102}) \in \mathcal{D}
\end{aligned}
```

## 3. Computational Complexity & Algorithmic Bounds

Header key normalization and column binding operate strictly within Complexity Class $`\mathbf{P}`$. For each raw header $``H_j``$, string trimming, case folding, and punctuation stripping execute in a single pass in deterministic $``O(|H_j|)``$ time. For bounded header length $``|H_j| \le L_{\text{max}} = 256``$ bytes, normalization runs in $`O(1)`$ constant time. Canonical alias lookup against $``\mathcal{K}_{\text{canonical}}``$ runs in deterministic $`O(1)`$ time via a static perfect hash table or Trie.

For a table with $``C \le C_{\text{max\_cols}} = 32``$ columns, computing binding vector $`\vec{\beta}`$ takes $``O(C \cdot L_{\text{max}}) = O(C) = O(1)``$ time. Injective collision checks and mandatory coverage evaluate over 64-bit integer masks in $`O(C)`$ time and $`O(1)`$ space. For $`M`$ data rows with total table byte size $`N`$, positional cell extraction via $`\vec{\beta}`$ executes in $`O(M \cdot C) = O(N)`$ time. Total table ingestion runs in deterministic $`O(N)`$ linear time in input size with $`O(C) = O(1)`$ auxiliary stack space ($`\le 128`$ bytes) and zero heap allocations during row ingestion. Bounded linear parsing operates strictly within $`\mathbf{P}`$ and bypasses all NP-complete combinatorial frontiers (NP-1--NP-8).

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Order-Independent Column Permutation Invariance
- **Given:** A CommonMark table defining component `Classifier_Alpha` with canonical columns $`\langle \text{Name}, \text{Type}, \text{Multiplicity}, \text{Description} \rangle`$.
- **When:** The compiler ingests tables across all $`4! = 24`$ column permutations (e.g., $`\langle \text{Description}, \text{Name}, \text{Type}, \text{Multiplicity} \rangle`$).
- **Then:** All 24 permuted tables synthesize bitwise identical AST entities with zero diff churn.
- **Diagnostic:** Deterministic AST generation; zero diagnostics emitted.

### AC-02: Multi-Stage Semantic Header Normalization Equivalence
- **Given:** Header strings with varied case (`"NAME"`, `"name"`), whitespace (`" Name "`), punctuation (`"part-name"`, `"part_name"`, `"[Part Name]"`), and aliases (`"id"`, `"identifier"`, `"name"`).
- **When:** The parser executes normalization $`\eta(H)`$ and alias lookup.
- **Then:** All header variations resolve deterministically to identical canonical key $``k_{\text{name}}``$.
- **Diagnostic:** Successful resolution to $``k_{\text{name}}``$; zero diagnostics emitted.

### AC-03: Injective Column Assignment & Duplicate Header Collision Detection
- **Given:** A table containing duplicate column headers or distinct headers resolving to identical key $``k_{\text{name}}``$ (e.g., columns `"Name"` and `"Identifier"`).
- **When:** The parser constructs binding vector $`\vec{\beta}`$.
- **Then:** Injective assignment fails, entity synthesis halts, synchronization token recovery engages, and a structured diagnostic is emitted.
- **Diagnostic:** Emits `E0102` with colliding column indices, raw header tokens, and source span coordinates.

### AC-04: Mandatory Coverage & Bounded Column Arity Enforcement
- **Given:** A table omitting mandatory attribute $``k_{\text{type}} \in \mathcal{M}(T_{\text{entity}})``$, or an unmapped header in strict mode, or a table exceeding $``C = 33 \gt C_{\text{max\_cols}}``$ columns.
- **When:** The parser inspects the table header row and validates binding vector $`\vec{\beta}`$.
- **Then:** The parser halts schema ingestion prior to row processing and emits a structured diagnostic without allocating unbounded buffers.
- **Diagnostic:** Emits `E0102` identifying missing mandatory attribute, unmapped header, or column limit exceeded.
