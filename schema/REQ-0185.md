## 1. Normative Statement

Subsystem 10 SHALL synthesize MISRA C99 source (`.c`) and header (`.h`) files via `MisraEmitter_Alpha` from AST classifiers (`Classifier_Alpha`).

---

## 2. Formal Invariant

Lowered C99 module $``\mathcal{M}_{\text{c99}}``$ satisfies memory, acyclicity, loop, exit, and diagnostic invariants:

```math
\begin{aligned}
\forall S\in\mathcal{S}_{\text{struct}},\quad\text{sizeof}(S)=K_S\in\mathbb{N}^+\land\text{alignof}(S)\in\{1,2,4,8\} \\
N_{\text{dyn}}=\sum_{F\in\mathcal{F}_{\text{c99}}}(|\text{AllocCalls}(F)|+|\text{VLADecls}(F)|)=0 \\
\mathcal{G}_{\text{call}}=(\mathcal{F}_{\text{c99}},\mathcal{E}_{\text{call}}),\quad\text{Cycles}(\mathcal{G}_{\text{call}})=\emptyset \\
\forall L\in\mathcal{L}_{\text{loops}},\quad\text{TripCount}(L)\le N_{\text{max\_loop}}\lt\infty \\
\forall F\in\mathcal{F}_{\text{c99}},\quad|\text{EntryPoints}(F)|=1\land|\text{ExitPoints}(F)|=1\land|\text{Jumps}(F)|=0 \\
\forall v\in\mathcal{V}_{\text{vars}},\quad\text{type}(v)\in\mathcal{T}_{\text{misra}} \\
(N_{\text{dyn}}\gt 0\lor\text{Cycles}(\mathcal{G}_{\text{call}})\ne\emptyset\lor\text{TripCount}(L)\gt N_{\text{max\_loop}}\lor|\text{ExitPoints}(F)|\ne 1)&\implies\text{Diagnostic}(v,\text{E0511})\in\mathcal{D}_{\text{sink}}\land v\gets\bot_{\text{c99}} \\
\text{type}(v)\notin\mathcal{T}_{\text{misra}}&\implies\text{Diagnostic}(v,\text{E0300})\in\mathcal{D}_{\text{sink}}\land v\gets\bot_{\text{c99}} \\
|\mathcal{D}_{\text{sink}}|\ge C_{\text{max\_errors}}&\implies\text{Diagnostic}(\text{E0199})\in\mathcal{D}_{\text{sink}} \\
\Delta_v=\text{UUIDv5}(\text{OID}_{\text{DEAP}},\text{FQN}(v))
\end{aligned}
```

| Symbol / Term | Domain / Formal Definition |
| :--- | :--- |
| $``\mathcal{S}_{\text{struct}}, K_S``$ | Struct types and static size |
| $``N_{\text{dyn}}``$ | Dynamic allocation and VLA count |
| $``\mathcal{G}_{\text{call}}, \mathcal{E}_{\text{call}}``$ | Call graph DAG and edges |
| $``\mathcal{L}_{\text{loops}}, N_{\text{max\_loop}}``$ | Loops and maximum trip bound |
| $``\mathcal{T}_{\text{misra}}``$ | Compliant scalar and bool types |
| $``\bot_{\text{c99}}, \mathcal{D}_{\text{sink}}, C_{\text{max\_errors}}``$ | Sentinel, diagnostic sink, error limit |
| $``\Delta_v, \text{OID}_{\text{DEAP}}, \text{FQN}(v)``$ | UUIDv5 anchor, namespace OID, FQN |

## 3. Computational Complexity & Algorithmic Bounds

- **Complexity Class:** Class $\mathbf{P}$.
- **Asymptotic Bound:** $``O(|V_{\text{AST}}|)``$ for AST nodes $``V_{\text{AST}}``$. Emission and layout checks run in $``O(|V_{\text{AST}}|)``$ time. Cycle checks take $``O(|\mathcal{F}_{\text{c99}}| + |\mathcal{E}_{\text{call}}|) \subseteq O(|V_{\text{AST}}|)``$. Work-stealing scales as $``O(|V_{\text{AST}}| / N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$; arena is $``O(|V_{\text{AST}}|)``$.
- **Tractable Subclass and Frontier:** N/A (Deterministic P). DAG traversal avoids NP-1 intervals (REQ-0117), NP-2 packing (REQ-0147), and NP-8 solving (REQ-0197).

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Static Memory Footprint
- **Given:** `Classifier_Alpha` declaring `StaticState_0`.
- **When:** Lowering C99 via `MisraEmitter_Alpha`.
- **Then:** Emits static struct, zero dynamic allocations, zero VLAs.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: Call Graph Cycle Rejection
- **Given:** Cycle in `CallGraph_1`.
- **When:** Evaluating call graph acyclicity.
- **Then:** Fails closed, emits `E0511`, binds $``\bot_{\text{c99}}``$, and records cycle.
- **Diagnostic:** `E0511`.

### AC-03: Unbounded Loop Interception
- **Given:** Loop exceeding $``N_{\text{max\_loop}}``$ or lacking bound.
- **When:** Evaluating loop termination.
- **Then:** Halts lowering, binds $``\bot_{\text{c99}}``$, and emits `E0511`.
- **Diagnostic:** `E0511`.

### AC-04: Delimiter Error Recovery
- **Given:** Invalid type, delimiter `;`, and `Classifier_Beta`.
- **When:** Recovering across delimiters.
- **Then:** Emits `E0300`, binds $``\bot_{\text{c99}}``$, recovers across `;`, halting at $``C_{\text{max\_errors}}``$ with `E0199`.
- **Diagnostic:** `E0300`, `E0199`.
