## 1. Normative Statement

The compiler SHALL bootstrap KerML `Base` (`Package_Base`) into root scope at initialization, providing `Anything`, classifiers `Element` and `Relationship`, `Nothing`, and operators `Op_Equal` and `Op_NotEqual`.

Lowering MUST enforce:
1. **Top-Type**: `Anything` ($\top$) is maximal; classifiers `Type_Alpha` specialize `Anything` ($``\text{Type\_Alpha} \le \text{Anything}``$).
2. **Hierarchy**: `Element` specializes `Anything`; `Relationship` specializes `Element`.
3. **Bottom-Type**: `Nothing` ($\bot$) is minimal, satisfying $`\forall T \in \mathcal{T}, \text{Nothing} \le T`$ ($⟦ \text{Nothing} ⟧ = \emptyset$).
4. **Equivalence**: `Op_Equal` evaluates data types by congruence ($``\equiv_{\text{val}}``$) and classes by identity ($`\text{id}(u) = \text{id}(v)`$); cross-domain comparisons yield `false`. `Op_NotEqual` negates equality.
5. **Visibility**: Symbols are injected into root scope without explicit imports.
6. **Reserved Names**: Redefinition emits `E0200`; cycles above `Anything` emit `E0203`.

## 2. Formal Invariant

Subtyping meet-semilattice, equivalence semantics, and identity invariants:

```math
\begin{aligned}
\forall T \in \mathcal{T},\; &\bot \le T \le \top,\; \top = \text{Anything},\; \bot = \text{Nothing} \\
\text{Relationship} &\le \text{Element} \le \text{Anything} \le C \implies C = \text{Anything} \\
\mathcal{U}_{\text{univ}} &= \mathcal{V}_{\text{val}} \cup \mathcal{O}_{\text{obj}},\; \mathcal{V}_{\text{val}} \cap \mathcal{O}_{\text{obj}} = \emptyset \\
(a == b) &\iff \begin{cases} a \equiv_{\text{val}} b, & a, b \in \mathcal{V}_{\text{val}} \\ \text{id}(a) = \text{id}(b), & a, b \in \mathcal{O}_{\text{obj}} \\ \text{false}, & \text{otherwise} \end{cases} \\
(a != b) &\iff \neg(a == b),\; \Delta_n = \text{UUIDv5}(\text{NS}_{\text{DEAP}}, \text{FQN}(n))
\end{aligned}
```

## 3. Computational Complexity & Algorithmic Bounds

- **Complexity Class:** $\mathbf{P}$ (Deterministic Polynomial)
- **Asymptotic Bound:** $O(1)$ lookup, subtyping, and equality ($O(L)$ composite); aggregate lowering is $O(N + M)$.
- **Tractable Subclass & Frontier:** Top-type meet-semilattice subtyping evaluates in $O(1)$ time, bypassing NP-complete search (NP-3). Work-stealing scales as $``O((N + M) / N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Canonical `Base` Bootstrapping
- **Given:** Initialized compiler environment.
- **When:** Resolving root library symbols.
- **Then:** `Anything`, `Element`, `Relationship`, `Nothing`, `==`, and `!=` resolve in $O(1)$.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: Top-Type Maximality and Specialization
- **Given:** Metamodel with classifier `Classifier_Alpha`.
- **When:** Evaluating subtyping queries.
- **Then:** `Classifier_Alpha <= Anything`, `Element <= Anything`, and `Relationship <= Element` evaluate `true`; `Anything <= Classifier_Alpha` is `false`.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-03: Primitive Equality Semantics
- **Given:** Values $``a, b \in \mathcal{V}_{\text{val}}``$ with congruent fields, and distinct entities $``u, v \in \mathcal{O}_{\text{obj}}``$ ($\text{id}(u) \ne \text{id}(v)$).
- **When:** Evaluating `a == b`, `u == v`, and cross-domain `a == u`.
- **Then:** `a == b` is `true`; `u == v` and `a == u` are `false`.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-04: Reserved Symbol and Cycle Rejection
- **Given:** Model redeclaring `Anything` or declaring cycle `Anything :> Classifier_Alpha`.
- **When:** Namespace validation and cycle detection execute.
- **Then:** Rejection emits `E0200` or `E0203`; recovery halts at $``C_{\text{max\_errors}}``$ with `E0199`.
- **Diagnostic:** `E0200`, `E0203`, or `E0199`.
