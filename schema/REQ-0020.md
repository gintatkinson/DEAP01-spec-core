## 1. Normative Statement

The CommonMark table parser within the Universal Schema Ingestion Engine shall implement deterministic lexical disambiguation of array indexing syntax across tabular MBSE schemas. When ingesting cell tokens for structural identifiers, component references, port bindings, or interconnect endpoints, the engine shall decompose bracketed identifiers into a base symbol identifier and integer index qualifiers without lexical backtracking or confusion with type multiplicity brackets (`Type[1..*]`).

The engine shall support four syntactic forms:
1. **Scalar Identifiers**: Unindexed strings (`base`, e.g., `Classifier_Alpha`), lowered to $`\langle \text{base}, \bot \rangle`$.
2. **Single-Dimensional Indexed Identifiers**: Bracketed strings (`base[index]`, e.g., `Part_Alpha[0]`), decomposed to base symbol and integer qualifier $``k \in \mathbb{N}_0``$.
3. **Multi-Dimensional Indexed Identifiers**: Chained bracketed indices (`base[i_1]...[i_K]`, e.g., `Matrix_Node[2][3]`), bounded by rank $`K \le 8`$, decomposed to base symbol and index tuple $``\langle i_1, \dots, i_K \rangle``$.
4. **Type Multiplicity Brackets**: Range-bounded types (`Type[lower..upper]`, e.g., `Classifier_Alpha[1..*]`), decomposed to type symbol and multiplicity bounds $`\langle L, U \rangle`$.

Bracket contents with `..` or `*` designate type multiplicity $``\theta_{\text{multiplicity}}``$ and are rejected with diagnostic `E0102` if present in an instance column; bracket contents containing strictly decimal digits designate array indexing $``\theta_{\text{array}}``$.

## 2. Formal Invariant

Let $`\Sigma`$ denote the ASCII alphabet, with $``\Sigma_{\text{digit}} = \{ 0\text{x}30, \dots, 0\text{x}39 \}``$ and identifier grammar $``\text{Ident} \in (\Sigma_{\text{alpha}} \cup \{ \text{\_} \}) \cdot (\Sigma_{\text{alpha}} \cup \Sigma_{\text{digit}} \cup \{ \text{\_} \})^*``$. Digit sequence valuation $``\text{Val} : \Sigma_{\text{digit}}^+ \to \mathbb{N}_0``$ is:

```math
\text{Val}(d_0 \dots d_{m-1}) = \sum_{j=0}^{m-1} (d_j - 0\text{x}30) \cdot 10^{m-1-j}
```

Array decomposition operator $``\theta_{\text{array}} : \Sigma^* \to (\Sigma^+ \times (\mathbb{N}_0 \cup \{ \bot \})) \cup \{ \bot_{\text{err}} \}``$ is defined as:

```math
\theta_{\text{array}}(S) = \begin{cases}
\langle u, \text{Val}(v) \rangle, & \text{if } S = u \mathbin{\Vert} \text{"["} \mathbin{\Vert} v \mathbin{\Vert} \text{"]"} \;\wedge\; u \in \text{Ident} \;\wedge\; v \in \Sigma_{\text{digit}}^+ \;\wedge\; \text{Val}(v) \lt 2^{32} \\
\langle S, \bot \rangle, & \text{if } S \in \text{Ident} \\
\bot_{\text{err}}, & \text{otherwise}
\end{cases}
```

For multi-dimensional indexing with rank $`K \le 8`$:

```math
\theta_{\text{multi}}(S) = \begin{cases}
\langle u, \langle \text{Val}(v_1), \dots, \text{Val}(v_K) \rangle \rangle, & \text{if } S = u \mathbin{\Vert} \prod_{j=1}^K (\text{"["} \mathbin{\Vert} v_j \mathbin{\Vert} \text{"]"}) \;\wedge\; u \in \text{Ident} \;\wedge\; 1 \le K \le 8 \\
\bot_{\text{err}}, & \text{otherwise}
\end{cases}
```

Let $``\text{RangeExpr} = (v_L \mathbin{\Vert} \text{".."} \mathbin{\Vert} v_U) \mid (v_L \mathbin{\Vert} \text{"..*"}) \mid \text{"*"} \mid v_L``$. Multiplicity decomposition $``\theta_{\text{multiplicity}}``$, disjointness, and diagnostic binding per REQ-0191 satisfy:

```math
\begin{aligned}
\theta_{\text{multiplicity}}(S) &= \begin{cases}
\langle \text{Type}(S), \langle L(S), U(S) \rangle \rangle, & \text{if } S = \text{Ident} \mathbin{\Vert} \text{"["} \mathbin{\Vert} \text{RangeExpr} \mathbin{\Vert} \text{"]"} \\
\langle S, \langle 1, 1 \rangle \rangle, & \text{if } S \in \text{Ident} \\
\bot_{\text{err}}, & \text{otherwise}
\end{cases} \\
\mathcal{L}(\text{IndexedIdentifier}) &\cap \mathcal{L}(\text{MultiplicityRangeType}) = \emptyset \\
(\kappa = \text{ColKind}_{\text{Instance}} \;\wedge\; \theta_{\text{array}}(S) = \bot_{\text{err}}) &\implies \exists D \in \mathcal{D} : \text{Code}(D) = \text{DiagnosticCode::E0102}
\end{aligned}
```

## 3. Computational Complexity & Algorithmic Bounds

Disambiguation of array indexing syntax executes within Complexity Class $`\mathbf{P}`$. Monotonic single-pass character scanning evaluates each byte of token $`S`$ in $`O(1)`$ operations, achieving deterministic $`O(|S|)`$ linear time without backtracking. For cell tokens bounded by $``|S| \le L_{\text{max\_cell}} = 256``$ bytes, evaluation executes in $`O(1)`$ constant time. Across a table of $`N`$ total bytes, ingestion executes in deterministic $`O(N)`$ linear time and $`O(1)`$ auxiliary stack space for rank $`K \le 8`$. Lexical character scanning bypasses NP-complete combinatorial frontiers (NP-1--NP-8), executing strictly in polynomial time.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Positive Single-Dimensional Array Indexing
- **Given:** Tabular cells with bracketed identifiers (`Part_Alpha[0]`, `Port_1[42]`, `Flow_A[65535]`).
- **When:** Lowering cells via disambiguation pass $``\theta_{\text{array}}``$.
- **Then:** Decomposes into interned base symbol `SymbolId` and 32-bit unsigned integers ($`0, 42, 65535`$) in `IndexedReferenceNode`.
- **Diagnostic:** `E0102` on decomposition failure.

### AC-02: Scalar Identifier Passthrough
- **Given:** Tabular cells with unindexed scalar identifiers (`Classifier_Alpha`, `Port_1`, `Flow_A`).
- **When:** Lowering cells via $``\theta_{\text{array}}``$.
- **Then:** Evaluates to scalar references $`\langle \text{base}, \bot \rangle`$ without triggering array logic.
- **Diagnostic:** `E0102` on false-positive index detection.

### AC-03: Multi-Dimensional Array Indexing Bounds
- **Given:** Tabular cells with multi-dimensional indexing (`Matrix_Node[2][5]`, `Node_Alpha[1][0][7]`) with rank $`K \le 8`$.
- **When:** Lowering cells via $``\theta_{\text{multi}}``$.
- **Then:** Decomposes into base symbol and index tuples ($`\langle 2, 5 \rangle`$, $`\langle 1, 0, 7 \rangle`$); rejects $`K \gt 8`$.
- **Diagnostic:** `E0102` on rank overflow ($`K \gt 8`$).

### AC-04: Strict Lexical Separation of Type Multiplicity Ranges
- **Given:** Schema cells with type multiplicity bounds (`Classifier_Alpha[1..*]`, `DataType_Beta[0..1]`).
- **When:** Processing type columns versus instance columns.
- **Then:** Decomposes type cells to multiplicity $`\langle L, U \rangle`$; rejects multiplicity syntax in instance columns.
- **Diagnostic:** `E0102` on multiplicity syntax in instance columns.
