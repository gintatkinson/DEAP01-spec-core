## 1. Normative Statement

The network solver SHALL construct incidence matrix $\mathbf{A}\in\{-1,0,1\}^{n\times b}$ for network $``\mathcal{G}_{\text{flow}}=(\mathcal{V}_{\text{junc}},\mathcal{E}_{\text{flow}})``$, verify topological rank, and synthesize cut-set and cycle matrices.

Lowering MUST enforce:
1. **Incidence Assembly**: Branch $``e_j=(u_j,v_j)``$ sets $``A_{i,j}=+1``$ at source $``u_j``$, $``A_{i,j}=-1``$ at target $``v_j``$, and $0$ elsewhere, with $``\sum_{i=1}^n A_{i,j}=0``$. Self-loops ($``u_j=v_j``$) emit `E0203`.
2. **Rank Solvability**: Components $``\mathcal{K}_c``$ require $\text{rank}(\mathbf{A})=n-p$ where $p=|\mathcal{K}|$. Single components ($p=1$) have defect 1 ($\text{rank}(\mathbf{A})=n-1$). Deficiencies emit `E0301`.
3. **Reduced Incidence**: Designating datum $``J_{\text{ref},m}``$ per component ($``e(J_{\text{ref},m})=0``$) yields full-rank $``\mathbf{A}_{\text{red}}\in\{-1,0,1\}^{(n-p)\times b}``$ with $``\text{rank}(\mathbf{A}_{\text{red}})=n-p``$.
4. **Duality**: Spanning forest $\mathcal{T}$ partitions tree $``\mathcal{E}_{\text{tree}}``$ and chords $``\mathcal{E}_{\text{chord}}``$, giving $``\mathbf{A}_{\text{red}}=[\mathbf{A}_T\mid\mathbf{A}_C]``$ with $``\det(\mathbf{A}_T)\in\{-1,+1\}``$. Cut-set $``\mathbf{Q}=[\mathbf{I}_{n-p}\mid\mathbf{Q}_C]``$ ($``\mathbf{Q}_C=\mathbf{A}_T^{-1}\mathbf{A}_{\text{red}}``$) requires $\mathbf{Q}\mathbf{f}=\mathbf{0}$. Cycle $``\mathbf{B}=[-\mathbf{Q}_C^T\mid\mathbf{I}_{b-n+p}]``$ requires $\mathbf{B}\mathbf{\Delta e}=\mathbf{0}$.
5. **Orthogonality**: Requires $\mathbf{A}\mathbf{B}^T=\mathbf{0}$, $\mathbf{Q}\mathbf{B}^T=\mathbf{0}$, $\mathbf{f}^T\mathbf{\Delta e}=0$, and $``\mathbf{Y}_{\text{node}}=\mathbf{A}_{\text{red}}\mathbf{Y}\mathbf{A}_{\text{red}}^T\succ 0``$. Common junctions require $``\mathbf{d}_{\text{through}}\in\mathbb{Q}^7``$ (mismatches emit `E0300`). Degree $\le 1$ junctions emit `E0220`.

## 2. Formal Invariant

Topological incidence, rank solvability, cut-set and cycle duality, and diagnostic predicates:

```math
\begin{aligned}
\mathcal{G}_{\text{flow}}=(\mathcal{V}_{\text{junc}},\mathcal{E}_{\text{flow}}),\quad A_{i,j}\in\{-1,0,+1\},\quad \sum_{i=1}^n A_{i,j}=0 \\
u_j=v_j\implies\text{Diagnostic}(e_j,\text{E0203})\wedge e_j\gets\bot_{\text{branch}} \\
\text{rank}(\mathbf{A})=n-p,\quad \text{rank}(\mathbf{A})\lt n-p\implies\text{Diagnostic}(\text{Network},\text{E0301}) \\
\mathbf{A}_{\text{red}}=[\mathbf{A}_T\mid\mathbf{A}_C],\quad \text{rank}(\mathbf{A}_{\text{red}})=n-p,\quad \det(\mathbf{A}_T)\in\{-1,+1\} \\
\mathbf{Q}=[\mathbf{I}_{n-p}\mid\mathbf{Q}_C],\quad \mathbf{B}=[-\mathbf{Q}_C^T\mid\mathbf{I}_{b-n+p}],\quad \mathbf{Q}\mathbf{f}=\mathbf{0},\quad \mathbf{B}\mathbf{\Delta e}=\mathbf{0} \\
```

## 3. Computational Complexity & Algorithmic Bounds

- **Complexity Class:** $\mathbf{P}$ (Deterministic Polynomial)
- **Asymptotic Bound:** $O(n+b)$ for incidence, components, and rank; $O(n\cdot b)$ for tree factorization and cut-set/cycle matrices.
- **Tractable Subclass & Frontier:** Linear traversal avoids cut-set search (NP-4 polynomial fragment); tree substitution replaces matrix inversion. Work-stealing scales as $``O((n\cdot b)/N_{\text{max\_workers}}+\log N_{\text{max\_workers}})``$.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Two-Junction Branch Incidence and Column Sum
- **Given:** Network `Network_Alpha` with `Junction_Alpha`, `Junction_Beta`, and `FlowBranch_1`.
- **When:** Lowering constructs matrix $\mathbf{A}$.
- **Then:** Emits $\mathbf{A}=[+1;-1]$ with column sum 0 and $\text{rank}(\mathbf{A})=1$.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: Connected Triangular Loop Spanning Tree and Duality
- **Given:** Triangle network with 3 junctions, 3 branches, and admittances $``y_j\gt 0``$.
- **When:** Lowering spanning tree, cut-set $\mathbf{Q}$, and cycle $\mathbf{B}$.
- **Then:** Partitions 2 tree branches, 1 chord, yielding $``\mathbf{B}_T=-\mathbf{Q}_C^T``$, $\mathbf{A}\mathbf{B}^T=\mathbf{0}$, and $``\mathbf{Y}_{\text{node}}\succ 0``$.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-03: Self-Loop and Floating Interface Rejection
- **Given:** Branch with $``u_1=v_1``$ and isolated junction `Junction_Alpha` ($\text{deg}=0$).
- **When:** Auditing incidence and degree invariants.
- **Then:** Rejection emits `E0203` for self-loop and `E0220` for isolated junction.
- **Diagnostic:** `E0203`, `E0220`.

### AC-04: Rank Deficiency and Delimiter Recovery
- **Given:** Defective network ($\text{rank}(\mathbf{A})\lt n-p$) before delimiter (`;`) and valid `Network_Beta`.
- **When:** Verifying solvability and executing recovery.
- **Then:** Emits `E0301`, resynchronizes on `;`, parses `Network_Beta`, halting at $``C_{\text{max\_errors}}``$ with `E0199`.
- **Diagnostic:** `E0301`, `E0199`.
