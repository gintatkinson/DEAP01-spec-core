## 1. Normative Statement

The semantic type checker and metamodel lowering engine shall implement a formal Boolean algebra over classifier type denotations, providing set-theoretic type operators (`unioning`, `intersecting`, `differencing`, `disjoining`) to construct compound classifiers and enforce static disjointness invariants.

The lowering engine shall enforce the following normative provisions:
1. `unioning`: The compound union classifier $``T_1 \cup T_2``$ denotes $``⟦ T_1 ⟧ \cup ⟦ T_2 ⟧``$, satisfying subtyping covariance: $``T_1 \le (T_1 \cup T_2) \wedge T_2 \le (T_1 \cup T_2)``$.
2. `intersecting`: The compound intersection classifier $``T_1 \cap T_2``$ denotes $``⟦ T_1 ⟧ \cap ⟦ T_2 ⟧``$, satisfying subtyping contravariance: $``(T_1 \cap T_2) \le T_1 \wedge (T_1 \cap T_2) \le T_2``$.
3. `differencing`: Relative complement $``T_1 \setminus T_2``$ denotes $``⟦ T_1 ⟧ \setminus ⟦ T_2 ⟧``$, satisfying $``(T_1 \setminus T_2) \le T_1``$ and $``(T_1 \setminus T_2) \perp T_2``$. If $``T_1 \le T_2``$, difference denotes empty type $``\bot_{\text{type}}``$; instantiating an uninhabitable difference type shall trigger diagnostic error code `E0200`.
4. `disjoining`: Asserts mutual exclusion $``T_1 \perp T_2 \iff ⟦ T_1 ⟧ \cap ⟦ T_2 ⟧ = \emptyset``$. Disjointness propagates monotonically down the subtyping semilattice: $``\forall S_1 \le T_1, S_2 \le T_2 \implies S_1 \perp S_2``$. Asserting a joint instance, non-empty intersection, or joint specialization ($``C \le T_1 \wedge C \le T_2``$) shall trigger diagnostic error code `E0200`.
5. Subtyping Consistency: Set operations shall preserve subtyping equivalence: $``T_1 \le T_2 \iff ⟦ T_1 ⟧ \subseteq ⟦ T_2 ⟧ \iff ⟦ T_1 \setminus T_2 ⟧ = \emptyset``$.

## 2. Formal Invariant

Let $`\mathcal{T}`$ denote classifier types, $`\mathcal{U}`$ the instance universe, and $`⟦ \cdot ⟧ : \mathcal{T} \to \mathcal{P}(\mathcal{U})`$ type denotation:

```math
\begin{aligned}
⟦ T_1 \cup T_2 ⟧ &= ⟦ T_1 ⟧ \cup ⟦ T_2 ⟧, & T_1 \le (T_1 \cup T_2) \wedge T_2 \le (T_1 \cup T_2) \\
⟦ T_1 \cap T_2 ⟧ &= ⟦ T_1 ⟧ \cap ⟦ T_2 ⟧, & (T_1 \cap T_2) \le T_1 \wedge (T_1 \cap T_2) \le T_2 \\
⟦ T_1 \setminus T_2 ⟧ &= ⟦ T_1 ⟧ \setminus ⟦ T_2 ⟧, & (T_1 \setminus T_2) \le T_1 \wedge (T_1 \setminus T_2) \perp T_2 \\
T_1 \perp T_2 &\iff ⟦ T_1 ⟧ \cap ⟦ T_2 ⟧ = \emptyset, & (T_1 \perp T_2 \wedge S_1 \le T_1 \wedge S_2 \le T_2) \implies S_1 \perp S_2 \\
T_1 \le T_2 &\iff ⟦ T_1 ⟧ \subseteq ⟦ T_2 ⟧ \iff ⟦ T_1 \setminus T_2 ⟧ = \emptyset
\end{aligned}
```

```math

```

```math
\begin{aligned}
(T_1 \perp T_2 \wedge \exists C \in \mathcal{T} : C \le T_1 \wedge C \le T_2) &\implies \text{Diagnostic}(C, \text{E0200}) \in \mathcal{D}_{\text{sink}} \\
(T_1 \perp T_2 \wedge \exists x : x : T_1 \wedge x : T_2) &\implies \text{Diagnostic}(x, \text{E0200}) \in \mathcal{D}_{\text{sink}} \\
```

## 3. Computational Complexity & Algorithmic Bounds

Type algebra evaluation and disjointness verification execute in Complexity Class $`\mathbf{P}`$.

For $`V = |\mathcal{T}|`$ classifier types and $`E`$ specialization and disjointness edges:
1. Poset & Disjointness Queries: Subtyping reachability bitset lookup executes in $`O(1)`$ time following $`O(V + E)`$ transitive closure initialization.
2. Compound Type Normalization: Set-theoretic operations over finite bitsets evaluate in deterministic $`O(V)`$ time.
3. Model Invariant Checking: Complete model disjointness verification executes in $`O(V \cdot \lceil V / 64 \rceil) \subseteq O(V^2)`$ worst-case and $`O(V + E)`$ sparse time.
4. Parallel Work-Stealing: Scheduled on $``N_{\text{max\_workers}}``$ threads, verification executes in $``O((V + E) / N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$ time.
5. Space Bounds: Storage is bounded by $`O(V + E)`$ arena memory and $``O(C_{\text{max\_errors}}) = O(1)``$ error sink buffer.

NP Frontier Reference (NP-3): Arbitrary poset subtyping with Boolean operators is NP-complete. Restricting type algebra expressions to finite classifier meet-semilattices and deterministic C3 linearization without backtracking guarantees deterministic polynomial-time execution.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Unioning Compound Type Subtyping Invariant
- **Given:** Classifiers `Classifier_Alpha` and `Classifier_Beta` in `Package_0`.
- **When:** Lowering processes `Classifier_Alpha unioning Classifier_Beta`.
- **Then:** Engine emits compound type $``T_{\text{union}}``$ with $``⟦ T_{\text{union}} ⟧ = ⟦ \text{Classifier\_Alpha} ⟧ \cup ⟦ \text{Classifier\_Beta} ⟧``$, enforces covariance $``\text{Classifier\_Alpha} \le T_{\text{union}}``$ and $``\text{Classifier\_Beta} \le T_{\text{union}}``$, and binds deterministic RFC 4122 UUIDv5.
- **Diagnostic:** `E0200` emitted on invalid or unresolvable operand types.

### AC-02: Intersecting Compound Type Conformance Invariant
- **Given:** Classifiers `Classifier_Alpha` and `Classifier_Beta` in `Package_0`.
- **When:** Lowering processes `Classifier_Alpha intersecting Classifier_Beta`.
- **Then:** Engine emits intersection type $``T_{\text{inter}}``$ with $``⟦ T_{\text{inter}} ⟧ = ⟦ \text{Classifier\_Alpha} ⟧ \cap ⟦ \text{Classifier\_Beta} ⟧``$, enforces contravariance $``T_{\text{inter}} \le \text{Classifier\_Alpha}``$ and $``T_{\text{inter}} \le \text{Classifier\_Beta}``$, preserving feature conjunction.
- **Diagnostic:** `E0200` emitted on invalid operand types.

### AC-03: Differencing Relative Complement Evaluation
- **Given:** Specializing classifiers where $``\text{Classifier\_Beta} \le \text{Classifier\_Alpha}``$.
- **When:** Lowering evaluates `Classifier_Alpha differencing Classifier_Beta`.
- **Then:** Denotation satisfies $``⟦ \text{Classifier\_Alpha} \setminus \text{Classifier\_Beta} ⟧ = ⟦ \text{Classifier\_Alpha} ⟧ \setminus ⟦ \text{Classifier\_Beta} ⟧``$; declaring an instance on empty difference $``\text{Classifier\_Beta} \setminus \text{Classifier\_Alpha}``$ binds $``\bot_{\text{type}}``$.
- **Diagnostic:** `E0200` emitted on uninhabitable difference type instantiation.

### AC-04: Disjoining Mutual Exclusion Enforcement
- **Given:** Classifiers declared mutually disjoint via `disjoining Classifier_Alpha, Classifier_Beta`.
- **When:** Classifier `Classifier_Gamma` specializes both `Classifier_Alpha` and `Classifier_Beta`.
- **Then:** Engine detects $``\text{Classifier\_Alpha} \perp \text{Classifier\_Beta}``$, identifies empty intersection $``⟦ \text{Classifier\_Gamma} ⟧ \subseteq \emptyset``$, binds sentinel $``\bot_{\text{type}}``$, and recovers at delimiter.
- **Diagnostic:** `E0200` emitted with source span identifying the disjoint type conflict.
