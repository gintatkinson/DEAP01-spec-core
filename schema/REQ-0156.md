## 1. Normative Statement

The compiler SHALL verify dynamic schedulability for real-time tasks under scheduler `EDF_Scheduler_0` during Level 1C ICD synthesis.

---

## 2. Formal Invariant

Let $\mathcal{K}$ denote channels and $``\Gamma_K``$ tasks on channel $K$. Dynamic schedulability satisfies:

```math
\begin{aligned}
\Gamma_K=\{\tau_1,\dots,\tau_n\}, & \quad \tau_i=\langle\text{id}_i,\text{name}_i,C_i,D_i,T_i,K,\Delta_i,\text{span}_i\rangle \\
\forall\tau_i\in\Gamma_K,\,0\lt C_i\le D_i\le T_i, & \quad U(\Gamma_K)=\sum_{i=1}^n(C_i/T_i)\le 1.0 \\
(\forall\tau_i,\,D_i=T_i) & \implies (\text{Schedulable}_{\text{EDF}}(\Gamma_K)\iff U(\Gamma_K)\le 1.0) \\
h(t)=\sum_{i=1}^n\max(0,\lfloor(t-D_i)/T_i\rfloor+1)C_i, & \quad \mathcal{D}_K=\{k\cdot T_i+D_i\le L^*\} \\
(\exists i:D_i\lt T_i) & \implies (\text{Schedulable}_{\text{EDF}}(\Gamma_K)\iff(U\le 1.0\land\forall t\in\mathcal{D}_K,\,h(t)\le t)) \\
(U\gt 1.0\lor\exists t\in\mathcal{D}_K:h(t)\gt t\lor C_i\gt D_i) & \implies \text{Diagnostic}(K,\text{E0211})\in\mathcal{D}_{\text{sink}}\land\Gamma_K\gets\bot_{\text{sched}} \\
\text{Endpoint}(e)\notin\mathcal{K} & \implies \text{Diagnostic}(e, \text{E0200})\in\mathcal{D}_{\text{sink}} \\
|\mathcal{D}_{\text{sink}}|\ge C_{\text{max\_errors}}\implies\text{Diagnostic}(\text{E0199})\in\mathcal{D}_{\text{sink}}, & \quad \Delta_x=\text{UUIDv5}(\text{OID}_{\text{DEAP}},\text{FQN}(x))
\end{aligned}
```

| Symbol / Term | Domain / Formal Definition |
| :--- | :--- |
| $``\Gamma_K, \mathcal{K}``$ | Task set and channel set |
| $``\tau_i, C_i, D_i, T_i``$ | Task tuple, execution time, deadline, period |
| $``U(\Gamma_K), h(t)``$ | Utilization factor and demand function |
| $``\mathcal{D}_K, L^*``$ | Testing deadline set and busy period |
| $``\bot_{\text{sched}}, \mathcal{D}_{\text{sink}}, C_{\text{max\_errors}}, \Delta_x``$ | Sentinel, error sink, error cap, UUIDv5 anchor |

## 3. Computational Complexity & Algorithmic Bounds

- **Complexity Class:** Class $\mathbf{P}$ (Deterministic Polynomial Time).
- **Asymptotic Bound:** $O(n)$ dynamic utilization accumulation $``\sum C_i/T_i \le 1``$ ($``n = |\Gamma_K|``$). Pseudo-polynomial $``O(|\mathcal{D}_K| \cdot n)``$ for constrained deadlines. Pool bound: $``O((|\mathcal{K}| \cdot n)/N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$. Space: $``O(n + |\mathcal{D}_K|)``$.
- **Tractable Subclass & Frontier:** N/A (Deterministic P). Dynamic accumulation bypasses NP-1 (REQ-0117), NP-2 (REQ-0147), and NP-8 (REQ-0197).

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Implicit Deadline Schedulability
- **Given:** Task set `DynamicTaskSet_Alpha` on `Channel_0` ($``C_1=1, T_1=4; C_2=2, T_2=6; C_3=1, T_3=8``$).
- **When:** Computing $U = 17/24 \le 1.0$.
- **Then:** Confirms EDF schedulability.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: Exact Saturation Dynamic Bound
- **Given:** Task set on `Channel_0` ($``C_1=1, T_1=2; C_2=1, T_2=4; C_3=1, T_3=4``$).
- **When:** Evaluating dynamic bound.
- **Then:** Passes under EDF (RMS rejects).
- **Diagnostic:** Diagnostic sink remains empty.

### AC-03: Dynamic Overload Rejection
- **Given:** Tasks on `Channel_0` with $U = 1.10 \gt 1.0$.
- **When:** Evaluating schedulability gate.
- **Then:** Fails closed, binds $``\bot_{\text{sched}}``$, emits `E0211`.
- **Diagnostic:** `E0211` (DynamicSchedulabilityViolation).

### AC-04: Unmapped Endpoint & Delimiter Recovery
- **Given:** Flow `Flow_1` with unmapped `Port_1` and overutilized channel.
- **When:** Synthesizing contracts with delimiter recovery.
- **Then:** Emits `E0200` and `E0211`, halts at $``C_{\text{max\_errors}}``$ with `E0199`.
- **Diagnostic:** `E0200`, `E0211`, `E0199`.
