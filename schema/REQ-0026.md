## 1. Normative Statement

The Universal Schema Ingestion Engine shall parse CommonMark tables specifying behavioral actions, activities, and discrete state transitions into intermediate `IngestedAction` and `IngestedTransition` AST entities. For action rows, the parser must extract action identifier `id`, owning classifier handle, kind (`Action`, `Activity`, `OpaqueAction`), typed inputs $`\mathcal{I}`$, typed outputs $`\mathcal{O}`$, optional trigger $``e_{\text{trigger}}``$, guard $``g_{\text{guard}}``$, preconditions $``\mathcal{P}_{\text{pre}}``$, and postconditions $``\mathcal{P}_{\text{post}}``$. For state transition rows, the parser shall extract source state $``s_{\text{source}}``$, target state $``s_{\text{target}}``$, trigger $``e_{\text{trigger}}``$, guard $``g_{\text{guard}}``$, and effect handle $``A_{\text{effect}}``$, validating that $``s_{\text{source}}``$ and $``s_{\text{target}}``$ resolve within the owning classifier state scope.

On syntax faults, malformed parameter signatures, duplicate names, or unresolvable states, the engine shall emit diagnostic `E0102` per REQ-0191., REQ-0013, and REQ-0016, the engine shall execute synchronization token error recovery on row line breaks ($``\text{SYM}_{\text{LF}}``$), substitute typed error sentinel $``\bot_{\text{action}}``$ or $``\bot_{\text{trans}}``$, and resume ingestion. If diagnostics reach capacity limit $``C_{\text{max\_errors}}``$, the parser shall emit `E0199` and terminate table processing. The parser shall enforce a deterministic, non-panicking execution contract. Test fixtures shall strictly use abstract MBSE placeholders (e.g., `Package_0`, `Classifier_Alpha`, `StateMachine_0`, `State_Idle`, `State_Active`, `Action_0`, `Event_0`, `param_x : Real`).

## 2. Formal Invariant

Let tabular schema $``\mathcal{T}_{\text{behavior}} = (\mathbf{H}, \mathbf{R})``$ have column headers $``\mathbf{H} = \langle H_0, \dots, H_{C-1} \rangle``$ ($`1 \le C \le 32`$) and rows $``\mathbf{R} = \langle R_1, \dots, R_M \rangle``$. Attribute mapping $``\vec{\beta} : \{0, \dots, C-1\} \to \mathcal{K}_{\text{behavior}} \cup \{ \bot \}``$ maps columns to canonical attributes:

```math
\mathcal{K}_{\text{behavior}} = \{ \text{id}, \text{owner}, \text{kind}, \text{inputs}, \text{outputs}, \text{trigger}, \text{guard}, \text{pre}, \text{post}, \text{source}, \text{target}, \text{effect} \}
```

Each behavioral action row lowers to an `IngestedAction` 8-tuple:

```math
A = \langle \text{id}, \text{owner}, \mathcal{I}, \mathcal{O}, e_{\text{trigger}}, g_{\text{guard}}, \mathcal{P}_{\text{pre}}, \mathcal{P}_{\text{post}} \rangle
```

where typed parameter sets $``\mathcal{I} = \{ (p_i, \tau_i) \mid 1 \le i \le m \}``$ and $``\mathcal{O} = \{ (q_j, \tau_j) \mid 1 \le j \le k \}``$ satisfy parameter uniqueness and disjointness:

```math
\begin{aligned}
\forall a \ne b &\implies p_a \ne p_b \\
\forall c \ne d &\implies q_c \ne q_d \\
\{ p_1, \dots, p_m \} &\cap \{ q_1, \dots, q_k \} = \emptyset
\end{aligned}
```

Each state transition row lowers to an `IngestedTransition` 5-tuple:

```math
T = \langle s_{\text{source}}, s_{\text{target}}, e_{\text{trigger}}, g_{\text{guard}}, A_{\text{effect}} \rangle
```

satisfying endpoint state machine containment and guard determinism:

```math
s_{\text{source}}, s_{\text{target}} \in \text{States}(\text{owner}) = \{ s \in \mathcal{S}_{\text{sym}} \mid \text{DeclaredState}(s, \text{owner}) \}
```

```math
(s_{\text{source}, a} = s_{\text{source}, b} \;\wedge\; e_{\text{trigger}, a} = e_{\text{trigger}, b} \;\wedge\; a \ne b) \implies (g_{\text{guard}, a} \wedge g_{\text{guard}, b} \equiv \text{false})
```

Row evaluation and diagnostic code bindings satisfy:

```math
\Phi_{\text{behavior}}(R_i) =
\begin{cases}
A_i \text{ or } T_i, & \text{if } \text{ValidRow}(R_i) \\
\bot_{\text{action}} \text{ or } \bot_{\text{trans}}, & \text{if } \neg\text{ValidRow}(R_i)
\end{cases}
```

```math
\begin{aligned}
\neg\text{ValidRow}(R_i) &\implies \text{Diagnostic}(R_i, \text{DiagnosticCode::E0102}) \in \mathcal{D} \\
|\mathcal{D}| \ge C_{\text{max\_errors}} &\implies \exists D_{\text{term}} \in \mathcal{D} : \text{Code}(D_{\text{term}}) = \text{DiagnosticCode::E0199}
\end{aligned}
```

## 3. Computational Complexity & Algorithmic Bounds

The ingestion engine operates within Complexity Class $`\mathbf{P}`$. For byte length $`N`$ with $`R`$ rows and $`C \le 32`$ columns, lexical scanning and delimiter detection advance monotonically in $`O(N)`$ operations. Header binding $`\vec{\beta}`$ executes in $`O(C) = O(1)`$ time. Per row $``R_i``$, parameter parsing over $`P \le 32`$ tokens, symbol interning, state scope hash lookup, and arena node allocation execute in $`O(1)`$ amortized time. Total sequential runtime is strictly linear:

```math
T(R, N) \in O(N) = O(R \cdot C) = O(R)
```

Parallel execution across $`K`$ tables on $``N_{\text{max\_workers}}``$ threads scales in $``O(\lceil K / N_{\text{max\_workers}} \rceil \cdot R_{\text{max}})``$. Auxiliary heap space is bounded by $`O(R)`$ arena storage and $``O(C_{\text{max\_errors}}) = O(1)``$ diagnostics. Downstream state reachability and temporal consistency verification are decoupled and addressed in Subsystems 6 and 7 (NP-1, NP-5).

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Canonical Behavioral Action Ingestion
- **Given:** CommonMark table declaring actions `Action_0` and `Activity_Alpha` with inputs (`param_in : Real`), outputs (`param_out : Integer`), trigger `Event_0`, guard `guard_cond_0`, and constraints `pre_0`, `post_0`.
- **When:** The parser ingests and lowers table rows.
- **Then:** 100% of rows lower into `IngestedAction` AST nodes in contiguous AST storage with valid symbol handles, disjoint parameter sets, and zero diagnostics.
- **Diagnostic:** `E0102` emitted on extraction or parameter syntax failure.

### AC-02: State Transition Table Ingestion & Endpoint Scoping
- **Given:** CommonMark table declaring transitions `Transition_0` and `Transition_1` in `StateMachine_0` between states `State_Idle` and `State_Active` with trigger `Event_Start` and effect `Action_Notify`.
- **When:** The parser resolves transition rows against state scope $``\text{States}(\text{StateMachine\_0})``$.
- **Then:** Rows lower into `IngestedTransition` AST entities with verified endpoint handles $``s_{\text{source}}, s_{\text{target}} \in \text{States}(\text{StateMachine\_0})``$.
- **Diagnostic:** `E0102` emitted if $``s_{\text{source}}``$ or $``s_{\text{target}}``$ fails scope resolution.

### AC-03: Parameter Signature Well-Formedness & Disjointness Gate
- **Given:** Behavioral table row with duplicate parameter names (`param_x : Real, param_x : Integer`) or non-disjoint parameter sets ($`\mathcal{I} \cap \mathcal{O} \ne \emptyset`$).
- **When:** The parameter parser tokenizes and validates declared parameter sets.
- **Then:** The row is rejected, sentinel $``\bot_{\text{action}}``$ is substituted, and parsing resumes.
- **Diagnostic:** `E0102` emitted with exact byte span and parameter error classification.

### AC-04: Delimiter Synchronization Recovery on Row Boundaries
- **Given:** 10-row behavioral table with syntax faults on rows 3 and 7 (unclosed delimiter and malformed parameter syntax).
- **When:** The parser ingests the table under Synchronization Token Error Recovery.
- **Then:** Rows 1, 2, 4, 5, 6, 8, 9, 10 lower into valid AST entities, rows 3 and 7 record $``\bot_{\text{action}}``$, exactly 2 diagnostics are logged, and parsing resumes on $``\text{SYM}_{\text{LF}}``$ boundaries.
- **Diagnostic:** `E0102` emitted for rows 3 and 7; `E0199` emitted if fault count reaches $``C_{\text{max\_errors}}``$.
