## 1. Normative Statement

The flow solver SHALL classify all connections $``f \in \mathcal{F}_{\text{flow}}``$ into Conservative ($``\mathcal{F}_{\text{cons}}``$) or Non-Conservative ($``\mathcal{F}_{\text{noncons}}``$) flows.

Lowering MUST enforce:
1. **Conservative Flows ($``\mathcal{F}_{\text{cons}}``$)**: Classified as conservative if both ports are acausal with conjugate Across-Through pairs in $``\mathbb{Q}^7``$ satisfying $``\mathbf{d}_e+\mathbf{d}_f \equiv \mathbf{d}_{\text{power}} = (1,2,-3,0,0,0,0)``$, synthesizing Kirchhoff constraints ($``\mathbf{A}_{\text{cons}}\mathbf{f}=\mathbf{0}``$, $``\mathbf{B}_{\text{cons}}\mathbf{\Delta e}=\mathbf{0}``$).
2. **Non-Conservative Flows ($``\mathcal{F}_{\text{noncons}}``$)**: Flows linking directional ports (`in`, `out`) lacking conjugate pairs evaluate in causal DAG $``\mathcal{G}_{\text{causal}}``$ with broadcast fan-out.
3. **Disjoint Partition & Diagnostics**: Sets must be disjoint ($``\mathcal{F}_{\text{cons}} \cap \mathcal{F}_{\text{noncons}} = \emptyset``$). Incompatible hybrid connections or power invariant violations emit `E0300`. Multiple unarbitrated drivers emit `E0201`.

## 2. Formal Invariant

Disjoint flow partition, conjugate power, and network conservation laws:

```math
\begin{aligned}
\mathcal{F}_{\text{flow}} &= \mathcal{F}_{\text{cons}} \cup \mathcal{F}_{\text{noncons}}, \quad \mathcal{F}_{\text{cons}} \cap \mathcal{F}_{\text{noncons}} = \emptyset \\
\mathbf{d}_e+\mathbf{d}_f &\equiv \mathbf{d}_{\text{power}} = (1,2,-3,0,0,0,0) \in \mathbb{Q}^7 \\
\kappa(f) = \text{FlowClass}_{\text{cons}} &\iff \text{kind}(p_{\text{src}}) = \text{kind}(p_{\text{tgt}}) = \text{PortKind}_{\text{cons}} \wedge (\mathbf{d}_e+\mathbf{d}_f = \mathbf{d}_{\text{power}}) \\
\kappa(f) = \text{FlowClass}_{\text{noncons}} &\iff \text{kind}(p_{\text{src}}) = \text{PortKind}_{\text{out}} \wedge \text{kind}(p_{\text{tgt}}) = \text{PortKind}_{\text{in}} \\
\mathbf{A}_{\text{cons}}\mathbf{f}_{\text{through}} &= \mathbf{0}, \quad \mathbf{B}_{\text{cons}}\mathbf{\Delta e} = \mathbf{0}, \quad \mathbf{A}_{\text{cons}}\mathbf{B}_{\text{cons}}^T = \mathbf{0} \\
\forall f \in \mathcal{F}_{\text{flow}}, \quad &\Delta_f = \text{UUIDv5}(\text{NS}_{\text{DEAP}}, \text{FQN}(f))
\end{aligned}
```

| Symbol / Term | Domain / Formal Definition |
| :--- | :--- |
| $``\mathcal{F}_{\text{flow}}``$ | Universal set of port connections and item flows |
| $``\mathcal{F}_{\text{cons}}, \mathcal{F}_{\text{noncons}}``$ | Disjoint subsets of conservative and non-conservative flows |
| $``\mathbf{d}_e, \mathbf{d}_f, \mathbf{d}_{\text{power}}``$ | Across, Through, and Power $(1,2,-3,0,0,0,0)\in\mathbb{Q}^7$ dimension vectors |
| $\kappa(f)$ | Total classification mapping $f$ to its flow class |
| $``\mathbf{A}_{\text{cons}}, \mathbf{B}_{\text{cons}}``$ | Incidence and fundamental cycle matrices |
| $``\Delta_f``$ | Deterministic RFC 4122 UUIDv5 topological anchor |

## 3. Computational Complexity & Algorithmic Bounds

- **Complexity Class:** Class $\mathbf{P}$ (Deterministic Polynomial Time)
- **Asymptotic Bound:** $``O(N_F + N_V + N_P)``$ where $``N_F = |\mathcal{F}_{\text{flow}}|``$, $``N_V = |\mathcal{V}_{\text{junc}}|``$, $``N_P = |\mathcal{P}_{\text{port}}|``$.
- **Tractable Subclass & Frontier:** Abelian group $(\mathbb{Q}^7, +)$ validates power sums in $O(1)$ per flow, bypassing NP search (NP-6). Graph assembly and sorting run in linear time. Work-stealing scales as $``O((N_F + N_V) / N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Conservative Flow Classification
- **Given:** Acausal ports `Port_1` and `Port_2` linked by `Flow_A` with $``\mathbf{d}_e = (1,-1,-2,0,0,0,0)``$ and $``\mathbf{d}_f = (0,3,-1,0,0,0,0)``$.
- **When:** Lowering validates conjugate dimensions.
- **Then:** $``\mathbf{d}_e + \mathbf{d}_f \equiv \mathbf{d}_{\text{power}}``$ holds and `Flow_A` enters $``\mathcal{F}_{\text{cons}}``$.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: Non-Conservative Signal Flow
- **Given:** Output `Port_1` driving inputs `Port_2`, `Port_3`, `Port_4` with scalar `param_x : Real`.
- **When:** Lowering builds signal routing.
- **Then:** Connections enter $``\mathcal{F}_{\text{noncons}}``$ with unattenuated broadcast.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-03: Incompatible Hybrid Connection Rejection
- **Given:** Direct flow between conservative and non-conservative ports, and flow with $``\mathbf{d}_e+\mathbf{d}_f = (1,1,-2,0,0,0,0) \not\equiv \mathbf{d}_{\text{power}}``$.
- **When:** Lowering checks flow compatibility.
- **Then:** Rejection emits `E0300` and binds sentinel $``\bot_{\text{class}}``$.
- **Diagnostic:** `E0300`.

### AC-04: Multiple Driver Conflict Rejection
- **Given:** Two non-conservative outputs directly driving one input without arbitration.
- **When:** Lowering audits causal dependencies in $``\mathcal{G}_{\text{causal}}``$.
- **Then:** Rejection emits `E0201` for multiple drivers on the receiver port.
- **Diagnostic:** `E0201`.
