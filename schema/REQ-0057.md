## 1. Normative Statement

The semantic metamodel lowering engine shall formalize the foundational KerML classifier hierarchy into a bounded subtyping poset $`(\mathcal{K}, \le)`$ rooted at `Type`. Classifiers shall be partitioned into structural value types (`DataType`) and extensional identity-bearing entities (`Class`, `Structure`) under set-theoretic denotational semantics. The compiler shall enforce the specialization chain: `Structure` specializes `Class`, `Class` specializes `Classifier`, `DataType` specializes `Classifier`, and `Classifier` specializes `Type`.

The compiler shall enforce semantic disjointness: $`⟦ \text{DataType} ⟧ \cap ⟦ \text{Class} ⟧ = \emptyset`$. Multiple inheritance across both `DataType` and `Class` (or `Structure`), or mutable and behavioral features declared in a `DataType`, shall be rejected with diagnostic `E0200`.

The compiler shall evaluate identity duality across all instances:
1. For $`a, b \in ⟦ \text{DataType} ⟧`$, equivalence is structural value congruence ($``a \equiv_{\text{val}} b``$) across all feature projections.
2. For $`u, v \in ⟦ \text{Class} ⟧ \cup ⟦ \text{Structure} ⟧`$, equivalence requires extensional object token identity ($`\text{id}(u) = \text{id}(v)`$), remaining non-identical despite feature value congruence.

The subtyping relation $`(\mathcal{K}, \le)`$ shall be reflexive, transitive, and antisymmetric. Circular inheritance cycles ($``(C, C) \in \mathcal{E}_{\text{gen}}^+``$) shall trigger diagnostic `E0203`. Unresolved supertypes shall trigger `E0200`.

## 2. Formal Invariant

Let $`\mathcal{K}`$ denote the finite set of classifier definition nodes. The foundational taxonomic hierarchy forms a partial order satisfying:

```math
\begin{aligned}
\text{Structure} &\le \text{Class} \le \text{Classifier} \le \text{Type} \\
\text{DataType} &\le \text{Classifier} \le \text{Type}
\end{aligned}
```

Denotational semantics maps each classifier $`C`$ to an instance set $`⟦ C ⟧`$, where specialization denotes subset inclusion:

```math
C_1 \le C_2 \iff ⟦ C_1 ⟧ \subseteq ⟦ C_2 ⟧
```

Disjointness between value types and identity-bearing entities is invariant:

```math
⟦ \text{DataType} ⟧ \cap ⟦ \text{Class} ⟧ = \emptyset, \quad ⟦ \text{DataType} ⟧ \cap ⟦ \text{Structure} ⟧ = \emptyset
```

Identity duality is governed by structural congruence and token identity:

```math
\begin{aligned}
a, b \in ⟦ \text{DataType} ⟧ &\implies \left( a \equiv_{\text{val}} b \iff \forall f \in \mathcal{F}_{\tau(a)}, \, \pi_f(a) \equiv_{\text{val}} \pi_f(b) \right) \\
u, v \in ⟦ \text{Class} ⟧ \cup ⟦ \text{Structure} ⟧ &\implies \left( u = v \iff \text{id}(u) = \text{id}(v) \right)
\end{aligned}
```

DataType feature immutability and acyclicity invariants:

```math
\forall C \in \mathcal{K}, \quad C \le \text{DataType} \implies \forall f \in \mathcal{F}_C, \, (\text{is\_read\_only}(f) \equiv \text{true} \;\wedge\; \text{is\_behavioral}(f) \equiv \text{false})
```

```math
\forall C \in \mathcal{K}, \quad (C, C) \notin \mathcal{E}_{\text{gen}}^+
```

Deterministic RFC 4122 UUIDv5 topological anchoring satisfies:

```math
\forall C \in \mathcal{K}, \quad \Delta_C = \text{UUIDv5}(\text{NS}_{\text{DEAP}}, \text{FQN}(C))
```

## 3. Computational Complexity & Algorithmic Bounds

Core classifier lowering, subtyping verification, and cycle detection execute within Complexity Class $`\mathbf{P}`$. For $`V = |\mathcal{K}|`$ classifiers and $``E = |\mathcal{E}_{\text{gen}}|``$ generalization edges:
- Arena node allocation and symbol interning take amortized $`O(1)`$ time per classifier, giving $`O(V)`$ initialization.
- Acyclicity validation via Tarjan's SCC algorithm executes in deterministic $`O(V + E)`$ time and $`O(V)`$ space.
- Single-inheritance subtyping queries execute in $`O(1)`$ time via precomputed interval containment timestamps ($``l_{C_2} \le l_{C_1} \wedge r_{C_1} \le r_{C_2}``$).
- Multiple-inheritance reachability queries execute in $`O(V + E)`$ time, or $`O(1)`$ query time following $`O(V(V + E))`$ transitive closure bitset precomputation.

This grounds the tractable subclass of NP-3 (Subtyping Lattice & C3 Linearization), where subtyping over the monotonic meet-semilattice is resolved in deterministic $`O(V + E)`$ time without backtracking.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Foundational Taxonomic Subtyping Hierarchy

- **Given:** Metamodel definitions `Structure_Omega :> Class_Zeta :> Classifier_Alpha :> Type_0` and `DataType_Delta :> Classifier_Alpha`.
- **When:** Subtyping poset $`(\mathcal{K}, \le)`$ construction executes.
- **Then:** $``\text{Structure\_Omega} \le \text{Type\_0}``$ and $``\text{DataType\_Delta} \le \text{Type\_0}``$ evaluate to `true`; $``\text{Structure\_Omega} \le \text{DataType\_Delta}``$ evaluates to `false`; zero diagnostics emitted.
- **Diagnostic:** `E0200` emitted on invalid subtyping resolution.

### AC-02: Disjoint Classifier Specialization Enforcement

- **Given:** Classifier `Classifier_Invalid` declaring multiple inheritance over both `DataType_Delta` and `Class_Zeta`.
- **When:** Metamodel lowering verifies classifier disjointness $`⟦ \text{DataType} ⟧ \cap ⟦ \text{Class} ⟧ = \emptyset`$.
- **Then:** The compiler rejects the declaration, binds error sentinel $``\bot_{\text{classifier}}``$, and emits diagnostic `E0200`.
- **Diagnostic:** `E0200` emitted on disjoint classifier specialization violation.

### AC-03: Identity Duality Value Congruence vs. Object Identity

- **Given:** Instances $``a, b \in ⟦ \text{DataType\_Delta} ⟧``$ with identical feature values (`param_x = 42.0`), and instances $``u, v \in ⟦ \text{Class\_Zeta} ⟧``$ with identical values (`param_x = 42.0`) but distinct handles ($`\text{id}(u) \neq \text{id}(v)`$).
- **When:** Equivalence evaluation executes on pairs $`(a, b)`$ and $`(u, v)`$.
- **Then:** Value congruence yields $``a \equiv_{\text{val}} b = \text{true}``$; object identity yields $`u = v \equiv \text{false}`$.
- **Diagnostic:** `E0200` emitted on identity evaluation violation.

### AC-04: DataType Feature Immutability Enforcement

- **Given:** Declaration `DataType_Delta` containing a mutable feature or behavioral action lifecycle hook.
- **When:** Metamodel semantic checking inspects feature constraints.
- **Then:** The compiler rejects mutable or behavioral feature declarations in `DataType_Delta`, emitting diagnostic `E0200`.
- **Diagnostic:** `E0200` emitted on mutable feature declaration within a `DataType`.
