## 1. Normative Statement

The lowering engine SHALL formalize SysML v2 calculation definitions (`calc def`, `CalculationDefinition`) as functional classifiers specializing KerML `Function`, and calculation usages (`calc`, `CalculationUsage`) as steps specializing KerML `Step`.

The compiler MUST enforce five core invariants:
1. **Referential Transparency**: Calculations evaluate as pure functions ($y = f(\mathbf{x})$) without state mutation ($\Delta \text{State} \equiv \emptyset$). Any mutating syntax--including feature assignments or impure calls--emits diagnostic `E0200`.
2. **Parameter Directionality**: Input parameters declare $\text{dir}(p) = \text{In}$. Mutating modes (`InOut`, mutable `Out`) emit `E0201`. Exactly one return parameter ($``p_D^{\text{ret}}``$) of type $``T_{\text{out}}``$ SHALL be declared.
3. **Usage Typing**: Usages MUST type to functional classifiers ($\tau(u) \le \text{Function}$); non-functional types emit `E0200`. Bound arguments MUST satisfy covariant subtyping ($``\tau(a_i) \le \tau(p_i)``$); mismatches emit `E0200`. Missing mandatory parameters emit `E0200`.
4. **Multiplicity Bounds**: Multiplicity intervals $``\mu(u) = [m_{\min}, m_{\max}]``$ MUST satisfy $``0 \le m_{\min} \le m_{\max}``$; inverted intervals emit `E0200`.
5. **Dependency Acyclicity**: Calculation dependency graph $``G_{\text{calc}} = (V_{\text{calc}}, E_{\text{calc}})``$ MUST be a DAG; cycles ($``u \to_{\text{calc}}^+ u``$) emit `E0203`.

## 3. Computational Complexity & Algorithmic Bounds

Calculation lowering, typing, and dependency analysis execute strictly within Complexity Class $\mathbf{P}$.

For $``V = |\mathcal{C}_{\text{calc}}| + |\mathcal{U}_{\text{calc}}|``$ nodes and $``E = |E_{\text{calc}}|``$ dependency edges:
- Node allocation and symbol interning execute in amortized $O(1)$ time per node ($O(V)$).
- Parameter directionality and covariant subtyping evaluate in $O(1)$ checks via precomputed bitsets (tractable fragment of NP-3).
- Purity AST inspection traverses expression trees in linear time $O(V)$.
- Dependency acyclicity and evaluation ordering evaluate in $O(V + E)$ time using Tarjan's SCC or Kahn's algorithm.
- Multiplicity interval validation executes in $O(1)$ scalar checks ($O(V)$).

Total sequential complexity is $O(V + E)$. Parallel package lowering scales as $``O((V + E) / N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$. While equational constraint solving is NP-complete (NP-4 in REQ-0083), functional calculation DAG evaluation remains strictly polynomial.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Canonical Calculation Lowering
- **Given:** Valid `calc def CalcDef_Alpha(in Param_X : Real) : Real` and usage `calc Calc_1 : CalcDef_Alpha(Param_X = 1.0)`.
- **When:** Calculation lowering constructs the functional AST.
- **Then:** Nodes lower into arena storage specializing KerML `Function` and `Step` with zero diagnostics.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: Mutating Parameter Directionality Rejection
- **Given:** `calc def CalcDef_Impure(inout Param_M : Real) : Real`.
- **When:** Parameter directionality validation evaluates declared parameters.
- **Then:** Compiler rejects the declaration with sentinel $``\bot_{\text{calc}}``$ and emits diagnostic `E0201`.
- **Diagnostic:** `E0201` (Parameter directionality violation).

### AC-03: Covariant Argument Subtyping and Classifier Conformance
- **Given:** Usage `calc Calc_Err : CalcDef_Alpha(Param_X = "str")` or typed by structural `PartDef_Alpha`.
- **When:** Feature typing and argument subtyping execute.
- **Then:** Compiler rejects invalid typing with precise source spans and emits diagnostic `E0200`.
- **Diagnostic:** `E0200` (Argument type mismatch or non-functional classifier).

### AC-04: Static Circular Calculation Dependency Detection
- **Given:** Calculation usages inducing static cycle `Calc_1 -> Calc_2 -> Calc_1` in dependency graph $``G_{\text{calc}}``$.
- **When:** Topological acyclicity analysis executes via Tarjan's SCC algorithm.
- **Then:** Compiler isolates the cycle, halts recursive evaluation, and emits diagnostic `E0203`.
- **Diagnostic:** `E0203` (Circular calculation dependency).
