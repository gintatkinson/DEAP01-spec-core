## 1. Normative Statement

The safety compiler SHALL extract and validate a Hierarchical Control Structure (HCS) topology from the AST, partitioning entities into disjoint sets: controllers ($C$), actuators ($E$), processes ($P$), and sensors ($O$).

Lowering MUST enforce five topological invariants:
1. **Role Disjointness**: Controllers and processes SHALL be distinct per loop ($c \ne p$); interfaces disjoint ($E \cap O = \emptyset$). Conflicts emit `E0400`.
2. **Directed Flows**: Control actions bind $u=(c,e,p)\in\mathcal{U}$; feedbacks bind $y=(p,o,c)\in\mathcal{Y}$. Ports MUST follow directionality (`out` $\to$ `in` $\to$ `out` $\to$ `in`). Inversions or dangling interfaces emit `E0412`.
3. **Supervisory Stratification**: Levels $``\ell : C \cup P \to \mathbb{N}_0``$ assign base plants $\ell(p) = 0$ and supervisory flows $\ell(c) \gt \ell(x)$. Graphs MUST be acyclic DAGs; cycles emit `E0400`.
4. **Closed-Loop Observability**: Flows $(c, e, p) \in \mathcal{U}$ MUST pair with feedback $(p, o, c) \in \mathcal{Y}$ unless annotated `@open_loop`; omissions emit `E0400`.
5. **Process Model**: Controllers issuing actions MUST bind a process model ($``\mathcal{M}_{\text{proc}}(c)`` \in \mathcal{V}_{\text{AST}}``$); missing models emit `E0400`.

## 2. Formal Invariant

The HCS topology $``\text{HCS} = \langle C, E, P, O, \mathcal{U}, \mathcal{Y}, \ell, \mathcal{M}_{\text{proc}} \rangle``$ satisfies:

```math
\begin{aligned}
E\cap O=\emptyset,\quad \forall(c,e,p)\in\mathcal{U},\; c\ne p,\quad \forall(p,o,c)\in\mathcal{Y},\; c\ne p \\
\forall(c,e,p)\in\mathcal{U},\; (\exists(p',o,c')\in\mathcal{Y} : p'=p \land c'=c) \lor \text{IsOpenLoop}(c,p) \\
\forall c\in C,\; \mathcal{M}_{\text{proc}}(c)\ne\bot \land \neg(c\prec_{\text{sup}}^+ c) \\
\forall p\in P_{\text{base}},\; \ell(p)=0 \land \forall(c\prec_{\text{sup}} x),\; \ell(c)\gt\ell(x) \\
\forall v\in C\cup E\cup P\cup O,\; \Delta(v)=\text{UUIDv5}(\text{NS}_{\text{DEAP}},\text{FQN}(v)) \\
\forall u=(c,e,p)\in\mathcal{U},\; \Delta(u)=\text{UUIDv5}(\text{NS}_{\text{DEAP}},\text{FQN}(c)\mathbin{\Vert}\text{FQN}(e)\mathbin{\Vert}\text{FQN}(p))
\end{aligned}
```

| Symbol / Term | Domain / Formal Definition |
| :--- | :--- |
| $C, P, E, O$ | Controllers, processes, actuators, and sensors |
| $\mathcal{U}, \mathcal{Y}$ | Control actions ($C\times E\times P$) and feedbacks ($P\times O\times C$) |
| $``\ell, \prec_{\text{sup}}``$ | Supervisory level and DAG precedence |
| $``\mathcal{M}_{\text{proc}}(c)``, \text{IsOpenLoop}``$ | Bound process model and `@open_loop` flag |
| $\Delta(x), \text{FQN}(x)$ | Deterministic UUIDv5 and topological path |
| $``\bot_{\text{ctrl}}``, ``\bot_{\text{proc}}``, ``\bot_{\text{flow}}``$ | Typed error recovery sentinels |

## 3. Computational Complexity & Algorithmic Bounds

- **Complexity Class:** $\mathbf{P}$
- **Asymptotic Bound:** $``O(|N_{\text{ast}}|)``$ for $``|N_{\text{ast}}| = |V_{\text{AST}}| + |E_{\text{AST}}|``$. Traversal, matching, and topological sorting run in linear time.
- **Tractable Subclass & Frontier:** Avoids NP-complete STPA cut-set search (NP-4). Work-stealing scales as $``O(|N_{\text{ast}}| / N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Canonical Closed-Loop Extraction
- **Given:** `Package_0` with `Controller_Alpha`, `Process_Beta`, `ControlAction_0`, and `FeedbackChannel_1`.
- **When:** AST topology extraction executes.
- **Then:** Lowers 8-tuple HCS with valid port directions and feedback loop.
- **Diagnostic:** Diagnostic sink empty.

### AC-02: Multi-Level Supervisory Stratification
- **Given:** `Controller_Alpha` supervising `Controller_Beta`, commanding `Process_Beta`.
- **When:** Supervisory level stratification executes.
- **Then:** Assigns levels $\ell = 0, 1, 2$, verifying DAG acyclicity.
- **Diagnostic:** Diagnostic sink empty.

### AC-03: Unobservable Loop Rejection
- **Given:** `ControlAction_0` lacking feedback without `@open_loop`, or unbound controller.
- **When:** Observability and process model checks execute.
- **Then:** Emits `E0400` and binds sentinel $``\bot_{\text{ctrl}}``$.
- **Diagnostic:** `E0400`.

### AC-04: Port Inversion & Interface Violations
- **Given:** Inverted port directions or dangling interface handles delimited by `;`.
- **When:** Directionality and interface binding passes execute.
- **Then:** Emits `E0412`, resynchronizes on `;`, emitting `E0199` at $``C_{\text{max\_errors}}``$.
- **Diagnostic:** `E0412`, `E0199`.
