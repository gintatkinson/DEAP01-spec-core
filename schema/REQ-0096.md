## 1. Normative Statement

The compiler SHALL bootstrap `Package_ISQBase` and `Package_ISQ` into root scope at initialization.

Metamodel lowering MUST enforce:
1. **Base Dimensions**: `Package_ISQBase` defines base dimensions ($M, L, T, I, \Theta, N, J$) spanning $(\mathbb{Z}^7,+,-,\mathbf{0})$.
2. **Canonical Basis**: Base dimensions map bijectively to basis vectors $``\mathbf{e}_1 \dots \mathbf{e}_7 \in \mathbb{Z}^7``$; dimensionless quantities map to $\mathbf{0}$.
3. **Derived Spaces**: `Package_ISQ` defines derived dimensions $``\mathbf{d} = \sum_{i=1}^7 c_i \mathbf{e}_i``$ (Force $``\mathbf{e}_M+\mathbf{e}_L-2\mathbf{e}_T``$).
4. **Algebra**: Operations satisfy $``\mathbf{d}(Q_1 \cdot Q_2) = \mathbf{d}(Q_1) + \mathbf{d}(Q_2)``$, $``\mathbf{d}(Q_1 / Q_2) = \mathbf{d}(Q_1) - \mathbf{d}(Q_2)``$, $\mathbf{d}(Q^k) = k \cdot \mathbf{d}(Q)$.
5. **Homogeneity**: Operations ($A \pm B$, $A == B$) require $\mathbf{d}(A) = \mathbf{d}(B)$; mismatches emit `E0300`.
6. **Integrity**: Scope mutations emit `E0200`; derivation cycles in $``\mathcal{G}_{\text{dim\_dep}}``$ emit `E0203`; exponents outside $[-128, 127]$ emit `E0200`.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Canonical Library Bootstrapping
- **Given:** Initialized compiler runtime.
- **When:** Bootstrapping `Package_ISQBase` and `Package_ISQ`.
- **Then:** 7 base dimensions map to $``\mathbf{e}_1 \dots \mathbf{e}_7``$, derived dimensions register coordinates, and nodes bind deterministic UUIDv5 IDs.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: Dimensional Vector Arithmetic and Inference
- **Given:** Quantities `Quantity_A` (Force) and `Quantity_B` (Length).
- **When:** Lowering `Quantity_A * Quantity_B`, `Quantity_A / Quantity_B`, `Quantity_B^2`.
- **Then:** Product infers Energy in $O(1)$, quotient infers $(1,0,-2,0,0,0,0)$, and power infers Area.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-03: Static Dimensional Homogeneity Rejection
- **Given:** Expression `Quantity_A + Quantity_B` with mismatched dimensions ($``\mathbf{d}(Q_A) \ne \mathbf{d}(Q_B)``$).
- **When:** Dimensional type checking executes.
- **Then:** Rejection emits `E0300` and binds sentinel $``\bot_{\text{dim}}``$ to continue processing.
- **Diagnostic:** `E0300` (DimensionalMismatch).

### AC-04: Cyclic Derivation, Immutability, and Exponent Range Rejection
- **Given:** Cyclic derivation `Dimension_Alpha :> Dimension_Beta` or mutation in `Package_ISQBase`.
- **When:** Semantic validation and cycle detection run.
- **Then:** Cycle emits `E0203`, mutation emits `E0200`, and recovery halts at $``C_{\text{max\_errors}}``$ with `E0199`.
- **Diagnostic:** `E0203`, `E0200`, or `E0199`.
