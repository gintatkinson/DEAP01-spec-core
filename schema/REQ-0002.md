## 1. Normative Statement

The compiler platform shall enforce a strict, surjective lexical provenance gate across all synthesized abstract syntax tree (AST) elements. Every generated classifier, feature usage, port, connector, attribute, constraint, behavior, action, and state identifier shall establish a verifiable derivation link back to either a corresponding AST node within parsed schema source files or a deterministic synthetic topological parent anchor. Generation of ungrounded, fabricated, or hallucinated structural entities is strictly prohibited across all lowering, transformation, optimization, and code generation passes.

Each synthesized AST node must maintain an immutable provenance descriptor recording:
1. Originating source file identifier,
2. Physical source byte span ($`\text{ByteStart}`$ and $`\text{ByteEnd}`$ offsets),
3. Line and column coordinates, and
4. Parent AST node handle.

When intermediate scaffolding nodes (such as implicit root namespaces or structural containment boundaries) are synthetically generated, the compiler shall derive their provenance anchors deterministically via RFC 4122 UUIDv5 hashing seeded by a fixed namespace OID and the node fully qualified topological path.

The compiler shall verify surjective range completeness across all parsed schema source nodes, ensuring that zero user-defined structural entities are omitted during lowering. The provenance gate must execute as a mandatory verification pass immediately following schema ingestion and AST construction, failing closed upon any provenance violation.

## 2. Formal Invariant

Let $`\mathcal{A}`$ denote the synthesized AST with node set $`\text{Nodes}(\mathcal{A})`$, and $`\mathcal{S}`$ denote parsed schema source files with source node set $`\text{ASTNodes}(\mathcal{S})`$. Let $`\text{TopologicalAnchors}(\mathcal{S})`$ denote deterministic synthetic anchor nodes generated for intermediate scaffolding, and $``\text{OID}_{\text{DEAP}}``$ denote the fixed RFC 4122 namespace UUID.

For any canonical topological path $`p \in \text{TopologicalPaths}(\mathcal{S})`$, its deterministic anchor identifier is:

```math
\text{Anchor}(p) = \text{UUIDv5}(\text{OID}_{\text{DEAP}}, p)
```

The target provenance domain $``\mathcal{P}_{\text{domain}}``$ and total provenance derivation mapping $`\Pi`$ satisfy:

```math
\begin{aligned}
\mathcal{P}_{\text{domain}} &= \text{ASTNodes}(\mathcal{S}) \cup \text{TopologicalAnchors}(\mathcal{S}) \\
\Pi &: \text{Nodes}(\mathcal{A}) \longrightarrow \mathcal{P}_{\text{domain}}
\end{aligned}
```

Positive AST Provenance and Surjective Range Completeness Invariants:

```math
\begin{aligned}
\forall n \in \text{Nodes}(\mathcal{A}), \quad &\Pi(n) \ne \bot \quad \wedge \quad \Pi(n) \in \mathcal{P}_{\text{domain}} \\
\forall s \in \text{ASTNodes}(\mathcal{S}), \quad &\exists n \in \text{Nodes}(\mathcal{A}) \quad \text{such that} \quad \Pi(n) = s \implies \text{Range}(\Pi) \supseteq \text{ASTNodes}(\mathcal{S})
\end{aligned}
```

Source Byte Span Validity and Zero Ungrounded Hallucination Invariants:

```math
\begin{aligned}
0 &\le \text{ByteStart}(s) \lt \text{ByteEnd}(s) \le \text{Length}(\mathcal{B}(\text{FileID}(s))) \\
\text{Ungrounded}(\mathcal{A}) &= \{ n \in \text{Nodes}(\mathcal{A}) \mid \Pi(n) \notin \mathcal{P}_{\text{domain}} \lor \Pi(n) = \bot \} = \emptyset
\end{aligned}
```

## 3. Computational Complexity & Algorithmic Bounds

The surjective lexical provenance verification pipeline executes within Complexity Class $`\mathbf{P}`$. During schema parsing and lexical ingestion, source byte span capture and initial node registration operate in $`O(1)`$ amortized time per token, bounded by $`O(N)`$ for total input token count $`N = |\text{Tokens}(\mathcal{S})|`$.

Synthetic topological anchor generation via RFC 4122 UUIDv5 path hashing operates in $`O(V + E)`$ where $`V = |\text{Nodes}(\mathcal{A})|`$ and $`E = |\text{Edges}(\mathcal{A})|`$. Positive provenance verification traversing $`\text{Nodes}(\mathcal{A})`$ executes in deterministic linear time $`O(V)`$ via direct handle and table lookups. Surjective range completeness verification across all parsed schema nodes executes in $`O(V + |\text{ASTNodes}(\mathcal{S})|)`$ using a dense index coverage table or bitset tracking array.

Auxiliary memory consumption is strictly bounded by $`O(V + |\text{ASTNodes}(\mathcal{S})|)`$ for storing provenance mapping descriptors and source span coordinate tables. Unlike NP-complete scheduling or invariant satisfiability problems (e.g., NP-1 temporal consistency or NP-3 subtyping lattices), lexical provenance verification is strictly polynomial and free of combinatorial backtracking.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Positive Schema Node Provenance & Byte Span Verification
- **Given:** A valid input schema parsed into schema nodes $`\text{ASTNodes}(\mathcal{S})`$ containing classifier `Classifier_Alpha` and port `Port_1`.
- **When:** The compiler executes the lexical provenance gate on synthesized AST $`\mathcal{A}`$.
- **Then:** Every lowered node corresponding to `Classifier_Alpha` and `Port_1` resolves to non-null provenance $`\Pi(n) \in \text{ASTNodes}(\mathcal{S})`$ with valid source byte span coordinates satisfying $`0 \le \text{ByteStart} \lt \text{ByteEnd} \le \text{Length}(\mathcal{B})`$.
- **Diagnostic:** Diagnostic `E0100` emitted if provenance pointer is null or byte span coordinates exceed buffer bounds.

### AC-02: Deterministic Synthetic Topological Anchor Provenance
- **Given:** An intermediate structural scaffolding node (e.g., root namespace `Package_0`) synthetically generated without a direct source token.
- **When:** The compiler lowers `Package_0` and evaluates its provenance anchor.
- **Then:** Its provenance descriptor binds to a deterministic RFC 4122 UUIDv5 anchor derived from $``\text{OID}_{\text{DEAP}}``$ and canonical topological path `Package_0`, satisfying $`\Pi(n) \in \text{TopologicalAnchors}(\mathcal{S})`$.
- **Diagnostic:** Diagnostic `E0100` emitted if synthetic anchor fails to match deterministic RFC 4122 UUIDv5 path hash.

### AC-03: Surjective Lexical Range Completeness Enforcement
- **Given:** An input schema source containing a declared attribute `param_x : Real` in $`\text{ASTNodes}(\mathcal{S})`$, but where an erroneous lowering pass drops the attribute from synthesized AST $`\mathcal{A}`$.
- **When:** The provenance gate verifies range completeness $`\text{Range}(\Pi) \supseteq \text{ASTNodes}(\mathcal{S})`$.
- **Then:** The compiler detects the unmapped source node in $`\text{ASTNodes}(\mathcal{S})`$, halts compilation immediately, and refuses downstream code generation.
- **Diagnostic:** Diagnostic `E0100` emitted with source file identifier, line, column, and token byte span of `param_x`.

### AC-04: Rejection of Hallucinated or Ungrounded AST Nodes
- **Given:** A synthesized AST $`\mathcal{A}`$ containing an ungrounded node `Classifier_Beta` inserted without a corresponding entry in $`\text{ASTNodes}(\mathcal{S})`$ and without a valid RFC 4122 UUIDv5 topological anchor.
- **When:** The provenance gate traverses $`\text{Nodes}(\mathcal{A})`$ and checks $`\Pi(n)`$.
- **Then:** The compiler detects $`\Pi(n) = \bot`$, halts compilation in a fail-closed manner, and emits a structured error.
- **Diagnostic:** Diagnostic `E0100` emitted with offending AST node identifier and error message detailing lack of lexical provenance.
