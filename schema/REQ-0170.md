## 1. Normative Statement

Subsystem 9 SHALL project Engineering Tasks from AST definitions into a Work Breakdown Structure (WBS) rooted at `WBS_0`.

---

## 2. Formal Invariant

Engineering task projections satisfy:

```math
\begin{aligned}
\forall t\in\mathcal{T}_{\text{tasks}},&\quad t=\langle\text{id}_t,\text{name}_t,\text{parent}_t,\text{wbs}_t,\mathbf{C}_{\text{DoD}}(t),h_t,\Delta_t\rangle \\
\forall t\in\mathcal{T}_{\text{tasks}},&\quad\text{parent}_t\in(\mathcal{T}_{\text{tasks}}\cup\mathcal{F}_{\text{proj}})\land\mathbf{C}_{\text{DoD}}(t)\ne\emptyset\land h_t\gt 0 \\
\forall t\in\mathcal{T}_{\text{tasks}},&\quad\text{Children}(t)\ne\emptyset\implies h_t=\sum_{c\in\text{Children}(t)} h_c \\
\forall c\in\mathbf{C}_{\text{DoD}}(t),&\quad\neg\text{ContainsPlaceholder}(c) \\
(\text{parent}_t\notin(\mathcal{T}_{\text{tasks}}\cup\mathcal{F}_{\text{proj}})\lor\text{IsCycle}(t))&\implies\text{Diagnostic}(t,\text{E0300})\in\mathcal{D}_{\text{sink}}\land t\gets\bot_{\text{task}} \\
(\mathbf{C}_{\text{DoD}}(t)=\emptyset\lor\text{ContainsPlaceholder}(t))&\implies\text{Diagnostic}(t,\text{E0312})\in\mathcal{D}_{\text{sink}}\land t\gets\bot_{\text{task}} \\
(h_t\le 0\lor(\text{Children}(t)\ne\emptyset\land h_t\ne\sum_c h_c))&\implies\text{Diagnostic}(t,\text{E0312})\in\mathcal{D}_{\text{sink}}\land t\gets\bot_{\text{task}} \\
|\mathcal{D}_{\text{sink}}| \ge C_{\text{max\_errors}}&\implies\text{Diagnostic}(\text{E0199})\in\mathcal{D}_{\text{sink}},\quad\Delta_t=\text{UUIDv5}(\text{OID}_{\text{DEAP}},\text{FQN}(t))
\end{aligned}
```

| Symbol / Term | Domain / Formal Definition |
| :--- | :--- |
| $``\mathcal{T}_{\text{tasks}}, t, \text{wbs}_t``$ | Tasks set, task tuple, and WBS code |
| $``\mathbf{C}_{\text{DoD}}(t), h_t``$ | DoD criteria and effort hours ($\mathbb{R}^+$) |
| $``\text{Children}(t), \bot_{\text{task}}``$ | Child sub-tasks and recovery sentinel |
| $``\mathcal{D}_{\text{sink}}, C_{\text{max\_errors}}``$ | Diagnostic sink and error limit |
| $``\Delta_t, \text{OID}_{\text{DEAP}}``$ | UUIDv5 anchor and namespace OID |

## 3. Computational Complexity & Algorithmic Bounds

- **Complexity Class:** Class $\mathbf{P}$ (Deterministic Polynomial Time).
- **Asymptotic Bound:** $O(|T|)$ task decomposition ($``|T| = |\mathcal{T}_{\text{tasks}}|``$). Bottom-up effort aggregation and DoD validation run in $O(1)$ time per node ($O(|T|)$ total). Arena: $O(|T|)$. Work-stealing: $``O(|T| / N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$.
- **Tractable Subclass and Frontier:** N/A (Deterministic P). Linear tree decomposition bypasses NP-2 bin packing (REQ-0147) and NP-4 hitting sets (REQ-0135).

---

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Canonical WBS Task Hierarchy and Effort Projection
- **Given:** Feature `Feature_0` task `Task_0` containing leaves `Task_Alpha` ($h = 8.0$) and `Task_Beta` ($h = 16.0$) with `DoD_Criteria_0`.
- **When:** Lowering tasks and synthesizing WBS hierarchy.
- **Then:** Projects `WBS_0` with effort $``h_{\text{Task\_0}} = 24.0``$.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: Boundary Leaf Task Allocation and Minimum Effort
- **Given:** Leaf `Task_Alpha` with minimum effort $h = 0.5$ and criterion `DoD_Criteria_0`.
- **When:** Validating effort boundaries and DoD completeness.
- **Then:** Confirms $h \gt 0$, validates DoD satisfaction, and lowers task.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-03: Definition of Done Violation and Placeholder Rejection
- **Given:** Task `Task_Alpha` with empty DoD or placeholder `"TODO"`.
- **When:** Validating Definition of Done completeness.
- **Then:** Fails closed, emits `E0312`, and binds sentinel $``\bot_{\text{task}}``$.
- **Diagnostic:** `E0312` (TaskDefinitionOfDoneViolation).

### AC-04: Hierarchy Disconnect and Delimiter Recovery
- **Given:** Composite `Task_0` with effort mismatch ($h = 30.0 \ne 24.0$), child referencing `Task_Missing`, delimiter `;`, and valid `Task_Beta`.
- **When:** Recovering across delimiters on invalid tasks.
- **Then:** Emits `E0300` and `E0312`, binds sentinels $``\bot_{\text{task}}``$, recovers across `;`, parses `Task_Beta`, halting at $``C_{\text{max\_errors}}``$ with `E0199`.
- **Diagnostic:** `E0300`, `E0312`, `E0199`.
