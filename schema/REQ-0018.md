## 1. Normative Statement

The CommonMark table parser within the Universal Schema Ingestion Engine shall preserve multi-line cell content, nested bullet points, list items, and inline code spans within table cells without dropping formatting, truncating text, or losing structural hierarchy. The engine must normalize embedded HTML line break variants (`<br>`, `<br/>`, `<br />`, `<BR>`, `<BR/>`, `<BR />`) and escaped linefeeds (`\n`, `\r\n`) into canonical newline block tokens ($``\text{SYM}_{\text{LF}}``$) via deterministic byte prefix scanning strictly without regular expressions and backtracking. Inline code spans delimited by backticks shall be preserved verbatim without break normalization, delimiter splitting, or escape expansion.

Nested list items within cells shall parse into structured sub-item tokens, mapping indentation to bullet depths bounded by $``D_{\text{max\_bullet}} \le 8``$ and preserving list marker types (hyphens, asterisks, plus signs, numeric sequences). The normalizer shall operate with zero dynamic buffer reallocations, projecting token spans directly from input buffers.

On malformed cells--including unclosed code spans at delimiter pipes (`|`), illegal ASCII control bytes ($`b \lt 32, b \notin \{9, 10, 13\}`$), or bullet depths exceeding $``D_{\text{max\_bullet}}``$--the engine shall emit diagnostic `E0100` or `E0102` per REQ-0191 with coordinates $``[p_{\text{start}}, p_{\text{end}}]``$., the engine shall insert error sentinel $``\bot_{\text{block}}``$, retain preceding valid tokens, and resynchronize at the nearest pipe (`|`) or record break without aborting. The normalizer shall enforce a total, non-panicking execution contract. Latency and memory gates shall be verified.

## 2. Formal Invariant

Let $``C_{\text{raw}} = \langle b_0, b_1, \dots, b_{N-1} \rangle``$ denote the raw byte stream of a table cell, where $``b_i \in \Sigma = \{ b \in \mathbb{N}_0 \mid 0 \le b \le 255 \}``$ and $``N = |C_{\text{raw}}|``$. The deterministic block normalizer $``\Phi_{\text{block}}``$ maps $``C_{\text{raw}}``$ to an ordered sequence of structured block tokens:

```math
\Phi_{\text{block}} : \Sigma^* \longrightarrow \mathcal{T}_{\text{block}}^*, \quad \mathcal{T}_{\text{block}} = \{ \text{TextRun}(s), \text{LineBreak}(\text{SYM}_{\text{LF}}), \text{ListItem}(d, m, s), \text{CodeSpan}(s), \bot_{\text{block}} \}
```

where $``d \in \{1, \dots, D_{\text{max\_bullet}}\}``$ represents bullet depth, $`m \in \{ \text{Unordered}, \text{Ordered}(k) \}`$ is the marker kind, and $`s`$ is the token byte slice.

Let $``\mathcal{P}_{\text{break}}``$ denote the prefix byte sequence set for line break variants:

```math
\mathcal{P}_{\text{break}} = \{ \langle \text{0x3C}, \text{0x62}, \text{0x72}, \text{0x3E} \rangle, \langle \text{0x3C}, \text{0x62}, \text{0x72}, \text{0x2F}, \text{0x3E} \rangle, \langle \text{0x3C}, \text{0x62}, \text{0x72}, \text{0x20}, \text{0x2F}, \text{0x3E} \rangle, \langle \text{0x5C}, \text{0x6E} \rangle, \langle \text{0x5C}, \text{0x72}, \text{0x5C}, \text{0x6E} \rangle \}
```

The deterministic break detection operator $``\text{MatchBreak}(C_{\text{raw}}, p)``$ evaluates at byte offset $`p`$:

```math
\text{MatchBreak}(C_{\text{raw}}, p) = 
\begin{cases}
\pi, & \text{if } \exists \pi \in \mathcal{P}_{\text{break}} \text{ such that } \forall k \in \{0, \dots, |\pi|-1\}, \, C_{\text{raw}}[p+k] = \pi[k] \\
\emptyset, & \text{otherwise}
\end{cases}
```

Within an active backtick code span interval $``[p_{\text{open}}, p_{\text{close}}]``$, break matching is strictly suppressed:

```math
\forall p \in [p_{\text{open}}, p_{\text{close}}], \quad \text{MatchBreak}(C_{\text{raw}}, p) \implies \text{Suppressed}
```

```math
\text{Slice}(\text{CodeSpan}(s)) = \langle C_{\text{raw}}[p_{\text{open}} + 1], \dots, C_{\text{raw}}[p_{\text{close}} - 1] \rangle
```

In line-leading state, leading whitespace byte count $``S \in \mathbb{N}_0``$ determines bullet nesting depth $`d`$:

```math
d = \min \left( \left\lfloor \frac{S}{2} \right\rfloor + 1, \; D_{\text{max\_bullet}} \right)
```

The normalizer enforces the Zero Regex, Zero Backtracking, and Monotonic Progress Invariants:

```math
\begin{aligned}
\text{RegexEvaluations}(\Phi_{\text{block}}) &= 0 \\
\text{BacktrackCount}(\Phi_{\text{block}}) &= 0 \\
\forall t \in \mathbb{N}_0, \quad \text{pos}_{t+1} &\gt \text{pos}_t
\end{aligned}
```

Bijective Round-Trip Equivalence and Diagnostic Containment Invariants: Let $``\Psi_{\text{emit}} : \mathcal{T}_{\text{block}}^* \to \Sigma^*``$ map $``\text{LineBreak}(\text{SYM}_{\text{LF}})``$ to literal `"<br>"`. For all well-formed token sequences $``\mathcal{T} = \Phi_{\text{block}}(C_{\text{raw}})``$:

```math
\Phi_{\text{block}}(\Psi_{\text{emit}}(\mathcal{T})) \equiv \mathcal{T} \quad \wedge \quad \forall D \in \mathcal{D}_{\text{cell}}, \; \text{Code}(D) \in \{ \text{E0100}, \text{E0102} \}
```

## 3. Computational Complexity & Algorithmic Bounds

The table cell block token normalization pipeline operates strictly within Complexity Class $`\mathbf{P}`$. Deterministic prefix pattern matching against finite set $``\mathcal{P}_{\text{break}}``$ evaluates at most $``L_{\text{max}} = 6``$ bytes per position in $`O(1)`$ time. Monotonic forward stream traversal guarantees each byte in $``C_{\text{raw}}``$ is visited once, establishing a strict $`O(N)`$ time bound for $``N = |C_{\text{raw}}|``$. Auxiliary space complexity is $`O(1)`$ for streaming and $`O(K)`$ bounded arena storage for $`K \le N`$ token descriptors referencing existing byte buffer spans without heap reallocation. The algorithm requires zero combinatorial backtracking, operating strictly in $`\mathbf{P}`$ and remaining bounded well below NP-complete frontiers (e.g., REQ-0117 temporal interval consistency NP-1 or REQ-0135 minimal cut-sets NP-4).

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: HTML Line Break Variant and Escaped Linefeed Normalization

- **Given:** CommonMark table cell $``C_{\text{raw}}``$ containing break variants (`<br>`, `<br/>`, `<br />`, `<BR>`, `<BR/>`, `<BR />`) and escaped linefeeds (`\n`, `\r\n`) around text tokens (`param_x : Real`).
- **When:** Block normalizer pass $``\Phi_{\text{block}}``$ executes during table ingestion.
- **Then:** Every break sequence normalizes to $``\text{LineBreak}(\text{SYM}_{\text{LF}})``$, preserving surrounding text without loss.
- **Diagnostic:** `E0100` emitted on invalid escape sequences or corrupted break delimiters.

### AC-02: Verbatim Code Span Preservation

- **Given:** Table cell containing an inline code span enclosed in backticks (`` `Port_1 <br> Port_2 | Flow_A` ``).
- **When:** Block normalizer encounters code span delimiters during cell lexing.
- **Then:** Content is emitted verbatim as a single `CodeSpan` token without normalizing embedded HTML breaks or splitting on pipes.
- **Diagnostic:** `E0102` emitted if an unclosed code span reaches column delimiter pipe (`|`).

### AC-03: Nested List Item Hierarchy and Bullet Depth Extraction

- **Given:** Table cell containing multi-line bullet items with space indentation (`- Item_Alpha<br> - Subitem_Beta<br> - Subitem_Gamma`).
- **When:** Normalizer evaluates leading whitespace following a normalized line break.
- **Then:** Items lower into ordered `ListItem` tokens with indentation mapped to bullet depth $`d \in \{1, 2, 3\}`$ and marker kinds preserved.
- **Diagnostic:** `E0100` emitted if bullet nesting depth exceeds bound $``D_{\text{max\_bullet}} = 8``$.

### AC-04: Bijective Round-Trip Serialization

- **Given:** Normalized token sequence $``\mathcal{T} = \Phi_{\text{block}}(C_{\text{raw}})``$ from a schema cell defining synthetic ports (`Port_1`, `Port_2`).
- **When:** Serialization pass emits $`\mathcal{T}`$ via $``\Psi_{\text{emit}}``$ and re-ingests the resulting string via $``\Phi_{\text{block}}``$.
- **Then:** Round-trip identity $``\Phi_{\text{block}}(\Psi_{\text{emit}}(\mathcal{T})) \equiv \mathcal{T}``$ holds with 0-byte diff churn.
- **Diagnostic:** `E0100` emitted on round-trip token divergence or information loss.
