## 1. Normative Statement

The compiler SHALL lower SysML v2 view definitions (`view def`) and usages (`view`) into structural projection elements, and viewpoint definitions (`viewpoint def`) and usages (`viewpoint`) into requirement elements.

The lowering engine MUST enforce six invariants:
1. **Specialization**: `ViewDefinition` specializes `PartDefinition` and `Structure`; `ViewUsage` specializes `PartUsage`. `ViewpointDefinition` specializes `RequirementDefinition`; `ViewpointUsage` specializes `RequirementUsage`.
2. **Disjointness**: `ViewDefinition` MUST NOT specialize `DataType`, `ActionDefinition`, or interfaces; `ViewpointDefinition` MUST NOT specialize non-requirement classifiers (`E0200`).
3. **Framing**: Viewpoints frame concerns $``\mathbf{C}_{VP}``$ and query filter predicates $``\Phi_{\text{filter}} : \mathcal{V}_{\text{model}} \to \mathbb{B}``$.
4. **Conformance**: Views declare conformance via `satisfy viewpoint` (`SatisfyRequirementUsage`). Invalid targets or unsatisfied concerns emit `E0200`.
5. **Projection**: Model projection $``\pi_V``$ extracts induced subgraph $``\mathcal{M}_{\text{view}}``$ where $``\forall n \in \mathcal{V}_{\text{model}}, n \in \mathcal{V}_{\text{view}} \iff \Phi_{\text{filter}}(n) \equiv \text{true}``$, preserving edges between exposed vertices.
6. **Acyclicity**: Dependency graph $``G_{\text{vp\_dep}}``$ MUST be a DAG; cycles emit `E0203`.

## 3. Computational Complexity & Algorithmic Bounds

- **Complexity Class:** Class $\mathbf{P}$ (Deterministic Polynomial Time)
- **Asymptotic Bound:** $O(V + E)$ where $``V = |\mathcal{V}_{\text{model}}|``$ and $``E = |\mathcal{E}_{\text{model}}|``$.
- **Tractable Subclass & Frontier:** Viewpoint conformance and query filtering operate within the polynomial subtyping meet-semilattice fragment of NP-3, avoiding exponential graph isomorphism frontiers (NP-1, NP-8).

For $``N_V = |\mathcal{VD}| + |\mathcal{VU}|``$ views and $``N_{VP} = |\mathcal{VPD}| + |\mathcal{VPU}|``$ viewpoints over graph $``\mathcal{M}_{\text{model}}``$:
- **Allocation & Interning:** AST arena allocation takes amortized $``O(N_V + N_{VP})``$ time.
- **Projection:** Evaluating $``\Phi_{\text{filter}}``$ takes $O(V)$ time; extracting induced edges takes $O(E)$ time ($O(V + E)$ total).
- **Acyclicity:** Topological cycle check over $``G_{\text{vp\_dep}}``$ takes $``O(|\mathcal{VPD}| + |\mathcal{R}_{\text{vp\_dep}}|)``$ time.
- **Parallel Scaling:** Work-stealing across $``N_{\text{max\_workers}}``$ scales as $``O((V + E)/N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Canonical ViewDefinition and Viewpoint Lowering
- **Given:** `Package_0` with `viewpoint def ViewpointDef_Alpha { concern Concern_Alpha; }` and `view def ViewDef_Alpha { satisfy viewpoint ViewpointDef_Alpha; }`.
- **When:** Lowering and viewpoint conformance checking execute.
- **Then:** Nodes lower into arena storage with `SatisfyRequirementUsage` and empty diagnostic sink.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: View Subgraph Model Projection Completeness
- **Given:** Model $``\mathcal{M}_{\text{model}}``$ ($V=1000, E=2500$) matching filter predicate $``\Phi_{\text{filter}}``$.
- **When:** Projection engine executes $``\pi_V``$ for `ViewDef_Alpha`.
- **Then:** $``\mathcal{M}_{\text{view}}``$ contains 100% of matching vertices, 0% of non-matching vertices, and preserves induced edges.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-03: Invalid Specialization and Non-Viewpoint Target Rejection
- **Given:** Declarations `view def ViewDef_Alpha :> DataType_Alpha` or `satisfy viewpoint Classifier_Alpha`.
- **When:** Semantic type checking executes.
- **Then:** Lowering rejects invalid specializations and non-viewpoint targets with sentinel $``\bot_{\text{view}}``$ and diagnostic `E0200`.
- **Diagnostic:** `E0200` (Invalid classifier specialization or unresolved viewpoint target).

### AC-04: Circular Viewpoint Dependency and Delimiter Recovery
- **Given:** Cyclic definitions `ViewpointDef_Alpha :> ViewpointDef_Beta :> ViewpointDef_Alpha` followed by a malformed statement.
- **When:** Cycle detection and delimiter recovery execute.
- **Then:** Lowering detects dependency cycle `E0203`, resynchronizes on delimiter (`;`), and continues parsing.
- **Diagnostic:** `E0203` (Circular viewpoint dependency); `E0199` on terminal error cutoff.
