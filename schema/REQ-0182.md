## 1. Normative Statement

Subsystem 10 SHALL synthesize idiomatic, zero-allocation ROS2 node architectures (`RosNode_Alpha`) from AST components (`Classifier_Alpha`).

---

## 2. Formal Invariant

Let $\mathcal{C}$ denote the set of components and $\mathcal{P}(C)$ the set of directed ports. The node and endpoint generation invariants satisfy:

```math
\begin{aligned}
\forall C\in\mathcal{C},\quad\mathcal{N}(C)&=\langle\text{id}_N,\text{name}_N,\mathcal{E}_{\text{pub}},\mathcal{E}_{\text{sub}},\mathcal{E}_{\text{srv}},\mathcal{E}_{\text{cli}},\mathbf{\Theta}_{\text{param}},\Delta_N\rangle \\
\forall e\in\mathcal{E}(C),\quad e&=\langle\text{id}_e,\text{port}_e,\text{kind}_e,\text{topic}_e,\tau_{\text{msg}},\mathbf{QoS}_e,\Delta_e\rangle \\
\mathbf{QoS}_e&=\langle\mathcal{R}_{\text{rel}},\mathcal{D}_{\text{dur}},\mathcal{H}_{\text{hist}},d_{\text{depth}},T_{\text{deadline}},T_{\text{lifespan}}\rangle \\
\forall P\in\mathcal{P}(C),\quad\exists!e\in\mathcal{E}(C)&:\text{port}_e=P\land|\mathcal{E}(C)|=|\mathcal{P}(C)| \\
\mathcal{H}_{\text{hist}}=\text{KeepLast}&\implies d_{\text{depth}}\ge 1 \\
\text{RxO}(e_{\text{pub}},e_{\text{sub}})&\iff(\mathcal{R}_{\text{pub}}\ge\mathcal{R}_{\text{sub}})\land(\mathcal{D}_{\text{pub}}\ge\mathcal{D}_{\text{sub}})\land(T_{\text{pub}}\le T_{\text{sub}}) \\
\neg\text{ValidTopic}(\text{topic}_e)&\implies\text{Diagnostic}(e,\text{E0300})\in\mathcal{D}_{\text{sink}}\land e\gets\bot_{\text{endpoint}} \\
(\neg\text{RxO}(e_{\text{pub}},e_{\text{sub}})\lor d_{\text{depth}}\le 0)&\implies\text{Diagnostic}(e,\text{E0508})\in\mathcal{D}_{\text{sink}}\land e\gets\bot_{\text{endpoint}} \\
|\mathcal{D}_{\text{sink}}|\ge C_{\text{max\_errors}}&\implies\text{Diagnostic}(\text{E0199})\in\mathcal{D}_{\text{sink}} \\
\Delta_N=\text{UUIDv5}(\text{OID}_{\text{DEAP}},\text{FQN}(C)),&\quad\Delta_e=\text{UUIDv5}(\text{OID}_{\text{DEAP}},\text{FQN}(C)\mathbin{\Vert}\text{"::"}\mathbin{\Vert}\text{name}(\text{port}_e))
\end{aligned}
```

| Symbol / Term | Domain / Formal Definition |
| :--- | :--- |
| $\mathcal{N}(C), \mathcal{E}(C)$ | ROS2 node and endpoint set |
| $``\mathcal{P}(C), \text{port}_e``$ | Component AST ports and port handle |
| $``\mathbf{QoS}_e, d_{\text{depth}}``$ | QoS profile and depth ($``d_{\text{depth}}\in\mathbb{N}^+``$) |
| $``\text{RxO}(e_{\text{pub}}, e_{\text{sub}})``$ | Offered versus Requested compatibility |
| $``\bot_{\text{endpoint}}, \mathcal{D}_{\text{sink}}, C_{\text{max\_errors}}``$ | Recovery sentinel, sink, error limit |
| $``\Delta_N, \Delta_e, \text{OID}_{\text{DEAP}}``$ | UUIDv5 anchors and namespace OID |

## 3. Computational Complexity & Algorithmic Bounds

- **Complexity Class:** Class $\mathbf{P}$ (Deterministic Polynomial Time).
- **Asymptotic Bound:** $O(|P|)$ where $``|P|=\sum_{C\in\mathcal{C}}|\mathcal{P}(C)|``$. Lowering, QoS derivation, and topic checks take $O(1)$ per port ($O(|P|)$ total). Interconnect RxO checks take $O(|\mathcal{K}|)$ ($|\mathcal{K}|\le|P|$). Work-stealing scales as $``O(|P|/N_{\text{max\_workers}}+\log N_{\text{max\_workers}})``$. Arena space is $O(|P|)$.
- **Tractable Subclass and Frontier:** N/A (Deterministic P). Bypasses NP-1 intervals (REQ-0117), NP-2 packing (REQ-0147), and NP-8 solving (REQ-0197).

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Node and Endpoint Synthesis
- **Given:** Component `Classifier_Alpha` declaring ports `Port_0` and `Port_1`.
- **When:** Lowering `RosNode_Alpha` and endpoints.
- **Then:** Emits `Publisher_0`, `Subscriber_1`, and UUIDv5 anchors.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: QoS Depth Boundary Validation
- **Given:** `Port_0` with QoS `KeepLast` and depth $``d_{\text{depth}} = 10``$.
- **When:** Validating QoS boundaries.
- **Then:** Confirms $``d_{\text{depth}} \ge 1``$ and lowers profile.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-03: RxO Incompatibility Rejection
- **Given:** Connector linking `Publisher_0` (`BestEffort`) to `Subscriber_1` (`Reliable`).
- **When:** Evaluating RxO compatibility.
- **Then:** Fails closed, emits `E0508`, and binds sentinel $``\bot_{\text{endpoint}}``$.
- **Diagnostic:** `E0508`.

### AC-04: Topic Syntax Delimiter Recovery
- **Given:** `Classifier_Alpha` with invalid topic `"1_Bad//Topic"`, delimiter `;`, and `Port_1`.
- **When:** Recovering across delimiters.
- **Then:** Emits `E0300`, binds sentinel $``\bot_{\text{endpoint}}``$, recovers across `;`, parses `Port_1`, halting at $``C_{\text{max\_errors}}``$ with `E0199`.
- **Diagnostic:** `E0300`, `E0199`.
