## 1. Normative Statement

The Universal Schema Ingestion Engine shall parse OpenAPI 3.0 and 3.1 specifications in JSON and YAML formats into intermediate schema IR without external dependencies. The root document lowers to an `IngestedPackage` (e.g., `Package_0::Spec_Alpha`). Schema objects under `components/schemas` lower to `IngestedClassifierDef` (`ClassifierKind::Struct` or `ClassifierKind::Enum`) with `IngestedAttr` fields binding identifiers, types, and multiplicity $``\langle l, u \rangle \in \mathbb{N}_0 \times (\mathbb{N}_0 \cup \{\infty\})``$. Scalar types map deterministically: `string` to `String`, `integer` to `Int32`/`Int64`, `number` to `Real32`/`Real64`, `boolean` to `Boolean`, and `array` to item types with multiplicity.

API paths under `paths` (e.g., `/endpoint_alpha/{param_id}`) lower to interface endpoints. HTTP operations (`get`, `post`, `put`, `delete`, `patch`) lower to `IngestedAction` entities. Primary action identifiers derive from explicit `operationId` or deterministic concatenation (`verb_path`); duplicate action identifiers within scope trigger diagnostic `E0102`. Declared path parameters (`in: path`) require `required: true`, multiplicity $`\langle 1, 1 \rangle`$, and bijective equivalence to route template variables; mismatched path parameters trigger `E0102`. Query, header, and cookie parameters lower to input parameters with multiplicity $`\langle 1, 1 \rangle`$ (required), $`\langle 0, 1 \rangle`$ (optional), or array intervals $``\langle \kappa_{\min}, \kappa_{\max} \rangle``$.

Declared `requestBody` objects lower to an input parameter named `payload` with multiplicity $`\langle 1, 1 \rangle`$ (required) or $`\langle 0, 1 \rangle`$ (optional). Success responses ($`2xx`$) synthesize output parameter `result` with multiplicity $`\langle 1, 1 \rangle`$ (or $`\langle 0, 0 \rangle`$ for status 204); non-$`2xx`$ responses map to typed error variants. JSON Pointer references (`#/components/schemas/...`) dereference in the symbol table; cyclic references resolve via handle indirection; unresolvable references trigger `E0102`.

## 2. Formal Invariant

Let OpenAPI specification document $`\mathcal{O}`$ be formalized as a 4-tuple:

```math
\begin{aligned}
\mathcal{O} &= \langle V_{\text{version}}, \mathcal{I}_{\text{info}}, \mathcal{P}_{\text{paths}}, \mathcal{C}_{\text{components}} \rangle \\
\text{components/schemas/}S &\longmapsto \text{IngestedClassifierDef}(S, \text{kind}: \text{ClassifierKind::Struct}, \text{fields}: \mathcal{T}_{\text{schema}}(S)) \\
\text{paths/}P/m &\longmapsto \text{IngestedAction}(\text{ActionId}(P, m), \text{endpoint}: u(P), \text{inputs}: \mathcal{P}_{\text{in}}(P, m), \text{outputs}: \mathcal{P}_{\text{out}}(P, m))
\end{aligned}
```

Operation action identifier synthesis, uniqueness, and path parameter bijection satisfy:

```math
\begin{aligned}
\text{ActionId}(P, m) &= 
\begin{cases}
\text{id}_{\text{op}}, & \text{if } \text{operationId}(P, m) = \text{id}_{\text{op}} \ne \bot \\
m \mathbin{\Vert} \text{"\_"} \mathbin{\Vert} \text{Sanitize}(u(P)), & \text{otherwise}
\end{cases} \\
(P_1, m_1) \ne (P_2, m_2) &\implies \text{ActionId}(P_1, m_1) \ne \text{ActionId}(P_2, m_2) \\
\forall P \in \mathcal{P}_{\text{paths}}, \, \forall m \in \text{Ops}(P), &\quad \{ \text{name}(p) \mid p \in \text{Params}(P, m) \;\wedge\; \text{in}(p) = \text{Path} \} = \text{Vars}(u(P))
\end{aligned}
```

Payload schema lowering and reference resolution satisfy:

```math
\begin{aligned}
\text{requestBody}(P, m) &\longmapsto \text{IngestedAttr}(\text{"payload"}, \text{type}: \tau_{\text{req}}, \text{mult}: \mu_{\text{req}}) \\
\text{responses}(P, m, c) &\longmapsto \text{IngestedAttr}(\text{"result"}, \text{type}: \tau_{\text{resp}}, \text{mult}: \langle 1, 1 \rangle), \quad \forall c \in [200, 299] \\
\text{ResolveRef}(R, \mathcal{O}) &= 
\begin{cases}
\mathcal{C}_{\text{components}}.\mathcal{S}_{\text{schemas}}[S], & \text{if } R = \text{"\#/components/schemas/"} \mathbin{\Vert} S \;\wedge\; S \in \text{dom}(\mathcal{C}_{\text{components}}.\mathcal{S}_{\text{schemas}}) \\
\bot, & \text{otherwise}
\end{cases}
\end{aligned}
```

where $``\mu_{\text{req}} = \langle 1, 1 \rangle``$ if $`\text{required}(\text{requestBody}(P, m)) = \text{true}`$ and $`\langle 0, 1 \rangle`$ otherwise.

Deterministic UUIDv5 entity generation and diagnostic code binding per REQ-0191 satisfy:

```math
\begin{aligned}
\text{UUID}(u) &= \text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(u)) \\
(V_{\text{version}} \notin \{ \text{"3.0.0"}, \dots, \text{"3.1.0"} \} \;\vee\; \text{HasSyntaxError}(t)) &\implies \text{DiagnosticCode::E0100} \in \mathcal{D} \\
(\text{ActionId}(P_1, m_1) = \text{ActionId}(P_2, m_2) \;\vee\; \text{PathMismatch} \;\vee\; \text{ResolveRef} = \bot) &\implies \text{DiagnosticCode::E0102} \in \mathcal{D} \\
\text{IsUnsupportedType}(\tau) &\implies \text{DiagnosticCode::E0103} \in \mathcal{D} \\
|\mathcal{D}| \ge C_{\text{max\_errors}} &\implies \text{DiagnosticCode::E0199} \in \mathcal{D}
\end{aligned}
```

## 3. Computational Complexity & Algorithmic Bounds

The OpenAPI schema ingestion engine operates within Complexity Class $`\mathbf{P}`$. Monotonic single-pass parsing of an input document of $`N`$ bytes executes in $`O(N)`$ operations without backtracking. Symbol interning for scalar tokens ($`L \le 256`$) executes in $`O(1)`$ amortized time. Lowering $`S`$ component schemas with $`F`$ properties evaluates in $`O(S + F) \le O(N)`$ time. Resolving local JSON Pointer references over schema graph $``G_{\text{ref}} = (V_{\text{schema}}, E_{\text{ref}})``$ with cycle memoization executes in $``O(V_{\text{schema}} + E_{\text{ref}}) = O(N)``$ time. Lowering $`P`$ path items with $`M`$ operations and $`K`$ parameters evaluates in $`O(P + M + K) \le O(N)`$ time. AST memory entity allocation executes in $`O(1)`$ time per node. Multi-file parallel compilation across $`K`$ documents on a bounded work-stealing pool with $``N_{\text{max\_workers}}``$ workers scales in $``O(\lceil K / N_{\text{max\_workers}} \rceil \cdot N_{\text{max}})``$. Auxiliary space complexity is $`O(N)`$ for AST storage and symbol tables, $``O(D_{\text{max}}) = O(1)``$ stack frames ($``D_{\text{max}} \le 64``$), and $``O(C_{\text{max\_errors}}) = O(1)``$ for diagnostic records. Ingestion executes in polynomial time $`\mathbf{P}`$ and avoids all combinatorial NP-complete frontiers (NP-1--NP-8).

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Canonical Schema and Path Lowering
- **Given:** Valid OpenAPI 3.0/3.1 document declaring schema `Schema_Alpha` and path `/endpoint_alpha` (`get`, `post`).
- **When:** Ingesting and lowering into schema IR.
- **Then:** Synthesizes `IngestedPackage`, `IngestedClassifierDef`, and two `IngestedAction` entities in AST storage without diagnostics.
- **Diagnostic:** `E0100` or `E0102` on lowering failure.

### AC-02: Path Route Template and Parameter Consistency
- **Given:** Path `/endpoint_alpha/{param_x}` with operation parameter `param_x` (`in: path`, `required: true`).
- **When:** Validating route template consistency.
- **Then:** Maps `param_x` to required input parameter with multiplicity $`\langle 1, 1 \rangle`$; template mismatch triggers diagnostic.
- **Diagnostic:** Emits `E0102` on route mismatch.

### AC-03: Request Body and Response Payload Binding
- **Given:** Operation declaring `requestBody` schema `Payload_0` (`required: true`) and response status 200 schema `Response_Alpha`.
- **When:** Lowering payloads.
- **Then:** Synthesizes input parameter `payload : Payload_0` ($`\langle 1, 1 \rangle`$) and output parameter `result : Response_Alpha` ($`\langle 1, 1 \rangle`$).
- **Diagnostic:** Emits `E0102` or `E0103` on binding failure.

### AC-04: JSON Pointer Dereferencing and Cycle Safety
- **Given:** Schemas with local pointer references (`#/components/schemas/Schema_Alpha`) including recursive reference (`Schema_Beta` to `Schema_Beta`).
- **When:** Resolving references during type binding.
- **Then:** Resolves targets via handle indirection without recursion overflow; unresolvable reference emits diagnostic.
- **Diagnostic:** Emits `E0102` on unresolvable target.
