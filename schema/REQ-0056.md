## 1. Normative Statement

The KerML scoping engine shall evaluate namespace import declarations as deterministic relational projections over exported membership sets across compilation units.

The engine shall parameterize import visibility across a two-point bounded lattice $`\mathcal{V} = \{ \text{Private}, \text{Public} \}`$ where $`\text{Private} \prec \text{Public}`$:
1. Private imports (`private import` or default unqualified imports) shall bind symbols strictly into the target namespace internal scope; they shall not be re-exported.
2. Public imports (`public import`) shall bind symbols into the target public interface, transitively re-exporting them to foreign importing scopes.

The scoping engine shall support four import modalities:
1. Single-element import (`import Package_0::Classifier_Alpha;`), projecting a designated public member identified by qualified path.
2. Namespace wildcard import (`import Package_0::*;`), projecting all directly declared public members of the source namespace into the target scope.
3. Recursive wildcard import (`import Package_0::**;`), computing the reflexive-transitive closure of public sub-namespace containment with cycle-detection protection.
4. Filtered and aliased import (`import Package_0::Classifier_Alpha as Classifier_Beta;` or predicate filter $`\phi`$), projecting members satisfying boolean filter predicates and binding explicit symbol aliases.

The scoping engine shall enforce deterministic shadow precedence: locally declared members within target namespace $``N_{\text{tgt}}``$ shall strictly shadow imported members sharing an identical unqualified identifier. Shadowed imported symbols shall remain accessible via fully qualified paths. When an unqualified identifier lookup matches two or more distinct imported members in the absence of a shadowing local declaration, the engine shall reject the reference and emit diagnostic error code `E0200`. If an import declaration targets an unresolved namespace or member, the engine shall emit diagnostic error code `E0200`.

## 2. Formal Invariant

Let $`\mathcal{N}`$ denote the set of namespaces, and $`\mathcal{M}`$ denote membership bindings $`\langle s, e \rangle`$ mapping identifier $`s \in \Sigma^*`$ to AST node $`e \in \mathcal{E}`$. Each namespace $`N \in \mathcal{N}`$ maintains owned memberships $``\mathcal{M}_{\text{owned}}(N)``$ and imported memberships $``\mathcal{M}_{\text{imp}}(N)``$.

Visibility lattice:

```math
\mathcal{V} = \{ \text{Private}, \text{Public} \}, \quad \text{Private} \prec \text{Public}
```

An import declaration $``I = \langle N_{\text{src}}, V, \phi, \alpha \rangle``$ with visibility $`V \in \mathcal{V}`$, filter predicate $`\phi : \mathcal{M} \to \mathbb{B}`$, and alias function $`\alpha : \Sigma^* \to \Sigma^*`$ induces imported memberships:

```math
\begin{aligned}
\mathcal{M}_{\text{imp}}(I) &= \{ \langle \alpha(s), e \rangle \mid \langle s, e \rangle \in \text{ExportedMemberships}(N_{\text{src}}) \;\wedge\; \phi(\langle s, e \rangle) \equiv \text{true} \} \\
\text{ExportedMemberships}(N) &= \{ m \in \mathcal{M}_{\text{owned}}(N) \cup \mathcal{M}_{\text{imp}}(N) \mid \text{Vis}(m) = \text{Public} \}
\end{aligned}
```

Recursive wildcard imports (`::**`) expand over the reflexive-transitive closure of accessible sub-namespaces:

```math
\mathcal{M}_{\text{rec}}(N_{\text{src}}) = \bigcup_{N' \in \text{SubNamespaces}^*(N_{\text{src}})} \text{ExportedMemberships}(N')
```

Symbol lookup resolution $``\text{Find}(s, N_{\text{tgt}})``$ and conflict detection:

```math
\begin{aligned}
\text{Find}(s, N_{\text{tgt}}) &= \begin{cases}
\{ e \mid \langle s, e \rangle \in \mathcal{M}_{\text{owned}}(N_{\text{tgt}}) \}, & \text{if } \exists \langle s, e \rangle \in \mathcal{M}_{\text{owned}}(N_{\text{tgt}}) \\
\{ e \mid \langle s, e \rangle \in \mathcal{M}_{\text{imp}}(N_{\text{tgt}}) \}, & \text{otherwise}
\end{cases} \\
\text{Ambiguous}(s, N_{\text{tgt}}) &\iff (\forall e, \langle s, e \rangle \notin \mathcal{M}_{\text{owned}}(N_{\text{tgt}})) \;\wedge\; |\{ e \mid \langle s, e \rangle \in \mathcal{M}_{\text{imp}}(N_{\text{tgt}}) \}| \gt 1
\end{aligned}
```

Diagnostic trigger:

```math
\text{Ambiguous}(s, N_{\text{tgt}}) \;\vee\; \text{TargetNotFound}(I) \implies \text{Diagnostic}(s, \text{E0200}) \in \mathcal{D}_{\text{sink}}
```

## 3. Computational Complexity & Algorithmic Bounds

The KerML import declaration evaluation and scoping engine executes strictly within Complexity Class $`\mathbf{P}`$. For a model with $`V`$ namespaces, $`E`$ containment edges, and $`M`$ memberships, hierarchy traversal evaluates via depth-first search in $`O(V + E)`$ time. Direct and wildcard import set constructions execute in $`O(M)`$ operations over indexed membership hash sets. Unqualified symbol resolution against hash-indexed scopes executes in $`O(1)`$ amortized time ($`O(L)`$ for identifier length $`L`$). Total runtime satisfies:

```math
T_{\text{import}} \in O(V + E + M \cdot L) \subseteq O(V + E + M)
```

Memory footprint is bounded by $`O(V + M)`$ references in contiguous storage.

NP Frontier Reference: Decoupled from NP-complete multiple inheritance and subtyping lattice frontiers (NP-3, REQ-0061--REQ-0063); import resolution and shadow precedence evaluate deterministically in linear polynomial time without combinatorial search or backtracking.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Public vs Private Import Visibility Re-export
- **Given:** Namespace `Package_0` declaring public `Classifier_Alpha`, namespace `Package_1` declaring `public import Package_0::Classifier_Alpha;`, and namespace `Package_2` declaring `import Package_1::*;`.
- **When:** Metamodel lowering resolves symbol `Classifier_Alpha` within `Package_2`.
- **Then:** `Classifier_Alpha` is resolved in `Package_2` via public re-export; replacing `Package_1` with `private import` causes lookup to fail with diagnostic error code `E0200`.
- **Diagnostic:** `E0200` emitted on foreign access to non-exported private import.

### AC-02: Recursive Wildcard Import and Sub-Namespace Closure
- **Given:** Nested namespace hierarchy `Package_0::SubPackage_1::Classifier_Alpha` and target namespace `Package_2` declaring `import Package_0::**;`.
- **When:** Scoping engine evaluates reflexive-transitive closure $``\mathcal{M}_{\text{rec}}(\text{Package\_0})``$.
- **Then:** Symbol `Classifier_Alpha` resolves unqualified within `Package_2`, and visited-set cycle detection guarantees deterministic completion without infinite recursion.
- **Diagnostic:** `E0203` emitted if cyclic namespace containment causes an illegal containment loop.

### AC-03: Deterministic Shadow Precedence
- **Given:** Target namespace `Package_1` declaring local member `Classifier_Alpha` and an import `import Package_0::Classifier_Alpha;`.
- **When:** Scoping engine resolves unqualified reference `Classifier_Alpha` within `Package_1`.
- **Then:** Unqualified lookup binds strictly to the local member ($``\text{Find} = \mathcal{M}_{\text{owned}}``$), while the imported symbol remains accessible via fully qualified path `::Package_0::Classifier_Alpha`.
- **Diagnostic:** `E0200` emitted if shadow precedence fails to bind local declaration.

### AC-04: Ambiguous Unqualified Import Collision Detection
- **Given:** Namespaces `Package_0` and `Package_1` both exporting public `Classifier_Alpha`, and target namespace `Package_2` containing `import Package_0::*; import Package_1::*;` with no local `Classifier_Alpha`.
- **When:** Metamodel lowering attempts unqualified resolution of `Classifier_Alpha` within `Package_2`.
- **Then:** Scoping engine detects conflicting imported symbols ($`|\{e\}| \gt 1`$), rejects the resolution, and emits diagnostic error code `E0200`.
- **Diagnostic:** `E0200` emitted on ambiguous unqualified import collision.
