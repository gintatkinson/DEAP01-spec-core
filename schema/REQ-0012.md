## 1. Normative Statement

All concurrent compilation operations--including parallel schema ingestion, multi-file AST parsing, graph traversals, STPA Cartesian product hazard tensor expansions, temporal reachability evaluations, and downstream artifact code generation--shall execute exclusively through a bounded work-stealing thread pool. Parallel task execution must be strictly bounded by an upper worker limit $``N_{\text{workers}} = \min(C_{\text{logical}}, N_{\text{max\_workers}})``$, where $``C_{\text{logical}} \in \mathbb{N}_{\ge 1}``$ is the detected host logical CPU core count and $``N_{\text{max\_workers}} \in \mathbb{N}_{\ge 1}``$ is a configurable runtime worker ceiling.

The compiler runtime shall strictly prohibit unbounded, ad-hoc, or manual operating system thread creation. Worker threads must operate in complete memory isolation without shared mutable state across thread boundaries. Concurrent worker tasks shall access shared compiler structures exclusively via immutable references or frozen AST views. All task-local mutations and intermediate state synthesis must remain confined to thread-local memory regions or task-private accumulators.

Parallel reductions and multi-threaded aggregations must enforce deterministic combination ordering such that thread scheduling interleavings never induce non-deterministic AST mutations or artifact diff churn. If any compiler component attempts to spawn an unmanaged thread, if worker thread allocation exceeds $``N_{\text{max\_workers}}``$, or if concurrent data race or shared mutable state violations are detected, the compiler shall halt execution immediately and emit diagnostic error code `E0100`.

## 2. Formal Invariant

Let $``P_{\text{workers}}``$ denote the active worker thread pool, $``C_{\text{logical}}``$ the host logical CPU core count, and $``N_{\text{max\_workers}}``$ the configured maximum worker limit. Active worker pool cardinality satisfies:

```math
|P_{\text{workers}}| = N_{\text{workers}} = \min(C_{\text{logical}}, N_{\text{max\_workers}}) \le N_{\text{max\_workers}}
```

Let $``\mathcal{T}_{\text{spawned}}``$ denote all operating system threads instantiated by the compiler, and $``N_{\text{coord}} \in \{0, 1\}``$ the coordination thread. Total thread creation satisfies:

```math
|\mathcal{T}_{\text{spawned}}| \le |P_{\text{workers}}| + N_{\text{coord}}
```

Let $`\text{Memory}(\tau)`$, $`\text{Writes}(\tau)`$, and $`\text{Reads}(\tau)`$ denote the accessed address set, write-set, and read-set of worker $``\tau \in P_{\text{workers}}``$. Concurrency safety enforces pairwise memory disjointness for all distinct workers $``\tau_i \ne \tau_j \in P_{\text{workers}}``$:

```math
\begin{aligned}
\text{Writes}(\tau_i) \cap \text{Writes}(\tau_j) &= \emptyset \\
\text{Writes}(\tau_i) \cap \text{Reads}(\tau_j) &= \emptyset \\
\text{Reads}(\tau_i) \cap \text{Writes}(\tau_j) &= \emptyset
\end{aligned}
```

The global shared mutable state invariant across the thread pool asserts:

```math
\text{SharedMutableState}(P_{\text{workers}}) = \bigcup_{\tau_i \ne \tau_j} \left( \text{Writes}(\tau_i) \cap \text{Memory}(\tau_j) \right) = \emptyset
```

Workloads are partitioned into data-parallel tasks enqueued into worker-local double-ended deques $``Q_i = \langle w_{i,1}, \dots, w_{i,m} \rangle``$. Local execution and work-stealing satisfy:

```math
\begin{aligned}
\text{LocalExecution}(\tau_i) &: \quad Q_i \ne \emptyset \implies \text{PopBottom}(Q_i) \\
\text{StealRule}(\tau_i) &: \quad Q_i = \emptyset \implies \text{StealTop}(Q_j), \quad j \ne i, \; Q_j \ne \emptyset
\end{aligned}
```

Let $``\mathcal{G}_{\text{tasks}} = (\mathcal{V}_{\text{tasks}}, \mathcal{E}_{\text{dep}})``$ denote the compilation task DAG and $``\Pi(\mathcal{G}_{\text{tasks}})``$ the set of topological execution schedules. Serialized output $`\mathcal{O}(\pi)`$ satisfies schedule independence:

```math
\forall \pi_1, \pi_2 \in \Pi(\mathcal{G}_{\text{tasks}}), \quad \mathcal{O}(\pi_1) = \mathcal{O}(\pi_2)
```

## 3. Computational Complexity & Algorithmic Bounds

Work-stealing task execution operates within Complexity Class $`\mathbf{P}`$. For any computation task DAG with sequential work $``T_1``$ and critical-path span $``T_\infty``$, the bounded work-stealing scheduler achieves expected execution time:

```math
T_P \le \frac{T_1}{P} + O(T_\infty)
```

where $``P = |P_{\text{workers}}| = \min(C_{\text{logical}}, N_{\text{max\_workers}})``$. Local deque operations execute in deterministic $`O(1)`$ time. Remote work-stealing attempts execute in $`O(1)`$ lock-free atomic compare-and-swap time per attempt, with total steal attempts bounded by $``O(P \cdot T_\infty)``$ with high probability. Space complexity is strictly bounded by $``O(P \cdot S_1)``$, where $``S_1``$ is peak sequential memory consumption.

Parallel task execution over the AST graph bypasses combinatorial explosion; phases subject to NP-hard complexity (such as NP-4 STPA minimal hazard cut-sets per REQ-0135 or NP-5 state reachability per REQ-0124) delegate combinatorial subproblems to bounded solvers with explicit timeout cutoffs ($``\kappa_{\text{safety}}``$), guaranteeing polynomial overhead in work distribution.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Bounded Worker Thread Allocation Gate

- **Given:** Host platform with $``C_{\text{logical}}``$ cores and compiler runtime configured with ceiling $``N_{\text{max\_workers}}``$.
- **When:** The compiler initializes thread pool $``P_{\text{workers}}``$ and dispatches parallel passes over model elements (`Package_0`, `Classifier_Alpha`, `Port_1`).
- **Then:** Active worker count satisfies $``|P_{\text{workers}}| = \min(C_{\text{logical}}, N_{\text{max\_workers}})``$, total OS threads satisfy $``|\mathcal{T}_{\text{spawned}}| \le |P_{\text{workers}}| + 1``$, and unmanaged thread spawning is prohibited.
- **Diagnostic:** `E0100` emitted if active OS threads exceed $``N_{\text{max\_workers}} + 1``$ or unmanaged thread instantiation occurs.

### AC-02: Strict Thread Isolation & Zero Shared Mutable State

- **Given:** Concurrent compilation passes processing synthetic AST nodes across worker pool $``P_{\text{workers}}``$.
- **When:** Concurrency audit harnesses inspect memory access traces $``\text{Reads}(\tau_i)``$ and $``\text{Writes}(\tau_i)``$ across all active workers.
- **Then:** $``\text{SharedMutableState}(P_{\text{workers}}) = \emptyset``$ holds identically, all shared AST references are strictly immutable, and mutations remain confined to thread-local accumulators.
- **Diagnostic:** `E0100` emitted upon detection of any cross-thread shared mutable reference, unsynchronized heap access, or data race.

### AC-03: Work-Stealing Deque Execution & Dynamic Load Balancing

- **Given:** An unbalanced workload distributed across worker-local deques $``Q_i``$.
- **When:** Worker thread $``\tau_i``$ empties local deque $``Q_i``$ while remote deque $``Q_j \ne \emptyset``$ contains pending tasks.
- **Then:** Worker $``\tau_i``$ steals tasks from the top of remote deque $``Q_j``$ via lock-free atomic operations without blocking other workers, sustaining throughput until all task deques are exhausted.
- **Diagnostic:** `E0100` emitted if thread starvation loops exceed timeout bounds or if deque corruption occurs.

### AC-04: Schedule-Independent Bitwise Determinism across Reductions

- **Given:** Synthetic MBSE model elements (`Package_0`, `Classifier_Alpha`, `Port_1`, `Flow_A`, `param_x : Real`) compiled under varying thread counts ($`P \in \{1, 2, 4, 8\}`$) and randomized scheduling delays.
- **When:** Parallel worker tasks complete and merge intermediate results into the final unified AST and emitted artifacts.
- **Then:** Deterministic reduction ordering produces 100% bitwise identical output representations across all execution schedules ($``\mathcal{O}(\pi_1) = \mathcal{O}(\pi_2)``$), asserting 0-byte diff churn against single-threaded baselines.
- **Diagnostic:** `E0100` emitted if emitted AST digests or generated artifacts diverge across different thread counts or execution schedules.
