## 1. Normative Statement

The core abstract syntax tree (AST) engine shall execute a deterministic two-pass symbol resolution pipeline across workspace compilation units, decoupling declaration order from reference order.

Pass 2 (Reference Resolution): The engine traverses the AST and resolves symbol references, cross-references, feature typings, connection endpoints, port bindings, subtyping relationships (`:>`, `:>>`), and constraint variables against $`\Gamma`$. Lookups search outward through ancestor scopes or evaluate double-colon paths (`::`), resolving forward references and mutual recursion across packages invariant to declaration order.

---

## 2. Formal Invariant

Let $``\mathcal{A} = (\mathcal{V}_{\text{AST}}, \mathcal{E}_{\text{AST}})``$ denote the AST partitioned into disjoint definitions $``\mathcal{V}_{\text{defs}}``$ and references $``\mathcal{V}_{\text{refs}}``$. Let $``\mathcal{T}_{\text{scope}} = (\mathcal{S}, \prec, \sigma_0)``$ denote the scope tree rooted at $``\sigma_0``$.

Pass 1 (Symbol Hoisting) constructs hierarchical symbol environment $`\Gamma`$:

```math
\Gamma = \text{Pass}_1(\mathcal{A}) = \bigcup_{n \in \mathcal{V}_{\text{defs}}} \{ \text{FQN}(n) \mapsto \text{Handle}(n) \}
```

Scope Uniqueness Invariant:

```math
\forall n_1, n_2 \in \mathcal{V}_{\text{defs}}, \quad (\text{Scope}(n_1) = \text{Scope}(n_2) \wedge \text{Name}(n_1) = \text{Name}(n_2)) \implies n_1 = n_2
```

Pass 2 (Reference Resolution) binds references via lookup function $`\rho`$:

```math
\mathcal{A}_{\text{resolved}} = \text{Pass}_2(\mathcal{A}, \Gamma) \iff \forall r \in \mathcal{V}_{\text{refs}}, \quad \text{BindTarget}(r, \rho(r, \text{Scope}(r), \Gamma))
```

where lookup $`\rho(r, s, \Gamma)`$ evaluates:

```math
\rho(r, s, \Gamma) = \begin{cases}
\mu_s(\text{Name}(r)), & \text{if } \mu_s(\text{Name}(r)) \ne \bot \\
\rho(r, p, \Gamma), & \text{if } \mu_s(\text{Name}(r)) = \bot \wedge (s \prec p) \\
\mu_{\text{global}}(\text{FQN}(r)), & \text{if } s = \sigma_0 \wedge \text{IsQualified}(r) \wedge \mu_{\text{global}}(\text{FQN}(r)) \ne \bot \\
\bot_{\text{sym}}, & \text{otherwise}
\end{cases}
```

Mutual Recursion, Permutation, and Binding Invariants:

```math
\begin{aligned}
\forall r \in \mathcal{V}_{\text{refs}}, \quad \text{Pos}(r) \lt \text{Pos}(d) &\implies \rho(r, \text{Scope}(r), \Gamma) = d \\
\text{Pass}_1(\pi(\mathcal{A})) = \Gamma, &\quad \text{Pass}_2(\pi(\mathcal{A}), \Gamma) = \mathcal{A}_{\text{resolved}} \\
\forall n \in \mathcal{V}_{\text{defs}}, \quad \text{UUID}(n) &= \text{UUIDv5}(\text{NS}_{\text{DEAP}}, \text{FQN}(n)) \\
\exists r \in \mathcal{V}_{\text{refs}} : \rho(r, \text{Scope}(r), \Gamma) = \bot_{\text{sym}} &\implies \text{Diagnostic}(r, \text{E0200}) \in \mathcal{D}_{\text{sink}}
\end{aligned}
```

## 3. Computational Complexity & Algorithmic Bounds

The two-pass symbol resolution pipeline operates strictly within Complexity Class $`\mathbf{P}`$.

1. Pass 1 Hoisting: Traverses $``N = |\mathcal{V}_{\text{AST}}|``$ nodes once. Interning strings and inserting symbols into scope tables requires amortized $`O(1)`$ time, yielding $``T_{\text{Pass1}}(N) \in O(N)``$.
2. Pass 2 Resolution: For $``N_{\text{refs}} \le N``$ references, scope chain depth is bounded by $``D_{\text{depth}} \le 64 = O(1)``$ and qualified path lookup by $`k \le 16 = O(1)`$ segments, yielding $``T_{\text{Pass2}}(N) \in O(N)``$.
3. Bounds & Scalability: Total execution time is $`T(N) = O(N)`$ and space complexity is $`O(N)`$ arena storage with $`O(1)`$ stack depth. Parallel execution across $`K`$ packages on $``N_{\text{max\_workers}}``$ threads scales as $``O(N / N_{\text{max\_workers}} + K \log N_{\text{max\_workers}})``$.

Decoupling definition hoisting from reference lookup eliminates backtracking and avoids combinatorial search, bypassing NP-hard subtyping and scheduling frontiers (NP-1 through NP-8) with guaranteed polynomial termination.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Mutual Recursion & Forward Reference Resolution

- **Given:** Sibling packages `Package_0` and `Package_1` where `Classifier_Alpha` in `Package_0` references `Package_1::Classifier_Beta`, and `Classifier_Beta` in `Package_1` references `Package_0::Classifier_Alpha`.
- **When:** Pass 1 hoists symbols and Pass 2 resolves references.
- **Then:** Both cross-references resolve to exact 32-bit arena node handles in $`\Gamma`$ with zero diagnostics emitted.
- **Diagnostic:** `E0200` on resolution failure.

### AC-02: Declaration Order Permutation Invariance

- **Given:** An AST model with 500 definitions and 1,000 cross-references permuted into 10 distinct declaration sequences $``\pi_1, \dots, \pi_{10}``$.
- **When:** The two-pass symbol pipeline executes on each permutation.
- **Then:** All 10 runs produce bitwise identical symbol tables $`\Gamma`$ and resolved AST graphs with 0-byte diff churn.
- **Diagnostic:** `E0200` if resolved handles depend on declaration order.

### AC-03: Duplicate Symbol Declaration Rejection

- **Given:** An AST declaring two classifier definitions with identical name `Classifier_Alpha` in scope `Package_0`.
- **When:** Pass 1 hoists definitions in `Package_0`.
- **Then:** Pass 1 rejects the duplicate declaration, retains the primary definition handle in $`\Gamma`$, records exact source coordinates, and continues AST traversal.
- **Diagnostic:** `E0200` on duplicate symbol declaration in the same scope.

### AC-04: Unresolved and Ambiguous Symbol Diagnostics

- **Given:** An AST containing reference $``r_1``$ targeting missing symbol `Classifier_Missing` and reference $``r_2``$ matching multiple candidate definitions across imported scopes.
- **When:** Pass 2 resolves references against symbol table $`\Gamma`$.
- **Then:** Pass 2 binds sentinel $``\bot_{\text{sym}}``$ to each faulted reference, accumulates structured diagnostic records, and completes traversal.
- **Diagnostic:** `E0200` on unresolvable or ambiguous symbol references.
