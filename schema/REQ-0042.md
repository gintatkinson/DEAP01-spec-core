## 1. Normative Statement

The core abstract syntax tree (AST) engine shall implement a deterministic cycle detection engine utilizing Tarjan's strongly connected components (SCC) algorithm to identify, isolate, and reject circular dependencies across metamodel relationship graphs during compile-time semantic analysis.

The engine shall enforce acyclicity across three directed relational subgraphs:
1. Specialization Hierarchies ($``G_{\text{inherit}}``$): Specialization relations (`specializes`, `:>`) between classifier definitions (`ClassifierDef`) must be strictly acyclic, prohibiting self-specialization ($`u :> u`$) and mutual circular chains ($``v_1 :> \dots :> v_k :> v_1``$).
2. Composition Hierarchies ($``G_{\text{comp}}``$): Containment relations (`contains`, `owns`) between packages, definitions, and usages must be strictly acyclic, prohibiting direct or transitive self-containment.
3. Feature Redefinition Hierarchies ($``G_{\text{redef}}``$): Feature redefinition and subsetting relations (`redefines`, `:>>`, `subsets`) across feature usages must be strictly acyclic.

Upon detecting any cycle, the engine shall reconstruct deterministic directed cycle path $``\mathcal{P}_{\text{cycle}} = \langle v_1, \dots, v_k, v_1 \rangle``$ starting at origin $``v_1 = \min_{v \in C} \text{Handle}(v)``$ and emit diagnostic error code `E0203` with source byte spans, coordinates, cycle category (`InheritanceCycle`, `ContainmentCycle`, or `RedefinitionCycle`), and ordered traceback per REQ-0191.

, the engine shall apply synchronization token error recovery: it records `E0203` into sink $``\mathcal{D}_{\text{sink}}``$, prunes closing back-edge $``(v_k, v_1)``$ in overlay $``\mathcal{E}_{\text{overlay}}``$, and binds sentinel $``\bot_{\text{cycle}}``$, enabling independent subgraphs to continue semantic validation. If accumulated diagnostics reach capacity $``C_{\text{max\_errors}}``$, the compiler shall emit `E0199` and terminate gracefully.

## 2. Formal Invariant

Let $``\mathcal{V} \subset \mathbb{N}_{32}``$ denote 32-bit arena node handles, and let $`\mathcal{E} \subseteq \mathcal{V} \times \mathcal{V}`$ denote directed relation edges:

```math
\begin{aligned}
G_{\text{inherit}} &= (\mathcal{V}_{\text{class}}, \mathcal{E}_{\text{inherit}}) \quad \text{where } (u, v) \in \mathcal{E}_{\text{inherit}} \iff \text{Specializes}(u, v) \\
G_{\text{comp}} &= (\mathcal{V}_{\text{elem}}, \mathcal{E}_{\text{comp}}) \quad \text{where } (u, v) \in \mathcal{E}_{\text{comp}} \iff \text{Contains}(u, v) \\
G_{\text{redef}} &= (\mathcal{V}_{\text{feat}}, \mathcal{E}_{\text{redef}}) \quad \text{where } (u, v) \in \mathcal{E}_{\text{redef}} \iff \text{Redefines}(u, v)
\end{aligned}
```

Let $`\to^+`$ denote the transitive closure of directed edges, with descendants $`\text{Descendants}(v) = \{ u \in \mathcal{V} \mid v \to^+ u \}`$.

Universal Graph Acyclicity and Tarjan Singleton Invariants:

```math
\text{IsAcyclic}(G) \iff \forall v \in \mathcal{V}, \quad v \notin \text{Descendants}(v) \iff \forall C \in \text{TarjanSCC}(G), \quad (|C| = 1 \wedge \forall v \in C, \, (v, v) \notin \mathcal{E})
```

Tarjan Lowlink Recurrence and Root Condition:

```math
\text{lowlink}(u) = \min \left( \{ \text{dfn}(u) \} \cup \{ \text{lowlink}(w) \mid (u, w) \in \mathcal{E}_{\text{tree}} \} \cup \{ \text{dfn}(w) \mid (u, w) \in \mathcal{E} \setminus \mathcal{E}_{\text{tree}}, \, w \in \mathcal{S}_{\text{stack}} \} \right)
```

```math
\text{IsSCCRoot}(u) \iff \text{lowlink}(u) = \text{dfn}(u)
```

Deterministic Cycle Traceback and Diagnostic Invariants:

```math
\begin{aligned}
\exists C \in \text{TarjanSCC}(G) : (|C| \gt 1 \vee \exists v \in C, \, (v, v) \in \mathcal{E}) &\implies \text{Diagnostic}(\mathcal{P}_{\text{cycle}}, \text{E0203}) \in \mathcal{D}_{\text{sink}} \\
\mathcal{E}_{\text{overlay}} = \mathcal{E} \setminus \{ (v_k, v_1) \} &\implies \text{IsAcyclic}((\mathcal{V}, \mathcal{E}_{\text{overlay}})) \equiv \text{true} \\
\forall u \in \mathcal{V}, \quad \text{UUID}(u) &= \text{UUIDv5}(\text{NS}_{\text{DEAP}}, \text{FQN}(u))
\end{aligned}
```

where $``\mathcal{P}_{\text{cycle}} = \langle v_1, \dots, v_k, v_1 \rangle``$ with $``v_1 = \min_{v \in C} \text{Handle}(v)``$.

## 3. Computational Complexity & Algorithmic Bounds

Cycle verification operates strictly within Complexity Class $`\mathbf{P}`$.

1. Direct Arena Indexing: Auxiliary DFS state arrays (`dfn`, `lowlink`, `on_stack`) are indexed directly by 32-bit arena offset in $`O(1)`$ constant time.
2. Linear Graph Traversal: In directed graph $`G = (\mathcal{V}, \mathcal{E})`$ with $`V = |\mathcal{V}|`$ nodes and $`E = |\mathcal{E}|`$ edges, Tarjan's algorithm inspects every node and edge exactly once:

```math
T_{\text{SCC}}(V, E) \in O(V + E)
```

3. Space & Parallel Bounds: Auxiliary memory is bounded by $`O(V)`$ for DFS arrays and stack $``\mathcal{S}_{\text{stack}}``$. Parallel execution across $`M`$ components over $``N_{\text{max\_workers}}``$ threads scales as $``O((V + E) / N_{\text{max\_workers}} + M \log N_{\text{max\_workers}})``$.

Operating strictly on directed graphs via linear DFS numbering eliminates backtracking, bypassing NP-hard subtyping and scheduling frontiers (NP-1 through NP-8) and ensuring deterministic polynomial termination.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Direct Self-Specialization Cycle Detection

- **Given:** Classifier `Classifier_Alpha` declared with self-specialization `Classifier_Alpha :> Classifier_Alpha`.
- **When:** Cycle detection executes on specialization graph $``G_{\text{inherit}}``$.
- **Then:** Tarjan SCC analysis identifies a self-loop of size 1, extracts traceback $``\langle \text{Classifier\_Alpha}, \text{Classifier\_Alpha} \rangle``$, and emits diagnostic `E0203`.
- **Diagnostic:** `E0203` emitted on direct self-specialization cycle.

### AC-02: Mutual and Multi-Node Inheritance Cycle Rejection

- **Given:** An AST model declaring mutual specialization (`Classifier_Alpha :> Classifier_Beta`, `Classifier_Beta :> Classifier_Alpha`) or a 4-node circular chain ($`A :> B :> C :> D :> A`$).
- **When:** Cycle detection evaluates specialization graph $``G_{\text{inherit}}``$.
- **Then:** The engine detects the multi-node SCC, derives deterministic cycle path $``\mathcal{P}_{\text{cycle}}``$ ordered by minimum handle, and rejects compilation.
- **Diagnostic:** `E0203` emitted on cyclic inheritance chains.

### AC-03: Structural Composition and Feature Redefinition Cycle Rejection

- **Given:** An AST model where `Part_0` contains `Part_1` and `Part_1` contains `Part_0`, or where feature `Usage_1` redefines `Usage_2` (`:>>`) and `Usage_2` redefines `Usage_1`.
- **When:** Cycle detection evaluates composition graph $``G_{\text{comp}}``$ and redefinition graph $``G_{\text{redef}}``$.
- **Then:** The engine detects the cyclic dependency in each respective graph, rejects recursive instantiation, and emits diagnostic `E0203`.
- **Diagnostic:** `E0203` emitted on structural containment or feature redefinition cycles.

### AC-04: Synchronization Token Error Recovery and Overlay Pruning

- **Given:** An AST model containing two disjoint inheritance cycles alongside valid acyclic subgraphs.
- **When:** Cycle detection executes with synchronization token error recovery enabled.
- **Then:** The engine records distinct `E0203` diagnostics for both cycles in $``\mathcal{D}_{\text{sink}}``$, prunes closing back-edges in $``\mathcal{E}_{\text{overlay}}``$ substituting sentinel $``\bot_{\text{cycle}}``$, and completes semantic validation on remaining valid subgraphs.
- **Diagnostic:** `E0203` recorded per cycle; `E0199` emitted if total diagnostics reach $``C_{\text{max\_errors}}``$.
