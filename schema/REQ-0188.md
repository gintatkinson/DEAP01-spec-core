## 2. Formal Invariant

Encoding transformations, refutational proof obligations, and admissibility guardrails satisfy:

```math
\begin{aligned}
\text{UNSAT}(\mathcal{M}\land\neg\mathcal{I}_{\text{safe}})\iff\text{Valid}(\mathcal{I}_{\text{safe}}),&\quad\text{AST}(\psi)\cong\text{Parse}_{\text{SMT}}(\text{Emit}(\psi)) \\
\Phi_{\text{base}}=I(s_0)\land\neg\mathcal{I}_{\text{safe}}(s_0),&\quad\Phi_{\text{step}}=\mathcal{I}_{\text{safe}}(s)\land T(s,s')\land\neg\mathcal{I}_{\text{safe}}(s') \\
\Phi_{\text{bmc}}^{(k)}=I(s_0)\land\left(\bigwedge_{j=0}^{k-1}T(s_j,s_{j+1})\right)&\land\left(\bigvee_{j=0}^k\neg\mathcal{I}_{\text{safe}}(s_j)\right) \\
\tau(v)\notin\mathcal{T}_{\text{sorts}}&\implies\text{Diagnostic}(v,\text{E0300})\in\mathcal{D}_{\text{sink}}\land v\gets\bot_{\text{smt}} \\
(\text{Degree}(\phi)>1\lor\text{Quantifiers}(\phi)\ne\emptyset\lor\text{Theory}(\phi)\notin\mathcal{T}_{\text{decidable}})&\implies\text{Diagnostic}(\phi,\text{E0514})\in\mathcal{D}_{\text{sink}}\land\phi\gets\bot_{\text{smt}} \\
|\mathcal{D}_{\text{sink}}| \ge C_{\text{max\_errors}}&\implies\text{Diagnostic}(\text{E0199})\in\mathcal{D}_{\text{sink}} \\
\Delta_M=\text{UUIDv5}(\text{OID}_{\text{DEAP}},\text{FQN}(M)),&\quad\Delta_{\text{ob}}=\text{UUIDv5}(\text{OID}_{\text{DEAP}},\text{FQN}(M)\mathbin{\Vert}\text{"::SMTLIB2::"}\mathbin{\Vert}\text{id}_{\text{ob}})
\end{aligned}
```

## 3. Computational Complexity & Algorithmic Bounds

- **Complexity Class:** Class $\mathbf{P}$.
- **Asymptotic Bound:** Generation takes linear time $``O(|V_{\text{AST}}|)``$ and $O(1)$ heap overhead via 64 KB buffers. Work-stealing scales as $``O(|V_{\text{AST}}| / N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$.
- **Tractable Subclass and Frontier:** N/A (Deterministic P). Syntax-directed emission is polynomial, isolated from NP-8 solver complexity (REQ-0197).

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Standard SMT-LIB2 Benchmark and Invariant Synthesis
- **Given:** Model `Classifier_Alpha` with linear constraints `Constraint_0` and invariant `Invariant_0`.
- **When:** `SMTEncoder_Alpha` generates code targeting logic `QF_LRA`.
- **Then:** Emits `.smt2` script asserting `(assert (not Invariant_0))` with `(check-sat)` and `(get-model)`.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: Sort Mapping and Inductive Consecution Generation
- **Given:** Model with states `State_0`, `State_1` and transition `Transition_1`.
- **When:** `SMTEncoder_Alpha` synthesizes inductive step $``\Phi_{\text{step}}``$.
- **Then:** Emits sort `(declare-sort State_Sort 0)` with distinctness, primed variables, and transition assertions.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-03: Non-Linear Arithmetic and Quantifier Rejection
- **Given:** Constraint `Constraint_0` with non-linear product `param_x * param_y` or alternating quantifiers.
- **When:** `SMTEncoder_Alpha` checks theory admissibility before emission.
- **Then:** Halts lowering, binds sentinel $``\bot_{\text{smt}}``$, and emits `E0514`.
- **Diagnostic:** `E0514`.

### AC-04: Sort Mismatch and Delimiter Error Recovery
- **Given:** Malformed sort declaration followed by delimiter `;` and valid `Constraint_1`.
- **When:** Pipeline encounters sort fault.
- **Then:** Emits `E0300`, binds $``\bot_{\text{smt}}``$, recovers across `;`, encodes `Constraint_1`, halting at $``C_{\text{max\_errors}}``$ with `E0199`.
- **Diagnostic:** `E0300`, `E0199`.
