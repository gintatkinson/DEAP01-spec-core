## 1. Normative Statement

The ICD engine of Subsystem 8 SHALL construct the $N^2$ System Interface Matrix representing component interactions, placing internal identities on diagonal cells and directed contracts in off-diagonal cells.

---

## 2. Formal Invariant

Let $``\mathcal{V}_{\text{AST}}``$ denote AST entities and $``\mathcal{S}_{\text{intern}}``$ denote interned symbols. Interface matrix $``\mathbf{M}_{N^2}``$ satisfies:

```math
\begin{aligned}
\mathbf{M}_{N^2}=\langle\mathcal{S},\text{Index},\mathbf{M},\mathcal{C},\Delta_{\mathbf{M}}\rangle,\;\mathcal{S}=\{S_1,\dots,S_N\}\subset\mathcal{V}_{\text{AST}} \\
\forall a\ne b,\;S_a\cap S_b=\emptyset,\;S_a\prec_{\text{lex}}S_b\iff\text{Index}(S_a)\lt\text{Index}(S_b) \\
M_{ii}=S_i,\;M_{ij}=\{c\in\mathcal{C}\mid\text{source}(c)\in S_i\land\text{target}(c)\in S_j\}\;(i\ne j) \\
\forall c\in M_{ij},\;p_{\text{src}}(c)\in\text{Ports}(S_i)\land p_{\text{tgt}}(c)\in\text{Ports}(S_j)\land\text{DirMatch}(p_{\text{src}},p_{\text{tgt}}) \\
(\text{source}(c)\notin\mathcal{S}\lor\text{target}(c)\notin\mathcal{S})\implies\text{Diagnostic}(c,\text{E0200})\land c\gets\bot_{\text{icd}} \\
\neg\text{DirMatch}(p_{\text{src}}(c),p_{\text{tgt}}(c))\implies\text{Diagnostic}(c,\text{E0201})\land c\gets\bot_{\text{icd}} \\
(a\ne b\land\text{Index}(S_a)=\text{Index}(S_b))\implies\text{Diagnostic}(\mathbf{M}_{N^2},\text{E0200}) \\
|\mathcal{D}_{\text{sink}}|\ge C_{\text{max\_errors}}\implies\text{Diagnostic}_{\text{term}}(\text{E0199})\in\mathcal{D}_{\text{sink}},\;\forall x,\Delta_x=\text{UUIDv5}(\text{OID}_{\text{DEAP}},\text{FQN}(x))
\end{aligned}
```

| Symbol / Term | Domain / Formal Definition |
| :--- | :--- |
| $``\mathbf{M}_{N^2}, \mathbf{M}``$ | Interface matrix tuple and cell grid |
| $\mathcal{S}, \text{Index}$ | Subsystem roster and bijective index mapping |
| $``M_{ij}, \mathcal{C}``$ | Matrix cell and connection handles |
| $\text{DirMatch}$ | Reciprocal port directionality predicate |
| $``\bot_{\text{icd}}, \mathcal{D}_{\text{sink}}``$ | Error sentinel and diagnostic sink |
| $``\Delta_x``$ | RFC 4122 UUIDv5 topological anchor |

## 3. Computational Complexity & Algorithmic Bounds

- **Complexity Class:** Class $\mathbf{P}$ (Deterministic Polynomial Time).
- **Asymptotic Bound:** $O(N^2 + |\mathcal{C}|)$ for $N=|\mathcal{S}|$ subsystems and $|\mathcal{C}|$ connections. Sparse indexing requires $O(N\log N + |\mathcal{C}|)$; dense export requires $O(N^2 + |\mathcal{C}|)$. Work-stealing executes in $``O((N^2 + |\mathcal{C}|)/N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$. Space is $O(N^2 + |\mathcal{C}|)$.
- **Tractable Subclass & Frontier:** N/A (Deterministic P). Operates in polynomial time, avoiding NP-2 (REQ-0147) and NP-8 (REQ-0197) via relational indexing.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Canonical $N^2$ Matrix Construction
- **Given:** `Package_0` with `Subsystem_Alpha`, `Subsystem_Beta`, and `Interconnect_1`.
- **When:** Lowering interface matrix `InterfaceMatrix_0`.
- **Then:** Generates $2 \times 2$ matrix with diagonal subsystems, $``M_{12}=\{\text{Interconnect\_1}\}``$, and $``M_{21}=\emptyset``$.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: Lexicographical Indexing & Directional Placement
- **Given:** `Subsystem_Gamma` and `Subsystem_Alpha` with flows `Flow_A` and `Flow_B`.
- **When:** Subsystem sorting and coordinate assignment execute.
- **Then:** Sorts $``\text{Index}(S_{\alpha})=1, \text{Index}(S_{\gamma})=2``$; maps `Flow_A` to $``M_{12}``$ and `Flow_B` to $``M_{21}``$.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-03: Unmapped Subsystem Endpoint & Collision Rejection
- **Given:** `Interconnect_1` referencing unmapped endpoint, or conflicting coordinates.
- **When:** Validating coordinates and endpoints.
- **Then:** Halts lowering, binds sentinel $``\bot_{\text{icd}}``$, and emits `E0200`.
- **Diagnostic:** `E0200` on unmapped endpoint or collision.

### AC-04: Port Directionality Mismatch Rejection
- **Given:** `Interconnect_1` connecting incompatible directions (`in` to `in`).
- **When:** Validating port directionality.
- **Then:** Halts lowering, binds sentinel $``\bot_{\text{icd}}``$, and emits `E0201`.
- **Diagnostic:** `E0201` on port directionality violation.
