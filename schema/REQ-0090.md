## 1. Normative Statement

The compiler SHALL lower SysML v2 metadata definitions (`metadata def`, `MetadataDefinition`) as structural classifiers specializing KerML `Structure` and `Class`, and semantic annotation usages (`@`, `MetadataUsage`) as extrinsic metadata attachments linking attribute dictionaries to AST nodes without altering host execution semantics.

The lowering engine MUST enforce five core invariants:
1. **Specialization**: `MetadataDefinition` specializes KerML `Structure`, `Class`, and `Classifier` ($``\text{MetadataDef} \le \text{Structure} \le \text{Class} \le \text{Classifier}``$); action/state specialization emits `E0200`. `MetadataUsage` specializes KerML `ItemUsage` and `Feature` ($``\text{MetadataUsage} \le \text{ItemUsage} \le \text{Feature}``$).
2. **Metamodel Neutrality**: Annotations are non-intrusive. Attaching or detaching an annotation preserves host semantics ($``⟦ e ⟧ \equiv ⟦ e \mathbin{\Vert} @M ⟧``$), maintaining invariant typing and control flow.
3. **Target Conformance**: Constraint $``\tau_{\text{target}}``$ (`about`) requires $``\text{kind}(e) \le \tau_{\text{target}}``$; violations emit `E0200`.
4. **Attribute Typing & Uniqueness**: Attributes $``\mathbf{A} = (a_1 : T_1, \dots, a_p : T_p)``$ enforce typed arguments ($``\tau(v_i) \le \tau(a_i)``$); mismatches, unknown keys, or missing attributes emit `E0200`. Cycles emit `E0203`. Duplicate non-repeatable annotations emit `E0200`.
5. **Extrinsic Indexing**: Annotations populate dictionary $\alpha(h, a)$. Forward ($``\mathcal{I}_{\text{fwd}}``$) and reverse ($``\mathcal{I}_{\text{rev}}``$) indices query in amortized $O(1)$ time.

## 2. Formal Invariant

Metamodel specialization, semantic neutrality, dictionary mapping, typing, and UUIDv5 invariants:

```math
\begin{aligned}
\text{MetadataDef} &\le \text{Structure} \le \text{Class} \le \text{Classifier} \le \text{Type} \\
\text{MetadataUsage} &\le \text{ItemUsage} \le \text{Feature} \\
⟦ e ⟧ &\equiv ⟦ e \mathbin{\Vert} @M ⟧ \\
\alpha : \mathcal{V}_{\text{AST}} \times \mathcal{S}_{\text{intern}} &\longrightarrow \mathcal{V}_{\text{val}} \cup \{ \bot_{\text{none}} \} \\
\forall MU \in \mathcal{MU}, \forall (a \mapsto v) \in \mathbf{V}_{MU}, \quad &\alpha(h_{\text{target}}(MU), a) = v \;\wedge\; \tau(v) \le \tau(a) \\
\tau_{\text{target}}(\tau(MU)) \ne \top_{\text{any}} &\implies \text{kind}(h_{\text{target}}(MU)) \le \tau_{\text{target}}(\tau(MU)) \\
(h_{\text{target}}(MU_1) = h_{\text{target}}(MU_2) \;\wedge\; \tau(MU_1) &= \tau(MU_2) \;\wedge\; \kappa_{\text{rep}} = \text{Unique}) \implies MU_1 = MU_2 \\
\forall n \in \mathcal{MD} \cup \mathcal{MU}, \quad \Delta_n &= \text{UUIDv5}(\text{NS}_{\text{DEAP}}, \text{FQN}(n))
\end{aligned}
```

## 3. Computational Complexity & Algorithmic Bounds

- **Complexity Class:** Class $\mathbf{P}$ (Deterministic Polynomial Time)
- **Asymptotic Bound:** $``O(V + N_{\text{MD}} + N_{\text{MU}})``$ AST lowering and indexing time. Extrinsic dictionary query $\alpha(h, a)$ and forward lookup $``\mathcal{I}_{\text{fwd}}(h)``$ execute in amortized $O(1)$ time; reverse lookup $``\mathcal{I}_{\text{rev}}(MD)``$ in $``O(|\mathcal{I}_{\text{rev}}(MD)|)``$ time.
- **Tractable Subclass & Frontier:** Subtyping conformance checks evaluate in $O(1)$ time via bitset operations over the precomputed poset closure (NP-3 fragment). Parallel work-stealing across $``N_{\text{max\_workers}}``$ threads scales as $``O((V + N_{\text{MD}} + N_{\text{MU}}) / N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Canonical Metadata Lowering and Annotation
- **Given:** Package `Package_0` declaring `metadata def MetadataDef_Alpha { attr attr_1 : Integer; }` and `@MetadataDef_Alpha(attr_1 = 42) part def Classifier_Alpha;`.
- **When:** Lowering and symbol resolution execute.
- **Then:** `MetadataDef_Alpha` lowers as KerML `Structure`, attribute bindings populate dictionary $\alpha$, and diagnostic sink remains empty.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: Target Metaclass Restriction Enforcement
- **Given:** Definition `MetadataDef_Alpha` restricting target to `Feature` (`about Feature`), and `part def Classifier_Alpha;` annotated with `@MetadataDef_Alpha`.
- **When:** Metaclass target conformance validation executes.
- **Then:** Lowering detects `Classifier_Alpha` is not a feature, rejects attachment, and emits `E0200`.
- **Diagnostic:** `E0200` (Invalid annotated element target).

### AC-03: Attribute Type Incompatibility Rejection
- **Given:** Usage `@MetadataDef_Alpha(attr_1 = "invalid") part def Classifier_Alpha;` where `attr_1` expects `Integer`.
- **When:** Attribute argument type-checking executes.
- **Then:** Lowering detects type mismatch ($``\text{String} \not\le \text{Integer}``$), substitutes sentinel $``\bot_{\text{meta}}``$, and emits `E0200`.
- **Diagnostic:** `E0200` (Metadata attribute type mismatch).

### AC-04: Delimiter Synchronization and Error Recovery
- **Given:** Source buffer with malformed `@UnresolvedDef(err;;) part def Classifier_Beta;` preceding valid `part def Classifier_Alpha;`.
- **When:** Parsing and synchronization error recovery execute.
- **Then:** Parser resynchronizes on delimiters, records `E0200`, lowers `Classifier_Alpha`, and emits `E0199` upon reaching $``C_{\text{max\_errors}}``$.
- **Diagnostic:** `E0200` on syntax/resolution fault; `E0199` on error threshold overflow.
