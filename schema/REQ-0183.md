## 1. Normative Statement

Subsystem 10 SHALL synthesize OMG DDS IDL schemas (`IDL_0`) and CDR codecs (`CDR_Codec_1`) from AST structures (`Struct_Alpha`) via `DdsGenerator_Alpha`.

---

## 2. Formal Invariant

Let $``\mathcal{S}_{\text{AST}}``$ denote composite AST structures and $\mathbf{W}$ the serialized CDR wire buffer. The schema emission and codec layout invariants satisfy:

```math
\begin{aligned}
\forall S\in\mathcal{S}_{\text{AST}},\quad S&=\langle\text{id}_S,\text{name}_S,\mathbf{\Phi}_S,\Delta_S\rangle,\quad\phi_i=\langle\text{id}_i,\text{name}_i,\tau_i,\text{is\_key}_i,\Delta_i\rangle \\
A(\tau_i)&=\min(8,\text{sizeof}(\tau_i)),\quad A(S)=\max_{\phi_i\in\mathbf{\Phi}_S}A(\tau_i) \\
\text{PadBytes}(\phi_i)&=\left(A(\tau_i)-(\text{Offset}_{\text{raw}}(\phi_i)\pmod{A(\tau_i)})\right)\pmod{A(\tau_i)} \\
\text{Offset}(\phi_i)&=\text{Offset}_{\text{raw}}(\phi_i)+\text{PadBytes}(\phi_i)\implies\text{Offset}(\phi_i)\equiv 0\pmod{A(\tau_i)} \\
\mathbf{W}&=\mathbf{H}_{\text{encap}}\mathbin{\Vert}\mathbf{P}_{\text{payload}},\quad|\mathbf{H}_{\text{encap}}|=4,\quad\forall j<\text{PadBytes}(\phi_i):\mathbf{P}_{\text{payload}}[\text{pad}_j]=0x00 \\
\forall x\in\mathcal{D}_S,\quad&\text{Deserialize}_S(\text{Serialize}_S(x))\equiv x\land\text{HeapAllocations}(\text{Codec})=0 \\
(\text{IsReserved}(\text{name}_i)\lor\tau_i\notin\mathcal{T}_{\text{IDL}})&\implies\text{Diagnostic}(\phi_i,\text{E0300})\in\mathcal{D}_{\text{sink}}\land\phi_i\gets\bot_{\text{idl}} \\
(|\mathbf{W}|>C_{\text{buf}}\lor\text{IsUnbounded}(\tau_i))&\implies\text{Diagnostic}(S,\text{E0509})\in\mathcal{D}_{\text{sink}}\land S\gets\bot_{\text{cdr}} \\
|\mathcal{D}_{\text{sink}}| \ge C_{\text{max\_errors}}&\implies\text{Diagnostic}(\text{E0199})\in\mathcal{D}_{\text{sink}} \\
\Delta_S=\text{UUIDv5}(\text{OID}_{\text{DEAP}},\text{FQN}(S)),&\quad\Delta_i=\text{UUIDv5}(\text{OID}_{\text{DEAP}},\text{FQN}(S)\mathbin{\Vert}\text{"::"}\mathbin{\Vert}\text{name}_i)
\end{aligned}
```

| Symbol / Term | Domain / Formal Definition |
| :--- | :--- |
| $``\mathcal{S}_{\text{AST}}, S, \phi_i``$ | Lowered AST structures, struct tuple, field descriptor |
| $A(\tau), A(S)$ | Natural alignment of type $\tau$ and struct $S$ |
| $``\text{PadBytes}(\phi_i)``$ | Zero-valued padding count preceding field $``\phi_i``$ |
| $``\mathbf{W}, \mathbf{H}_{\text{encap}}, \mathbf{P}_{\text{payload}}``$ | Wire buffer, 4-byte header, serialized payload |
| $``\bot_{\text{idl}}, \bot_{\text{cdr}}, \mathcal{D}_{\text{sink}}``$ | Failure sentinels, diagnostic error sink |
| $``C_{\text{buf}}, C_{\text{max\_errors}}, \Delta_S``$ | Buffer capacity, error bound, UUIDv5 anchor |

## 3. Computational Complexity & Algorithmic Bounds

- **Complexity Class:** Class $\mathbf{P}$ (Deterministic Polynomial Time).
- **Asymptotic Bound:** Schema emission runs in $O(|S|)$ for fields $``|S|=\sum|\mathbf{\Phi}_S|``$. Serialization runs in $O(|B|)$ for wire length $|B|$. Work-stealing scales as $``O(|S|/N_{\text{max\_workers}})``$. Space is $O(|S|)$ with $O(1)$ heap.
- **Tractable Subclass and Frontier:** N/A (Deterministic P). Bypasses NP-1 intervals (REQ-0117), NP-2 packing (REQ-0147), and NP-8 solving (REQ-0197).

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: IDL Schema Generation and Key Annotation
- **Given:** `Struct_Alpha` with `Field_0` and key `Field_1`.
- **When:** Lowering `IDL_0` via `DdsGenerator_Alpha`.
- **Then:** Emits IDL v4.2 syntax with `@key` and UUIDv5 anchors.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: CDR Natural Alignment and Zero Padding Boundary
- **Given:** `Struct_Alpha` with 8-bit `Field_0` and 64-bit `Field_1`.
- **When:** `CDR_Codec_1` serializes payload into wire buffer.
- **Then:** Satisfies $``\text{Offset}(\phi_i) \equiv 0 \pmod{A_i}``$, inserting 7 zero bytes (`0x00`).
- **Diagnostic:** Diagnostic sink remains empty.

### AC-03: Buffer Overflow and Unbounded Type Rejection
- **Given:** Unbounded sequence in freestanding profile, or buffer $``C_{\text{buf}} < |\mathbf{W}|``$.
- **When:** Validating layout or serializing payload.
- **Then:** Fails closed, binds sentinel $``\bot_{\text{cdr}}``$, emitting `E0509`.
- **Diagnostic:** `E0509`.

### AC-04: IDL Keyword Collision and Delimiter Recovery
- **Given:** Field `interface` colliding with keyword, delimiter `;`, and `Field_1`.
- **When:** Lowering fields across delimiters.
- **Then:** Emits `E0300`, recovers at `;`, parses `Field_1`, halting at $``C_{\text{max\_errors}}``$ with `E0199`.
- **Diagnostic:** `E0300`, `E0199`.
