## 1. Normative Statement

The compiler metamodel lowering engine shall define and enforce the foundational KerML abstract syntax root hierarchy as a rooted directed multigraph of semantic elements $`\mathcal{E}`$, directed relationships $`\mathcal{R} \subseteq \mathcal{E}`$, metadata annotations $`\mathcal{M} \subseteq \mathcal{E}`$, and containment ownership relations $`\mathcal{O} \subset \mathcal{E} \times \mathcal{E}`$, with `Element` as the universal root entity.

A `Relationship` ($`r \in \mathcal{R}`$) specializes `Element`, connecting non-empty source ($`\text{source}(r) \subseteq \mathcal{E}`$) and target ($`\text{target}(r) \subseteq \mathcal{E}`$) endpoints. Directed non-reflexive relationships require $`\text{source}(r) \cap \text{target}(r) = \emptyset`$. Empty, reflexive, or dangling endpoints shall emit diagnostic `E0200` per REQ-0191.

Containment $`\mathcal{O}`$ forms a strict directed forest enforcing single ownership ($`\forall v \in \mathcal{E}, |\text{owner}(v)| \le 1`$). Cycles ($`(e, e) \in \mathcal{O}^+`$) are prohibited; detected cycles shall emit diagnostic `E0203` with cycle path $``\mathcal{P}_{\text{cycle}}``$ per REQ-0042. Conflicting multiple ownership shall emit `E0200`.

`Annotation` ($`\alpha \in \mathcal{M}`$) specializes `Element`, attaching metadata such that $`⟦ e \oplus \alpha ⟧ \equiv ⟦ e ⟧`$.

## 2. Formal Invariant

Let $``\mathcal{V}_{\text{arena}} \subset \mathbb{N}_{32}``$ denote contiguous arena slot handles. The KerML root multigraph is:

```math
G_{\text{KerML}} = \langle \mathcal{E}, \mathcal{R}, \mathcal{M}, \mathcal{O} \rangle, \quad \mathcal{R} \subseteq \mathcal{E}, \quad \mathcal{M} \subseteq \mathcal{E}, \quad \mathcal{O} \subset \mathcal{E} \times \mathcal{E}
```

Every element $`e \in \mathcal{E}`$ is an immutable tuple:

```math
e = \langle \text{id}_e, \text{name}_e, \text{owner}_e, \mathcal{C}_e, \mathcal{A}_e, \Delta_e, \text{span}_e \rangle
```

where $``\text{id}_e \in \mathcal{V}_{\text{arena}}``$, $``\text{name}_e \in \mathcal{S}_{\text{intern}} \cup \{ \bot \}``$, $``\text{owner}_e \in \mathcal{E} \cup \{ \bot \}``$, $``\mathcal{C}_e \subseteq \mathcal{E}``$, $``\mathcal{A}_e \subseteq \mathcal{M}``$, $``\Delta_e = \text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(e))``$, and $``\text{span}_e``$ is lexical provenance.

Relationship endpoint invariants:

```math
\begin{aligned}
\text{directed}(r) &\implies (\text{source}(r) \neq \emptyset) \wedge (\text{target}(r) \neq \emptyset) \wedge (\text{source}(r) \cap \text{target}(r) = \emptyset) \\
\forall u &\in (\text{source}(r) \cup \text{target}(r)), \quad \text{IsAllocated}(\text{id}(u)) \equiv \text{true}
\end{aligned}
```

Ownership forest and acyclicity invariants:

```math
\forall v \in \mathcal{E}, \quad |\{ u \in \mathcal{E} \mid (u, v) \in \mathcal{O} \}| \le 1 \quad \wedge \quad (v, v) \notin \mathcal{O}^+
```

```math
\forall u, v \in \mathcal{E}, \quad (u, v) \in \mathcal{O} \iff v \in \mathcal{C}_u \iff \text{owner}(v) = u
```

Annotation non-interference:

```math
\forall e \in \mathcal{E}, \; \forall \alpha \in \mathcal{M}, \quad ⟦ e \oplus \alpha ⟧ \equiv ⟦ e ⟧
```

Diagnostic trigger mappings per REQ-0191:

```math
\begin{aligned}
\text{source}(r) = \emptyset \vee \text{target}(r) = \emptyset \vee (\text{source}(r) \cap \text{target}(r) \neq \emptyset) &\implies \text{Diagnostic}(r, \text{E0200}) \in \mathcal{D}_{\text{sink}} \\
\exists u \in (\text{source}(r) \cup \text{target}(r)), \, \neg\text{IsAllocated}(\text{id}(u)) &\implies \text{Diagnostic}(r, \text{E0200}) \in \mathcal{D}_{\text{sink}} \\
|\{ u \in \mathcal{E} \mid (u, v) \in \mathcal{O} \}| \gt 1 &\implies \text{Diagnostic}(v, \text{E0200}) \in \mathcal{D}_{\text{sink}} \\
(e, e) \in \mathcal{O}^+ &\implies \text{Diagnostic}(\mathcal{P}_{\text{cycle}}, \text{E0203}) \in \mathcal{D}_{\text{sink}} \\
|\mathcal{D}_{\text{sink}}| \ge C_{\text{max\_errors}} &\implies \text{DiagnosticCode::E0199} \in \mathcal{D}_{\text{sink}}
\end{aligned}
```

## 3. Computational Complexity & Algorithmic Bounds

KerML root abstract syntax lowering, relationship endpoint validation, and containment cycle checking execute strictly within Complexity Class $`\mathbf{P}`$.

Contiguous AST memory slot allocation and handle dereferencing execute in deterministic $`O(1)`$ constant time with zero pointer indirection. Endpoint validation for bounded endpoints ($``K_{\text{src}}, K_{\text{tgt}} \le 16``$) requires $`O(1)`$ per relationship, yielding $`O(|\mathcal{R}|)`$ total endpoint validation time.

Single ownership verification requires $`O(1)`$ time per element, bounding model checks to $`O(|\mathcal{E}|)`$. Tarjan strongly connected components (SCC) cycle detection on containment forest $``G_{\text{own}} = (\mathcal{E}, \mathcal{O})``$ evaluates in deterministic linear time $`O(|\mathcal{E}| + |\mathcal{O}|) \subseteq O(|\mathcal{E}|)`$ since $`|\mathcal{O}| \le |\mathcal{E}|`$. Annotation attachment and lookup execute in $`O(1)`$ amortized and $``O(|\mathcal{A}_e|)``$ linear time. Parallel lowering over $``N_{\text{max\_workers}}``$ threads scales as $``O((|\mathcal{E}| + |\mathcal{R}| + |\mathcal{M}|) / N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$. Arena memory footprint is bounded by $`O(|\mathcal{E}| + |\mathcal{R}| + |\mathcal{M}|)`$, with stack depth bounded by $``O(D_{\max}) \le 64``$ frames.

NP Frontier Reference: Decoupled from NP-hard combinatorial frontiers (NP-1 through NP-8); all root structural graph checks evaluate deterministically in linear time $`O(V + E)`$ without backtracking.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Universal Root Element Allocation and Deterministic Identity
- **Given:** Abstract model declaring `Package_0` and `Classifier_Alpha`.
- **When:** Lowering allocates entities into the contiguous AST memory.
- **Then:** Every element occupies an AST handle ($`\text{PointerIndirectionDepth} = 0`$), assigns an interned scalar `SymbolId`, and receives an RFC 4122 UUIDv5 identifier from $``\text{OID}_{\text{DEAP}}``$ and $`\text{FQN}(e)`$.
- **Diagnostic:** `E0200` emitted on handle exhaustion, alignment fault, or invalid topological identifier formatting.

### AC-02: Directed Relationship Endpoints and Non-Reflexivity Validation
- **Given:** Model declaring relationship `Rel_Alpha` with source $``\{ \text{Element\_Alpha} \}``$ and target $``\{ \text{Element\_Beta} \}``$.
- **When:** Relationship endpoint validation executes.
- **Then:** Endpoints are verified as non-empty, mutually disjoint ($`\text{source} \cap \text{target} = \emptyset`$), and allocated in active arena storage without emitting diagnostics.
- **Diagnostic:** `E0200` emitted if endpoints are empty, reflexive, or unallocated.

### AC-03: Structural Containment, Single Ownership, and Cycle Recovery
- **Given:** Containment hierarchy with single ownership and an injected cycle $``\langle \text{Package\_0}, \text{Element\_Alpha}, \text{Package\_0} \rangle``$.
- **When:** Containment validation and cycle analysis execute.
- **Then:** Conflicting owners ($`|\text{owner}| \gt 1`$) trigger `E0200`; cycles ($`(e, e) \in \mathcal{O}^+`$) trigger `E0203` with cycle path reconstruction, and synchronization token recovery severs the back-edge.
- **Diagnostic:** `E0200` for multiple owners; `E0203` for containment cycles; `E0199` upon exhausting $``C_{\text{max\_errors}}``$.

### AC-04: Non-Intrusive Annotation Semantics and Type Invariance
- **Given:** Semantic element `Element_Alpha` with denotation $``⟦ \text{Element\_Alpha} ⟧``$.
- **When:** Metadata annotation `Annotation_0` is attached to `Element_Alpha`.
- **Then:** Algebraic type denotation satisfies $``⟦ \text{Element\_Alpha} \oplus \text{Annotation\_0} ⟧ \equiv ⟦ \text{Element\_Alpha} ⟧``$, preserving subtyping and operational semantics without alteration.
- **Diagnostic:** `E0200` emitted if metadata alters type denotation or triggers semantic evaluation side-effects.
