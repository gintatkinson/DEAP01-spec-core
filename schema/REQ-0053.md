## 1. Normative Statement

The compilation persistence engine shall maintain a centralized artifact manifest (`CodegenManifest`) and execute automated tombstone pruning (`prune_tombstones`) during each compilation pass. When any AST element (such as `Package_0`, `Classifier_Alpha`, or `Port_1`) is deleted, renamed, or relocated, the engine shall compute the exact set difference between previous manifest paths $``\mathcal{A}_{\text{manifest}}``$ and active output paths $``\mathcal{A}_{\text{active}}``$, producing the tombstone pruning set $``\mathcal{T}_{\text{prune}} = \mathcal{A}_{\text{manifest}} \setminus \mathcal{A}_{\text{active}}``$.

The engine shall enforce strict filesystem path confinement for every $``f \in \mathcal{T}_{\text{prune}}``$: paths must resolve within output root $``\mathcal{W}_{\text{out}}``$, contain zero parent traversal segments (`..`), and never escape $``\mathcal{W}_{\text{out}}``$ via symlinks. Unconfined paths shall trigger diagnostic error code `E0200` without unlinking.

For each validated path, the engine shall atomically unlink the file. External pre-deletion shall be treated as an idempotent no-op. If filesystem permissions or I/O locks prevent deletion, the engine shall record diagnostic error code `E0200` and continue processing remaining tombstones without panicking.

Following file unlinking, the engine shall recursively delete empty parent directories up to $``\mathcal{W}_{\text{out}}``$, terminating upon encountering non-empty directories.

## 2. Formal Invariant

Let $``\mathcal{W}_{\text{out}}``$ denote the workspace output root directory, and let $``\mathcal{P}_{\text{rel}}``$ denote normalized relative paths:

```math
\mathcal{P}_{\text{rel}} = \{ p \in \Sigma^* \mid \neg\text{HasTraversalPrefix}(p) \;\wedge\; \text{NormalizePath}(p) = p \}
```

Output confinement requires:

```math
\forall p \in \mathcal{P}_{\text{rel}}, \quad \text{IsDescendant}(\text{Resolve}(\mathcal{W}_{\text{out}}, p), \mathcal{W}_{\text{out}}) \equiv \text{true}
```

Let manifest $``\mathcal{M} = \{ \langle p, u, h, s \rangle \mid p \in \mathcal{P}_{\text{rel}}, \, u \in \mathcal{U}_{\text{UUIDv5}}, \, h \in \{0, 1\}^{64}, \, s \in \mathbb{N}_0 \}``$ where $``u = \text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(v))``$, $``h = \text{XXH3}_{64}(B)``$, and $`s = |B|`$. With path projection $``\pi_{\text{path}}(\mathcal{M})``$, let $``\mathcal{A}_{\text{manifest}} = \pi_{\text{path}}(\mathcal{M}_{\text{prev}})``$ and active output set $``\mathcal{A}_{\text{active}} \subset \mathcal{P}_{\text{rel}}``$. The tombstone set satisfies:

```math
\mathcal{T}_{\text{prune}} = \mathcal{A}_{\text{manifest}} \setminus \mathcal{A}_{\text{active}}
```

Safe idempotent unlinking:

```math
\text{UnlinkFile}(p) = \begin{cases}
\text{true}, & \text{if } \neg\text{FileExists}(\text{Resolve}(\mathcal{W}_{\text{out}}, p)) \;\vee\; \text{Unlink}(\text{Resolve}(\mathcal{W}_{\text{out}}, p)) = \text{OK} \\
\text{false}, & \text{if } \text{Unlink}(\text{Resolve}(\mathcal{W}_{\text{out}}, p)) = \text{Err}(e)
\end{cases}
```

Recursive directory pruning:

```math
\text{CleanEmptyParentDirs}(d) = \begin{cases}
0, & \text{if } d = \mathcal{W}_{\text{out}} \;\vee\; \neg\text{DirExists}(d) \;\vee\; |\text{Entries}(d)| \gt 0 \\
1 + \text{CleanEmptyParentDirs}(\text{Parent}(d)), & \text{if } |\text{Entries}(d)| = 0 \;\wedge\; \text{Rmdir}(d) = \text{OK}
\end{cases}
```

Manifest synchronization and tree cleanliness invariant:

```math
\begin{aligned}
\forall p \in \mathcal{T}_{\text{prune}}, &\quad \text{FileExists}(\text{Resolve}(\mathcal{W}_{\text{out}}, p)) \equiv \text{false} \\
\pi_{\text{path}}(\mathcal{M}_{\text{updated}}) &\equiv \mathcal{A}_{\text{active}} \;\wedge\; \pi_{\text{path}}(\mathcal{M}_{\text{updated}}) \cap \mathcal{T}_{\text{prune}} = \emptyset
\end{aligned}
```

Diagnostic error binding:

```math
\neg\text{IsDescendant}(\text{Resolve}(\mathcal{W}_{\text{out}}, p), \mathcal{W}_{\text{out}}) \;\vee\; \text{UnlinkFile}(p) = \text{false} \implies \text{Diagnostic}(p, \text{E0200}) \in \mathcal{D}_{\text{sink}}
```

## 3. Computational Complexity & Algorithmic Bounds

The tombstone pruning engine executes strictly within Complexity Class $`\mathbf{P}`$. For $``N_{\text{prev}} = |\mathcal{A}_{\text{manifest}}|``$ and $``N_{\text{act}} = |\mathcal{A}_{\text{active}}|``$, hash set insertion and set difference evaluate in $``O(N_{\text{prev}} + N_{\text{act}})``$ linear time. Unlinking $``K = |\mathcal{T}_{\text{prune}}|``$ files executes in $`O(K)`$ filesystem operations, and empty directory cleanup ascends bounded depth $``D_{\max} \le 32``$ in $``O(K \cdot D_{\max})``$ steps. Total sequential runtime satisfies:

```math
T_{\text{total}} \in O(N_{\text{prev}} + N_{\text{act}} + K \cdot D_{\max}) \subseteq O(N_{\text{prev}} + N_{\text{act}})
```

Parallel execution over $``N_{\text{max\_workers}}``$ threads scales as $``O((N_{\text{prev}} + N_{\text{act}}) / N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$. Memory footprint is bounded by $``O((N_{\text{prev}} + N_{\text{act}}) \cdot \bar{L}_{\text{path}})``$, with stack depth bounded by $``O(D_{\max}) \le 32``$ frames.

NP Frontier Reference: Decoupled from NP-hard combinatorial frontiers (NP-1 through NP-8); all set operations and directory traversals evaluate deterministically in polynomial time without backtracking.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Classifier Renaming and Tombstone Pruning
- **Given:** Model containing `Package_0::Classifier_Alpha` with manifested artifacts $``\mathcal{A}_{\text{manifest}}``$, where `Classifier_Alpha` is renamed to `Package_0::Classifier_Beta`.
- **When:** Code generation invokes `prune_tombstones`.
- **Then:** Obsolete files for `Classifier_Alpha` are added to $``\mathcal{T}_{\text{prune}}``$ and unlinked ($`\text{FileExists} \equiv \text{false}`$), new files exist, and $``\mathcal{A}_{\text{manifest}}^{\text{updated}}``$ records strictly active files.
- **Diagnostic:** `E0200` emitted on unlinking failure or residual obsolete files.

### AC-02: Element Deletion and Recursive Directory Pruning
- **Given:** Model containing `Package_0::SubPackage_1::Classifier_Alpha` whose output directory `generated/Package_0/SubPackage_1/` contains strictly files from `Classifier_Alpha`.
- **When:** `Classifier_Alpha` is deleted and compilation executes.
- **Then:** All generated files are unlinked, empty directory `generated/Package_0/SubPackage_1/` is deleted, and non-empty ancestor `generated/Package_0/` is preserved.
- **Diagnostic:** `E0200` emitted on directory deletion failure.

### AC-03: Workspace Output Confinement and Traversal Rejection
- **Given:** A manifest entry containing traversal tokens (`../Package_0/Escaped.sysml`).
- **When:** `prune_tombstones` validates paths prior to unlinking.
- **Then:** Resolution rejects unconfined paths ($`\text{IsDescendant} \equiv \text{false}`$), zero unlinking syscalls are issued, and compilation proceeds.
- **Diagnostic:** `E0200` emitted on traversal violation.

### AC-04: Idempotent Unlinking and Non-Panicking Fault Tolerance
- **Given:** An orphaned file in $``\mathcal{T}_{\text{prune}}``$ that is missing or has read-only permissions (`EACCES`).
- **When:** `prune_tombstones` attempts unlinking.
- **Then:** Missing files succeed as idempotent no-ops; permission faults record `E0200` and pruning continues without panicking.
- **Diagnostic:** `E0200` emitted on filesystem permission or I/O failure.
