## 1. Normative Statement

The downstream projection engine of Subsystem 9 SHALL synthesize a specification manifest (`Manifest_Alpha`) and verification ledger (`HashLedger_0`) covering all emitted artifacts ($\mathcal{A}$).

---

## 2. Formal Invariant

Let $``\mathcal{A} = \{ a_1, \dots, a_N \}``$ be the emitted specification artifacts. The manifest and ledger invariants satisfy:

```math
\begin{aligned}
\forall a\in\mathcal{A},\quad\text{Entry}(a)&=\langle\mathcal{P}_{\text{rel}}(a),\tau_a,S_a,h_a,\Delta_a\rangle \\
h_a=\text{Digest}(\text{Bytes}(a))\in\{0,1\}^{256},&\quad S_a=|\text{Bytes}(a)|\in\mathbb{N}^+ \\
\mathcal{P}_{\text{rel}}(a_1)\prec_{\text{lex}}\dots\prec_{\text{lex}}\mathcal{P}_{\text{rel}}(a_N),&\quad H_{\text{root}}=\text{Digest}\left(\bigoplus_{i=1}^N(\mathcal{P}_{\text{rel}}(a_i)\mathbin{\Vert}\text{Hex}(h_{a_i}))\right) \\
\Delta_a&=\text{UUIDv5}(\text{OID}_{\text{DEAP}},\mathcal{P}_{\text{rel}}(a)\mathbin{\Vert}\text{"::Manifest"}) \\
\neg\text{IsValidRelPath}(\mathcal{P}_{\text{rel}}(a))&\implies\text{Diagnostic}(a,\text{E0300})\in\mathcal{D}_{\text{sink}}\land\text{Entry}(a)\gets\bot_{\text{path}} \\
h_a\ne h_a^{\text{actual}}&\implies\text{Diagnostic}(a,\text{E0316})\in\mathcal{D}_{\text{sink}}\land\text{Ledger}\gets\bot_{\text{ledger}} \\
|\mathcal{D}_{\text{sink}}|\ge C_{\text{max\_errors}}&\implies\text{Diagnostic}(\text{E0199})\in\mathcal{D}_{\text{sink}}
\end{aligned}
```

| Symbol / Term | Domain / Formal Definition |
| :--- | :--- |
| $``\mathcal{A}, a, \mathcal{P}_{\text{rel}}(a), \tau_a``$ | Artifact set, element, relative path, and type handle |
| $``S_a, h_a, H_{\text{root}}``$ | Byte size, 256-bit artifact digest, and composite root hash |
| $``\Delta_a, \text{OID}_{\text{DEAP}}``$ | RFC 4122 UUIDv5 anchor and canonical namespace OID |
| $``\bot_{\text{path}}, \bot_{\text{ledger}}, \mathcal{D}_{\text{sink}}, C_{\text{max\_errors}}``$ | Error sentinels, diagnostic sink, and error capacity limit |

## 3. Computational Complexity & Algorithmic Bounds

- **Complexity Class:** Class $\mathbf{P}$ (Deterministic Polynomial Time).
- **Asymptotic Bound:** $O(|\mathcal{A}| \cdot \text{size})$ for artifacts $\mathcal{A}$ of average byte size $\text{size}$. Streaming evaluation executes in $``O(S_a)``$; sorting takes $O(|\mathcal{A}| \log |\mathcal{A}|)$; root hashing takes $O(|\mathcal{A}| \cdot K)$ ($K = 32$ bytes). Work-stealing scales as $``O((|\mathcal{A}| \cdot \text{size})/N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$. Arena space is $O(|\mathcal{A}|)$.
- **Tractable Subclass and Frontier:** N/A (Deterministic P). Ledger hashing avoids NP-1 intervals (REQ-0117), NP-2 packing (REQ-0147), and NP-8 solving (REQ-0197).

---

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Canonical Manifest and Cryptographic Ledger Generation
- **Given:** Model with specification artifacts (`Artifact_Alpha`) in `Package_0`.
- **When:** Lowering `Manifest_Alpha` and `HashLedger_0`.
- **Then:** Emits relative paths, sizes, digests (`Digest_1`), root hash $``H_{\text{root}}``$, and UUIDv5 anchors.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: Boundary Artifact Size and Large Manifest Scaling
- **Given:** Artifact `Artifact_0` of $16\text{ MB}$ within $10^4$ artifacts.
- **When:** Computing digests and aggregating ledger entries.
- **Then:** Processes artifacts within $O(|\mathcal{A}| \cdot \text{size})$ bounds without memory exhaustion.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-03: Tamper Detection and Hash Mismatch Rejection
- **Given:** Ledger `HashLedger_0` where `Artifact_Alpha` is modified by 1 byte.
- **When:** Validating manifest integrity.
- **Then:** Fails closed, emits `E0316` (`HashVerificationMismatch`), and binds sentinel $``\bot_{\text{ledger}}``$.
- **Diagnostic:** `E0316`.

### AC-04: Malformed Relative Path and Delimiter Recovery
- **Given:** Artifact with absolute path `"/opt/spec.md"`, delimiter `|`, and `Artifact_Beta`.
- **When:** Recovering across delimiter boundaries.
- **Then:** Emits `E0300`, recovers on `|`, parses `Artifact_Beta`, halting at $``C_{\text{max\_errors}}``$ with `E0199`.
- **Diagnostic:** `E0300`, `E0199`.
