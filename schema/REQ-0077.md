## 1. Normative Statement

The SysML v2 lowering engine SHALL formalize allocation definitions (`allocation def`) and usages (`allocate... to...`, `AllocationUsage`) as a typed bipartite relation from behavioral source elements to structural target elements. `AllocationDefinition` SHALL specialize KerML `ConnectionDefinition`, and `AllocationUsage` SHALL specialize `ConnectionUsage`.

The lowering engine MUST enforce bipartite domain disjointness, structural port consistency, and dependency acyclicity:
1. **Bipartite Disjointness**: Allocations $``U_{\text{alloc}}``$ MUST bind actions $``u_{\text{src}} \in V_S``$ to parts $``u_{\text{tgt}} \in V_T``$ ($``V_S \cap V_T = \emptyset``$). Inverted or reflexive allocations ($``u_{\text{src}} = u_{\text{tgt}}``$) SHALL emit diagnostic `E0200`.
2. **Port Consistency**: Allocating $``u_{\text{src}}``$ to $``u_{\text{tgt}}``$ requires each port $``p_s \in \text{Ports}(u_{\text{src}})``$ to map to port $``p_t \in \text{Ports}(u_{\text{tgt}})``$ with identical direction ($``\text{dir}(p_t) = \text{dir}(p_s)``$) and covariant payload ($``\tau(p_s) \le \tau(p_t)``$). Mismatches SHALL emit diagnostic `E0200`.
3. **Multiplicity Bounds**: Multiplicity intervals $``\mu(U) = [m_{\min}, m_{\max}]``$ MUST satisfy $``0 \le m_{\min} \le m_{\max}``$. Inverted intervals SHALL emit `E0200`.
4. **Dependency Acyclicity**: Circular allocation chains in $``E_{\text{alloc}}^+``$ SHALL emit diagnostic `E0203`.

## 2. Formal Invariant

Metamodel subtyping taxonomy and bipartite allocation mapping invariants:

```math
\begin{aligned}
\text{AllocationDefinition} \le \text{ConnectionDefinition} &\le \text{Classifier}, \quad \text{AllocationUsage} \le \text{ConnectionUsage} \le \text{Feature} \\
V_S \cap V_T = \emptyset, \quad \forall (s,t) &\in E_{\text{alloc}} : s \in V_S \wedge t \in V_T \wedge s \ne t \\
\forall p_s \in \text{Ports}(s), \, \exists ! p_t &\in \text{Ports}(t) : \text{dir}(p_t) = \text{dir}(p_s) \wedge \tau(p_s) \le \tau(p_t) \\
\forall v \in V_S \cup V_T, \, (v,v) \notin E_{\text{alloc}}^+, &\quad \forall n \in \mathcal{D}_{\text{alloc}} \cup \mathcal{U}_{\text{alloc}} : \Delta_n = \text{UUIDv5}(\text{NS}_{\text{DEAP}}, \text{FQN}(n))
\end{aligned}
```

| Symbol / Term | Domain / Formal Definition |
| :--- | :--- |
| $``\mathcal{D}_{\text{alloc}}, \mathcal{U}_{\text{alloc}}``$ | Lowered `AllocationDefinition` and `AllocationUsage` records |
| $``V_S, V_T``$ | Disjoint source and target sets ($``V_S \cap V_T = \emptyset``$) |
| $``E_{\text{alloc}}``$ | Bipartite allocation relation edges $``E_{\text{alloc}} \subseteq V_S \times V_T``$ |
| $\text{Ports}(v)$ | Interaction ports declared on element $v$ |

| $``E_{\text{alloc}}^+``$ | Transitive closure of the allocation dependency graph |
| $``\Delta_n``$ | Deterministic RFC 4122 UUIDv5 hash from $``\text{NS}_{\text{DEAP}}``$ and FQN |

## 3. Computational Complexity & Algorithmic Bounds

Allocation lowering, bipartite validation, port consistency, and acyclicity passes execute in Complexity Class $\mathbf{P}$:
- Record allocation, symbol interning, and bipartite tagging execute in $O(1)$ amortized time per element, totaling $O(V + E)$ for $``V = |V_S| + |V_T|``$ elements and $``E = |E_{\text{alloc}}|``$ allocations.
- Interface port consistency evaluates in $O(1)$ time per edge given bounded port count ($``K_{\text{ports}} \le 64``$) and subtyping bitsets, totaling $O(E)$.
- Acyclicity verification over $``(V, E_{\text{alloc}})``$ executes via Tarjan SCC in deterministic $O(V + E)$ time and $O(V)$ space.

**Tractable Subclass & Frontier**: While general allocation is NP-hard (governed by NP-2 in REQ-0147), static allocation lowering operates over declared relations in deterministic $O(V + E)$ time without backtracking. Parallel lowering scales as $``O((V + E) / N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Canonical Allocation Lowering and Port Realization
- **Given:** Action `Action_A` with `Port_Out : out Classifier_Alpha` allocated to `Part_Alpha` with identical `Port_Out`.
- **When:** Lowering `allocate Action_A to Part_Alpha`.
- **Then:** Lowered as valid bipartite edge $(s, t)$ in arena storage with mapped ports; zero diagnostics.
- **Diagnostic:** `E0200` on failure.

### AC-02: Bipartite Inversion and Reflexive Rejection
- **Given:** Inverted `allocate Part_Alpha to Action_A` or reflexive `allocate Action_A to Action_A`.
- **When:** Bipartite domain and reflexivity validation executes.
- **Then:** Compile-time rejection binding sentinel $``\bot_{\text{alloc}}``$ with diagnostic `E0200`.
- **Diagnostic:** `E0200` on violation.

### AC-03: Port Mismatch and Polarity Conflict
- **Given:** `Action_A` with `Port_In : in Classifier_Alpha` allocated to `Part_Alpha` with inverted or missing `Port_In`.
- **When:** Port allocation consistency is validated.
- **Then:** Rejection of the allocation usage with diagnostic `E0200`.
- **Diagnostic:** `E0200` on violation.

### AC-04: Circular Allocation Dependency Detection
- **Given:** Cyclic allocation chain $``\text{Element}_1 \mapsto \text{Element}_2 \mapsto \text{Element}_3 \mapsto \text{Element}_1``$.
- **When:** Topological acyclicity analysis executes over the allocation graph.
- **Then:** Cycle detected via Tarjan SCC, emitting diagnostic `E0203`.
- **Diagnostic:** `E0203` on violation.
