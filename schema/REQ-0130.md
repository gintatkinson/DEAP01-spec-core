## 1. Normative Statement

The safety compiler SHALL enforce downward realization completeness (`RealizationGate_Alpha`) across traceability DAG $``G_{\text{trace}}``$.

Verification MUST enforce:
1. **Universal Realization**: Elements $``e \in V_{\text{elem}}``$ (classifiers, parts, ports, actions, states) MUST satisfy $``(r, e) \in E_{\text{realize}}``$ for requirement $``r \in V_{\text{req}}``$. Orphans emit `E0405`.
2. **Hierarchical Inheritance**: Direct realization links $r$ to $e$. Nested children ($``e_{\text{child}} \sqsubset^+ e_{\text{parent}}``$) inherit parent realizers. Elements pass when $|\text{Realizers}(e)| \ge 1$.
3. **Mission Grounding**: Realizing requirements $r \in \text{Realizers}(e)$ MUST trace to mission roots $``m \in V_{\text{mission}}``$. Ungrounded requirements emit `E0400`.
4. **Incidence Matrix**: Synthesis emits boolean matrix $``\mathbf{M}_{\text{realize}} \in \{0, 1\}^{|V_{\text{elem}}| \times |V_{\text{req}}|}``$ with row completeness ($``\sum_j M_{\text{realize}, i, j} \ge 1``$).

---

## 2. Formal Invariant

Downward realization completeness, hierarchical inheritance, and diagnostic mappings satisfy:

```math
\begin{aligned}
G_{\text{trace}}=\langle V_{\text{trace}},E_{\text{trace}}\rangle,\quad E_{\text{realize}}\subseteq E_{\text{trace}}\cap(V_{\text{req}}\times V_{\text{elem}}),\quad V_{\text{elem}}\cap V_{\text{req}}=\emptyset \\
\text{Realizers}(e)=\{r\in V_{\text{req}}\mid(r,e)\in E_{\text{realize}}\lor\exists p\in\text{anc}(e):(r,p)\in E_{\text{realize}}\} \\
\forall e\in V_{\text{elem}},\quad|\text{Realizers}(e)|\ge 1\land(\exists r\in\text{Realizers}(e),\exists m\in V_{\text{mission}}:(m,r)\in E_{\text{trace}}) \\
\mathbf{M}_{\text{realize}}\in\{0,1\}^{|V_{\text{elem}}|\times|V_{\text{req}}|},\quad\forall i\in\{1,\dots,|V_{\text{elem}}|\},\;\sum_{j=1}^{|V_{\text{req}}|}M_{\text{realize},i,j}\ge 1 \\
(|\text{Realizers}(e)|=0\implies\text{Diagnostic}(e,\text{E0405}))\land(\text{Ungrounded}(e)\implies\text{Diagnostic}(e,\text{E0400})) \\
|\mathcal{D}_{\text{sink}}|\ge C_{\text{max\_errors}}\implies\text{Diagnostic}(\text{E0199}),\quad\Delta_e=\text{UUIDv5}(\text{NS}_{\text{DEAP}},\text{FQN}(e))
\end{aligned}
```

| Symbol / Term | Domain / Formal Definition |
| :--- | :--- |
| $``G_{\text{trace}}, E_{\text{realize}}``$ | Traceability graph and realization relation |
| $``V_{\text{elem}}, V_{\text{req}}``$ | Architectural elements ($``T_3``$) and system requirements ($``T_2``$) |
| $\text{Realizers}(e), \text{anc}(e)$ | Realizing requirements and containment ancestors ($\sqsubset^+$) |
| $``V_{\text{mission}}, \mathbf{M}_{\text{realize}}``$ | Mission requirements ($``T_1``$) and realization matrix |
| $``\bot_{\text{elem}}, \Delta_e``$ | Semantic error sentinel and UUIDv5 anchor |

## 3. Computational Complexity & Algorithmic Bounds

- **Complexity Class:** Class $\mathbf{P}$ (Deterministic Polynomial Time)
- **Asymptotic Bound:** $``O(|V_{\text{elem}}| + |E_{\text{realize}}|)``$ downward realization verification; containment takes $``O(|V_{\text{elem}}|)``$; sparse matrix takes $``O(|V_{\text{elem}}| + |E_{\text{realize}}|)``$. Work-stealing scales as $``O((|V_{\text{elem}}| + |E_{\text{realize}}|) / N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$.
- **Tractable Subclass & Frontier:** N/A (Deterministic P). Traverses DAGs via single-pass reachability, avoiding NP-4 and NP-8 without backtracking.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Direct Downward Realization
- **Given:** `Package_0` with `Element_0` and requirement `Requirement_0`.
- **When:** Lowering processes `satisfy Requirement_0 by Element_0`.
- **Then:** Registers $``(r_0, e_0) \in E_{\text{realize}}``$, validating completeness.
- **Diagnostic:** Diagnostic sink empty.

### AC-02: Hierarchical Inheritance Traversal
- **Given:** Composite `Element_0` with child `Element_Child_0`, where `Element_0` realizes `Requirement_0`.
- **When:** Lowering executes containment traversal.
- **Then:** `Element_Child_0` inherits realization ($``\text{Realizers}_{\text{inherited}} \ne \emptyset``$).
- **Diagnostic:** Diagnostic sink empty.

### AC-03: Orphan Element Rejection
- **Given:** Model declaring unallocated `Element_1` lacking realization traces.
- **When:** Completeness pass executes.
- **Then:** Traps $``|\text{Realizers}(e_1)| = 0``$, halts lowering, emits `E0405`, and binds $``\bot_{\text{elem}}``$.
- **Diagnostic:** `E0405` (DownwardRealizationIncomplete).

### AC-04: Delimiter Error Recovery
- **Given:** Malformed realization and ungrounded requirement before `;`, followed by `Element_0`.
- **When:** Lowering parses declarations.
- **Then:** Emits `E0400`, recovers on `;`, halting at $``C_{\text{max\_errors}}``$ with `E0199`.
- **Diagnostic:** `E0400`, `E0199`.
