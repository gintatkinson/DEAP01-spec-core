## 1. Normative Statement

The semantic model lowering engine shall represent lexical scopes, naming environments, and containment hierarchies as formal `Namespace` scopes composed of typed `Membership` relationships, mapping interned member symbols to semantic element node handles in the AST graph.

Memberships shall partition into two disjoint subsets:
1. `OwningMembership`: Establishes composite ownership and lifecycle containment. The engine shall enforce single ownership: every owned element in the model shall be bound by exactly one `OwningMembership`. Conflicting owning memberships shall trigger diagnostic error code `E0200`. Ownership relations shall form a directed forest; containment cycles shall trigger diagnostic error code `E0203`.
2. Non-Owning Reference `Membership`: Establishes visible reference bindings between a namespace and an element owned elsewhere without altering lifecycle containment.

Within any given `Namespace`, named memberships must satisfy lexical uniqueness. Colliding member names resolving to distinct elements within the same namespace shall trigger diagnostic error code `E0200`. Identical names resolving to identical elements are permitted.

Every named element shall possess a deterministic qualified name sequence (`QN`), defined inductively as the owner namespace qualified name concatenated with its interned member name, serialized with `::` delimiters (e.g., `Package_0::Classifier_Alpha::Port_1`). Anonymous elements possess no qualified name. Absolute paths prefixed with `::` resolve from root; relative paths resolve from active local scope. Unresolved path segments shall trigger diagnostic error code `E0200`.

## 2. Formal Invariant

Let $`\mathcal{E}`$ denote semantic elements, $`\mathcal{N} \subseteq \mathcal{E}`$ namespaces, $``\mathcal{S}_{\text{intern}}``$ interned symbols, and $`\mathcal{M}`$ memberships partitioned into owning $``\mathcal{M}_{\text{own}}``$ and non-owning $``\mathcal{M}_{\text{ref}}``$:

```math
\mathcal{M} = \mathcal{M}_{\text{own}} \cup \mathcal{M}_{\text{ref}}, \quad \mathcal{M}_{\text{own}} \cap \mathcal{M}_{\text{ref}} = \emptyset
```

Local symbol resolution map $``\mu_N : \mathcal{S}_{\text{intern}} \rightharpoonup \mathcal{E}``$:

```math
\mu_N(\sigma) = \begin{cases}
e_m, & \text{if } \exists m \in \mathcal{M}_N : \sigma_m = \sigma \\
\bot, & \text{otherwise}
\end{cases}
```

Single-ownership bijection on owned elements $``\mathcal{E}_{\text{owned}} \subseteq \mathcal{E}``$ and owner projection $`\text{owner} : \mathcal{E} \to \mathcal{N} \cup \{ \bot \}`$:

```math
\forall e \in \mathcal{E}_{\text{owned}}, \; |\{ m \in \mathcal{M}_{\text{own}} \mid \text{member}(m) = e \}| = 1, \quad \text{owner}(e) = \begin{cases}
N_m, & \text{if } \exists ! m \in \mathcal{M}_{\text{own}} : \text{member}(m) = e \\
\bot, & \text{otherwise}
\end{cases}
```

Acyclic ownership relation $``\mathcal{O} = \{ (N_m, \text{member}(m)) \mid m \in \mathcal{M}_{\text{own}} \}``$ with irreflexive transitive closure $`\mathcal{O}^+`$:

```math
\forall e \in \mathcal{E}, \quad (e, e) \notin \mathcal{O}^+
```

Lexical uniqueness within namespace $`N`$:

```math
\forall m_1, m_2 \in \mathcal{M}_N, \quad (\sigma_{m_1} = \sigma_{m_2} \ne \bot) \implies \text{member}(m_1) = \text{member}(m_2)
```

Qualified name recurrence, canonical path serialization, and deterministic UUIDv5 anchor:

```math
\begin{aligned}
\text{QN}(e) &= \begin{cases} [\text{name}(e)], & \text{if } \text{owner}(e) = \bot \\ \text{QN}(\text{owner}(e)) \mathbin{\Vert} [\text{name}(e)], & \text{otherwise} \end{cases} \\
\text{FQN}(e) &= \text{StringOf}(\sigma_1) \mathbin{\Vert} \text{"::"} \dots \text{"::"} \mathbin{\Vert} \text{StringOf}(\sigma_k), \quad \Delta_e = \text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(e))
\end{aligned}
```

Diagnostic trigger invariants:

```math
\begin{aligned}
(\sigma_{m_1} = \sigma_{m_2} \ne \bot) \wedge \text{member}(m_1) \ne \text{member}(m_2) &\implies \text{Diagnostic}(m_2, \text{E0200}) \in \mathcal{D}_{\text{sink}} \\
|\{ m \in \mathcal{M}_{\text{own}} \mid \text{member}(m) = e \}| \gt 1 &\implies \text{Diagnostic}(e, \text{E0200}) \in \mathcal{D}_{\text{sink}} \\
(e, e) \in \mathcal{O}^+ &\implies \text{Diagnostic}(e, \text{E0203}) \in \mathcal{D}_{\text{sink}} \\
\text{ResolvePath}(\pi, N) = \bot &\implies \text{Diagnostic}(\pi, \text{E0200}) \in \mathcal{D}_{\text{sink}}
\end{aligned}
```

## 3. Computational Complexity & Algorithmic Bounds

Namespace indexing and resolution execute strictly within Complexity Class $`\mathbf{P}`$. Local symbol lookup executes in amortized $`O(1)`$ time via interned 32-bit `SymbolId` handles. Ownership tree acyclicity verification executes in deterministic linear time $``O(|\mathcal{E}| + |\mathcal{M}_{\text{own}}|) \subseteq O(|\mathcal{E}|)``$ via depth-first cycle detection. Qualified name construction traverses bounded depth $``D_{\max} \le 16``$ in bounded constant time $``O(D_{\max}) = O(1)``$. Qualified path resolution of length $`k \le 16`$ executes $`k`$ sequential lookups in $`O(k) = O(1)`$ time. Total compilation runtime satisfies $``T_{\text{total}} \in O(V + M + N_{\text{ref}})``$. Parallel execution over $``N_{\text{max\_workers}}``$ threads scales as $``O((V + M) / N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$. Arena memory is bounded by $`O(V + M)`$, with stack depth bounded by $``O(D_{\max}) \le 16``$ frames ($`O(1)`$ stack space).

NP Frontier Reference: Decoupled from NP-hard combinatorial frontiers (NP-1 through NP-8); all namespace scoping and naming recurrences evaluate deterministically in linear polynomial time without backtracking.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Membership Partitioning and O(1) Local Scope Resolution
- **Given:** Model declaring `Package_0` hosting `OwningMembership` for `Classifier_Alpha` and non-owning `Membership` for `Classifier_Beta` owned by `Package_1`.
- **When:** Symbol indexing resolves local members by interned `SymbolId`.
- **Then:** Both resolve in amortized $`O(1)`$ time with $``\text{owner}(\text{Classifier\_Alpha}) = \text{Package\_0}``$ and $``\text{owner}(\text{Classifier\_Beta}) = \text{Package\_1}``$.
- **Diagnostic:** `E0200` emitted on local lookup failure.

### AC-02: Single-Ownership Bijection Invariant Enforcement
- **Given:** Element `Classifier_Alpha` owned by `Package_0` via `OwningMembership`.
- **When:** Lowering processes a secondary `OwningMembership` for `Classifier_Alpha` in `Package_1`.
- **Then:** The compiler rejects duplicate ownership, retains singular ownership in `Package_0`, and binds sentinel $``\bot_{\text{node}}``$.
- **Diagnostic:** `E0200` emitted on duplicate owning membership violation.

### AC-03: Lexical Uniqueness and Colliding Name Rejection
- **Given:** Namespace `Package_0` declaring distinct elements `Classifier_Alpha` and `Classifier_Beta`.
- **When:** Both declarations specify identical member name `Item_X` within `Package_0`.
- **Then:** The compiler rejects the second membership as a duplicate name collision, while permitting distinct memberships binding to identical elements.
- **Diagnostic:** `E0200` emitted on duplicate member name collision.

### AC-04: Ownership Forest Strict Acyclicity Verification
- **Given:** Circular ownership where `Package_0` owns `Package_1` and `Package_1` attempts to own `Package_0` via `OwningMembership`.
- **When:** Lowering executes ownership cycle validation.
- **Then:** The engine detects $`(e, e) \in \mathcal{O}^+`$, severs back-edge, binds sentinel $``\bot_{\text{node}}``$, and continues compilation.
- **Diagnostic:** `E0203` emitted with cycle path trace $``\langle \text{Package\_0}, \text{Package\_1}, \text{Package\_0} \rangle``$.
