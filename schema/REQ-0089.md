## 1. Normative Statement

The compiler SHALL lower SysML v2 `expose` statements in `ViewDefinition` and `ViewUsage` as declarative selection expressions, projecting conformant induced subgraphs and validating viewpoint obligations.

The lowering engine MUST enforce six core invariants:
1. **Modality**: `expose` statements SHALL support explicit paths (`expose <path>;`), shallow wildcards (`expose <path>::*;`), recursive wildcards (`expose <path>::**;`), and predicate filtering (`expose filter <expr>;`) over types, metadata tags (`@Tag_Alpha`), and boolean expressions.
2. **Path Resolution**: Target paths MUST resolve in scope; unresolvable paths emit `E0200`.
3. **Predicate Typing**: Filter expressions MUST evaluate to `Boolean` ($``\tau(\Phi) \equiv \mathbb{B}``$); non-boolean expressions or unbound attributes emit `E0202`.
4. **Induced Subgraph**: View $V$ SHALL project graph $``G_{\text{view}}(V) = (V_{\text{exp}}, E_{\text{exp}})``$ preserving exposed vertices $``V_{\text{exp}}``$ and induced edges $``E_{\text{exp}} = \{ (u, v) \in \mathcal{E}_{\text{model}} \mid u, v \in V_{\text{exp}} \}``$, guaranteeing soundness and completeness.
5. **Viewpoint Conformance**: Conformance (`satisfy viewpoint <ViewpointDef>;`) MUST target valid viewpoints, enforcing coverage ($``\mathbf{M}_{\text{vp}} \subseteq V_{\text{exp}}``$), filter consistency ($``\forall u \in V_{\text{exp}}, \Phi_{\text{vp}}(u) \equiv \text{true}``$), and exclusion ($``V_{\text{exp}} \cap \mathbf{X}_{\text{vp}} = \emptyset``$); violations emit `E0200`.
6. **Acyclicity**: Cross-view expose references $``\mathcal{G}_{\text{exp\_dep}}``$ MUST form a DAG; cycles emit `E0203`.

## 3. Computational Complexity & Algorithmic Bounds

Lowering, filtering, induced projection, and conformance checking execute in Complexity Class $\mathbf{P}$.

For model multigraph with $``V = |\mathcal{V}_{\text{model}}|``$ vertices, $``E = |\mathcal{E}_{\text{model}}|``$ edges, and $``K = |\mathcal{E}_{\text{exp}}|``$ expose statements across $``N_V``$ views:
- **Path Resolution & Expansion**: Scoped symbol lookup takes $O(1)$ amortized; shallow expansion takes $O(\text{deg}(p))$; recursive expansion takes $``O(V_{\text{subtree}}) \subseteq O(V)``$.
- **Query Filtering**: Static filter predicates evaluate in $O(1)$ per candidate ($O(V)$ total).
- **Induced Subgraph Extraction**: Traversal over incident edges of exposed vertices executes in $``O(\sum_{u} \text{deg}(u)) \subseteq O(E)``$.
- **Viewpoint Conformance & Acyclicity**: Validation takes $``O(V_{\text{exp}} + |\mathbf{M}_{\text{vp}}| + |\mathbf{X}_{\text{vp}}|) \subseteq O(V)``$; cycle check takes $``O(N_V + |\mathcal{R}_{\text{exp\_dep}}|)``$.

Sequential complexity is $``O(V + E + K + N_V + |\mathcal{R}_{\text{exp\_dep}}|) \subseteq O(V + E)``$. Parallel work-stealing scales as $``O((V + E) / N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$. Filtering establishes the tractable fragment of NP-3 without exponential subgraph isomorphism search.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Canonical Expose Path Resolution and Induced Subgraph Projection
- **Given:** `Package_0` with classifiers `Classifier_Alpha` and `Classifier_Beta` connected by relation `Rel_A`.
- **When:** Lowering `view def ViewDef_Alpha { expose Package_0::Classifier_Alpha, Package_0::Classifier_Beta; }`.
- **Then:** Classifiers resolve into $``V_{\text{exp}}``$ and induced edge `Rel_A` is included in $``E_{\text{exp}}``$.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: Wildcard Expansion and Predicate Filtering Boundary
- **Given:** `Package_0` with 10 parts typed by `PartDef_Alpha` and 5 ports, tagged `@Tag_Alpha`.
- **When:** Lowering `view def ViewDef_Alpha { expose Package_0::*; expose filter (isKindOf(PartDef_Alpha) and @Tag_Alpha); }`.
- **Then:** Shallow wildcard and filter admit exactly the tagged parts into $``V_{\text{exp}}``$ without descending into sub-packages.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-03: Unresolved Path Target and Filter Codomain Type Mismatch
- **Given:** View declaring `expose Package_0::UndefinedClassifier;` and `expose filter (param_x + 5.0);` with `param_x : Real`.
- **When:** Scoped symbol resolution and predicate type analysis execute.
- **Then:** Lowering rejects undefined target with `E0200`, rejects non-boolean predicate with `E0202`, and assigns sentinel $``\bot_{\text{exp}}``$.
- **Diagnostic:** `E0200` on unresolved path; `E0202` on filter type mismatch.

### AC-04: Viewpoint Conformance Violation and Circular Expose Recovery
- **Given:** View declaring `satisfy viewpoint ViewpointDef_Alpha;` omitting mandatory `Classifier_Alpha`, alongside cyclic views `ViewDef_Alpha` and `ViewDef_Beta`.
- **When:** Conformance checking and cycle detection execute.
- **Then:** Validator emits `E0200` for omission, `E0203` for cycle, recovers on `;` and `}`, and emits terminal `E0199` at $``C_{\text{max\_errors}}``$.
- **Diagnostic:** `E0200` on viewpoint violation; `E0203` on cycle; `E0199` on error ceiling.
