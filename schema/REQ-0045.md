## 1. Normative Statement

The Core Metamodel, Node Arena & AST Graph Engine shall provide an immutable graph traversal engine that visits vertices and directed edges of the abstract syntax tree (AST) multigraph $``G = (\mathcal{V}_{\text{AST}}, \mathcal{E}_{\text{AST}})``$ in topological, depth-first (pre-order and post-order), or breadth-first (level-order) disciplines with strictly bounded $`O(V + E)`$ linear time complexity. Traversal algorithms must operate strictly over shared immutable references without allocating temporary graph structures or mutating node payloads, headers, or edge relations.

---

## 2. Formal Invariant

Let $``G = (\mathcal{V}_{\text{AST}}, \mathcal{E}_{\text{AST}})``$ represent the AST multigraph with arena capacity $``C_{\text{arena}} \in \mathbb{N}``$, where $``\mathcal{V}_{\text{AST}} \subset \mathbb{U}_{64}``$ denotes typed node handles and $``\mathcal{E}_{\text{AST}} \subseteq \mathcal{V}_{\text{AST}} \times \mathcal{V}_{\text{AST}} \times \mathcal{K}_{\text{edge}}``$ denotes directed edges with classifications $``\mathcal{K}_{\text{edge}} = \{ \text{Containment}, \text{Specialization}, \text{Connection}, \text{Sequencing}, \text{Reference} \}``$.

For root $``v_0 \in \mathcal{V}_{\text{AST}}``$, let $``V_{\text{reach}}(v_0) = \{ v \in \mathcal{V}_{\text{AST}} \mid v_0 \rightsquigarrow v \}``$ and $``E_{\text{reach}}(v_0) = \{ (u, v, \kappa) \in \mathcal{E}_{\text{AST}} \mid u \in V_{\text{reach}}(v_0) \}``$.

Bounded Traversal Time and Zero Mutation Invariants:

```math
\begin{aligned}
T_{\text{traversal}}(G, v_0) &\le c_1 \cdot (|V_{\text{reach}}(v_0)| + |E_{\text{reach}}(v_0)|) + c_0 \\
\forall v \in \mathcal{V}_{\text{AST}}, \quad \sigma(v, t_{\text{post}}) &\equiv \sigma(v, t_{\text{pre}}), \quad \text{Mutations} = 0, \quad \text{HeapAllocs} = 0
\end{aligned}
```

Bitset Completeness and Cycle Termination Invariants:

```math
\begin{aligned}
\forall v \in V_{\text{reach}}(v_0), \quad \text{VisitedCount}(v) &= 1, \qquad \forall v \notin V_{\text{reach}}(v_0), \quad \text{VisitedCount}(v) = 0 \\
B[\text{Index}(v_1)] = 1 &\implies \text{TraverseEdge}(v_m, v_1) = \text{Skip}
\end{aligned}
```

Traversal Ordering Sequence Invariants:

```math
\begin{aligned}
\forall (u, v, \kappa) \in \mathcal{E}_{\text{tree}}, \quad \text{pos}(\sigma_{\text{pre}}, u) &\lt \text{pos}(\sigma_{\text{pre}}, v), \quad \text{pos}(\sigma_{\text{post}}, u) \gt \text{pos}(\sigma_{\text{post}}, v) \\
\forall (u, v, \kappa) \in \mathcal{E}_{\text{DAG}}, \quad \text{pos}(\sigma_{\text{topo}}, u) &\lt \text{pos}(\sigma_{\text{topo}}, v)
\end{aligned}
```

Auxiliary Depth Bound and Diagnostic Bindings per REQ-0191:

```math
\begin{aligned}
|S_{\text{stack}}(t)| &\le D_{\text{max\_depth}} \\
\neg\text{ValidHandle}(H, \mathcal{A}_{\text{node}}) \vee (|S_{\text{stack}}(t)| \gt D_{\text{max\_depth}}) &\implies \exists D \in \mathcal{D}_{\text{sink}} : \text{code}(D) = \text{DiagnosticCode::E0200} \\
|\mathcal{D}_{\text{sink}}| \ge C_{\text{max\_errors}} &\implies \exists D_{\text{term}} \in \mathcal{D}_{\text{sink}} : \text{code}(D_{\text{term}}) = \text{DiagnosticCode::E0199}
\end{aligned}
```

## 3. Computational Complexity & Algorithmic Bounds

The immutable graph traversal engine executes within Complexity Class $`\mathbf{P}`$. Traversal over reachable subgraphs runs in deterministic linear time $`O(|V| + |E|)`$ for reachable vertices $``V = |V_{\text{reach}}(v_0)|``$ and edges $``E = |E_{\text{reach}}(v_0)|``$. Direct arena handle dereferences and bitset lookups execute in $`O(1)`$ constant time via base-plus-offset addressing and bitwise masks. Auxiliary workspace memory is bounded by $``O(C_{\text{arena}})``$ bits for the bitset ($``\lceil C_{\text{arena}} / 8 \rceil``$ bytes) and $``O(D_{\text{max\_depth}})``$ for the frontier stack/queue, incurring zero heap allocations ($`\text{HeapAllocs} = 0`$)., parallel time satisfies $``O((|V| + |E|) / N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$. Traversal accesses pre-constructed edges directly, bypassing combinatorial graph search NP frontiers (NP-1--NP-8) without backtracking.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Linear Traversal Scaling Across Scale Topologies
- **Given:** Synthetic AST multigraphs rooted at `Package_0` scaling from $`10^3`$ to $`10^5`$ vertices and edges (`Classifier_Alpha`, `Port_1`, `Flow_A`).
- **When:** The traversal engine executes DFS pre-order, DFS post-order, and BFS passes.
- **Then:** Runtime scales linearly satisfying $``T(V, E) \le c_1 \cdot (V + E) + c_0``$ ($`R^2 \ge 0.99`$), visiting all reachable vertices exactly once ($`\text{VisitedCount}(v) = 1`$) and unreachable vertices zero times.
- **Diagnostic:** `E0200` emitted on traversal failure or non-linear scaling termination.

### AC-02: Immutability and Zero Heap Allocation Verification
- **Given:** A populated node arena $``\mathcal{A}_{\text{node}}``$ containing synthetic elements `Package_0`, `Classifier_Alpha`, and `Port_1`, instrumented with SHA-256 digests and allocator hooks.
- **When:** The traversal engine executes DFS and BFS passes across the full model graph.
- **Then:** Post-traversal SHA-256 arena digests are bitwise identical to pre-traversal digests ($`\text{Mutations} = 0`$), and allocator hooks record zero heap allocations ($`\text{HeapAllocs} = 0`$).
- **Diagnostic:** `E0200` emitted on arena byte alteration or unexpected heap allocation.

### AC-03: Cyclic Graph Termination and Single-Visit Invariant
- **Given:** A synthetic AST multigraph with circular references (`Classifier_Alpha -> Classifier_Beta -> Classifier_Alpha` and self-loop `Port_1 -> Port_1`).
- **When:** The engine executes traversal starting from root vertex `Package_0`.
- **Then:** The visited bitset detects back-edges, skips redundant exploration, terminates deterministically without infinite loops, and records $`\text{VisitedCount}(v) = 1`$ for all reachable cycle nodes in $`O(V + E)`$ steps.
- **Diagnostic:** `E0200` emitted on cycle-induced divergence or duplicate node visitation.

### AC-04: Traversal Ordering Sequences and Visitor Control Directives
- **Given:** A synthetic DAG containing hierarchy `Package_0::Classifier_Alpha::Port_1` and visitors configured with `Continue`, `Prune`, and `Halt` directives.
- **When:** Executing pre-order, post-order, topological, and directive-controlled traversals.
- **Then:** Pre-order visits parents before children ($`\text{pos}(u) \lt \text{pos}(v)`$); post-order visits children before parents ($`\text{pos}(u) \gt \text{pos}(v)`$); `Prune` skips child branches; `Halt` terminates traversal immediately in $`O(1)`$ steps.
- **Diagnostic:** `E0200` emitted on traversal order sequence violation.
