## 2. Formal Invariant

Feature Layer 3 projections satisfy:

```math
\begin{aligned}
\forall G\in\mathcal{G}(F),&\quad G=(J,E)\land\forall e\in E,e=\langle j_{\text{src}}(e),j_{\text{tgt}}(e),\mathbf{u}_e(e),\mathbf{u}_f(e),\Delta e(e),f(e)\rangle \\
\forall j\in J,&\quad\sum_{e\in\text{In}(j)}f(e)-\sum_{e\in\text{Out}(j)}f(e)=0 \\
\forall C\in\mathcal{C}(G),&\quad\sum_{e\in C}\text{sgn}(e,C)\cdot\Delta e(e)=0 \\
\forall j\in J,\forall e_1,e_2\in\text{Incident}(j),&\quad\mathbf{u}_f(e_1)=\mathbf{u}_f(e_2)\in\mathbb{Q}^7\land\mathbf{u}_e(e_1)=\mathbf{u}_e(e_2)\in\mathbb{Q}^7 \\
(j_{\text{src}}\notin J\lor j_{\text{tgt}}\notin J\lor\mathbf{u}_f(e_1)\ne\mathbf{u}_f(e_2))&\implies\text{Diagnostic}(e,\text{E0300})\in\mathcal{D}_{\text{sink}}\land e\gets\bot_{\text{flow}} \\
\left(\left|\sum_{\text{In}}f-\sum_{\text{Out}}f\right|\gt 0\lor\left|\sum_{C}\Delta e\right|\gt 0\right)&\implies\text{Diagnostic}(j,\text{E0309})\in\mathcal{D}_{\text{sink}}\land j\gets\bot_{\text{junction}} \\
|\mathcal{D}_{\text{sink}}| \ge C_{\text{max\_errors}}&\implies\text{Diagnostic}(\text{E0199})\in\mathcal{D}_{\text{sink}},\quad\Delta_x=\text{UUIDv5}(\text{OID}_{\text{DEAP}},\text{FQN}(x))
\end{aligned}
```

## 3. Computational Complexity & Algorithmic Bounds

- **Complexity Class:** Class $\mathbf{P}$ (Deterministic Polynomial Time).
- **Asymptotic Bound:** $O(|E|)$ topological Kirchhoff conservation ($|E|$ flows). Incidence and flow sums evaluate in $O(|E|)$ time. Cycle checks run in $O(|E|)$ on planar graphs. Work-stealing scales as $``O(|E|/N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$. Arena: $O(|J| + |E|)$.
- **Tractable Subclass and Frontier:** N/A (Deterministic P). Linear balance avoids continuous LCP solving in NP-6 (REQ-0105).

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Canonical Kirchhoff Network Lowering
- **Given:** Feature `Feature_0` with network `KirchhoffNetwork_Alpha`, junctions `Junction_0`, `Junction_1`, and balanced flows `Flow_1`, `Flow_2`.
- **When:** Lowering Feature Layer 3 projections.
- **Then:** Lowers network graph into arena storage with balanced equations.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: Fundamental Cycle Potential Balance Boundary
- **Given:** Loop $C$ in `KirchhoffNetwork_Alpha` with three flows whose potential drops sum to zero.
- **When:** Validating cycle potential balance.
- **Then:** Confirms potential conservation across cycle $C$.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-03: Non-Zero Junction Divergence Rejection
- **Given:** Network `KirchhoffNetwork_Alpha` with junction `Junction_0` having flow imbalance ($``f_{\text{in}} \ne f_{\text{out}}``$).
- **When:** Validating Kirchhoff flow conservation.
- **Then:** Rejects junction, emits `E0309`, and binds sentinel $``\bot_{\text{junction}}``$.
- **Diagnostic:** `E0309` (KirchhoffFlowConservationViolation).

### AC-04: Unmapped Junction and Delimiter Recovery
- **Given:** Flow `Flow_1` referencing undefined `Junction_Missing`, delimiter `;`, and valid `Flow_2`.
- **When:** Recovering across statement delimiters.
- **Then:** Emits `E0300`, binds $``\bot_{\text{flow}}``$, lowers `Flow_2`, and halts at $``C_{\text{max\_errors}}``$ with `E0199`.
- **Diagnostic:** `E0300`, `E0199`.
