## 1. Normative Statement

The core abstract syntax tree (AST) graph engine shall provide deterministic topological dependency scheduling, cycle detection, and shortest-path routing across model elements. Vertices represent lowered AST entities (packages, classifier definitions, feature usages, and ports) in the AST addressed by typed node handles (`NodeHandle<T>`). Nodes possess deterministic RFC 4122 UUIDv5 identifiers from namespace $``\text{NS}_{\text{DEAP}}``$ and canonical fully qualified paths. Copying string bytes into the symbol interner pool for scalar `SymbolId` tokens is the sole permitted exception to zero-copy memory management.

The graph engine shall enforce four deterministic transformations:

1. Kahn Topological Scheduling: Computes linear schedule $``\mathcal{L} = \langle v_1, \dots, v_n \rangle``$ where $`\text{Index}(u, \mathcal{L}) \lt \text{Index}(v, \mathcal{L})`$ for each dependency edge $`(u, v) \in E`$. Schedulable vertices in ready queue $`Q`$ with zero in-degree are dequeued in ascending lexicographical order of interned qualified names ($`\text{QualifiedName}(v)`$), ensuring bitwise reproducibility per REQ-0003.

2. Tarjan SCC Decomposition: Traverses directed multigraphs via linear-time depth-first search to compute maximal strongly connected components $``\mathcal{C} = \{ C_1, \dots, C_k \}``$ and condensation DAG $`G^{\text{scc}} = (\mathcal{C}, E^{\text{scc}})`$.

3. Cycle Diagnostics & Synchronization Recovery: In acyclic contexts (inheritance, containment, execution flows), non-trivial SCCs ($`|C| \gt 1`$ or self-loops) trigger diagnostic `E0203` with circular traceback $``\mathcal{P}_{\text{cycle}}``$., the engine tags cyclic nodes invalid, accumulates diagnostics, and resumes scheduling over acyclic components. Reaching limit $``C_{\text{max\_errors}}``$ emits `E0199` and terminates.

4. Shortest-Path Interconnect Routing: Executes breadth-first search (BFS) between port handles $``P_{\text{src}}``$ and $``P_{\text{tgt}}``$ across directed connection edges, breaking equidistant ties via intermediate qualified name comparison.

## 2. Formal Invariant

Let $`G = (V, E)`$ denote the directed AST dependency graph where $``V \subset \mathbb{U}_{32}``$ represents contiguous arena node handles and $`E \subseteq V \times V`$ represents directed dependency edges:

```math
G = (V, E), \quad V \subset \mathbb{U}_{32}, \quad E \subseteq V \times V, \quad \text{deg}^{-}(v) = |\{ u \in V \mid (u, v) \in E \}|
```

Kahn Topological Linear Ordering & Deterministic Tie-Breaking Invariant:

```math
\begin{aligned}
\forall (u, v) \in E, \quad &\text{Index}(u, \mathcal{L}) \lt \text{Index}(v, \mathcal{L}) \\
Q_t &= \{ v \in V \setminus \{ v_1, \dots, v_{t-1} \} \mid \text{deg}^{-}_t(v) = 0 \} \\
v_t &= \arg\min_{v \in Q_t} (\text{QualifiedName}(v)), \quad \mathcal{L}_t = \mathcal{L}_{t-1} \mathbin{\Vert} \langle v_t \rangle
\end{aligned}
```

Tarjan Strongly Connected Components (SCC) and Condensation DAG Invariant:

```math
\begin{aligned}
\text{low\_link}(v) &= \min \left( \{ \text{df\_num}(v) \} \cup \{ \text{low\_link}(w) \mid (v, w) \in E_{\text{tree}} \} \cup \{ \text{df\_num}(w) \mid (v, w) \in (E_{\text{back}} \cup E_{\text{cross}}) \wedge w \in S \} \right) \\
G^{\text{scc}} &= (\mathcal{C}, E^{\text{scc}}), \quad E^{\text{scc}} = \{ (C_i, C_j) \in \mathcal{C} \times \mathcal{C} \mid i \ne j \wedge \exists u \in C_i, v \in C_j : (u, v) \in E \}
\end{aligned}
```

Cycle Detection Diagnostics and Shortest-Path Query Invariants:

```math
\begin{aligned}
(|C| \gt 1 \lor \exists v \in C : (v, v) \in E) &\implies \text{Diagnostic}(C, \text{E0203}, \mathcal{P}_{\text{cycle}}) \in \mathcal{D}_{\text{sink}} \\
\text{ShortestPath}(u, v) &= \arg\min_{\mathcal{P} \in \text{Paths}(u, v)} |\mathcal{P}|
\end{aligned}
```

## 3. Computational Complexity & Algorithmic Bounds

Topological scheduling, Tarjan SCC decomposition, and shortest-path routing execute strictly within Complexity Class $`\mathbf{P}`$.

- Kahn Topological Scheduling: $``T_{\text{Kahn}}(V, E) \in O(|V| \log |V| + |E|)``$ time and $`O(|V|)`$ space using a min-heap with $`O(1)`$ scalar comparisons on interned symbols.
- Tarjan SCC Decomposition: Optimal linear time $``T_{\text{Tarjan}}(V, E) \in O(|V| + |E|)``$ and $`O(|V|)`$ stack space.
- Condensation DAG Construction: Executes in $`O(|V| + |E|)`$ time and space.
- BFS Shortest-Path Queries: Traverses interconnect multigraphs in $`O(|V| + |E|)`$ time and $`O(|V|)`$ queue memory.
- Parallel Scheduling: Across $`K`$ components on $``N_{\text{max\_workers}}``$ threads scales as $``O((|V| + |E|) / N_{\text{max\_workers}} + K \log N_{\text{max\_workers}})``$.

Linear-time decomposition and tie-breaking eliminate backtracking, bypassing NP-complete subtyping (NP-3) and state reachability (NP-5) frontiers with guaranteed polynomial termination.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Diamond DAG Topological Scheduling & Dependency Invariant

- **Given:** A DAG over elements `Package_0`, `Classifier_Alpha`, `Classifier_Beta`, `Classifier_Gamma`, and `Classifier_Delta`, where `Classifier_Alpha` precedes `Classifier_Beta` and `Classifier_Gamma`, and both precede `Classifier_Delta`.
- **When:** Kahn topological sorting executes to establish compilation schedule $`\mathcal{L}`$.
- **Then:** Sequence $`\mathcal{L}`$ orders `Classifier_Alpha` before `Classifier_Beta` and `Classifier_Gamma`, and both before `Classifier_Delta`, satisfying $`\text{Index}(u, \mathcal{L}) \lt \text{Index}(v, \mathcal{L})`$ for all $`(u, v) \in E`$.
- **Diagnostic:** `E0200` on ordering violation.

### AC-02: Deterministic Lexicographical Tie-Breaking

- **Given:** Sibling nodes `Classifier_Beta` and `Classifier_Gamma` in `Package_0` attaining in-degree zero simultaneously in ready queue $`Q`$.
- **When:** Kahn algorithm dequeues the next schedulable node handle.
- **Then:** Node `Package_0::Classifier_Beta` is selected before `Package_0::Classifier_Gamma` by lexicographical order of interned `SymbolId` tokens, producing identical schedule $`\mathcal{L}`$ across edge insertion permutations.
- **Diagnostic:** `E0200` on non-deterministic tie-breaking.

### AC-03: Tarjan SCC Condensation & Trivial Component Isolation

- **Given:** An acyclic model multigraph $`G`$ containing 1,000 nodes and 2,500 edges.
- **When:** Tarjan SCC decomposition executes.
- **Then:** Exactly 1,000 singleton components ($``|C_i| = 1``$) are identified, producing condensation DAG $`G^{\text{scc}}`$ without self-loops and zero diagnostics emitted.
- **Diagnostic:** `E0203` if false cycles are reported.

### AC-04: Circular Dependency Detection, Traceback & Synchronization Recovery

- **Given:** An AST model containing cyclic loop `Classifier_Alpha` $`\to`$ `Classifier_Beta` $`\to`$ `Classifier_Gamma` $`\to`$ `Classifier_Alpha` and independent acyclic element `Classifier_Delta`.
- **When:** Tarjan SCC evaluates the model graph.
- **Then:** The engine detects component $`|C| = 3`$, extracts traceback path $``\langle \text{Classifier\_Alpha}, \text{Classifier\_Beta}, \text{Classifier\_Gamma}, \text{Classifier\_Alpha} \rangle``$, records diagnostic `E0203`, marks cyclic handles invalid, and recovers to schedule `Classifier_Delta`.
- **Diagnostic:** `E0203` on cycle detection; `E0199` on diagnostic sink overflow ($``C_{\text{max\_errors}}``$).
