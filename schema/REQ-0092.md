## 1. Normative Statement

The compiler SHALL lower KerML `ScalarValues` types (`Boolean`, `Integer`, `Real`, `String`) and numeric subtypes (`Natural`, `Positive`) into canonical machine representations, preserving semantic value precision, exact integer boundaries, and IEEE 754-2019 binary64 semantics.

---

## 2. Formal Invariant

Subtyping lattice, canonical mappings, precision preservation, and disjointness:

```math
\begin{aligned}
\text{Positive} &\le \text{Natural} \le \text{Integer} \le \text{Real},\quad \mathcal{T}_{\text{disjoint}} = \{ \mathbb{B}, \text{SymbolId}, \mathbb{R}_{64} \} \\
⟦ \text{Boolean} ⟧ &\longleftrightarrow \mathbb{B},\quad ⟦ \text{String} ⟧ \longleftrightarrow \text{SymbolId},\quad ⟦ \text{Integer} ⟧ \longleftrightarrow \mathbb{Z}_{64},\quad ⟦ \text{Real} ⟧ \longleftrightarrow \mathbb{R}_{64} \\
\forall n \in \mathbb{Z}_{64}, &\; (|n| \le 2^{53} \implies \text{float64}(n) = n) \;\wedge\; (|n| \gt 2^{53} \implies |\text{float64}(n) - n| \le \tfrac{1}{2} \text{ulp}(n)) \\
\forall \tau_1, \tau_2 \in \mathcal{T}_{\text{scalar}}, &\; \tau_1 \not\le \tau_2 \implies \text{Coerce}(\tau_1, \tau_2) = \bot_{\text{scalar}},\quad \Delta_v = \text{UUIDv5}(\text{NS}_{\text{DEAP}}, \text{FQN}(v))
\end{aligned}
```

| Symbol / Term | Domain / Formal Definition |
| :--- | :--- |
| $``\mathcal{T}_{\text{scalar}}``$ | Primitive types $\{ \text{Boolean}, \text{Positive}, \text{Natural}, \text{Integer}, \text{Real}, \text{String} \}$ |
| $``\mathbb{B}, \mathbb{Z}_{64}, \mathbb{R}_{64}``$ | Target domains: boolean byte, 64-bit signed int, IEEE 754 binary64 |
| $\text{SymbolId}$ | 32-bit interned UTF-8 string token handle |
| $\text{float64}(n), \text{ulp}(n)$ | Widening injection $``\iota(n)``$ and unit in last place |
| $``\bot_{\text{scalar}}, \Delta_v``$ | Error sentinel and deterministic UUIDv5 anchor |

## 3. Computational Complexity & Algorithmic Bounds

- **Complexity Class:** $\mathbf{P}$ (Deterministic Polynomial)
- **Asymptotic Bound:** $O(1)$ lookup, subtyping, and literal lowering ($O(L)$ string interning for length $L$); aggregate lowering is $O(N)$.
- **Tractable Subclass & Frontier:** Chain subtyping and disjoint singletons evaluate in $O(1)$ ordinal comparisons, avoiding general NP-complete poset search (NP-3). Work-stealing scales as $``O(N / N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Canonical Scalar Lowering
- **Given:** Package `Package_0` declaring scalar attributes `val_b : Boolean = true`, `val_i : Integer = 42`, `val_r : Real = 3.14159`, and `val_s : String = "alpha"`.
- **When:** Lowering scalar expressions into arena storage.
- **Then:** Values map to $\mathbb{B}$, $``\mathbb{Z}_{64}``$, $``\mathbb{R}_{64}``$, and interned `SymbolId` without loss.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: Monotonic Widening & Precision
- **Given:** Literals $``n_1 = 2^{53}``$ and $``n_2 = 2^{53} + 1``$ promoted to `Real`.
- **When:** Applying widening injection $\iota$.
- **Then:** $``n_1``$ promotes losslessly ($``\text{float64}(n_1) = n_1``$); $``n_2``$ rounds within $``\frac{1}{2}\text{ulp}``$.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-03: Integer Overflow & Malformed Literal Rejection
- **Given:** Integer literal exceeding $2^{63}-1$ or malformed float literal.
- **When:** Parsing and evaluating literal expressions.
- **Then:** Rejection assigns sentinel $``\bot_{\text{scalar}}``$ and emits `E0200`.
- **Diagnostic:** `E0200` (Scalar literal bounds or syntax violation).

### AC-04: Narrowing Prohibition & Delimiter Recovery
- **Given:** Narrowing assignment `param_y : Integer = 3.14159` followed by `;` and `val_pos : Positive = 1`.
- **When:** Type checking and recovery execute.
- **Then:** Rejection emits `E0200`, resynchronizes at `;`, lowers subsequent declarations, and halts at $``C_{\text{max\_errors}}``$ with `E0199`.
- **Diagnostic:** `E0200`; `E0199` upon error threshold saturation.
