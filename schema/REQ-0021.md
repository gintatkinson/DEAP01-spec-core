## 1. Normative Statement

The Universal Schema Ingestion Engine shall parse CommonMark tabular schemas specifying structural parts and component assemblies into `IngestedPart` intermediate entities. For each data row, the parser shall extract the part definition or usage name, the classifier type reference, the multiplicity interval $`\langle l, u \rangle`$, the structural containment hierarchy, and owned property sets. Part identifiers shall be sanitized according to REQ-0019.

The parser shall evaluate multiplicity interval strings into integer pairs $``\langle l, u \rangle \in \mathbb{N}_0 \times (\mathbb{N}_0 \cup \{ \infty \})``$ with $`0 \le l \le u`$ and $`u \ge 1`$. Empty cells ($`M = \bot`$) shall default to $`\langle 1, 1 \rangle`$. Malformed syntax or inverted ranges ($`l \gt u`$) shall emit diagnostic `E0103` (per REQ-0191), substitute sentinel $``\bot_{\text{mult}}``$, and trigger delimiter synchronization per REQ-0016.

Structural containment shall form an acyclic directed forest across part entities. A part shall not directly or transitively contain its ancestor. Containment cycles or multiple-parent assignments shall emit diagnostic `E0102`. Missing mandatory part name or classifier type columns shall emit diagnostic `E0102`.

## 2. Formal Invariant

Let $``\mathcal{T}_{\text{part}} = (\mathbf{H}, \mathbf{R})``$ be a tabular schema where $``\mathbf{H} = \langle H_0, \dots, H_{C-1} \rangle``$ ($`1 \le C \le 32`$) and $``\mathbf{R} = \langle R_1, \dots, R_M \rangle``$. Each synthesized entity $``P_i \in \mathcal{P}``$ is a 6-tuple:

```math
P_i = \langle \text{id}_i, \text{name}_i, \text{type}_i, \text{mult}_i, \text{parent}_i, \mathcal{A}_i \rangle
```

where $``\text{id}_i \in \mathcal{H}_{\text{node}}``$, $``\text{name}_i \in \mathcal{S}_{\text{sym}}``$, $``\text{type}_i \in \mathcal{S}_{\text{sym}} \cup \mathcal{H}_{\text{node}}``$, $``\text{mult}_i = \langle l_i, u_i \rangle``$, $``\text{parent}_i \in \mathcal{H}_{\text{node}} \cup \{ \bot \}``$, and $``\mathcal{A}_i``$ is the property set.

Multiplicity evaluation $``\text{ParseMultiplicity} : (\Sigma^* \cup \{ \bot \}) \to (\mathbb{N}_0 \times (\mathbb{N}_0 \cup \{ \infty \})) \cup \{ \bot_{\text{mult}} \}``$ satisfies:

```math
\text{ParseMultiplicity}(M) = \begin{cases}
\langle 1, 1 \rangle, & \text{if } M \in \{ \bot, \text{""} \} \\
\langle k, k \rangle, & \text{if } M = \text{Str}(k) \;\wedge\; k \in \mathbb{N}_0 \\
\langle 0, \infty \rangle, & \text{if } M = \text{"*"} \\
\langle l, u \rangle, & \text{if } M = \text{"[}l\text{..}u\text{]"} \;\wedge\; l \le u \\
\langle l, \infty \rangle, & \text{if } M = \text{"[}l\text{..*]"} \\
\bot_{\text{mult}}, & \text{otherwise}
\end{cases}
```

Bounded Multiplicity and Default Invariants:

```math
\begin{aligned}
\forall P_i \in \mathcal{P}, \quad \text{mult}_i = \langle l_i, u_i \rangle &\implies 0 \le l_i \le u_i \;\wedge\; u_i \ge 1 \\
M = \bot &\implies \text{ParseMultiplicity}(M) = \langle 1, 1 \rangle
\end{aligned}
```

Let $``G_{\text{contain}} = (\mathcal{P}, \mathcal{E}_{\text{contain}})``$ where $``(P_p, P_c) \in \mathcal{E}_{\text{contain}} \iff \text{parent}(P_c) = \text{id}(P_p)``$. The hierarchy forms an acyclic directed forest with unique immediate parents:

```math
\begin{aligned}
\forall P \in \mathcal{P}, \quad &(P, P) \notin \mathcal{E}_{\text{contain}}^+ \\
\forall P_c \in \mathcal{P}, \quad &|\{ P_p \in \mathcal{P} \mid (P_p, P_c) \in \mathcal{E}_{\text{contain}} \}| \le 1
\end{aligned}
```

Diagnostic Code Bindings per REQ-0191:

```math
\begin{aligned}
(\text{ParseMultiplicity}(M_i) = \bot_{\text{mult}} \;\vee\; l_i \gt u_i) &\implies \exists D \in \mathcal{D} : \text{code}(D) = \text{DiagnosticCode::E0103} \\
((P_i, P_i) \in \mathcal{E}_{\text{contain}}^+ \;\vee\; \text{name}_i = \bot \;\vee\; \text{type}_i = \bot) &\implies \exists D \in \mathcal{D} : \text{code}(D) = \text{DiagnosticCode::E0102}
\end{aligned}
```

## 3. Computational Complexity & Algorithmic Bounds

Tabular schema ingestion for structural parts executes within Complexity Class $`\mathbf{P}`$. For a table of $`R`$ rows and $`C \le 32`$ columns, cell extraction and token parsing execute in $`O(R \cdot C) = O(R)`$ deterministic time. Multiplicity interval evaluation operates on strings of length $``L_M \le 32``$ in $`O(1)`$ time per row ($`O(R)`$ total). Contiguous AST node construction and symbol interning take $`O(1)`$ amortized time per row. Structural containment validation over graph $``G_{\text{contain}} = (V, E)``$ with $`|V| = R`$ and $`|E| \le R`$ executes in deterministic $`O(V + E) = O(R)`$ time via single-pass topological traversal. Space complexity is $`O(R)`$ auxiliary space. Combinatorial NP frontiers (NP-1--NP-8) are bypassed, as validation is restricted to acyclic forest topologies solvable in deterministic linear time.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Canonical Component Definition Lowering
- **Given:** A CommonMark table declaring structural parts with names, classifier types, and multiplicity strings (`[1..*]`, `[0..1]`, `[2..4]`).
- **When:** Lowering table rows into `IngestedPart` entities.
- **Then:** 100% of rows lower into valid typed arena nodes with interned `SymbolId` handles, accurate bounds $`\langle l, u \rangle`$, and stable node offsets.
- **Diagnostic:** `E0102` on AST generation failure.

### AC-02: Default Multiplicity Assignment
- **Given:** A structural part table row with an empty multiplicity cell ($`M = \bot`$).
- **When:** Applying multiplicity evaluation $`\text{ParseMultiplicity}`$.
- **Then:** Assigns the default interval $`\langle 1, 1 \rangle`$ to the entity without emitting diagnostics.
- **Diagnostic:** `E0103` on default multiplicity derivation failure.

### AC-03: Multiplicity Syntax and Inverted Range Rejection
- **Given:** A component definition table with malformed multiplicity (`[5..2]`, `[-1..3]`, `[alpha]`, `[1..`).
- **When:** Parsing multiplicity cells during schema ingestion.
- **Then:** Rejects invalid tokens, substitutes sentinel $``\bot_{\text{mult}}``$, emits diagnostic `E0103` with byte coordinates, and recovers at the next row delimiter.
- **Diagnostic:** `E0103` recorded in diagnostic sink $`\mathcal{D}`$.

### AC-04: Structural Containment Forest and Hierarchy
- **Given:** A multi-tier assembly table specifying hierarchical nesting (`Assembly_0` containing `Subsystem_1`, containing `Part_1`).
- **When:** Constructing the structural containment graph $``G_{\text{contain}}``$.
- **Then:** Constructs an acyclic forest where parent handles match owning assemblies and root assemblies have $`\text{parent} = \bot`$.
- **Diagnostic:** `E0102` on parent handle resolution failure.
