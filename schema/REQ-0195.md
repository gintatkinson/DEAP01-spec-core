## 1. Normative Statement

Subsystem 12 SHALL provide a headless CLI and deterministic subcommand interface via `CliEngine_Alpha`.

---

## 2. Formal Invariant

Headless CLI dispatch, stream partitioning, and diagnostic triggers satisfy:

```math
\begin{aligned}
\text{CLI}:\mathcal{A}_{\text{args}}\times\mathcal{E}_{\text{env}}&\longrightarrow\langle\text{ExitCode},\text{Stdout},\text{Stderr}\rangle \\
\text{ExitCode}(A,E)=0&\iff\text{ValidSyntax}(A)\land|\mathcal{D}_{\text{fatal}}|=0\land|\mathcal{D}_{\text{error}}|=0 \\
\text{ExitCode}(A,E)=1&\iff\text{ValidSyntax}(A)\land|\mathcal{D}_{\text{fatal}}|+|\mathcal{D}_{\text{error}}|\gt 0 \\
\text{ExitCode}(A,E)=2&\iff\neg\text{ValidSyntax}(A)\lor\neg\text{ValidPath}(A) \\
\Delta_{\text{exec}}&=\text{UUIDv5}(\text{OID}_{\text{DEAP}},\text{Subcommand}\mathbin{\Vert}\text{"::CLI::"}\mathbin{\Vert}\text{Digest}(E)) \\
\forall\sigma,\quad\text{Stdout}(A,E\mid\text{IsTTY}(\sigma))&\equiv\text{Stdout}(A,E\mid\neg\text{IsTTY}(\sigma)) \\
\neg\text{ValidPath}(p)&\implies\text{Diagnostic}(p,\text{E0300})\in\mathcal{D}_{\text{sink}}\land p\gets\bot_{\text{cli}} \\
\text{Drift}(\mathcal{A}_{\text{schema}}, \mathcal{A}_{\text{artifact}})\gt 0&\implies\text{Diagnostic}(v,\text{E0500})\in\mathcal{D}_{\text{sink}}\land v\gets\bot_{\text{cli}} \\
|\mathcal{D}_{\text{sink}}|\ge C_{\text{max\_errors}}&\implies\text{Diagnostic}(\text{E0199})\in\mathcal{D}_{\text{sink}}
\end{aligned}
```

| Symbol / Term | Domain / Formal Definition |
| :--- | :--- |
| $``\mathcal{A}_{\text{args}}, \mathcal{E}_{\text{env}}``$ | Argument token space, isolated execution environment |
| $\text{ExitCode}, \text{Stdout}, \text{Stderr}$ | Termination status code, partitioned stream payloads |
| $``\mathcal{D}_{\text{sink}}, \mathcal{D}_{\text{fatal}}, \mathcal{D}_{\text{error}}``$ | Diagnostic sink, severity partitions |
| $``\Delta_{\text{exec}}, \text{OID}_{\text{DEAP}}``$ | UUIDv5 session anchor, namespace OID |
| $``\text{IsTTY}(\sigma), \bot_{\text{cli}}``$ | Terminal predicate, CLI fault sentinel |
| $``\text{Drift}, C_{\text{max\_errors}}``$ | Drift metric, diagnostic saturation limit |

## 3. Computational Complexity & Algorithmic Bounds

- **Complexity Class:** Class $\mathbf{P}$ (Deterministic Polynomial Time).
- **Asymptotic Bound:** $O(|A|)$ dispatch for tokens $|A|$, and $O(|S|)$ serialization for bytes $|S|$. Token lookup takes $O(1)$ time. Work-stealing incurs $``O(|U| / N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$ for $|U|$ units. Arena memory is $O(|A| + |S|)$.
- **Tractable Subclass and Frontier:** N/A (Deterministic P). CLI dispatch and serialization execute in linear time, bypassing NP-1 intervals (REQ-0117) and NP-8 SMT solving (REQ-0197).

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Headless Subcommand Dispatch Baseline
- **Given:** Model `Package_0` with `Classifier_Alpha` and `Port_1`.
- **When:** `CliEngine_Alpha` dispatches `Subcommand_0` in headless mode.
- **Then:** Executes with code `0`, emitting payload to `stdout` without TTY escapes.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: Structured JSON Telemetry and UUIDv5 Anchor
- **Given:** `Args_1` specifying `--format=json` for `Subcommand_0`.
- **When:** `CliEngine_Alpha` serializes output streams.
- **Then:** Emits JSON on `stdout` binding $``\Delta_{\text{exec}}``$ from $``\text{OID}_{\text{DEAP}}``$.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-03: Path Confinement and Syntax Rejection
- **Given:** Arguments referencing escaping `../Package_0` or invalid flag.
- **When:** `CliEngine_Alpha` validates arguments and paths.
- **Then:** Fails closed with exit code `2`, binds $``\bot_{\text{cli}}``$, registering `E0300`.
- **Diagnostic:** `E0300`.

### AC-04: Drift Detection and Saturation Recovery
- **Given:** Model generating `E0500` and 120 errors with $``C_{\text{max\_errors}} = 100``$.
- **When:** `CliEngine_Alpha` recovers across `;`, accumulating diagnostics in $``\mathcal{D}_{\text{sink}}``$.
- **Then:** Exits with code `1`, binds $``\bot_{\text{cli}}``$, halting at limit with `E0199`.
- **Diagnostic:** `E0500`, `E0199`.
