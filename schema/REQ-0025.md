## 1. Normative Statement

The CommonMark table parser within the Universal Schema Ingestion Engine shall parse tabular schemas specifying topological connections into `IngestedConnection` intermediate AST entities. For each data row, the parser must extract the connection identifier, source port endpoint path ($``P_{\text{src}}``$), target port endpoint path ($``P_{\text{tgt}}``$), protocol handle ($`\pi`$), optional latency upper bound ($``\tau_{\text{lat}}``$), and explicit delay model flag ($`\delta`$). Column headers shall be dynamically normalized into canonical connection attributes in an order-independent manner. All identifiers must conform to lexical sanitization grammar rules.

Endpoint paths must comprise at least two segments delimited by canonical scope delimiters (`::`), decomposing into an owning component hierarchy path and a terminal port identifier ($`P = \text{OwnerPath} \mathbin{\Vert} \text{"::"} \mathbin{\Vert} \text{PortIdentifier}`$). In the topological multigraph, each connection establishes directed edge $``E = (P_{\text{src}}, P_{\text{tgt}})``$. Direct self-loops ($``P_{\text{src}} = P_{\text{tgt}}``$) lacking an explicit delay model ($`\delta = \text{false}`$) are invalid and shall deterministically trigger diagnostic error code `E0104`.

## 2. Formal Invariant

Let connection schema $``\mathcal{T}_{\text{conn}} = (\mathbf{H}, \mathbf{R})``$ contain normalized headers $``\mathbf{H} = \langle H_0, \dots, H_{C-1} \rangle``$ ($`C \le 32`$) and rows $``\mathbf{R} = \langle R_1, \dots, R_M \rangle``$. Each lowered `IngestedConnection` entity $``C_i``$ is a 7-tuple:

```math
C_i = \langle \text{id}_i, P_{\text{src}, i}, P_{\text{tgt}, i}, \pi_i, \tau_{\text{lat}, i}, \delta_i, \text{span}_i \rangle
```

where $``\text{id}_i \in \mathcal{S}_{\text{sym}}``$ is the interned symbol handle, $``P_{\text{src}, i}, P_{\text{tgt}, i} \in \mathcal{P}_{\text{path}}``$ are endpoint paths, $``\pi_i \in \Pi_{\text{proto}} \cup \{ \bot \}``$ is the protocol handle, $``\tau_{\text{lat}, i} \in \mathbb{R}_{\ge 0} \cup \{ \bot \}``$ is the latency bound, $``\delta_i \in \mathbb{B}``$ is the delay flag, and $``\text{span}_i = \langle \text{file\_id}, p_{\text{start}}, p_{\text{end}}, \text{line}, \text{col} \rangle``$ is source provenance.

Endpoint path decomposition and segment bounds satisfy:

```math
\begin{aligned}
P &= \text{OwnerPath}(P) \mathbin{\Vert} \text{"::"} \mathbin{\Vert} \text{PortIdentifier}(P) \\
\text{Segments}(P) &= k \ge 2 \quad \wedge \quad \forall j \in \{1, \dots, k\}, \; s_j \in \text{Ident}
\end{aligned}
```

In topological multigraph $``G_{\text{topo}} = (\mathcal{V}_{\text{port}}, \mathcal{E}_{\text{conn}})``$, edge $``E_i = (P_{\text{src}, i}, P_{\text{tgt}, i}) \in \mathcal{E}_{\text{conn}}``$. Self-loops without delay models are strictly prohibited:

```math
(P_{\text{src}} = P_{\text{tgt}}) \implies (\delta = \text{true}) \quad \wedge \quad (P_{\text{src}} = P_{\text{tgt}} \;\wedge\; \delta = \text{false}) \implies \bot_{\text{conn}}
```

Latency bounds and scoped identifier uniqueness satisfy:

```math
\begin{aligned}
\tau_{\text{lat}} \ne \bot &\implies \tau_{\text{lat}} \ge 0 \\
\forall C_a, C_b \in \mathcal{C}, \quad (\text{Scope}(C_a) = \text{Scope}(C_b) \;\wedge\; C_a.\text{id} = C_b.\text{id}) &\implies C_a = C_b
\end{aligned}
```

Diagnostic code binding per REQ-0191 and sink saturation satisfy:

```math
\begin{aligned}
(\text{Segments}(P_{\text{src}}) \lt 2 \;\vee\; \text{Segments}(P_{\text{tgt}}) \lt 2 \;\vee\; (P_{\text{src}} = P_{\text{tgt}} \wedge \neg\delta) \;\vee\; \tau_{\text{lat}} \lt 0) &\implies \text{DiagnosticCode::E0104} \in \mathcal{D} \\
|\mathcal{D}| \ge C_{\text{max\_errors}} &\implies \text{DiagnosticCode::E0199} \in \mathcal{D}
\end{aligned}
```

## 3. Computational Complexity & Algorithmic Bounds

The connection table ingestion engine operates within Complexity Class $`\mathbf{P}`$. Monotonic single-pass scanning of $`N`$ input bytes executes in $`O(N)`$ operations. Decomposing bounded endpoint paths ($``L_P \le 256``$) executes in $``O(L_P) = O(1)``$ deterministic time. Scalar symbol interning, self-loop evaluation, latency bound verification, and AST memory entity allocation execute in $`O(1)`$ amortized time per row. Total execution time across $`R`$ connection rows and $`C \le 32`$ columns is strictly linear in $`O(R \cdot C) = O(R) = O(N)`$. Auxiliary space complexity is $`O(R)`$ for AST storage, $`O(1)`$ stack frames, and $``O(C_{\text{max\_errors}}) = O(1)``$ for diagnostic records. Tabular connection ingestion executes in polynomial time $`\mathbf{P}`$ and avoids all combinatorial NP-complete frontiers (NP-1--NP-8).

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Canonical Connection Ingestion and Endpoint Decomposition
- **Given:** Valid table declaring connection `Conn_0` between `Part_0::Port_1` and `Part_1::Port_2` with protocol `Protocol_A` and latency bound `5.0`.
- **When:** Lowering the connection row.
- **Then:** Emits `IngestedConnection` with decomposed `OwnerPath` and `PortIdentifier` in AST storage without diagnostics.
- **Diagnostic:** `E0104` on failure.

### AC-02: Endpoint Path Well-Formedness Enforcement
- **Given:** Connection row with malformed endpoint path having fewer than two segments (`Port_1`) or empty segments (`Part_0::::Port_1`).
- **When:** Performing endpoint path structural validation.
- **Then:** Rejects path, substitutes sentinel $``\bot_{\text{conn}}``$, and records localized diagnostic with byte span $``[p_{\text{start}}, p_{\text{end}})``$.
- **Diagnostic:** Emits `E0104` with source span coordinates.

### AC-03: Self-Loop Detection and Explicit Delay Enforcement
- **Given:** Connection row specifying identical endpoints (`Part_0::Port_1` to `Part_0::Port_1`).
- **When:** Evaluated with unbuffered delay flag ($`\delta = \text{false}`$) versus explicit delay flag ($`\delta = \text{true}`$).
- **Then:** Unbuffered self-loop is rejected with sentinel substitution; explicit delay self-loop lowers successfully into AST entity.
- **Diagnostic:** Emits `E0104` when $`\delta = \text{false}`$; zero diagnostics when $`\delta = \text{true}`$.

### AC-04: Latency Bounds and Scoped Identifier Uniqueness
- **Given:** Connection rows specifying negative latency ($``\tau_{\text{lat}} = -5.0``$) or duplicate identifier `Conn_0` in scope `Package_0::Classifier_Alpha`.
- **When:** Validating temporal bounds and scope uniqueness.
- **Then:** Rejects invalid rows with diagnostic emission and sentinel substitution $``\bot_{\text{conn}}``$.
- **Diagnostic:** Emits `E0104` on envelope or uniqueness violation.
