## 1. Normative Statement

The KerML lowering engine SHALL formalize occurrence decomposition operators, lowering `snapshot`, `time slice`, and `event occurrence` constructs into rigorous geometric intersections over 4-dimensional occurrence world-lines and world-volumes ($``\mathcal{W} \subseteq \mathbb{R}^3 \times \mathbb{R}``$). An occurrence $O$ instantiated from `OccurrenceDefinition` or `OccurrenceUsage` defines a spatio-temporal extent $\mathcal{W}(O)$ bounded by lifetime interval $``\mathcal{T}(O) = [t_{\text{start}}(O), t_{\text{end}}(O)]``$ with $``t_{\text{start}}(O) \le t_{\text{end}}(O)``$.

The lowering engine MUST enforce the following formal semantic rules:
1. **Snapshot Lowering**: A snapshot declaration `Snapshot(O, t_0)` SHALL project the state and active feature values of occurrence $O$ at temporal coordinate $``t_0 \in \mathbb{R}``$. A snapshot has zero Lebesgue measure in time ($``\Delta t = 0``$, $``\lambda_t = 0``$) and MUST satisfy temporal inclusion $``t_{\text{start}}(O) \le t_0 \le t_{\text{end}}(O)``$. Any instant outside parent bounds ($``t_0 \lt t_{\text{start}}(O)``$ or $``t_0 \gt t_{\text{end}}(O)``$) SHALL emit diagnostic `E0200`. Two snapshots at distinct instants ($``t_a \ne t_b``$) are strictly disjoint ($``\text{Snapshot}(O, t_a) \cap \text{Snapshot}(O, t_b) = \emptyset``$).
2. **TimeSlice Lowering**: A time slice declaration `TimeSlice(O, t_1, t_2)` SHALL project occurrence behavior over closed interval $``[t_1, t_2]``$. The engine MUST enforce non-negative duration ($``t_1 \le t_2``$, $``\Delta t = t_2 - t_1 \ge 0``$) and parent lifetime containment ($``[t_1, t_2] \subseteq [t_{\text{start}}(O), t_{\text{end}}(O)]``$). Inverted intervals ($``t_1 \gt t_2``$) or boundary breaches SHALL emit diagnostic `E0200`.
3. **EventOccurrence Lowering**: An event occurrence `EventOccurrence(O, t_e, \Phi)` SHALL formalize an instantaneous trigger satisfying predicate $\Phi$ at coordinate $``t_e``$. The engine MUST verify temporal inclusion ($``t_e \in \mathcal{T}(O)``$) and boolean typing ($``\tau(\Phi) = \text{Boolean}``$). Ill-typed triggers or temporal breaches SHALL emit diagnostic `E0200`.

## 2. Formal Invariant

Let $\mathcal{W}(O)$ denote the 4D world-volume manifold of occurrence $O$. Geometric lowering operators satisfy:

```math
\begin{aligned}
\text{Snapshot}(O, t_0) &= \mathcal{W}(O) \cap \{ (\mathbf{x}, t) \in \mathbb{R}^3 \times \mathbb{R} \mid t = t_0 \} \\
\text{TimeSlice}(O, t_1, t_2) &= \mathcal{W}(O) \cap \{ (\mathbf{x}, t) \in \mathbb{R}^3 \times \mathbb{R} \mid t_1 \le t \le t_2 \} \\
\text{EventOccurrence}(O, t_e, \Phi) &= \{ (\mathbf{x}, t) \in \mathcal{W}(O) \mid t = t_e \wedge \Phi(\mathbf{x}, t_e) = \text{true} \}
\end{aligned}
```

Temporal Lebesgue measure and pairwise disjointness invariants:

```math
\begin{aligned}
\lambda_t(\pi_t(\text{Snapshot}(O, t_0))) &= 0 \\
\lambda_t(\pi_t(\text{TimeSlice}(O, t_1, t_2))) &= t_2 - t_1 \ge 0 \\
\lambda_t(\pi_t(\text{EventOccurrence}(O, t_e, \Phi))) &= 0 \\
\forall t_a, t_b \in \mathcal{T}(O), \quad t_a \ne t_b &\implies \text{Snapshot}(O, t_a) \cap \text{Snapshot}(O, t_b) = \emptyset
\end{aligned}
```

Portioning transitivity and RFC 4122 UUIDv5 topological anchoring invariants:

```math
\begin{aligned}
P_{\text{sub}} \sqsubseteq_{\text{portion}} P_{\text{sup}} \sqsubseteq_{\text{portion}} O &\implies \mathcal{W}(P_{\text{sub}}) \subseteq \mathcal{W}(P_{\text{sup}}) \subseteq \mathcal{W}(O) \\
\forall n \in \mathcal{V}_{\text{portion}}, \quad \Delta_n &= \text{UUIDv5}(\text{NS}_{\text{DEAP}}, \text{FQN}(n))
\end{aligned}
```

| :--- | :--- |
| $\mathcal{W}(O)$ | Four-dimensional spatio-temporal world-volume manifold $\mathbb{R}^3 \times \mathbb{R}$ |
| $``\pi_t``$ | Temporal projection operator mapping world-volume to 1D temporal extent |
| $``\lambda_t``$ | One-dimensional Lebesgue measure over temporal dimension |

## 3. Computational Complexity & Algorithmic Bounds

The portion lowering, temporal validation, and predicate typing passes execute strictly within Complexity Class $\mathbf{P}$.

For an input model with $N$ portion nodes:
1. Node allocation in AST memory and symbol interning take amortized $O(1)$ time per node, totaling $O(N)$ time.
2. Temporal lifetime verification ($``t_{\text{start}} \le t_0 \le t_{\text{end}}``$) executes in strictly 2 scalar comparisons ($O(1)$ time).
3. Time slice interval validation ($``t_1 \le t_2``$ and parent containment) executes in strictly 3 scalar comparisons ($O(1)$ time).
4. Trigger predicate boolean type check evaluates root type tag in $O(1)$ time.

Total sequential verification complexity is $O(N)$. Because all temporal bounds are fixed scalar intervals without existential quantification or backtracking, this pass operates strictly within the tractable polynomial fragment of NP-1 (Temporal Constraint Satisfiability). Parallel execution across packages scales as $``O(N / N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Canonical Snapshot, TimeSlice & EventOccurrence Lowering
- **Given:** Occurrence `Occurrence_Alpha` with lifetime `[0.0, 100.0]`, containing `Snapshot_T0` at `t0 = 25.0`, `TimeSlice_Phase1` over `[10.0, 40.0]`, and `EventOccurrence_Ev1` at `te = 15.0` with boolean predicate `param_x > 0.0`.
- **When:** The compiler executes occurrence portion lowering and validation.
- **Then:** All three constructs lower into contiguous arena storage with valid 32-bit handles, verified temporal bounds, and zero diagnostic emissions.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: Temporal Lifetime Breach Rejection
- **Given:** Occurrence `Occurrence_Alpha` with lifetime `[0.0, 100.0]`.
- **When:** A snapshot `Snapshot_T1` is declared at `t0 = 120.0` ($``t_0 \gt t_{\text{end}}``$) or time slice `TimeSlice_Phase2` spans `[-10.0, 50.0]` ($``t_1 \lt t_{\text{start}}``$).
- **Then:** The compiler rejects the out-of-bounds declarations, binds error sentinels, and records diagnostic code `E0200`.
- **Diagnostic:** `E0200` emitted for temporal lifetime boundary breach.

### AC-03: Inverted TimeSlice Interval Rejection
- **Given:** Occurrence `Occurrence_Alpha` with lifetime `[0.0, 100.0]`.
- **When:** A time slice `TimeSlice_Inv` declares inverted bounds `[60.0, 20.0]` ($``t_1 \gt t_2``$).
- **Then:** The compiler rejects the inverted interval and emits diagnostic code `E0200`.
- **Diagnostic:** `E0200` emitted for inverted time slice interval.

### AC-04: Non-Boolean Event Trigger Predicate Rejection
- **Given:** Occurrence `Occurrence_Alpha` with lifetime `[0.0, 100.0]`.
- **When:** An event occurrence `EventOccurrence_Bad` declares trigger expression `param_x + 1.0` typed as `Real` instead of `Boolean`.
- **Then:** The compiler rejects the non-boolean trigger predicate and records diagnostic code `E0200`.
- **Diagnostic:** `E0200` emitted for invalid trigger expression type.
