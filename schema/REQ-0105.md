## 1. Normative Statement

The compiler SHALL partition flow networks into continuous linear subgraphs solved via sparse LU and hybrid switched junctions formulated as a Linear Complementarity Problem (LCP), solved via Lemke pivoting bounded by iteration cutoff $``\kappa_{\text{pivot}}``$.

Lowering MUST enforce:
1. **Network Partitioning**: Partition multigraph $``\mathcal{G}_{\text{flow}}=(\mathcal{V}_{\text{junc}},\mathcal{E}_{\text{flow}})``$ into continuous branches $``\mathcal{E}_{\text{lin}}``$ and switched branches $``\mathcal{E}_{\text{switch}}``$, fixing reference $``J_{\text{ref}}``$ ($``e_{\text{ref}}=0``$).
2. **Sparse LU Factorization**: Assemble conductance $``\mathbf{K}=\mathbf{A}_{\text{lin}}\mathbf{G}\mathbf{A}_{\text{lin}}^T``$ and reduced matrix $``\mathbf{K}_{\text{red}}``$, solving $``\mathbf{K}_{\text{red}}\mathbf{e}=\mathbf{f}_{\text{ext}}``$. Rank deficiency ($\text{rank}\lt n-1$) emits `E0301`.
3. **Canonical LCP Formulation**: Switched branches pair flow $``z_k\ge 0``$ with drop $``w_k\ge 0``$. Schur reduction yields $\operatorname{LCP}(\mathbf{M},\mathbf{q})$: $\mathbf{w}-\mathbf{M}\mathbf{z}=\mathbf{q}$, $\mathbf{w}\ge\mathbf{0}$, $\mathbf{z}\ge\mathbf{0}$, $\mathbf{w}^T\mathbf{z}=0$, with matrix $``\mathbf{M}=\mathbf{A}_{\text{switch}}^T\mathbf{K}_{\text{red}}^{-1}\mathbf{A}_{\text{switch}}``$ and offset $``\mathbf{q}=\mathbf{A}_{\text{switch}}^T\mathbf{K}_{\text{red}}^{-1}\mathbf{f}_{\text{ext}}+\mathbf{q}_0``$.
4. **Lemke Pivot Solver**: Solve $\operatorname{LCP}(\mathbf{M},\mathbf{q})$ with vector $``\mathbf{d}_{\text{aux}}=\mathbf{1}``$ and bound $``N_{\text{pivot}}\le\kappa_{\text{pivot}}``$ (default $4m^2$). Driving $``z_0=0``$ yields solution $(\mathbf{w}^*,\mathbf{z}^*)$. Cutoff or ray termination ($``z_0\gt 0``$) emits `E0399`.
5. **Dimensional Homogeneity**: Drops $``w_k``$ and flows $``z_k``$ MUST conform to $``\mathbf{d}_{\text{across}},\mathbf{d}_{\text{through}}\in\mathbb{Q}^7``$, summing to power $[M]^1[L]^2[T]^{-3}$; mismatches emit `E0300`.

## 2. Formal Invariant

Topological partitioning, continuous conductance, canonical LCP, and dimensional invariants:

```math
\begin{aligned}
\mathcal{E}_{\text{flow}}&=\mathcal{E}_{\text{lin}}\cup\mathcal{E}_{\text{switch}},\;\mathcal{E}_{\text{lin}}\cap\mathcal{E}_{\text{switch}}=\emptyset,\;\mathbf{K}_{\text{red}}\mathbf{e}=\mathbf{f}_{\text{ext}},\;\mathbf{P}\mathbf{K}_{\text{red}}\mathbf{Q}=\mathbf{L}\mathbf{U} \\
\mathbf{w}-\mathbf{M}\mathbf{z}&=\mathbf{q},\;\mathbf{w}\ge\mathbf{0},\;\mathbf{z}\ge\mathbf{0},\;\mathbf{w}^T\mathbf{z}=0,\;\mathbf{M}=\mathbf{A}_{\text{switch}}^T\mathbf{K}_{\text{red}}^{-1}\mathbf{A}_{\text{switch}} \\
\mathbf{w}-\mathbf{M}\mathbf{z}-\mathbf{d}_{\text{aux}}z_0&=\mathbf{q},\;N_{\text{pivot}}\le\kappa_{\text{pivot}},\;z_0=0\implies(\mathbf{w}^*,\mathbf{z}^*)\in\operatorname{SOL}(\mathbf{M},\mathbf{q}) \\
\text{rank}(\mathbf{K}_{\text{red}})\lt n-1&\implies\text{Diagnostic}(J,\text{E0301}),\;N_{\text{pivot}}\gt\kappa_{\text{pivot}}\implies\text{Diagnostic}(S,\text{E0399}) \\
```

## 3. Computational Complexity & Algorithmic Bounds

- **Complexity Class:** Class $\mathbf{NP}\text{-complete}$ (LCP) / Class $\mathbf{P}$ ($``O(V^3+\kappa_{\text{pivot}} m^2)``$).
- **Asymptotic Bound:** Sparse LU runs in $O(V^3)$ ($O(V^{1.5})$ planar sparse); Schur reduction runs in $``O(m V^2+m^2 V)``$; Lemke pivoting runs in $``O(\kappa_{\text{pivot}} m^2)``$.
- **Tractable Subclass & Frontier:** Anchored in NP-6. Cutoff $``\kappa_{\text{pivot}}\le 4m^2``$ eliminates exponential branching ($O(2^m)$), ensuring polynomial execution in $O(V^3+m^4)$. Work-stealing on $``N_{\text{max\_workers}}``$ threads scales as $``O((V^3+\kappa_{\text{pivot}} m^2)/N_{\text{max\_workers}}+\log N_{\text{max\_workers}})``$.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Continuous Linear Subgraph Sparse LU Factorization
- **Given:** Network `FlowNetwork_Alpha` in `Package_0` with 12 junctions, 18 branches, and grounded `Junction_1`.
- **When:** Sparse LU solves continuous branches.
- **Then:** System $``\mathbf{K}_{\text{red}}\mathbf{e}=\mathbf{f}_{\text{ext}}``$ solves with residual $``\|\mathbf{K}_{\text{red}}\mathbf{e}-\mathbf{f}_{\text{ext}}\|_2\lt 10^{-12}``$.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: Hybrid Switched Junction Complementarity & Lemke Pivot Convergence
- **Given:** Network `FlowNetwork_Alpha` with 4 switched branches, matrix $\mathbf{M}\succeq 0$, and cutoff $``\kappa_{\text{pivot}}=64``$.
- **When:** Lemke algorithm solves canonical $\operatorname{LCP}(\mathbf{M},\mathbf{q})$.
- **Then:** Solver terminates with $``z_0=0``$ in $``N_{\text{pivot}}\le\kappa_{\text{pivot}}``$, with $\mathbf{w}\ge\mathbf{0},\mathbf{z}\ge\mathbf{0}$ and $\mathbf{w}^T\mathbf{z}=0$.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-03: Singular Conductance Matrix Rejection
- **Given:** Network `FlowNetwork_Alpha` with ungrounded junctions yielding $``\text{rank}(\mathbf{K}_{\text{red}})\lt n-1``$.
- **When:** Conductance matrix factorization executes.
- **Then:** Lowering halts, assigns sentinel $``\bot_{\text{flow}}``$, and emits `E0301`.
- **Diagnostic:** `E0301`.

### AC-04: Pivot Iteration Limit Exceeded & Delimiter Recovery
- **Given:** Cyclic network `FlowNetwork_Alpha` with cutoff $``\kappa_{\text{pivot}}=2``$ requiring 6 pivots, preceding `;` and valid `Classifier_Beta`.
- **When:** Lemke solving exceeds cutoff ($``N_{\text{pivot}}\gt\kappa_{\text{pivot}}``$).
- **Then:** Compiler records `E0399`, assigns $``\bot_{\text{lcp}}``$, recovers on `;`, parses `Classifier_Beta`, emitting `E0199` at $``C_{\text{max\_errors}}``$.
- **Diagnostic:** `E0399`, `E0199`.
