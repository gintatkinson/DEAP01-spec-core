## 1. Normative Statement

The dynamics solver SHALL construct directed causal precedence graph $``G_{\text{prec}} = (V, E)``$ across action executions, behavioral steps, and state transitions, asserting acyclicity to guarantee deadlock-free execution.

---

## 2. Formal Invariant

Causal precedence DAG construction, Tarjan SCC decomposition, temporal consistency, and topological scheduling:

```math
\begin{aligned}
G_{\text{prec}}=(V,E),\quad E=E_{\text{seq}}\cup E_{\text{flow}}\cup E_{\text{state}}\cup E_{\text{trig}}\cup E_{\text{temp}}\subseteq V\times V \\
u\prec v\iff (u,v)\in E,\quad \text{Reach}(v,G_{\text{prec}})=\{w\in V\mid v\prec^+ w\} \\
\text{Acyclic}(G_{\text{prec}})\iff \forall v\in V,\; v\notin\text{Reach}(v,G_{\text{prec}})\iff\forall C\in\text{TarjanSCC}(G_{\text{prec}}),\; (|C|=1\land (v,v)\notin E) \\
\forall (u,v)\in E,\; t_{\text{start}}(u)\le t_{\text{start}}(v)\quad\land\quad\forall (u,v)\in E_{\text{seq}},\; t_{\text{end}}(u)\le t_{\text{start}}(v) \\
\mathcal{L}=\langle v_1,\dots,v_n\rangle\implies \forall (u,v)\in E,\; \text{Index}(u,\mathcal{L})\lt\text{Index}(v,\mathcal{L}) \\
v_t=\arg\min_{v\in Q_t}(\text{FQN}(v)),\quad Q_t=\{v\in V\setminus\{v_1,\dots,v_{t-1}\}\mid\text{deg}^{-}(v)=0\} \\
\exists C:(|C|\gt 1\lor (v,v)\in E)\implies\text{Diagnostic}(\mathcal{P}_{\text{cycle}},\text{E0400})\land E_{\text{overlay}}=E\setminus\{(v_k,v_1)\} \\
(t_{\text{start}}(v)\lt t_{\text{start}}(u)\lor ((u,v)\in E_{\text{seq}}\land t_{\text{start}}(v)\lt t_{\text{end}}(u)))\implies\text{Diagnostic}((u,v),\text{E0403}) \\
|\mathcal{D}_{\text{sink}}|\ge C_{\text{max\_errors}}\implies\text{Diagnostic}(\text{Compiler},\text{E0199}),\quad \Delta_v=\text{UUIDv5}(\text{NS}_{\text{DEAP}},\text{FQN}(v))
\end{aligned}
```

| Symbol / Term | Domain / Formal Definition |
| :--- | :--- |
| $``G_{\text{prec}}, (V, E)``$ | Causal precedence graph and classified edge sets |
| $``\text{Reach}(v, G_{\text{prec}}), \prec^+``$ | Transitive reachability set and precedence relation |
| $``\text{TarjanSCC}(G_{\text{prec}}), C``$ | Disjoint partition of maximal strongly connected components |
| $``[t_{\text{start}}, t_{\text{end}}]``$ | Assigned temporal interval bounds per occurrence entity |
| $``\mathcal{L}, Q_t``$ | Topological schedule and in-degree zero ready set |
| $``\mathcal{P}_{\text{cycle}}, E_{\text{overlay}}``$ | Circular traceback sequence and pruned overlay |
| $``\bot_{\text{prec}}, \bot_{\text{cycle}}, \Delta_v``$ | Error sentinels and RFC 4122 UUIDv5 identifier |

## 3. Computational Complexity & Algorithmic Bounds

- **Complexity Class:** $\mathbf{P}$ (Deterministic Polynomial)
- **Asymptotic Bound:** $O(V + E)$ for precedence assembly, Tarjan SCC cycle detection, and interval checks; $O(V \log V + E)$ for Kahn topological sorting via min-heap.
- **Tractable Subclass & Frontier:** Acyclicity verification belongs to polynomial fragment (P), preventing exponential cycle searches. Work-stealing scales as $``O((V \log V + E) / N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Valid Acyclic Pipeline Precedence and Linearization
- **Given:** Valid `Package_0` declaring sequential actions `Action_1`, `Action_2`, `Action_3` with intervals $[0.0, 10.0]$, $[10.0, 20.0]$, $[20.0, 30.0]$.
- **When:** Lowering constructs $``G_{\text{prec}}``$, verifies acyclicity via Tarjan SCC, and synthesizes topological order $\mathcal{L}$.
- **Then:** Verifies strict acyclicity, emitting schedule $``\langle \text{Action\_1}, \text{Action\_2}, \text{Action\_3} \rangle``$.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: Deterministic Lexicographical Ready Queue Tie-Breaking
- **Given:** Diamond DAG `PrecedenceGraph_Alpha` where `Action_1` precedes `Action_2` and `Action_3`, both preceding `Action_4`.
- **When:** Kahn topological linearization dequeues candidate ready vertices.
- **Then:** Dequeues `Action_2` before `Action_3` via FQN byte order, yielding reproducible schedules across permuted runs.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-03: Directed Causal Cycle Rejection and Traceback
- **Given:** Malformed model declaring mutual cycle `Action_1` $\prec$ `Action_2` and `Action_2` $\prec$ `Action_1`.
- **When:** Tarjan SCC decomposition audits $``G_{\text{prec}}``$.
- **Then:** Isolates component $|C| = 2$, reconstructs traceback $``\langle \text{Action\_1}, \text{Action\_2}, \text{Action\_1} \rangle``$, and emits `E0400`.
- **Diagnostic:** `E0400` (CausalPrecedenceCycleDetected).

### AC-04: Temporal Ordering Inversion and Delimiter Recovery
- **Given:** Invalid dependency `Action_1` $``\prec_{\text{seq}}``$ `Action_2` with intervals $[10.0, 20.0]$ and $[5.0, 15.0]$ before delimiter (`;`), followed by valid `PrecedenceGraph_Beta`.
- **When:** Lowering checks interval ordering and triggers delimiter recovery.
- **Then:** Emits `E0403`, binds $``\bot_{\text{prec}}``$, recovers on `;`, parses `PrecedenceGraph_Beta`, halting at $``C_{\text{max\_errors}}``$ with `E0199`.
- **Diagnostic:** `E0403`, `E0199`.
