# Component Failure Mode Registry (Step 1.5 Pre-STPA/FMECA Research)

- **Authority SSOT**: `.pipeline/upstream/schema/model.sysml` and `.pipeline/upstream/schema/modular_codegen.sysml`
- **Methodology**: Deterministic AST `part def` decomposition across the 4 Universal Failure Dimensions prior to STPA/FMECA synthesis:
  1. `(1) Input/Boundary & Malformed Syntax`
  2. `(2) State/Concurrency & Ordering`
  3. `(3) Resource/Depth/Arithmetic Exhaustion`
  4. `(4) Output/Serialization & Partial-Write Integrity`
- **Verification Scope**: Pure MBSE compiler toolchain (`deap-core`, `compile-sysml`, `ingest-sysml`, `verify-baseline`, `assemble-conops`, `reconcile-backlog`).
