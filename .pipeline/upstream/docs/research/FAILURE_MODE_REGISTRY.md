# Failure Mode Registry (Step 1.5 Universal Failure Dimensions)

## Architectural Governance & Safety Contracts

- **Contract A (100% Normative OMG SysML v2.0 + KerML 1.0 Grammar Coverage)**: Every component failure mode and STPA/FMECA safety constraint in this registry governs the complete OMG SysML v2.0 and KerML 1.0 textual grammar with full Definition (`* def`) and Usage symmetry and zero 16-construct artificial caps (`package`, `library package`, `standard library package`, `import`, `alias`, `doc`, `comment`, `rep`, `dependency`, `metadata def`/`metadata`/`@Metadata`/`#user_keyword` for `#hazard`, `#risk`, `#capability`, `#rt_loop`, `#dal`, `#fls` with backward-compatible legacy `hazard def`/`risk def`/`capability def`, `attribute def`/`attribute`, `enum def`/`enum`, `item def`/`item`, `part def`/`part`, `port def`/`port`, `connection def`/`connection`, `interface def`/`interface`, `flow def`/`flow`, `allocation def`/`allocation`, `occurrence def`/`occurrence`, `action def`/`action`, `state def`/`state`, `calc def`/`calc`, `constraint def`/`constraint`, `requirement def`/`requirement`, `concern def`/`concern`, `use case def`/`use case`, `analysis def`/`analysis`, `verification def`/`verification`, `test case def`/`test case`, `interaction def`/`interaction`, `view def`/`view`, `viewpoint def`/`viewpoint`, `rendering def`/`rendering`, `variation`/`variant`, and KerML 1.0 `:`, `:>`, `:>>`, `::>`, `~`, `ref`, `abstract`, `readonly`, `derived`, `end`, `default`, `:=`, `[lo..hi]`, `[*]`, `{ordered, nonunique}`, `implies`, `xor`, `??`, `->`, `collect`, `select`, `forAll`, `exists`, `ISQ`/`SI`/`ScalarValues`).
- **Contract B (Official `rust-lang/*` Compiler & Tooling Crates -- Zero Legacy Hand-Rolled Scanners)**: Every component failure dimension is mitigated exclusively via official compiler and lossless CST crates (`ra_ap_syntax`, `ra_ap_vfs`, `ra_ap_paths`, `ra_ap_line_index`, `ra_ap_text_edit`, `rowan`, `logos`, `salsa`, `ariadne`, `miette`, `syn`, `proc-macro2`, `quote`, `prettyplease`, `pulldown-cmark`, `pulldown-cmark-to-cmark`, `cargo_metadata`, `cargo-lock`, `cargo-util-schemas`, `cargo-platform`, `toml_edit`, `cargo-dylint`, `cargo miri`, `cargo kani`, `criticalup`) with zero legacy hand-rolled character, line, or string-slice scanners (`source_ast.rs` and ad-hoc text scanners retired).
