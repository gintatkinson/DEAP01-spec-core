# Implementation Plan: Defect #333 Resolution (Level 1C ICD Suite & Unified 8-Pillar STPA Matrix)

## 1. Executive Summary & Objective

This implementation plan governs the resolution of Defect #333 (`[AUDIT] [docs/interfaces & docs/safety]: Incomplete Level 1C ICD Suite (Missing gnssFix Binding) and Missing 8-Pillar STPA Matrix`) in `DEAP01-spec-core`.

Root causes:
1. `check_icd_completeness` (Check 24) in `crates/verify-baseline` was a hollow stub returning `Ok(ParityOutcome::Verified)` without checking port connections, dangling ports, signal metrology completeness, or hierarchical subsystem qualification (`gnssFix` nested connection binding).
2. `compile-sysml` generated `STPA_MATRIX.md` as an incomplete, hollow cross-traceability table lacking the 8 mandatory pillars required by `.pipeline/constitution.md:193-211`.
3. `check_safety_integrity` (Check 17) in `crates/verify-baseline` concatenated all markdown files in `docs/safety/` without asserting that `docs/safety/STPA_MATRIX.md` itself exists and embodies the 8 pillars.
4. `skills/spec-icd-engineering/SKILL.md` lacked explicit requirements for hierarchical subsystem qualification on nested connections and contained deprecated python script references.
